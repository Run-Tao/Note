## 第 1 页｜间断点四步卡

### 四步流程（每题 ≤ 3 分钟）

| 步 | 动作 | 关键句 |
| --- | --- | --- |
| 1 列点 | 分母 $0$、$\ln$ 真数 $\le0$、偶次根号端点、$\tan$ 极点、分段点、$\lim\limits_{n\to\infty}$ 定义出的分界点、单侧定义域端点 | **一个都别漏，先列全再算** |
| 2 分左右 | 遇 $\lvert x-a\rvert$、$(x-a)$ 奇次幂、$e^{\pm1/(x-a)}$、$\arctan\frac1{x-a}$、分段点 → 令 $x=a\mp t$，$t\to0^+$ | $t>0$，符号问题一次解决 |
| 3 算 | 单侧内等价替换 → 有理化 → 泰勒 → 洛必达全合法；夹逼要**同侧**上下界 | 单侧不是"只能算一侧" |
| 4 判 + 查 | 查判型表；左右都算，不相等 → 极限不存在；代数值验符号 | **没有"左 $\le$ 右"定理**，别拿大小关系当算错（反例 $f=1\,(x<0)$、$0\,(x>0)$） |

### 判型表

| 左极限 | 右极限 | 类型 | 类别 |
| --- | --- | --- | --- |
| 存在且相等 | | **可去**（$f(x_0)$ 无定义或取值不等时） | 第一类 |
| 存在但不等 | | **跳跃** | 第一类 |
| 至少一侧为 $\pm\infty$ | | **无穷** | 第二类 |
| 都不存在（非 $\infty$） | | **振荡** | 第二类 |

### 八类必须分左右的结构（$x\to a$）

1. $\dfrac{\lvert x-a\rvert}{x-a}$、$\operatorname{sgn}(x-a)$：左 $-1$、右 $+1$。
2. $(x-a)$ 的**奇次幂**（含 $\dfrac1{(x-a)^{2k+1}}$）：左负右正；偶次幂左右同号。
3. $e^{1/(x-a)}$：左 $0$、右 $+\infty$；$e^{-1/(x-a)}$ 反过来。
4. $\arctan\dfrac1{x-a}$：左 $-\frac\pi2$、右 $+\frac\pi2$（2018-19 原题结构）。
5. $\ln\lvert x-a\rvert$：两侧都是 $-\infty$（同值也写清）。
6. $\tan$ 在极点：两侧 $\pm\infty$ 反号。
7. 分段点、$\lim\limits_{n\to\infty}$ 定义出的分界点：先写分段表达式，再算分界点左右。
8. 单侧定义域：$\ln x$、$\sqrt x$ 只有右侧有定义，左侧**无定义**（不是极限值）。

### 替换表（$x=a\mp t$，$t>0$）

| 结构 | $x\to a^-$（$x=a-t$） | $x\to a^+$（$x=a+t$） |
| --- | --- | --- |
| $x-a$ | $-t$ | $+t$ |
| $(x-a)^{2k}$ / $(x-a)^{2k+1}$ | $t^{2k}$ / $-t^{2k+1}$ | $t^{2k}$ / $+t^{2k+1}$ |
| $e^{1/(x-a)}$ | $e^{-1/t}\to0$ | $e^{+1/t}\to+\infty$ |
| $e^{-1/(x-a)}$ | $e^{+1/t}\to+\infty$ | $e^{-1/t}\to0$ |
| $\arctan\dfrac1{x-a}$ | $-\frac\pi2$ | $+\frac\pi2$ |

### 五个扣分钩子

- **2018-19 填空**：官方只数了 $x=-1$ 的可去，漏掉 $x=0$ 的跳跃 → 第一类实为 **2 个**。
- **分母为 $0$ $\ne$ 无穷**：先看分子是否同时为 $0$；约分后极限存在就是可去。
- $\sin\frac1{x-1}$ 是振荡，但乘上 $\ln x\to0$ 后变**可去** —— 别见 $\sin\frac1x$ 就判振荡。
- $f(x_0)$ 有定义 $\ne$ 连续；"左右都存在" $\ne$ "极限存在"。
- $\tan\pi x$ 在 $x=1$ 处先写 $\tan\pi(x-1)\sim\pi(x-1)$，不能直接用 $\tan\pi x\sim\pi x$。

## 第 2 页｜求导检查表

### 动笔前 30 秒三问

1. **定义域**：$\ln$ 真数 $>0$；偶次根号 $\ge0$；$\arcsin/\arccos\in[-1,1]$；分母 $\ne0$；$\tan$ 的角 $\ne\frac\pi2+k\pi$。
2. **前提**：参数方程 $x'_t\ne0$；隐函数 $F_y\ne0$；反函数 $f'(x_0)\ne0$；除以含参因式前写明其非零。
3. **用哪条**：参数 → 链式除 $x'_t$；隐函数 → 两边对 $x$ 求导；分段 → 连续 + 左右导数；幂指 → 先取对数。

### 六类题的第一句与公式

| 题型 | 第一句先写 | 公式 / 步骤 | 常见错 |
| --- | --- | --- | --- |
| 参数方程 | $x'_t\ne0$（在 $t_0$ 处） | $\dfrac{dy}{dx}=\dfrac{y'_t}{x'_t}$；$\dfrac{d^2y}{dx^2}=\dfrac{y''_t x'_t-y'_t x''_t}{(x'_t)^3}$ | 二阶导要**再除一次** $x'_t$，不是乘 |
| 隐函数 | 写 $F(x,y)=0$，$F_y\ne0$ | $y'=-\dfrac{F_x}{F_y}$；$y''=-\dfrac{F_{xx}F_y^2-2F_{xy}F_xF_y+F_{yy}F_x^2}{F_y^3}$ | 对 $y'$ 求导时漏掉 $y'$（链式） |
| 分段函数 | 先验分界点**连续**（左右极限 $=$ 函数值） | 连续给 1 个方程 → 左右导数相等再给 1 个方程 | 只写可导、不验连续 |
| 反函数 | $f'(x_0)\ne0$ | $(f^{-1})'(y_0)=\dfrac1{f'(x_0)}$；$(f^{-1})''(y_0)=-\dfrac{f''(x_0)}{(f'(x_0))^3}$ | 忘写 $f'\ne0$ |
| 幂指 $u^v$ | $u>0$，两边取对数 | $\dfrac{y'}y=v'\ln u+v\dfrac{u'}u$ | 不先写 $u>0$ |
| Leibniz | 写出 $n$ 阶公式 | $(uv)^{(n)}=\sum\limits_{k=0}^{n}\binom nk u^{(k)}v^{(n-k)}$ | 在 $x_0$ 处不筛"只留非零项" |

### 四条防错句（作业 12–14 的 7 处漏写就出在这）

- **可导 $\Rightarrow$ 连续，但连续 $\nRightarrow$ 可导**；可导也**不保证** $f'$ 连续或有界（反例 $x^2\sin\frac1{x^2}$）。
- **高阶导先化简再求**：有理函数先部分分式、三角先降幂，别硬求。
- **分段点**：连续与可导是两个方程；求参数题先连续、后可导。
- **收尾自检**：把答案代一个具体数（如 $x=\frac13$、$t=\frac\pi4$）看符号与量级。
