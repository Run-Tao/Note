# 数列极限与新压轴 · 题型专题

> **定位**：数列极限的四条主力套路 + 2024-25 起出现的**抽象函数方程 / 迭代连续性**新压轴。
> 这是 17 套真题里「几乎年年在选择填空出现」却**一直没独立成册**的一块；题面与完整解析在 `Resources/Downloads/讲义_数列极限与压轴新题型.pdf`。
> 概念底座：[[Level1_Limits_and_Continuity]]（数列极限定义、单调有界准则）、[[Level4_Integrals]]（定积分定义求极限）、[[Level6_Series_and_ODEs]]（级数审敛，期末用）。

## 0. 默写卡（闭卷，≤7 行）

1. **夹逼**：找 $b_n\le a_n\le c_n$ 且 $b_n,c_n\to A$；常用放缩是"分母换成最大/最小"。
2. **单调有界**：证 $a_n$ 单调（$a_{n+1}-a_n$ 或 $\frac{a_{n+1}}{a_n}$）+ 有界 $\Rightarrow$ 收敛；再对递推式两边取极限解 $L$。
3. **定积分定义**：$\lim\frac1n\sum_{k=1}^n f\!\left(\frac kn\right)=\int_0^1 f(x)\D x$；认准 $\frac1n$ 与 $\frac kn$。
4. **Stolz**：$\lim\frac{a_n}{b_n}=\lim\frac{a_{n+1}-a_n}{b_{n+1}-b_n}$（$b_n$ 严格增且 $\to+\infty$）；专治"和式 / $n^p$"。
5. **压缩映射**：$|a_{n+1}-L|\le q|a_n-L|,\ 0<q<1\Rightarrow a_n\to L$；Newton 迭代 $a_{n+1}=\frac12(a_n+\frac ca_n)\to\sqrt c$。
6. **不动点 / 介值**：$f$ 连续且 $f([a,b])\subset[a,b]\Rightarrow\exists\xi:f(\xi)=\xi$（令 $g=f(x)-x$ 看两端符号）。
7. **等距平移**：$f$ 连续、$f(0)=f(1)\Rightarrow\exists\xi:f(\xi)=f(\xi+\frac1n)$（把 $n$ 段函数值相加，若都同号则矛盾）。

## 1. 四法逐条（例题答案经 sympy + 数值采样复核）

### S1 夹逼

$$\lim_{n\to\infty}\sum_{k=1}^n\frac1{\sqrt{n^2+k}}=1,\qquad \frac{n}{\sqrt{n^2+n}}\le S_n\le\frac{n}{\sqrt{n^2+1}}.$$

> [!warning] 别把 $n$ 项和当成"每项乘 $n$"
> 每项的极限都是 0，但项数在增长；必须先整体放缩或改写成 Riemann 和。

### S2 单调有界

$a_1=\sqrt2,\ a_{n+1}=\sqrt{2+a_n}\Rightarrow\lim a_n=2$：
归纳证 $0<a_n<2$（有界），$a_{n+1}-a_n=\frac{2+a_n-a_n^2}{\sqrt{2+a_n}+a_n}=\frac{(2-a_n)(a_n+1)}{\cdots}>0$（递增）⇒ 收敛；设 $\lim a_n=L$，对递推取极限得 $L=\sqrt{2+L}\Rightarrow L=2$（舍 $L=-1$）。

**Newton 压缩**：$a_{n+1}=\frac12\left(a_n+\frac3{a_n}\right)\to\sqrt3$（$a_1>0$）。取极限解 $L=\frac12(L+\frac3L)\Rightarrow L^2=3$。

### S3 定积分定义

$$\lim_{n\to\infty}\frac1n\sum_{k=1}^n\sin\frac{k\pi}{2n}=\int_0^1\sin\frac{\pi x}2\D x=\frac2\pi.$$

数值采样交叉验证：$n=200$ 得 $0.6391$、$n=2000$ 得 $0.63687$、$n=20000$ 得 $0.63664$，收敛到 $\frac2\pi\approx0.63662$。

> [!tip] 识别口令
> 看到 $\frac1n\sum f(\frac kn)$ 直接写积分；看到 $\sum\frac{n}{n^2+k^2}$ 先提 $\frac1n$ 变成 $\frac1n\sum\frac1{1+(k/n)^2}\to\int_0^1\frac{\D x}{1+x^2}=\frac\pi4$。

### S4 Stolz

$$\lim_{n\to\infty}\frac{1+2+\cdots+n}{n^2}=\lim_{n\to\infty}\frac{n+1}{(n+1)^2-n^2}=\lim\frac{n+1}{2n+1}=\frac12.$$

> [!warning] 用之前查条件
> $b_n$ 必须严格单调增且 $\to+\infty$；若差分比的极限不存在，Stolz 不给结论（但原极限仍可能存在）。

## 2. 选择填空的四条快判

1. $\lim\frac{a_{n+1}}{a_n}=A>0$ **只保证自某项起同号**，不保证有界、不保证单调、也不保证极限存在（$a_n=A^n$ 与 $a_n=A^n n$ 都是反例）。
2. $\sum\frac1{n^p}$：$p>1$ 收敛；$\sum\frac{(-1)^n}{n^p}$：$p>0$ 即收敛（Leibniz）。**条件收敛可重排改变和**。
3. 比值判别 $\rho=1$ 时**失效**，换 Raabe / 比较 / 积分判别（见 [[Level6_Series_and_ODEs]]）。
4. 已知 $a_n\to0$ 不能推出 $\sum a_n$ 收敛；反过来 $\sum a_n$ 收敛必有 $a_n\to0$。

## 3. 新压轴：抽象函数方程 + 连续性 / 介值

2024-25 卷压轴（七(18) 型）不再考中值定理，改考"**不给具体表达式，只给连续性与函数方程**"。三类母题：

### P1 等距平移（$n=2$）

设 $f\in C[0,1]$，$f(0)=f(1)$。证明 $\exists\,\xi\in[0,\tfrac12]$ 使 $f(\xi)=f(\xi+\tfrac12)$。

令 $g(x)=f(x+\tfrac12)-f(x)$（$x\in[0,\tfrac12]$），则 $g(0)+g(\tfrac12)=f(1)-f(0)=0$。若 $g(0)=0$ 取 $\xi=0$；否则 $g(0)$ 与 $g(\tfrac12)$ 异号，由介值定理存在 $\xi\in(0,\tfrac12)$ 使 $g(\xi)=0$。

**推广到任意 $n\ge2$**：设 $g_k=f(\frac{k+1}n)-f(\frac kn)$，则 $\sum_{k=0}^{n-1}g_k=f(1)-f(0)=0$；若所有 $g_k\ne0$ 则必有正负两项，由 $f$ 连续（离散版介值取相邻段）可得某 $k$ 使 $f(\frac kn)=f(\frac{k+1}n)$，或更标准的证法：令 $h(x)=f(x+\frac1n)-f(x)$，若 $h$ 无零点则由连续性恒正或恒负，$\sum h(\frac{k}{n})=f(1)-f(0)\ne0$，矛盾。

### P2 不动点

$f\in C[0,1]$ 且 $f([0,1])\subset[0,1]\Rightarrow\exists\,\xi:f(\xi)=\xi$。令 $g(x)=f(x)-x$，$g(0)=f(0)\ge0$，$g(1)=f(1)-1\le0$，介值定理。

### P3 迭代与极限（压缩 / 单调）

若 $f$ 连续、$a_{n+1}=f(a_n)$ 且 $|f(x)-f(y)|\le q|x-y|\ (q<1)$，则 $a_n$ 收敛到唯一不动点（Banach 压缩映射）。证明用 $|a_{n+1}-a_n|\le q^n|a_1-a_0|$ 证 Cauchy，再用连续性取极限。

> [!warning] 新压轴的两个得分点
> ① **先写连续性**（介值定理的前提）；② **构造辅助函数后验两端符号或求和为零**。只写"由介值定理得"不给构造，几乎拿不到分。

## 4. 错因 → 回炉路径

| 卡在哪 | 回做 |
| --- | --- |
| $n$ 项和逐项取极限 | S1 夹逼；S3 先写成 Riemann 和 |
| 单调有界不会证单调 | S2 的 $a_{n+1}-a_n$ 因式分解 |
| 认不出 Riemann 和 | S3 与 $\sum\frac{n}{n^2+k^2}\to\frac\pi4$ |
| Stolz 条件没查 | S4 先写"$b_n$ 严格增且 $\to\infty$" |
| 新压轴不会构造 | P1 的 $g(x)=f(x+\frac1n)-f(x)$、P2 的 $g=f-x$ |
| 级数审敛混用 | [[Level6_Series_and_ODEs]] 审敛表 |
