# 左右极限求法与间断点判型

> **定位**：间断点题真正卡人的不是"分类"，而是"左右极限算不算得出来、算完怎么判型"。本篇只解决这一件事。
> **分工**：定义与概念表述见 [[Level1_Limits_and_Continuity]] §5.3 / §6；成套讲义与真题精讲见 `Resources/Downloads/讲义_函数极限与间断点.pdf` §4–§6；本篇给**可操作的方法表 + 已复核的左右极限数值**，不重复概念。
> **数据来源**：本篇所有左右极限数值由 `Homework/_review/tools/verify_limits_continuity.py`（72 项 PASS）与 sympy `limit(dir='-')` / `limit(dir='+')` 逐条算出，未手写估计。

## 1. 判定链：左右极限 → 间断点类型

$$
\text{可疑点 } x_0 \;\longrightarrow\; \lim_{x\to x_0^-} f(x),\ \lim_{x\to x_0^+} f(x) \;\longrightarrow\; \text{判型}
$$

| 左极限 | 右极限 | 结论 | 名称 |
| --- | --- | --- | --- |
| 都存在且相等（有限） | | 极限存在 | **可去**（若 $f(x_0)$ 无定义或取值不等） |
| 都存在但不等 | | 极限不存在 | **跳跃**（第一类） |
| 一侧为 $\pm\infty$ | | 极限不存在 | **无穷**（第二类） |
| 都不存在 | | 极限不存在 | **振荡**（第二类） |

> [!warning] 官方答案就是在这里翻的车
> 2018-19 填空 $\arctan\!\left(x+\frac1x\right)+\dfrac{x^2+x}{x^2+3x+2}$ 的第一类间断点个数，官方给 **1 个**（只数了 $x=-1$ 的可去），实际是 **2 个** —— $x=0$ 处 $\arctan\!\left(x+\frac1x\right)$ 左 $-\frac\pi2$、右 $+\frac\pi2$，是**跳跃**，属第一类。只算一侧就漏。
> 正确做法：**每个可疑点都把左右两侧写出来，再查表**。

## 2. 五条必须背下来的定理

1. **存在性定理**：$\lim\limits_{x\to x_0}f(x)=A$ 存在 $\iff$ 左右极限都存在且都等于 $A$。
2. **左右不等 $\Rightarrow$ 极限不存在**：若 $\lim\limits_{x\to x_0}f(x)$ 存在，左右极限必都存在且等于该值；反之左右都存在但不等，就是**跳跃**（第一类），直接判型。
   → **别拿大小关系自查**：一般函数**没有**"左 $\le$ 右"的定理（反例：$f(x)=1\ (x<0)$、$f(x)=0\ (x>0)$，左 $1>$ 右 $0$，仍是正常跳跃）。自查只查"两侧是否都算出了具体数、是否与定义域一致"。
3. **无穷型**：左侧 $+\infty$ 而右侧 $-\infty$（或反之）→ 双侧极限**不存在**，但要写"$|f|\to\infty$"而不是 $f\to+\infty$。
4. **振荡型**：函数在 $x_0$ 附近不停穿越某条水平线 → 左右极限都不存在。判据是**极限值集合**不是单值（sympy 返回 `AccumBounds`，如 $\sin\frac1x$ 在 0 处为 $[-1,1]$）。
5. **单调有界准则**（数列）：单调且有界 $\Rightarrow$ 极限存在。用来**证明存在**很好用，但**求不出值**——真题要值的时候还得另想办法。

> [!tip] 自查顺序比"比大小"可靠
> 2018-19 那道题：$x=0$ 处 $\arctan\frac1x$ 左 $-\frac\pi2$、右 $+\frac\pi2$，**两侧都算出来**即可判跳跃；只算一侧就会像官方答案一样漏成"1 个"。

## 3. 四步流程

| 步骤 | 看到什么 | 第一动作 | 判据 / 注意 |
| --- | --- | --- | --- |
| 1 列点 | 分母为 0、对数真数 $\le 0$、偶次根号负数、$\tan$ 的极点、分段点、$\lim_n$ 定义的函数 | 把这些点全列出来 | 一个都别漏，尤其是**分段点**和**绝对值零点** |
| 2 分左右 | 分子分母含 $x-x_0$ 的**奇次幂**、$\lvert x-x_0\rvert$、$e^{\pm1/(x-x_0)}$、$\arctan\frac1{x-x_0}$、$\ln\lvert x-x_0\rvert$ | 令 $x=x_0\mp t$，$t\to0^+$ | $t>0$ 把符号问题一次解决 |
| 3 算 | 代入后是 $0/0$ | 等价替换 → 有理化 → 泰勒 → 洛必达（单侧可用） | **等价替换在一侧区间内是合法的**，放心用 |
| 4 自检 | 得到一个具体数 | 代 $x=x_0\mp10^{-3}$ 看符号与量级；再代 $x=x_0\pm10^{3}$ 看增长 | 10 秒钟，能抓出大部分符号错误 |

## 4. 八类必须分左右的结构

下表每一行的左右值都由 sympy `limit(dir='-')` / `limit(dir='+')` 复核过（可重跑 `verify_limits_continuity.py`）。

| 结构（在 $x\to0$ 处） | 左极限 | 右极限 | 判型 | 关键动作 |
| --- | --- | --- | --- | --- |
| $\dfrac{\lvert x\rvert}{x}$ | $-1$ | $1$ | 跳跃 | 分子恒正，分母变号 |
| $e^{1/x}$ | $0$ | $+\infty$ | 无穷 | $1/x\to-\infty$ → $e^{-\infty}=0$ |
| $e^{-1/x}$ | $+\infty$ | $0$ | 无穷 | 与上条互为倒数，符号相反 |
| $\arctan\dfrac1x$ | $-\frac\pi2$ | $+\frac\pi2$ | 跳跃 | 反正切趋于 $\pm\infty$ 得 $\pm\frac\pi2$ |
| $\arctan\!\left(x+\frac1x\right)$ | $-\frac\pi2$ | $+\frac\pi2$ | 跳跃 | 2018-19 原题结构 |
| $\dfrac1x$ | $-\infty$ | $+\infty$ | 无穷 | 奇次幂：左右反号 |
| $\dfrac1{x^{2}}$ | $+\infty$ | $+\infty$ | 无穷 | 偶次幂：左右同号，**都算不清就别猜** |
| $\ln\lvert x\rvert$ | $-\infty$ | $-\infty$ | 无穷 | 两侧同值，不需要分左右但要写清 |
| $\tan\pi x$（在 $x=\frac12$） | $+\infty$ | $-\infty$ | 无穷 | 正切在 $\frac\pi2+k\pi$ 处左右反号 |
| $\sin\frac1x$ | 不存在（$[-1,1]$） | 不存在（$[-1,1]$） | 振荡 | 无界振荡，sympy 给 `AccumBounds` |
| $x\sin\frac1x$ | $0$ | $0$ | 可去 | **有界 $\times$ 无穷小 $=$ 无穷小** |

> [!note] 定义域只在一侧的情况（很常考）
> $\ln x$、$\sqrt{x}$ 只有 $x>0$ 一侧有定义：右侧分别给出 $-\infty$ 与 $0$，左侧**根本不存在**（不是极限值，是无定义）。
> $\sqrt{-x}$、$\ln(-x)$ 反过来，只有左侧。
> ⚠️ sympy 在这些"实数域外"的一侧会按**复数主分支**给出结果（例如 $\sqrt{-x}$ 右侧给 $0$），**不能照抄** —— 判型必须自己先看定义域。

## 5. 代入替换法：$x = a \mp t$（$t\to0^+$）

所有"分左右"的问题都可以统一成一张表：

| 原式里的结构 | $x\to a^-$（令 $x=a-t$） | $x\to a^+$（令 $x=a+t$） |
| --- | --- | --- |
| $x-a$ | $-t$ | $+t$ |
| $(x-a)^{2k}$ | $t^{2k}$ | $t^{2k}$ |
| $(x-a)^{2k+1}$ | $-t^{2k+1}$ | $+t^{2k+1}$ |
| $\dfrac1{x-a}$ | $-\dfrac1t\to-\infty$ | $+\dfrac1t\to+\infty$ |
| $e^{1/(x-a)}$ | $e^{-1/t}\to0$ | $e^{+1/t}\to+\infty$ |
| $e^{-1/(x-a)}$ | $e^{+1/t}\to+\infty$ | $e^{-1/t}\to0$ |
| $\arctan\dfrac1{x-a}$ | $\arctan\!\left(-\frac1t\right)\to-\frac\pi2$ | $\arctan\!\left(\frac1t\right)\to+\frac\pi2$ |
| $\ln\lvert x-a\rvert$ | $\ln t\to-\infty$ | $\ln t\to-\infty$ |

**做法**：令 $t>0$，把 $x-a$ 换成 $\mp t$，然后**只算一个极限**，另一个由奇偶性/符号对照表直接读出。这样每道题只需算一次。

## 6. 单侧下这些工具都还合法

- **等价替换**（$\sin u\sim u$、$\ln(1+u)\sim u$、$1-\cos u\sim\frac{u^2}2$）：在一侧区间内替换是合法的 —— 前提是"在该侧 $u\to0$"。
- **洛必达**：单侧极限可以用，但**若该侧是 $0/0$ 或 $\infty/\infty$**，右侧的"求导后极限存在"要成立。
- **泰勒展开**：单侧同样可用（$x\to a^-$ 就是 $t\to0^+$ 的展开）。
- **有理化 / 提 $e$**：无条件可用。
- **夹逼准则**：要能构造出**同侧**的上下界。

> [!warning] 洛必达的三种失效（与左右无关，但常在单侧里遇到）
> ① 越算越繁；② 循环；③ **求导后极限不存在但原极限存在** —— 例如 $x\to+\infty$ 时 $\dfrac{x-\sin x}{x+\sin x}\to1$，但洛必达给出的是 $\dfrac{1-\cos x}{1+\cos x}$（振荡、无极限），于是误判"不存在"。
> ⚠️ 这个反例的 $x\to+\infty$ 不能写成 $x\to0$：$\lim\limits_{x\to0}\dfrac{x-\sin x}{x+\sin x}=0$（sympy 复核），两边答案完全不同。

## 7. 十条高频错误

1. 只算一侧就下结论（2018-19 的原样错误）。
2. 把 $\lvert x-a\rvert$ 当成 $x-a$（丢了整体符号）。
3. $e^{1/(x-a)}$ 的左右记反：左 0 右 $+\infty$。
4. $1/(x-a)^{k}$ 不看奇偶：奇次左右反号、偶次左右同号。
5. 看到分母为 0 就判无穷，**不检查分子是否同时为 0**。
6. $\tan\pi x$ 在 $x=1$ 处直接用 $\tan\pi x\sim\pi x$（必须先写成 $\tan\pi(x-1)$）。
7. 用 $\sin\frac1x$ 就断言振荡 —— 要看**别的因子**能不能把它压成无穷小（$\ln x\cdot\sin\frac1{x-1}$ 在 $x=1$ 处是可去）。
8. 忘记"$\lim f$ 存在 $\iff$ 左右相等"，把"左右都存在"当成"极限存在"。
9. 把 $f(x_0)$ 有定义当成连续（$f(x_0)$ 存在 ≠ 连续）。
10. 交卷前不代数值抽查（$x=x_0\mp10^{-3}$）。

## 9. 速查卡（一页）

1. **列点**：分母 0 / 对数真数 / 根号 / tan 极点 / 分段点 / lim 定义的点。
2. **分左右**：$\lvert\cdot\rvert$、$e^{\pm1/(x-a)}$、$\arctan\frac1{x-a}$、$(x-a)^{奇}$、单侧定义域、$\ln\lvert\cdot\rvert$。
3. **代换**：$x=a\mp t$，$t\to0^+$。
4. **算**：等价替换（单侧合法）→ 有理化 → 泰勒 → 洛必达。
5. **判**：都存在且等 = 可去；都存在不等 = 跳跃；一侧 $\infty$ = 无穷；都不存在 = 振荡。
6. **查**：左右都算；不相等 $\Rightarrow$ 极限不存在（跳跃/无穷/振荡）；代 $x=x_0\mp10^{-3}$ 验符号。
