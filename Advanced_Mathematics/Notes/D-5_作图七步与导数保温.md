## 1. 默写卡（抄到白纸上，≤10 行）

> **作图七步**：① 定义域（**含不可导点**）→ ② 奇偶/周期（若有）→ ③ 渐近线（垂直/水平/斜，**两端分别求**）→ ④ $f'$ → 单调区间 + 极值 → ⑤ $f''$ → 凹凸 + 拐点 → ⑥ **列表** → ⑦ 作图（标极值点、拐点、交点、渐近线）。
> **老卷给了 $y',y''$ 就从第 ④ 步开始**，时间花在列表和渐近线上（今天两道里 2021-22 给了、2022-23 没给）。
> **渐近线三查**：垂直＝找无定义点看单侧 $\lim f=\infty$；水平＝$\lim_{x\to\pm\infty}f=b$；斜＝$k=\lim f/x,\ b=\lim(f-kx)$。**两端各查一次**。
> **求导动笔前三问**：定义域？前提（$x'_t\ne0$ / $F_y\ne0$ / 分段点先验连续）？用哪条公式？

## 2. 两道真题的答案骨架（**做完第 2 步才准看**）

考点与结论均经 sympy 复核（渐近线四方向极限、$y'$/$y''$ 因式分解、驻点与拐点）；2022-23 的 $x=0$ 另用 30 位精度差商确认。

### 2.1 2021-22 Q17（p2，12 分，卷面附 $y',y''$）

$y=x^2-2x+\dfrac{2}{x-1}$，定义域 $x\ne1$，非奇非偶。

| 项目 | 结论 |
| --- | --- |
| 卷面给的导 | $y'=2x-2-\dfrac{2}{(x-1)^2}$，$y''=2+\dfrac{4}{(x-1)^3}$（sympy 一致） |
| 垂直渐近线 | $x=1$（左 $-\infty$ / 右 $+\infty$） |
| 水平 / 斜 | **都没有**：$y\sim x^2$，$y/x\to\infty$（二次增长，别硬套斜渐近线） |
| 驻点 | $x=2$（$y=2$，极小）；拐点 $x=1-\sqrt[3]{2}$ |

**这题练的是「有给导数时怎么省时间」**：直接从七步第 ④ 步进列表，别回头重算 $y'$。

### 2.2 2022-23 Q17（p3，12 分，**卷面不给导数**，今天最难）

$y=\sqrt[3]{\dfrac{x}{x-1}}$，定义域 $x\ne1$。

| 项目 | 结论 |
| --- | --- |
| 垂直渐近线 | $x=1$（左 $-\infty$ / 右 $+\infty$） |
| 水平渐近线 | $y=1$，**两端都是**（$x\to\pm\infty$ 时 $x/(x-1)\to1$） |
| 斜渐近线 | 无（已有水平） |
| 驻点 | **无**，$y'$ 在两支均恒负（两支分别递减） |
| **不可导点** | **$x=0$**：$y\to0$ 但差商 $\frac{y(h)-y(0)}h\to-\infty$，是**竖直切线**，不是驻点；须单列进第 ① 步 |

$y'=-\dfrac{1}{3x(x-1)}\left(\dfrac{x}{x-1}\right)^{1/3}$，$y''=\dfrac{2(3x-1)}{9x^2(x-1)^2}\left(\dfrac{x}{x-1}\right)^{1/3}$（同号分支）。

> [!warning] 今天最容易丢分的两处
> ① 漏掉 $x=0$ 这个不可导点 —— 七步第 ① 步就要列；② 斜渐近线只算 $x\to+\infty$ 一端（`sec2c.tex` 高频错误清单第 5 条）。
