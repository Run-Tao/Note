# 函数性态与作图 · 题型专题

> **定位**：本篇是"怎么做"的方法笔记；**真题题面与完整解答**在 `Resources/Downloads/讲义_函数性态与作图.pdf`，执行排期在 [[D-5_作图七步与导数保温]]。
> 考情：约 16/17 套卷考、倒数第二题、10–12 分（2021-22 / 2022-23 各 12 分，2023-24 为 10 分），是全年最稳的模板分。
> 七步的**权威出处**是 `Homework/学习进度与复习方案.md` §5-D（冲刺计划 §5-D 是极限定义三模板，别翻错）。

## 0. 默写卡（闭卷，≤6 行）

1. **七步**：① 定义域（**含不可导点**）→ ② 奇偶/周期 → ③ 渐近线（**两端分别求**）→ ④ $f'$ → 单调区间 + 极值 → ⑤ $f''$ → 凹凸 + 拐点 → ⑥ **列表** → ⑦ 作图（标极值点、拐点、交点、渐近线）。
2. **渐近线三查**：垂直＝无定义点看单侧 $\lim f=\infty$；水平＝$\lim_{x\to\pm\infty}f=b$；斜＝$k=\lim f/x,\ b=\lim(f-kx)$。**两端各查一次**。
3. **列表是给分点**：写清「区间 / $f'$ 符号 / 升降 / $f''$ 符号 / 凹凸」，只画图不给表要扣分。
4. **卷面附了 $y',y''$ 就从第 ④ 步开始**，别回头重算导数。
5. **不可导点在第 ① 步单列**：$f'=\infty$ 是竖直切线，不是驻点；$f''$ 不存在的点也可能是拐点。
6. **二次增长没有斜渐近线**：$f/x\to\infty$ 时判「无斜」，别硬凑一条。

## 1. 七步各自的判定口径

| 步 | 做什么 | 常见漏项 |
| --- | --- | --- |
| ① 定义域 | 分母为零、根号内负、$\ln$ 真数非正、分段点 | **$f'$ 不存在的点**（$|x|$ 型尖点、$\sqrt[3]x$ 型竖直切线） |
| ② 对称性 | 奇偶、周期 | 平移后才有奇偶性（如 $(x-1)^2$ 关于 $x=1$ 对称） |
| ③ 渐近线 | 垂直 / 水平 / 斜，两端 | 只算 $x\to+\infty$；水平与斜互斥但**不同端可以有不同答案** |
| ④ 一阶 | $f'=0$ 与 $f'$ 不存在的点，列表 | 只找 $f'=0$，漏不可导点；区间被无定义点切断时没分段 |
| ⑤ 二阶 | $f''=0$ 与 $f''$ 不存在的点，列表 | 把 $f''=0$ 直接当拐点（须左右变号，$x^4$ 反例） |
| ⑥ 列表 | 合并 ④⑤ 的分点 | 列数少于 5 行、忘了标渐近线那一列 |
| ⑦ 作图 | 先画渐近线，再描点连线 | 交点（与坐标轴）没标 |

## 2. 渐近线的四类情形（sympy 复核）

| 函数 | 垂直 | 水平 | 斜 | 备注 |
| --- | --- | --- | --- | --- |
| $y=\dfrac{x^2}{x-1}$ | $x=1$（左 $-\infty$ / 右 $+\infty$） | 无 | $y=x+1$，两端 | $y=x+1+\frac1{x-1}$，多项式部分直接读 |
| $y=x^2e^{-x}$ | 无 | $y=0$ **仅右端** | 无 | $x\to-\infty$ 时 $y\to+\infty$，且 $y/x\to-\infty$ |
| $y=\dfrac{\ln x}{x}$ | $x=0^+$（$y\to-\infty$） | $y=0$ 右端 | 无 | 定义域 $x>0$，左端根本不存在 |
| $y=\dfrac{x^3}{x^2+1}$ | 无 | 无 | $y=x$，两端 | $y=x-\frac{x}{x^2+1}$ |

> [!warning] 「无斜」也要写出理由
> $y=x^2-2x+\frac2{x-1}$（2021-22 Q17）因 $y\sim x^2$ 得 $y/x\to\infty$，**没有水平也没有斜渐近线**。只写"无渐近线"会被扣分——垂直 $x=1$ 是有的。

## 3. 三道自测题（题面与解析在讲义 §3–§5）

### G1 $y=\dfrac{x^2}{x-1}$（模拟卷 C Q17，卷面附 $y',y''$）

$$y'=\frac{x(x-2)}{(x-1)^2},\qquad y''=\frac{2}{(x-1)^3}.$$

- 定义域 $x\ne1$；垂直渐近线 $x=1$；斜渐近线 $y=x+1$（无水平）；
- 驻点 $x=0$（极大值 $0$）、$x=2$（极小值 $4$）；
- $y''$ 在定义域内不为零，$x=1$ 两侧变号但不在定义域 $\Rightarrow$ **无拐点**；
- 单调：$(-\infty,0)$ 增、$(0,1)$ 减、$(1,2)$ 减、$(2,+\infty)$ 增；凹凸：$(-\infty,1)$ 凸、$(1,+\infty)$ 凹。

> [!tip] 这题练的是"有给导数时怎么省时间"
> 直接从七步第 ④ 步进列表，时间花在渐近线与列表上。

### G2 $y=x^2e^{-x}$

- 驻点 $x=0$（极小 $0$）、$x=2$（极大 $4/e^2$）；
- $y''=(x^2-4x+2)e^{-x}$，拐点 $x=2\pm\sqrt2$（**两个**）；
- 水平渐近线 $y=0$ 仅 $x\to+\infty$；$x\to-\infty$ 时 $y\to+\infty$，无斜渐近线。

### G3 $y=\dfrac{\ln x}{x}$

- 定义域 $x>0$；$x\to0^+$ 时 $y\to-\infty$（垂直 $x=0$）；$x\to+\infty$ 时 $y\to0$（水平 $y=0$）；
- $y'=\frac{1-\ln x}{x^2}$，驻点 $x=e$（极大 $1/e$）；$y''=\frac{2\ln x-3}{x^3}$，拐点 $x=e^{3/2}$。

## 5. 十二条高频错误

1. 只算一侧渐近线；2. 二次增长硬凑斜渐近线；3. 把 $f(\pm1)=0$ 当成左右极限；4. 只找 $f'=0$ 漏不可导点；5. 把竖直切线当驻点；6. $f''=0$ 直接判拐点；7. 拐点漏了 $f''$ 不存在的点；8. 区间被无定义点切断却没分段列表；9. 列表少于 5 行 / 缺 $f''$ 符号行；10. 卷面给了 $y',y''$ 还回头重算；11. 图不标渐近线与交点；12. 两端凹凸性不同却合并成一个区间。

## 6. 错因 → 回炉路径

| 卡在哪 | 回做 |
| --- | --- |
| 渐近线判错 / 漏一端 | G1、G2，各把 $x\to\pm\infty$ 写两行 |
| 不可导点漏列 | 2022-23 Q17 的 $x=0$、G3 的 $x=0^+$ |
| 列表写不全 | G1 按「区间 / $f'$ / 升降 / $f''$ / 凹凸」五列抄一遍 |
| 极值拐点混淆 | G2（$y''$ 有两个零点，$y'$ 也有两个零点，正好对照） |
| 时间超 25 分钟 | 只做 G1（有给导数），练"从第 ④ 步开始" |
