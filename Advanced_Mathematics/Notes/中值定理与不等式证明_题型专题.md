# 中值定理与不等式证明 · 题型专题

> **定位**：概念在 [[Level3_Mean_Value_Theorems]]，**完整证明、15 类母题、24 道训练题**在 `Resources/Downloads/微分中值定理专题讲义.pdf`（25 页）。
> 本篇不复制那份讲义，只补两样它装不下的东西：**一页默写卡**与**考场上怎么落笔的答题模板**；页码索引放在 §4。
> 考情：2010–2023 高频压轴，但 **2024-25 压轴改成抽象函数方程 / 迭代连续性，没有中值定理** —— 基本型必须会，别把最后一周全押在它上面。

## 0. 默写卡（闭卷，≤8 行）

1. **费马引理**：内点取极值 + 可导 $\Rightarrow f'(x_0)=0$。全部中值定理的地基。
2. **Rolle**：$[a,b]$ 连续 + $(a,b)$ 可导 + $f(a)=f(b)$ $\Rightarrow\exists\xi:f'(\xi)=0$。
3. **Lagrange**：$f(b)-f(a)=f'(\xi)(b-a)$；用于**证不等式**与**估计函数差**。
4. **Cauchy**：$\frac{f(b)-f(a)}{g(b)-g(a)}=\frac{f'(\xi)}{g'(\xi)}$；L'Hôpital 由它推出。
5. **六个辅助函数**（倒推法，见 §1 表）—— 见 "$f'+\lambda f=0$ 型"先想指数因子。
6. **两个中值点**：把区间分成两段各用一次，或对不同函数各用一次。
7. **证不等式三条路**：单调性（移项造 $g$，$g(a)=0$ 且 $g'>0$）、Lagrange 放缩、Taylor 带 Lagrange 余项。
8. **条件三查**：闭区间连续？开区间可导？端点值相等 / $g'\ne0$？**缺一条结论就可能假**。

## 1. 万能构造表（默写级，推导见专题讲义 §3）

| 目标结论 | 构造 $F(x)$ | 对谁用 Rolle |
| --- | --- | --- |
| $f'(\xi)+\lambda f(\xi)=0$ | $e^{\lambda x}f(x)$ | $F(a)=F(b)$ 或已知两个零点 |
| $\xi f'(\xi)+n f(\xi)=0$ | $x^n f(x)$（$0\notin[a,b]$） | 同上 |
| $\xi f'(\xi)-n f(\xi)=0$ | $f(x)/x^n$ | 同上 |
| $f'(\xi)+g'(\xi)f(\xi)=0$ | $e^{g(x)}f(x)$ | 指数因子一般化 |
| $f'(\xi)=k$（常数） | $f(x)-kx$ | $F(a)=F(b)$ 时退化为 Rolle |
| $f'(\xi)=2\xi$ 一类 | $f(x)-x^2$ | 多项式右端直接积分回去 |

> [!tip] 倒推口令
> 把要证的式子看成**某个乘积的导数为零**：$u'+\frac{u'}{u}u$ 型就想 $\ln|u|$ 或 $e^{\lambda x}$；"$\xi f'+nf$" 就是 $(x^n f)'$ 除以 $x^{n-1}$。

## 2. 答题模板（把给分点写全）

```
1) 设辅助函数 F(x)=____ ，并说明 F 在 [a,b] 连续、在 (a,b) 可导（逐条写清理由）。
2) 验证端点：F(a)=____ ，F(b)=____ ，故 F(a)=F(b)。
3) 由 Rolle 定理，存在 ξ∈(a,b) 使 F'(ξ)=0。
4) 计算 F'(x)=____ ，代入 ξ 并整理，即得要证的等式。
5) 若题目要求 ξ 的唯一性 / 范围，再补一步单调性或介值定理。
```

> [!warning] 三个最容易丢分的动作
> ① 只写"由中值定理得"而不验证连续/可导条件；② 辅助函数写对了但**没有验端点值相等**；③ 结论含 $f''$ 时忘了用**两次** Rolle（先造 $f'$ 的两个零点）。

## 3. 不等式证明：选哪条路

| 特征 | 选路 | 模板 |
| --- | --- | --- |
| 单变量、能移项成 $g(x)>0$ | **单调性** | $g(a)=0$，$g'(x)>0$ $\Rightarrow g(x)>0$ |
| 出现 $f(b)-f(a)$、给了 $|f'|\le M$ | **Lagrange** | $|f(b)-f(a)|\le M|b-a|$ |
| 出现 $f''$ 有界、或要二阶精度 | **Taylor（Lagrange 余项）** | 在 $x_0$ 展开，余项统一放缩 |
| 含 $\ln$、两函数之比 | **Cauchy / 单调性** | 造 $\frac{f(x)}{g(x)}$ 或 $\ln\frac{\cdot}{\cdot}$ |
| 闭区间上的最大最小值 | **极值 + 端点比较** | 先找驻点再比端点 |

**范例**（模拟卷 C Q16）：证 $x>0$ 时 $\ln(1+x)>x-\frac{x^2}{2}$。

令 $g(x)=\ln(1+x)-x+\frac{x^2}{2}$，则 $g(0)=0$，且

$$g'(x)=\frac1{1+x}-1+x=\frac{x^2}{1+x}>0\ (x>0),$$

故 $g$ 在 $[0,+\infty)$ 严格递增，$g(x)>g(0)=0$。

> [!note] Taylor 是同一件事的高阶版
> 用 $\ln(1+x)=x-\frac{x^2}{2}+\frac{x^3}{3(1+\xi)^3}$（Lagrange 余项）可得更强结论；但 Peano 余项 $o(x^2)$ **不能**给出严格不等号，只能给极限。
