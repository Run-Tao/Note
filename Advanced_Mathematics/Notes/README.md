# Notes 学习笔记

按 Level 组织，**一个 Level 一个主要文件**（如 `Level2_Derivatives_and_Differentials.md`）；仅被大量引用且独立价值高的概念（如梯度、Taylor 公式、微积分基本定理）才单独建笔记。

## 写作规范

- 每篇笔记遵循 [config.md](../config.md) 的模板：直觉 → 定义 → 关键公式与结论 → 常见误解 → AI / 工程应用 → 遗留疑问；
- 用自己的话复述，禁止大段照抄教材；记录日期与来源；
- 公式用 Obsidian 原生 LaTeX（行内 `$...$`，独立 `$$...$$`）；
- **遗留疑问**：在笔记内用 `> [!question] 未解决` 标记，由 MOC 汇总跟踪，不设独立目录；
- 原始笔记从 `Inbox/` 整理而来，整理流程见根目录 [[Knowledge_Workflow]]；
- **例外（题型专篇）**：某题型若跨多套真题反复出现、且需要独立成套的方法与数据，允许单独建 `*_题型专题.md`（如 [[极限定义证明_题型专题]]）；它**不替代** Level 主笔记的定义表述，只承载"怎么做 + 考过什么"。
