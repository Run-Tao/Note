## 4. 在降权但要保底（优先级 3）

- **中值定理压轴**：2010–2023 高频（Rolle 构造、两次 Rolle、Lagrange 证不等式），但 **2024-25 压轴改成抽象函数方程 / 迭代连续性，没有中值定理**。结论：基本型必须会，但别把最后一周全押在它上面；要留精力给"抽象函数方程 + 连续性 / 介值"这类新压轴。
- **闭区间最值 / 不等式证明**（单调性法）：2009、2022-23 考过大题，10 分量级。

## 5. 两个影响答题策略的细节

1. **第 11 题的证明形式在轮换**（2026-11-02 用 pymupdf 定位第 11 题行 + 4x 渲染逐字复核，17 套全覆盖）：
   - $\varepsilon$-$\delta$ 型 **8 套**：2008-09、2011-12、2012-13、2014-15、2017-18、2020-21、2021-22、2022-23；
   - $\varepsilon$-$X$ 型 **6 套**：2010-11、2013-14、2016-17、2018-19、2019-20、2023-24；
   - 无穷大 $M$-型 **3 套**：2009-10（$x\to+\infty$）、2015-16（$x\to1$）、2024-25（$x\to0$）。

   **三种都要会写**，不能只练 $x\to0$ 的 $\varepsilon$-$\delta$；分布接近均匀轮换，按 **A : B : C ≈ 3 : 2 : 1** 分配练习量。完整定义、范例与陷阱见 [[极限定义证明_题型专题]]。
2. **作图题卷面常附 $y'$、$y''$ 提示**（2008、2009、2013 明确附了）：考的是"用导数列表 → 定性态 → 画图 → 找渐近线"的流程，不是硬算导数。
3. **一处官方答案与逐点复核不一致 + 两处 2026-11-04 复核结论**（sympy 复核；官方答案页 1.C 2.B 3.A 4.D 5.D）：
   - **2018-19 填空** $\arctan(x+\frac1x)+\frac{x^2+x}{x^2+3x+2}$ 的第一类间断点个数：官方 1 个，实际 **2 个** —— $x=0$ 处 $\arctan(x+\frac1x)$ 左 $-\frac\pi2$ / 右 $\frac\pi2$ 是**跳跃**，只算一侧就会漏；
   - **2023-24 选 3**（有界区间）：官方答案 **3.A**，与本库复核一致，取 **A：$(-1,0)$**（$x\to-1^+$ 时 $(x+1)\ln(x+1)\to0$，端点并不发散；数值网格 $\max|f|\approx0.38$）；
   - **2023-24 选 4**（$g=f(x)/x$）：官方答案 **4.D**（一阶连续可导），与本库 sympy 复核一致；旧记录写"正确 B"是错的。
   结论：**这类题必须逐点、分左右算完再选**，别背"标准答案"。
