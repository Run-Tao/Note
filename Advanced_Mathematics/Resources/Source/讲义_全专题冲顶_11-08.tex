\section{S1\quad 极限定义证明（12 题）}

\begin{methodbox}[这一组考什么]
真题第 11 题，\textbf{17/17 必考，8 分}。三种形式轮换出现：$\eps$-$\delta$ 8 套、$\eps$-$X$ 6 套、无穷大 $M$ 型 3 套。

\textbf{三种形式的量词顺序不一样，这是最常丢分的地方}：
\begin{itemize}
\item $\eps$-$\delta$ 型：$\forall\eps>0,\ \exists\delta>0,\ \forall x$（$0<|x-x_0|<\delta$）$\Rightarrow |f(x)-A|<\eps$；
\item $\eps$-$X$ 型：$\forall\eps>0,\ \exists X>0,\ \forall x>X$ $\Rightarrow |f(x)-A|<\eps$；
\item 无穷大 $M$ 型：$\forall M>0,\ \exists\delta>0,\ \forall x$（$0<|x-x_0|<\delta$）$\Rightarrow |f(x)|>M$。
\end{itemize}
\textbf{写证明前必须先写出量词行}，这是步骤分。
\end{methodbox}

\section{S4\quad 新压轴（8 题）}

\begin{methodbox}[这一组考什么]
\textbf{这是本册最有价值的部分。} 2010--2023 的压轴是中值定理（Rolle 构造、两次 Rolle、Lagrange 证不等式），但 \textbf{2024-25 的压轴换成了「抽象函数方程 + 迭代连续性」}。

\textbf{不要把最后一周全押在中值定理上}。真题考点索引的结论写得很清楚：基本型必须会，但要留精力给这类新形态。

\textbf{两种新形态}：
\begin{enumerate}
\item \textbf{抽象函数方程}：给出 $f$ 的某个函数方程（如 $f(x+y)=f(x)f(y)$），要求求出 $f$ 或证明 $f$ 的连续性。核心动作是「减掉特解，把方程化成 Cauchy 型」。
\item \textbf{迭代与压缩映射}：给出递推 $x_{n+1}=\varphi(x_n)$，要求证收敛并求极限。核心动作是「先证几何衰减，再证 Cauchy 列，最后给误差界」。
\end{enumerate}
\end{methodbox}

\q{S4.1}{设 $x_{1}=2$，$x_{n+1}=\dfrac{x_{n}+\dfrac{2}{x_{n}}}{2}$。证明 $(x_{n})$ 收敛，并求 $\lim\limits_{n\to\infty}x_{n}$。}
\tagline{对标 2013-14 填 7 升级（8 分）}

\q{S4.2}{设 $x_{1}=1$，$x_{n+1}=\dfrac{1+x_{n}}{x_{n}}$。证明 $(x_{n})$ 收敛，并求 $\lim\limits_{n\to\infty}x_{n}$；再讨论 $y_{1}=1$，$y_{n+1}=y_{n}+\dfrac{1}{y_{n}}$ 的情形。}
\tagline{对标 2018-19 计算型（8 分）}

\section{S5\quad 不等式与最值（10 题）}

\begin{methodbox}[这一组考什么]
真题的应用题块（约 18 分）考两种东西：\textbf{闭区间最值}和\textbf{用单调性 / 凹凸性 / 泰勒 / 中值定理证不等式}。

\end{methodbox}

\section{S6\quad 作图压轴（6 题）}

\begin{methodbox}[这一组考什么]
作图题约 16/17 套都考，是全卷第二高的大题（10--12 分）。\textbf{考的是流程不是硬算}：定义域 $\to$ 奇偶 $\to$ 截距 $\to$ 导数 $\to$ 极值 $\to$ 凹凸 $\to$ 渐近线。

\textbf{三个高频「反直觉点」}：
\begin{enumerate}
\item \textbf{驻点不是极值}（导数变号才叫极值）：$y=\frac{x^{3}}{x^{2}-1}$ 的 $x=0$ 是拐点不是极值；
\item \textbf{不可导点可以取极值}：$y=|x-1|\ee^{-x}$ 在 $x=1$ 处是尖点极小值；
\item \textbf{极坐标曲线的尖点}：心形线在 $\theta=\pi$ 处斜率是 $0/0$，必须取极限。
\end{enumerate}
\end{methodbox}

\q{S6.1}{作出 $y=\dfrac{x^{3}}{x^{2}+1}$ 的图形，写出定义域、对称性、截距、驻点、极值、凹凸区间与渐近线。}
\tagline{对标 2013 Q17（12 分）}

\q{S6.3}{作出 $y=\abs{x-1}\ee^{-x}$ 的图形，指出 $x=1$ 处的间断点性质与极值，并求其余极值与渐近线。}

\tagline{对标 2022-23 Q17（12 分）}
