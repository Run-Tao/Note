## 规范

- 每道题标注来源（教材章节 / 课程 / 竞赛）与难度；
- 计算题要写出关键步骤，证明题要写清"用了哪个定理、条件是否满足"；
- 错题必须写"错在哪一步、当时是怎么想的"，便于二刷；
- 关联到对应的 Notes 笔记（Wiki Link）。
