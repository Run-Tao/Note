# Weekly Report — 每周学习报告

## 用途

每周一次深度分析，读取最近 7 天内容，完成：

1. 学习进度分析
2. 知识体系分析
3. 知识漏洞发现
4. 推荐学习资料
5. 下一周计划

## 命名

`YYYY-Www.md`（如 `2026-W35.md`）

## 报告模板

```markdown
# 周报 2026-Wxx

## 本周学习进度
- ...

## 知识体系分析
- 各知识库进展 / 关系

## 知识漏洞
- 缺口（对应 Knowledge_Gaps/）

## 推荐资料
- 逐条：为什么推荐

## 下一周计划
- 优先级排序
```
