# Level 0 环境与编译

> 目标：打通"写代码 → 编译 → 运行 → 调试"的完整链路。
> 本笔记先整理"程序运行的基础：计算机硬件与软件"（来自 Inbox `2026-09-15`），编译工具链部分先列出清单、后续学习时补充。

## 直觉

写 C++ 代码，最终要交给真实的机器执行。先建立"程序如何操控硬件"的整体图景，再学编译器与调试工具，才能解释清楚"为什么需要编译""代码为什么能跑起来"。

## 1. 背景：程序运行的基础

### 1.1 计算机是什么

> [!note] 我的原始理解（未验证）
> 现代计算机可以被定义为"一个在由程序操控的可用于存储和处理信息的机器"。

这句话抓住三个要点：**可存储**、**可处理信息**、**由程序操控**。硬件不会自己决定做什么，必须靠程序（指令）驱动。

### 1.2 冯诺依曼架构

现代计算机普遍采用**冯诺依曼架构**（von Neumann architecture），分为五个部分：

1. 输入设备；
2. 输出设备；
3. 运算器（完成算术与逻辑运算，核心是算术逻辑单元 ALU）；
4. 控制器（取指令、译码、指挥各部件协调工作）；
5. 存储器（存放指令和数据）。

其中**运算器 + 控制器**合起来，就是通常说的 **CPU**。

> [!info] Agent 补充
> 冯诺依曼架构的核心是**存储程序**思想：程序（指令）与数据存放在同一存储器中，CPU 反复执行"取指令 → 译码 → 执行 → 写回"的循环。
> 它的经典局限是**冯诺依曼瓶颈**：CPU 与存储器之间的数据传输带宽限制整体速度，这也是缓存（cache）、流水线等技术存在的原因。
> 对应到 C++：源码经编译后变成机器指令存入内存，CPU 按指令顺序（或分支）执行——这就是"程序操控硬件"的具体过程。

### 1.3 计算机软件

- **软件决定计算机能做什么**：硬件提供能力上限，软件决定实际行为；
- **软件把用户与硬件隔离开**：我们通过操作系统、标准库等抽象使用机器，而不必直接操作电路。

> [!info] Agent 补充
> 软件大致分两层：**系统软件**（操作系统、编译器、驱动程序等）与**应用软件**（面向用户的程序）。
> 像 C++ 这样的系统级语言，处在"贴近硬件"（指针、内存布局）与"高级抽象"（类、模板、STL）之间，因此常用于对性能敏感的系统与 AI 工程。

## 2. 编程习惯：先画图，再写代码

> [!note] 我的原始理解（未验证）
> 写代码尝试使用流程图 / 盒图 / N-S 图。

- **流程图**（flowchart）：用图形符号描述处理流程——起止框、判断框、处理框、输入输出框，用箭头连接；
- **盒图 / N-S 图**（Nassi–Shneiderman diagram）：用嵌套矩形表示顺序、选择、循环三种基本结构，强制结构化，不用箭头跳转；
- **共同目的**：动手写 C++ 之前先把控制流与算法结构想清楚，减少逻辑错误，也便于向别人解释思路。

> [!info] Agent 补充
> 现代实践中也常用伪代码（pseudocode）、UML 活动图，或用 Mermaid / draw.io 画流程图。工具只是手段，重点仍是"先想清结构，再写代码"。

## 3. 标准输入输出：cout 与 endl

> [!note] 我的原始理解（未验证）
> - `cout`
> - `endl` 输出一个字符串然后再换行，刷新缓冲区
> - `flush` 输出一个字符串然后直接刷新缓冲区
> - `ends` 输出一个字符串和一个空字符，然后刷新缓冲区

- **`std::cout`**：标准输出流对象，定义在头文件 `<iostream>` 中，配合插入运算符 `<<` 把数据写到标准输出：

```cpp
#include <iostream>

int main() {
    std::cout << "Hello, C++" << std::endl;
    return 0;
}
```

- **三个流操纵符**（manipulator）：

| 操纵符 | 实际插入的内容 | 是否刷新缓冲区 |
| --- | --- | --- |
| `std::endl` | 换行符 `'\n'` | 是 |
| `std::flush` | 不插入任何字符 | 是 |
| `std::ends` | 空字符 `'\0'` | 是 |

> [!info] Agent 补充（纠正原始笔记）
> `endl / flush / ends` 并不"输出一个字符串"——它们本身不产生可见文本：`endl` 插入换行并刷新，`flush` 只刷新，`ends` 插入 `'\0'` 并刷新。
> 日常写换行更常用 `'\n'`；`endl` 与 `'\n'` 的唯一区别就是**强制刷新缓冲区**，在循环里频繁使用会明显影响性能。

> [!tip] 缓冲区（buffer）
> 输出先进入内存缓冲区，再成批交给操作系统，避免每次都做昂贵的 I/O。刷新（flush）强制立刻写出；程序正常结束或缓冲区写满时也会自动刷新。
