# Notes 学习笔记

按 Level 组织，**一个 Level 一个主要文件**（如 `Level1_Types_and_Syntax.md`）；仅被多次引用且独立价值高的概念（如 RAII、移动语义、智能指针）才单独建笔记。

## 写作规范

- 每篇笔记遵循 [config.md](../config.md) 的模板：直觉 → 语法与规则 → 示例 → 常见陷阱与 UB → 性能与代价 → 应用 → 遗留疑问；
- 用自己的话复述，禁止大段照抄教材；记录日期与来源；
- 示例代码应完整可编译，标注语言为 `cpp`；大段代码放 `Code/`，笔记只留关键片段；
- **遗留疑问**：在笔记内用 `> [!question] 未解决` 标记，由 MOC 汇总跟踪，不设独立目录；
- 原始笔记从 `Inbox/` 整理而来，整理流程见根目录 [[Knowledge_Workflow]]。
