# 作业1 四位数加密

> 题目：对一个 4 位整数加密——每位数字加 7 后除以 10 取余，再把第 1 位与第 3 位交换、第 2 位与第 4 位交换。
> 对应笔记：[[Level1_Types_and_Syntax]]。

## 原始代码（含 bug）

```cpp
#include <iostream>
using  namespace std;
int step_1(int y){
    return (y+7)%10;
}
int encrypt(int x){
    int a,b,c,d,temp_1,temp_2;
    a = step_1(x%1000);          // ← 错误
    b = step_1((x/100)%10);
    c = step_1((x/10)%10);
    d = step_1(x%10);
    temp_1 = a;  a = c;  c = temp_1;   // 交换第 1、3 位
    temp_2 = b;  b = d;  d = temp_2;   // 交换第 2、4 位
    return a*1000+b*100+c*10+d;
}
int main()
{
    int m,n;
    cin>>m>>n;
    cout<<encrypt(m)<<" "<<encrypt(n);
    return 0;
}
```

## 问题分析

### 核心 bug：千位取错

`a` 表示千位数字，应当用 `(x/1000)%10`，而原代码写成了 `x%1000`：

- `x%1000` 得到的是**后三位**（如 1234 → 234），不是千位；
- 对它加 7 取余，得到的是"后三位 + 7 的个位数"，与千位无关。

**验算 $x=1234$**（正确答案应为 189）：

| 位 | 正确取法 | 正确加密 | 原代码取法 | 原代码加密 |
| --- | --- | --- | --- | --- |
| 千位 | 1 | 8 | 234 | 1 |
| 百位 | 2 | 9 | 2 | 9 |
| 十位 | 3 | 0 | 3 | 0 |
| 个位 | 4 | 1 | 4 | 1 |

正确结果：8,9,0,1 → 交换 1/3 位得 0,9,8,1 → 交换 2/4 位得 0,1,8,9 = **189**。
原代码结果：1,9,0,1 → 交换后 0,1,1,9 = **119**。两者不同，说明 bug 会直接改变输出。

### 其他可改进点

1. `using namespace std;` 放在全局作用域，容易造成名字冲突，建议写 `std::cout` / `std::cin`（见 [[Level2_Functions_and_Scope]]）；
2. 函数名 `step_1` 含义不清，可改为 `addSevenModTen` 之类的自解释名字；
3. 魔法数字 `7`、`10` 建议提为具名常量或加注释；
4. 没有校验输入是否为 4 位整数（`x/1000 == 0` 时结果无意义），建议在 `encrypt` 里加断言或提示；
5. 交换两个变量可以直接用 `std::swap`，比手写临时变量更清晰。

## 修正后的代码

```cpp
#include <iostream>
#include <cassert>
#include <utility>

namespace {
constexpr int kAddend = 7;
constexpr int kBase = 10;

int addSevenModTen(int digit) {
    return (digit + kAddend) % kBase;
}
}  // namespace

int encrypt(int x) {
    assert(x >= 1000 && x <= 9999);           // 只接受 4 位数

    int a = addSevenModTen((x / 1000) % 10);  // 千位（已修正）
    int b = addSevenModTen((x / 100) % 10);   // 百位
    int c = addSevenModTen((x / 10) % 10);    // 十位
    int d = addSevenModTen(x % 10);           // 个位

    std::swap(a, c);                          // 交换第 1、3 位
    std::swap(b, d);                          // 交换第 2、4 位

    return a * 1000 + b * 100 + c * 10 + d;
}

int main() {
    int m = 0, n = 0;
    std::cin >> m >> n;
    std::cout << encrypt(m) << ' ' << encrypt(n) << '\n';
    return 0;
}
```

编译运行：`g++ -std=c++20 -Wall -Wextra -O2 encrypt.cpp -o encrypt`（Windows 上可用 MSVC 或 MinGW）。

## 易错点与收获

- 取十进制某一位的通用写法：**第 $k$ 位（从低位起）= $\left\lfloor x/10^{k-1}\right\rfloor \bmod 10$**；
- 提交前一定要**用一个具体例子手算验证**（本例中 1234 → 189，很轻松就能发现 119 不对）；
- 位交换时用 `std::swap` 更不易写错（手写临时变量时要确认没有覆盖）；
- 开启 `-Wall -Wextra` 能让编译器帮忙发现部分问题，但逻辑错误只能靠测试。
