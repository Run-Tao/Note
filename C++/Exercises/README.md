# Exercises 练习与错题本

按 Level 组织，题型建议：

- 语法 / 语义判断题（检验理解，例如"这段代码是否 UB"）；
- 编程题（实现数据结构、算法，写可编译运行的代码）；
- 调试找错题（给出有缺陷的代码，找出并修复）；
- 性能题（对比不同写法的开销，用基准测试验证）。

错题记录格式：题目 → 我的错误 → 正确思路 → 涉及概念。

代码放 `Code/` 对应 Level 目录下，练习说明写在本目录 Markdown 中。
