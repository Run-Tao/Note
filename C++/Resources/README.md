# Resources 资料库

汇总书籍、课程、文档、博客，按 Level 或主题分类。

每条记录：名称、难度（入门 / 进阶）、语言、推荐理由、链接。

- **可下载的文档**（标准草案、PDF、官方文档、可保存网页）统一下载到 `Downloads/` 子目录，索引记录本地路径，笔记引用本地文件而非外链；
- **仅在线资源**（视频、需登录等）才只记链接，并标注"仅在线"。

建议标注状态：已读 / 在读 / 待读，并定期清理。
