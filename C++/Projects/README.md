# Projects 项目记录

把知识变成可运行、可验证的实践：**概念理解 → 代码实现 → 测试 / 基准 → 项目记录**。

每个项目记录建议包含：

- 对应的概念与 Wiki Links（如 [[RAII]]、[[移动语义]]、[[智能指针]]）；
- 项目目标（想验证 / 练习什么）；
- 代码位置 / 运行方式（`Code/` 目录 + 构建命令）；
- 结果与测试（截图、输出、基准数据）；
- 与真实场景的联系（算法、系统、AI 工程）；
- 收获与遗留问题。

不追求项目数量，追求"用代码验证一个概念"的深度。
