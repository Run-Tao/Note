# C++ 知识库

> 面向人工智能 / 计算机方向本科生的个人 C++ 学习知识库。
>
> 目标不是应付考试或背语法，而是掌握现代 C++（C++ 17/20）的核心心智模型，能独立写出正确、清晰、可维护、性能可接受的程序，并把它用到算法、系统与 AI 工程中。

## 这个知识库要解决什么问题

很多人学 C++ 停留在"看得懂语法、抄得了代码"，却说不清内存怎么管理、`move` 到底是什么、为什么要用 `const` 与 RAII。

这个知识库坚持三个原则：

1. **理解语言模型** —— 每个特性都要理解它解决什么问题、代价是什么，而不是死记语法；
2. **建立知识体系** —— 从编译与内存基础，逐步通向模板、STL、并发与工程实践；
3. **学以致用** —— 每学一个特性，都要能写出可运行的代码，并说出它在真实项目中的用途。

## 各目录用途

| 目录 | 用途 |
| --- | --- |
| Inbox/ | 原始笔记：随手记的碎片化想法，每天一个 YYYY-MM-DD.md，无格式要求，永不删除；Agent 整理后整个文件移入 Inbox/Processed/ 归档 |
| Notes/ | 按 Level 和主题记录笔记，一主题一文件，用自己的话重写原理与示例；未解决疑问用 `> [!question]` 标记 |
| Exercises/ | 语法与语义题、算法题、调试找错题，并记录错题 |
| Projects/ | 概念 → 代码实现 → 测试 / 基准 → 项目记录 |
| Code/ | 可编译运行的源码（`.cpp` / `.h` / `CMakeLists.txt`），按 Level 组织；笔记中只记关键片段 |
| Resources/ | 汇总书籍、课程、文档、博客，标注难度与推荐理由；可下载文档存于 Downloads/ |
| Glossary.md | 术语表单文件：重要术语中英文对照，并链接相关笔记 |

## 使用建议

0. **维护知识库时默认遵守 [config.md](config.md)**：新建任何笔记、练习或代码前，先读一遍规范；
1. 先打开总览页 [[C++ MOC]] 或 [Learning_Roadmap.md](Learning_Roadmap.md)，确定自己当前所处的 Level；
2. 学完一个主题后按循环走一遍：**写笔记 → 写代码 → 做练习 → 解决遗留疑问**；
3. 每周回顾一次笔记中的未解决问题和错题；
4. 每次学习结束时在个人层学习日志（[[Learning Log/README|00 - Personal/Learning Log]]）记录当次进度与遗留问题。

## 学习路线概览

| Level | 主题 | 一句话目标 |
| --- | --- | --- |
| Level 0 | 环境与编译 | 打通"写代码 → 编译 → 运行 → 调试"的完整链路 |
| Level 1 | 类型与基础语法 | 理解类型系统、变量、运算符与表达式求值 |
| Level 2 | 函数与作用域 | 掌握函数、重载、引用、生命周期与作用域 |
| Level 3 | 面向对象 | 用类与封装组织代码，理解构造 / 析构与 RAII |
| Level 4 | 内存与指针 | 理解栈 / 堆、指针、智能指针与所有权 |
| Level 5 | 模板与泛型 | 用模板编写泛型代码，理解编译期计算 |
| Level 6 | STL 与算法 | 熟练使用容器、迭代器与算法库 |
| Level 7 | 现代 C++ 惯用法 | move 语义、RAII、异常安全、Concepts / Ranges |
| Level 8 | 并发与性能 | 线程、同步、内存模型与性能优化 |
| Level 9 | 工程与实战 | 构建系统、测试、调试工具，面向算法与 AI 工程 |

详细路线见 [Learning_Roadmap.md](Learning_Roadmap.md)。
