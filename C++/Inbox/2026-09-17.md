#cpp 
1. cout
	- endl 输出一个字符串然后再换行，刷新缓冲区
	- flush 输出一个字符串 然后直接刷新缓冲区
	- ends 输出一个字符串和一个空字符，然后刷新缓冲区
2. 变量：提供同一个具体的，可供程序操作的存储空间（内存中）
3. C++的每个变量都有其数据类型，数据类型决定着变量占内存空间的大小和布局方式，该空间能存储的值的范围，以及变量能参与的运算
	- 变量有萨格重要属性：数据类型，名称，值
	- 定义格式：类型名 变量名1，变量名2，…，变量名n;
	- 标识符命名：
		1. 名字必须以字母或下划线开头
		2. 名字中的其他字符必须是数字、字母或下划线，不能使用空格或其他特殊符号
		3. 名字不可以是系统的关键字/保留字
		4. C++没有规定过名字的长度，但各个编译系统都有自己规定
		5. C++语言中，大写小写字母有区别
		6. 名字应使读者易于明白其含义
4. 变量初始化：
	- int num2(2) 直接初始化
	- int nnum3 = {3} 列表初始化
	- 定义的位置：函数体的开始处集中定义；使用前，防止定义未使用
5. 整型数的表示——码制
	- 数字的三种编码方式为：源码、反码、补码
	- 原码就是符号位加上真值的绝对值
	- 反码：为了解决原码无法执行减法运算的问题
	- 补码：现代计算机使用的编码格式，解决了反码缺点
6. **枚举类型**
	- enum weekdayT {Sunday}
```C++
enum Season {Spring, Summer, Autumn, Winter};
Season mySeason = Spring;
```
