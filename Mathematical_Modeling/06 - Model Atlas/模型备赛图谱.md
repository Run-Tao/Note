> ① 这个赛题**属于哪类问题**？② 该调**哪个模型/算法**？③ 它的**跟谁相关、谁更好用**？

## 一、按问题类型选型（赛题第一步）

拿到赛题，先在下面找到你的问题**属于哪一行**，再横扫对应候选，最后用"关键判据"砍到一个主模型 + 一个对照模型。

### 0. 机制演化（有"谁影响谁"的知识，要算随时间的走势）

| 候选 | 适用条件 | 关键判据 / 坑 | 讲次 |
| --- | --- | --- | --- |
| **ODE 仓室模型（SEIR/SEAR 族）** | 有一个"池子之间互相流动"的机制（人、钱、货、口碑），且**没有历史同期数据可学** | 必须先说清仓室划分（多一层 $E$ 会改变峰值时刻）；峰值条件要用 $dA/dt=0$ 做自洽检验；参数必须报**可辨识性**，不能只报拟合残差 | [[Day49 - 微分方程建模SEAR谣言恐慌与县域应急撤离\|Day49]] |
| **阈值判据 $R_0$** | 判断"会不会自我扩散" | $R_0>1$ 只说明会扩散，**不说明峰值多高**；峰值由初值 + 干预时机决定 | [[Day49 - 微分方程建模SEAR谣言恐慌与县域应急撤离\|Day49]] |
| **干预强度决策曲线** | 要回答"投多强才够" | 把 $g$ 扫一遍画"强度→峰值"曲线，比拍脑袋保守/激进两头吵架强 | [[Day49 - 微分方程建模SEAR谣言恐慌与县域应急撤离\|Day49]] |

> **一句话**：有机制 → ODE；没机制但有历史 → ARIMA/ML；两样都有 → 用 ODE 解释 + 用数据校参。**库存型系统里脉冲式干预通常不如持续基线干预。**

### 1. 预测未来（给过去的数据，问以后会怎样）

| 候选 | 适用条件 | 关键判据 / 坑 | 讲次 |
| --- | --- | --- | --- |
| **ARIMA (Box-Jenkins)** | 单变量、等间隔时间序列、有平稳/差分平稳的自相关结构 | 先做平稳性检验定 $d$，再看 ACF/PACF 定 $p,q$；一定要留**滚动回测**比 MAPE，别只看拟合 | [[Day46 - 时间序列ARIMA与县域景区游客量预测|Day46]] |
| **GM(1,1) 灰色预测** | 只有 **4~10 个等间隔点**、近似单调增长/衰减、无机制、无历史同期 | 先做**级比检验**（不通过就平移/开方）；|a|>0.3 只能短期；**AGO 累计值不能直接比阈值**（要用斜率）；C/P 好看≠准，首点残差恒 0 要报剔首点口径；**末点极敏感 → 结论给区间不给单点** | [[Day50 - 灰色GM(1,1)与县域河段氨氮预警|Day50]] |
| **DGM(1,1) / 滚动 GM** | 同上，但要抵消「末点敏感」 | 每来一个新点丢最旧点、固定窗口 5~6 重估；窗口长度要做敏感性 | [[Day50 - 灰色GM(1,1)与县域河段氨氮预警|Day50]] |
| **PCA + 主成分回归 PCR** | 解释变量多且**高度相关**（共线性），导致回归系数符号乱跳 | 主成分要配合载荷解读，否则会排出业务上无意义的轴 | [[Day32 - 主成分分析PCA与主成分回归PCR|Day32]] |
| **Logistic 回归** | 预测**概率/二分类**（会不会违约、会不会复发） | 给概率不给硬标签，可调阈值权衡漏判/误判成本 | [[Day10 - 监督分类Logistic回归信贷概率与阈值权衡|Day10]] |
| **GBDT** | 表格数据、非线性 + 特征交互、样本量中等 | 串行降**偏差**；弱树太深会过拟合，必须交叉验证 | [[Day12 - 梯度提升GBDT信贷风控与Boosting集成|Day12]] |
| **随机森林** | 同上，但更怕方差、要稳健、要特征重要性 | 并行降**方差**；可输出可解释的 if-else 规则 | [[Day11 - 决策树与随机森林信贷规则与集成|Day11]] |
| **SVM** | 高维小样本、边界清晰、要"推得越开越好" | 只有支持向量决定边界；核函数选择需要交叉验证 | [[Day13 - 支持向量机SVM信贷最大间隔与支持向量|Day13]] |
| **KNN** | 无训练时间约束、样本少、特征尺度已归一化 | 惰性学习，每次预测扫全库；K 的选择靠验证集 | [[Day9 - 监督分类KNN信贷风险与定K|Day9]] |
| **OLS + 回归诊断** | 要给"某因素影响多大"的**系数**（写进考核/成本/政策），而不只是要一个预测值 | 只交 `summary()` 一定出事：**RESET 判设定、BP/White 判同方差、杠杆-残差-Cook 判影响点、QQ 判正态**；系数显著与否要同时报 **HC1 稳健 t**；删点必须报"删前删后系数漂移" | [[Day51 - 回归诊断OLS四假设与热电厂燃煤单耗账本|Day51]] |

> **一句话**：预测**单个数值序列** → ARIMA；预测**一个结果（分类/概率）** → 机器学习四件套（Logistic / 树 / GBDT / SVM / KNN）。

### 2.2 启发式与元启发式四范式（NP-hard 的主战场）

| 范式 | 代表 | 机制 | 何时选 | 讲次 |
| --- | --- | --- | --- | --- |
| 随机跳坑 | GA / SA | 群体交叉、可控退火 | 无先验结构，想简单粗暴 | [[Day6 - 启发式元启发式GA与SA求解TSP|Day6]] |
| 记忆引导 | 禁忌搜索 | 禁忌表防止回走 | 已有邻域定义、想精细化挖潜 | [[Day42 - 禁忌搜索与单机总加权延误排产|Day42]] |
| 群体智能·离散 | ACO | 信息素正反馈 | 路径/序列类（TSP、路由） | [[Day43 - 蚁群算法ACO求解TSP最短环游|Day43]] |
| 群体智能·连续 | PSO | 个体最优 + 群体最优牵引 | **连续**变量（选址坐标、参数） | [[Day44 - 粒子群优化PSO与县域冷链中转站选址|Day44]] |
| 进化·连续 | DE | 差分向量当步长，自适应 | 连续 + 非凸 + 多峰（23 个局部最优那种） | [[Day45 - 差分进化DE与县域农产品加工厂产量决策|Day45]] |
| 构造 + 改进 | NEH + IG | 先排出好初解，再迭代破坏-重建 | 调度类（流水车间） | [[Day47 - 置换流水车间调度FSP_NEH构造与迭代贪心IG|Day47]] |

> **选型判据**：变量**离散/序列** → ACO/GA/禁忌；变量**连续** → PSO/DE；**已有可行解**想提升 → 禁忌/IG；**对目标函数一无所知** → GA/SA 最稳。
> **论文硬要求**：任何启发式都必须给 **① 与规则解（贪心/EDD/NEH）对照 ② 多次运行的稳定性（浮动%）③ 小规模时的精确解裁判**。

### 2.3 匹配家族（配对类赛题的完整谱系）

```
二分图·最大基数  ── 匈牙利（Day22）
      │                 └─ 加权版 ──► KM（Day40）
      ├─ 理论：最大匹配 = 最小点覆盖 ── König（Day25）
      ├─ 应用到"走遍每条边" ──► CPP 奇度点最小权配对（Day41）
      └─ 升级到一般图（有奇环）──► Blossom 带花树（Day39）
偏好稳定匹配（无权重、讲公平）──► Gale-Shapley（Day24）
```

### 2.4 机器学习家族

```
无标签 ──► K-Means 聚类（Day8）── 定 K：肘部 + 轮廓
有标签 ──┬─ 惰性 ──► KNN（Day9）
         ├─ 参数化 ──► Logistic（Day10 概率）/ SVM（Day13 最大间隔）
         ├─ 树 ──► 单树 / 随机森林（Day11 Bagging 降方差）
         │          └─ GBDT（Day12 Boosting 降偏差）
         └─ 降维 ──► PCA / PCR（Day32），也服务于评价（Day20）
时间序列（无外生变量）──► ARIMA（Day46）
小样本（4~10 点、无机制）──► 灰色 GM(1,1)（Day50）⟷ 「平均增长率法」基线
过程监控（找异常）──────► SPC 控制图（Day48）
```

### 2.6 机制驱动 vs 数据驱动（两条建模哲学）

```
机制驱动：ODE / 差分方程（Day49）
             ├─ 连续时间 ──► 灵敏度 / 阈值 R0 / 决策曲线
             ├─ 离散时间差分 ──► DP 递推（Day16）= 带决策的差分方程
             └─ 随机版 SDE ──► 与两阶段 SP（Day28）/ CVaR（Day29）互补

数据驱动：ARIMA（Day46，本质是线性 ODE 的离散采样但不解释机制）
              └─ ML 家族（Day9–13、Day32）：无机制、要样本
```
> **选型口诀**：**有机制无数据 → ODE；有数据无机制 → ARIMA/ML；只有几个数 → 灰色 GM(1,1)（Day50）；都有 → ODE 定结构 + 数据反演参数（Day49 的做法）。**

### 2.5 评价家族

```
定指标 → 定权重（AHP 主观 / 熵权·CRITIC 客观 / 组合赋权）
       → 合成排序（TOPSIS 距离 / VIKOR 短板惩罚 / 灰色关联 小样本 / FCE 语言评语 / PCA 降维）
       → 必做：灵敏度分析 + 多法互证
```
