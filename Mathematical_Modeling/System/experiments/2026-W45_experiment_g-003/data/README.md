# 数据说明

- 来源：合成数据（ring+chord 结构的相关矩阵，n=10，rho=0.9，刻意构造为非正定）
- 是否为模拟数据：**是**
- 若模拟，参数如何设定：沿用 `experiments/2026-W45_math_g-001/experiment.py` 的 `ring_chord(10, 0.9)`；
  该矩阵最小特征值 < 0，保证「病态输入确实非 PSD」这个前提成立。组合收益由 Cholesky 分解生成的
  多元标准正态模拟（100,000 次），未使用任何真实收益序列。
- 为什么合成数据够用：本实验审计的是**断言设计**而非某个现实结论，
  输入只需满足「病态」这一性质。
- sha256：由 `env_record.snapshot` 自动记录（本实验无落盘 csv）
