# 数据说明（必须填写）

- 来源：**模拟/合成** —— 脚本内 `build_instance()` 按 `config.json` 的 `seed` 生成，无外部数据文件
- 是否为模拟数据：**是**
- 若模拟，参数如何设定：
  - 6 个项目 P0–P5，重量 [7,7,11,11,12,12]、价值 [16,16,7,7,7,7]
  - 强制配对 (P0,P1)/(P2,P3)/(P4,P5) 同重同价 ⇒ 每一对只能取一个时产生同价解族
  - 容量 = 30 = 每对取一个重量之和的最小值，恰好卡在「每对取一个」的边界上
  - 价值扰动扰动实验（A6/R7）把每对第二个项目的价值改为 `v_a + (k+1)`，k 为对的序号
- sha256：本实验**无数据文件**，`result.json → env.data` 为空数组（不伪造）；复现方式为重跑脚本
