## 十问

**1. 这一课解决什么决策？**
云溪县 16 个村的产业底账要分成几类、每类拿哪一套扶持政策。难点不在算法，在**「分几组」这个问法**。

**2. 为什么不能用 KMeans 直接跑？**
当「平原=1、山区=2」是编造的序关系。实测：手工编码 + z 标准化后，两两平均距离里
**分类项贡献 0.842、连续项只贡献 0.344** → 你以为在按经济水平分，实际 80% 在按地形分。

**3. Gower 距离好在哪？**
三族变量都映射到 [0,1] 再加权平均：连续 = |差|/极差；分类 = 1[不等]；有序 = 秩差/最大秩差。
**分类变量不再编序，连续变量不再吃量纲。**

**4. 为什么用 PAM 不用 KMeans？**
KMeans 的中心是虚构的「平均村」（耕地 913.3 亩、地形 0.42 平原），交付不了；
PAM 的 medoid 必须是真村，局里要的是「你拿东坪代表这一类」。

**5. 几组？**
四个口径给 **5 / 7 / 7 / 5**，都统计上说得过去 → **本讲的答案是「没有唯一答案」**，
选 k=7 并写明理由：三个单例村是决策信息，不能被并掉。

**6. 聚类比人拍脑袋强多少？**
对规则分（地形×主产业）ARI = **0.838**，置换检验 p ≈ 0.001。
但把 16% 的差异拆开看：**全部来自三个被拔出来的单例村**，不是「更聪明的分法」。

**7. 结论稳吗？**
Gower+PAM 稳定性 **0.733**，KMeans(one-hot) **0.820** —— 更「对」的距离反而更不稳，
因为 PAM 的分组里有 3 个单村簇，重抽少一个村就少一个簇。**稳定性高 ≠ 结论可靠。**

**8. 会不会被一个村绑架？**
会。剔除高岭后重解，与全样本在 15 个村上 ARI = **0.773**，桐子独立、联星被并走。
⇒ **三个「特色村」里有两个的「单例」身份不保。**

**9. $\gamma$ 怎么取？**
$\gamma=0$（丢掉分类项）轮廓掉到 0.238；$\gamma\in[1,4]$ 进平台（0.587）；$\gamma=8$ 掉到 0.479。
⇒ 结论对 $\gamma$ 在 [1,4] 稳健，**要说清是哪一段区间**，不能说「对 $\gamma$ 不敏感」。

**10. 能写进论文的一句话？**
「聚类分析的价值不在分组，在**哪几个样本不肯进任何一个组**。本模型识别出 3 个特例村，
其中 2 个的独立性在剔除任一邻居后不成立 → 建议对 3 个村做**个案**政策评估，而非按类分配。」
