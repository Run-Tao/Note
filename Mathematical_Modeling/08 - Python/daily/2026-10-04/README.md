# Day36 · 列生成法与 Dantzig-Wolfe 分解（代码）

> 教案正文见 [[Day36 - 列生成法与Dantzig-Wolfe分解]]（`04 - Optimization/`）。
> 脚本：`column_generation_cutting_stock.py`；图：`column_generation_cutting_stock.png`。

## 一句话

Day4 学了整数规划（分支定界）、Day26 学了 LP 对偶（影子价格）、
Day35 学了拉格朗日松弛（**对偶侧**把大问题裂开）——
本课补上**对偶侧方法的主原侧孪生体**：**列生成法（Column Generation）/ Dantzig-Wolfe 分解**。
当一个问题有**指数多个变量（列）**时，不预先枚举全部列，而是
"解一个只含部分列的**受限主问题 RMP** → 用对偶价向**定价子问题**要一个最该加入的新列 → 加入 → 再解"，
迭代直到没有更优的列可加（LP 达到最优），再整数化。
用「钢材厂一维下料」决策跑通全套。

## 真实决策背景

钢材厂库存里全是**同一长度的标准钢坯**（每根 $L=25$ 米），
客户下单要**一批不同长度、不同数量**的成品钢管：

- 规格 $r$：长度 $\ell_r$、需求 $d_r$ 根（本例 $[10,8,4,3]$ 米，需求 $[42,145,158,91]$）；
- 每根钢坯按某种**切割模式** $a=(a_1,\dots,a_R)$（切出规格 $r$ 共 $a_r$ 根）切割，
  须满足 $\sum_r \ell_r a_r \le L$，剩余是**废料**。

问：**怎么切，使耗用的标准钢坯总根数最少** = **一维下料问题（Cutting Stock Problem）**。

## 为什么需要列生成

两种等价建模：

- **按坯建模（item-based）**：变量 = 每根坯切出各规格数量——坯数未知、对称性极强，直接整数规划难解；
- **按模式建模（pattern-based，Gilmore–Gomory）**：
  $\min \sum_p x_p$ s.t. $\sum_p a_{rp} x_p \ge d_r,\ x_p\ge 0$ 整数，
  $x_p$ = 模式 $p$ 用几次。**每列 = 一种合法切割模式**。

**问题**：合法模式数量**指数爆炸**（本例小规模已 84 列，真实问题轻松上百万），
不可能"先枚举全部列再解 LP"。**列生成**正是为此而生——**需要哪个列就现场生成哪个列**。

## 手写实现的算法（`scipy.linprog/milp` 仅作独立对照/裁判）

- `all_patterns` / `initial_patterns`：暴力枚举全部合法模式（仅小规模对照）+ 平凡初始列；
- `solve_rmp`：解**受限主问题**（当前这批列的 LP），取出**对偶价** $y_r$（= 各规格的"边际价值"）；
- `pricing_knapsack`：**定价子问题** = **有界背包**
  $\max \sum_r y_r a_r$ s.t. $\sum_r \ell_r a_r \le L$，返回检验数 $1-\sum y_r a_r$
  （< 0 说明该列能改进 RMP）——本课用 DP 手写；
- `column_generation`：主循环——**解 RMP → 定价找新列 → 加入 → 再解**，直到无负检验数列；
- `round_up_integer`：**整数化**——LP 解向上取整成可执行方案；
- `solve_exact_milp`：`scipy.milp` 求真最优，**仅作独立对照**。

## 实测（`.venv` 真实跑通，L=25m，规格 [10,8,4,3]，需求 [42,145,158,91]）

| 口径 | 钢坯根数 | 说明 |
|---|---|---|
| 理论下界 $\lceil\sum \ell_r d_r / L\rceil$ | **100** | 总长度 2485m / 25m |
| **全枚举模式数** | **84 列** | 小规模就这么多 |
| **列生成 LP 下界** | **101.1111** | 仅用 **8 列** |
| 全列 LP 下界（对照） | 101.1111 | 与上一致（差 1.4e-14）|
| **整数最优**（`scipy.milp`） | **102** | 真最优 |
| LP 解向上取整（可行上界） | 103 | 保守整数化 |

- **列生成只用 8 列 / 全枚举 84 列（省 90%）**，却拿到**与全列 LP 完全相同的最优 LP 下界**；
- **LP 下界 101.11 < 整数最优 102**（存在 0.89 的**积分间隙**），
  **LP 最优解含 3 个"分数根数"的列**（用量 37.444 / 5.333 / 16.333 根）——不可执行，必须整数化；
- **用列生成得到的 8 列做 MILP = 全列 MILP = 102 根**——说明列生成拿到的列**足够**；
- 最终方案（4 种模式）：`(1,0,3,1)×42 + (0,3,0,0)×38 + (0,2,0,3)×17 + (0,0,6,0)×6 = 102` 根，废料极低。

## 怎么验证（七条硬约束，全部通过 ✓）

1. **列生成 LP 下界 == 全列 LP 下界**（列生成收敛到 LP 真最优，不是局部值）；
2. **LP 下界 $\le$ 整数最优**（下界性质）；
3. **列生成拿到的列做 MILP == 全列 MILP 最优**（列足够，没漏关键列）；
4. **向上取整方案可行且 $\ge$ 整数最优**（上界性质）；
5. **LP 最优解含分数根数**（LP 解不可执行，必须整数化）；
6. **列生成列数远小于全枚举**（本例 8 ≪ 84）；
7. **定价背包 DP == 同尺度暴力枚举**（20 个随机小实例，定价子问题实现正确）。

## 缺点与替代方法

- **只解 LP（对偶），整数化未必最优**：列生成解的是**主问题的 LP 松弛**，
  要拿整数解需再接**分支定价（Branch-and-Price）**，本课只做"LP 下界 + 启发式整数化"；
- **定价子问题必须解到最优**，否则可能漏列、错误收敛（下界不合法）；
- **退化/振荡**：对偶价来回摆动可能导致同一列反复被"发现"（需加扰动/稳定化）；
- **初始列必须有**（否则 RMP 不可行），本课用平凡模式；
- **替代**：直接 ILP（小规模）、拉格朗日松弛（Day35，另一侧）、
  分支定价、割平面（Cutting Planes）、商用 MILP（小规模首选）；
- **与 Day35 关系**：**列生成 = 对原问题做 Dantzig–Wolfe 分解（保整数）**，
  **拉格朗日 = 对偶侧松弛**，二者是"同一分解的两面"（定价子问题几乎相同）。

## 避坑记录（本课实测教训）

1. **教学实例必须有积分间隙，否则核心教学点落空**——初版用
   `L=20, 规格 [7,5,4,3], 需求 [80,120,90,100]`，LP 松弛**恰好整数**（91=91）、
   分数列数为 0，"必须取整""LP 只给下界"两个教学点**全部消失**；
   改用 `L=25, [10,8,4,3], [42,145,158,91]`（LP=101.11、整数=102、含 3 个分数列）后
   对比才立起来（**教学数据要刻意设计以暴露算法行为**，
   与 Day22/24/25/26/31/33/34/35 同一教训，已第 N 次复现）。
2. **"分数根数"的判定不能写 `x < 1`**——初版把"分数列"定义成 `1e-6 < x < 1`，
   于是用量 37.444、5.333 这类**大于 1 的分数列被漏掉**，报"0 个分数列"与事实相反；
   正解是**判断 `|x - round(x)| > tol`**（用量不是整数即分数列）。
3. **定价背包 DP 的长度离散必须"向上取整"（保守）**——初版用
   `int(round(长度*10))`，把 2.504m 精确成 25.0m（scale 10），
   于是 DP 认为"10 件 × 2.504=25.04m"可行（实际超长 0.04m），
   返回了**超长的非法模式**（利润 4.44 > 真最优 4.00）；
   改为 `int(ceil(...))` 后 DP 不再超填。
   **凡"离散 + 取整"的容量约束，宁可少装也不可超出**——
   这是下料/装箱/背包类算法最隐蔽的坑。
4. **验证断言本身也要"同一尺度"**——初版用连续浮点暴力枚举对照 DP，
   浮点误差让"DP 合法而暴力以为超长"，得出**假失败**；
   改为**同一整数离散尺度**的暴力对照后干净通过（与 Day35 避坑第 4 条同源）。
