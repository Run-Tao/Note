# Day 4 — 整数规划（ILP）：让"不能切半"的决策也能被优化

> 锚点：[[Learning_Roadmap|Learning Roadmap]] Level 6 · 优化模型第二课。
> 上一篇 Day3 通了线性规划 LP；但 LP 默认"决策变量可连续取值"。现实中**项目只能整投、产量只能是整数件**。今天把 LP 升级成**整数规划(ILP)**，并用 0-1 项目选择把它跑通，同时手写一遍**分支定界**看清搜索树与剪枝。

## 0. 一句话总结

LP 的直接四舍五入是错的：把松弛解的 $x_j=0.77$ 圆整后会**超预算/不可行**。整数规划用 **0-1 / 整数变量** 重新建模，`scipy.optimize.milp`（HiGHS 分支定界）一次求出**真正可落地**的最优方案——本课用"预算 100 万、6 个候选项目选投"的真实决策验证。

---

## 一、解决什么问题？（10问之1）

- 项目/投资选投、背包、选址、指派、排班、含固定成本的生产计划。
- 典型问法：*"预算 100 万，6 个项目各要钱/净收益，选哪几个使总收益最大？"*

## 二、何时用、为何适合？（10问之2、4）

- 变量须为 **整数/0-1**、目标与约束仍线性 → ILP。
- **LP 解 round 是陷阱**：圆整常不可行或次优；整数可行域是离散格点，最优不在连续顶点旁。
- 竞赛与运筹常客——选拔/投资/选址/调度；解法成熟（分支定界 + 割平面 + HiGHS）。

## 三、数学模型？（10问之3）

$$
\max \sum_j r_j\,x_j \quad \text{s.t.} \quad \sum_j c_j\,x_j \le B,\quad x_j\in\{0,1\}
$$

**逻辑约束的翻译**：至多选一 $\sum_{S}x_j\le1$；依赖"选 A 才可选 B" $x_A\le x_B$。这是 ILP 表达力的关键。

## 四、如何求解？（分支定界，10问之5）

1. 先解 **LP 松弛**得连续上界；
2. 某整数变量解出小数（如 0.77）就**分支**成 $x\le0$ 与 $x\ge1$ 两支各自再解 LP；
3. 某支上界已不优于当前整数最优 → **剪枝**整支砍掉；
4. 直到全为整数可行或剪光 → 整最优。工程上交给 `scipy.optimize.milp`(HiGHS)。

```python
from scipy.optimize import milp, LinearConstraint, Bounds
con = LinearConstraint(cost.reshape(1,-1), -np.inf, 100.0)
res = milp(c=-ret, constraints=con,            # min(-收益)
           integrality=np.ones(6),             # 全部要求整数(=0-1 via bounds)
           bounds=Bounds(0, 1))
```

## 五、结果与解读（代码实际跑通）

```
LP连续最优    = 308.5 万  (模型里"投 0.77 个项目3",现实不可行)
四舍五入 LP   → 选 {3,4}, 需 115 万  超预算 ❌ 不可行!
ILP 整数最优  = 275 万   选 {3,6} = 65+35=100 万(花满预算) ← 可落地
穷举 64 种核对一致 ✅   手写分支定界一致 ✅ (21 节点/剪 3)
整数间隙 = 308.5 − 275 = 33.5 万 (项目不可分割的代价)
```

- **LP 高估收益**(308.5>275)：33.5 万间隙正是"不可分割"的代价；
- **round 是反面教材**：松弛解圆整后超预算——对 LP 解直接 round 永远别照单全收；
- **剪枝省力气**：分支定界只探 21 个节点（剪 3 支），而不是穷举 64 个叶子全看。

## 六、如何验证？（10问之6）

- 断言 ILP=275、选 {3,6}、总成本=100≤预算；与穷举 `2^6` 交叉核对一致；
- 手写分支定界结果与 milp / 穷举三方一致。

## 七、缺点与替代？（10问之8、9）

- **NP-hard**：规模一大可能指数爆炸 → 大规模用启发式（遗传/模拟退火/禁忌，后续讲）；
- 只线性；非线性+整数组合很硬；表达力强但规模增长快；
- 纯连续线性 → 用 Day3 `linprog` 更快。

## 八、怎么写进论文？（10问之10）

符号表($x_j,c_j,r_j,B$) → 目标与约束公式(含 0-1与逻辑约束) → 求解器与算法(HiGHS 分支定界) → 结果表(LP vs ILP + 整数间隙决策意义 + 可行性核验) → 附"与穷举核对一致"增强可信度。

## 九、可迁移性（练习）

- 加"项目1与项目2至多选一""先选项目1才能选项目5"等逻辑约束看解变化；
- 把 0-1 换成"装几件"的整数背包体会 $x\in\mathbb{Z}$ 与 $\{0,1\}$ 差别；
- 对 3 项目背包手画分支定界搜索树并标剪枝支。
