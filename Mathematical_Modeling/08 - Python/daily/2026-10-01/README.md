# Day33 · 无约束非线性优化：梯度下降家族与拟牛顿法（代码）

> 教案正文见 [[Day33 - 无约束非线性优化梯度下降家族与拟牛顿法]]（`04 - Optimization/`）。
> 代码：`gradient_descent_quasi_newton.py`；图：`gradient_descent_quasi_newton.png`。

## 一句话

Day5 把 `scipy` 求解器当黑箱解 NLP——本课**打开黑箱**：
用同一个「化工厂双井工艺参数调优」决策，手写 **GD / Momentum / RMSProp / Adam / BFGS**
五类算法，回答：**收敛能差多少倍、学习率怎么定、非凸会不会陷住、拟牛顿凭什么快**。

## 真实决策背景

化工厂选 2 个连续工艺参数 $x=(c,t)$（配方浓度、反应温度）使成本最小。
成本地形是**双井非凸**（"低温低浓"浅井 = 局部最优、"高温高浓"深井 = 全局最优），
同时叠加**病态二次背景**（Hessian 条件数 ≈ 200，用来暴露"梯度下降在病态上锯齿/发散"）。
要求解 $\min_{c,t} f(c,t)$，并交代**怎么选算法、步长怎么定、会不会陷局部最优**。

## 手写实现的算法（零 `scipy.optimize`）

- `gd`：朴素梯度下降 $x \leftarrow x - \eta g$；
- `momentum`：$v \leftarrow \beta v + (1-\beta) g,\ x\leftarrow x-\eta v$；
- `rmsprop`：$s\leftarrow\beta s+(1-\beta)g^2,\ x\leftarrow x-\eta g/(\sqrt{s}+\epsilon)$；
- `adam`：一阶矩 + 二阶矩 + 偏差校正；
- `bfgs`：拟牛顿方向 $p=-Hg$ + **Armijo 回溯线搜索** + BFGS 逆 Hessian 更新
  $M=I-\rho s y^\top,\ H\leftarrow MHM^\top+\rho ss^\top$。
- **解析梯度自检**：中心差分数值梯度核对（偏差 $10^{-9}$ 级）。

## 实测（`.venv` 真实跑通）

### 实验1 · 收敛速度（同一双井地形，同一起点 (3.0, 0.0)）

| 算法 | 设置 | 进入全局最优邻域的步数 | 末点成本 |
|---|---|---|---|
| GD | lr=0.006 | **121** | −4.0134 |
| Momentum | lr=0.006 | 143 | −4.0134 |
| RMSProp | lr=0.15 | 7 | −3.96 |
| Adam | lr=0.35 | 34 | −4.0134 |
| **BFGS** | 线搜索 | **3** | **−4.0134** |

**BFGS 比朴素 GD 快约 40 倍**——不是因为每步算得多，而是它**隐式用了曲率**。

### 实验2 · 病态目标的学习率敏感性（$q=\tfrac12x_0^2+\tfrac12\cdot200\,x_1^2$）

| lr | 结果 |
|---|---|
| 0.0005 | 龟速（成本 3.33） |
| 0.002 | 成本 1.35 |
| 0.006 | 成本 0.12 |
| **0.011** | **发散!** |
| **0.02** | **发散!** |

理论稳定上限 $\text{lr}^\*<2/\lambda_{\max}=2/200=0.01$，**实测发散点与理论一致**。

### 实验3 · 非凸地形下不同起点的归宿（Adam）

| 起点 | 终点 | 成本 | 归宿 |
|---|---|---|---|
| (3.0, 0.0) | (4.80, 2.20) | −4.0134 | **全局最优** |
| (6.5, 1.0) | (4.80, 2.20) | −4.0134 | **全局最优** |
| (0.2, 2.0) | (0.86, 2.59) | 2.2898 | 局部最优（浅井） |
| (0.9, 3.4) | (0.86, 2.59) | 2.2898 | 局部最优（浅井） |

**一半起点陷进浅井**——非凸问题"收敛"≠"找到全局"。

### 实验4 · BFGS 隐式逼近 Hessian 逆

纯病态二次目标（真实 Hessian 逆对角 = $[1.0,\ 0.005]$）：
**BFGS 用 4 步**把 $H$ 对角学到 $[1.0000,\ 0.0050]$（几乎逐位吻合），
而它只用了一阶梯度。**这就是拟牛顿快的根本原因。**

## 避坑记录

1. **解析梯度必须用数值梯度自检**。优化课最隐蔽的坑就是梯度写错一个符号：
   求解器照样"收敛"，但收敛到一个错的地方、或根本不收敛。
   本课开发中一次 `grad` 少了一个负号（额外的加深项求导方向反了），
   就是靠 `assert np.allclose(解析, 数值)` 当场抓出来的——**这一步绝不能省**。
2. **病态与非凸不能混在同一个函数里教**。初版把"病态碗"和"双井"叠成一个函数，
   结果碗的最小值（中心点）直接**盖过**了两个井，所有算法都收敛到碗底、
   非凸教学点全部落空。拆成两个函数（双井讲非凸、二次讲病态）后各教学点才立起来。
   **教学函数要刻意设计以暴露算法行为**，不能只求"能跑"（与 Day22/24/25/26/31 同一教训）。
3. **`cost` 的调用签名要统一**。起手写成 `cost(x0, x1)` 又改成 `cost(x)`（最后一维为 2），
   中途漏改一处即 `TypeError`——向量化地形函数**统一约定"输入 shape (..., 2)"**最省心。
4. **BFGS 的 H 更新要防非正定**：若 $s^\top y \le 0$（线搜索没走好）就不更新，
   否则 H 会失去正定性、方向不再是下降方向。
