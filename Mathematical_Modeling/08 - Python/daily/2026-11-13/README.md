## A. 整数规划：酱菜厂「整箱接单」

### 十问

1. **解决什么问题？** 变量必须取整数（整箱/整辆/整台/整人）时的线性优化。
2. **什么时候用？** 生产批量、排班、选址、下料、装箱 —— 赛题里一半的「优化题」本质是 ILP。
3. **为什么适合？** 现实里不存在半箱；一旦整数化，可行域从多面体变成一堆孤立点，问题性质全变。
4. **数学模型？** $\max c^\top x$ s.t. $Ax\le b,\ x\ge0,\ x\in\mathbb{Z}^3$；LP 松弛 = 去掉整数那一行。
5. **怎么求解？** 小实例切片枚举（向量化，0.5 s）；中等规模 B&B + 割；本课还要**自己造一条割**。
6. **怎么实现？** 见本文「四条避坑」。
7. **怎么验证？** 5 类断言：LP 界 ≥ 整数最优、邻域全枚举一致、HiGHS 一致、间隙为正、**加割后界不得低于整数最优**且**必须严格下降**。
8. **有什么缺点？** NP-hard；间隙大小随实例剧烈变化（本例 0.023%，背包类可到 50%）。
9. **替代方法？** DP（Day16/Day56）、拉格朗日松弛（Day35）、列生成（Day36/Day65）、元启发式（Day6）。
10. **怎么进论文？** 三个数一起报（LP 界 / 整数最优 / 间隙）+ 舍入错在哪儿 + 间隙对本厂意味着什么。

### 实跑数字

| 量 | 值 |
|---|---|
| LP 松弛 | $x=(638.5522,\ 629.1246,\ 141.2458)$，$z=277{,}393.94$ |
| **整数最优** | $x=(640,623,145)$，$z=277{,}330$ |
| **整数性间隙** | **63.94 元/周（0.0231%）** |
| 裁判 | 邻域全枚举 277,330 ✔ / HiGHS MILP 277,330 ✔ |
| 四舍五入 | $x=(639,629,141)$ → **不可行**（灌装超 0.4 工分），账面 277,380（假） |
| 全向下取整 | $x=(638,629,141)$ → 277,210（最优的 99.957%） |
| 砍一刀修 | 同上 277,210 —— 「修复」连方向都找错了 |
| **割** $5(x_1+x_2+x_3)\le7040$ | LP 界 277,393.94 → **277,331.67**，间隙 63.94 → **1.67（缩 97.4%）**，$x^\ast$ 不动 |
| 敏感性 ρ=0.90~1.10 | 间隙在 **63.3~74.5 元**之间抖 → 间隙必须报区间，不是单点 |

### 四条避坑（全部实跑暴露）

1. 🔴 **126 万次 Python 双层循环 = 34 s；`np.meshgrid` 一次算完 = 0.5 s。** 枚举 10⁶ 量级先问「能不能一次算完」。
2. 🔴 **不要枚举全部整数点。** 一度想枚举 1041×1210×865 ≈ 1.1e9 个格子：`itertools.product` 跑满 5 分钟无输出；
   `np.meshgrid` 一次铺 float32 也要十几 GB，1.9 GB 的机器**直接被 OOM kill**（实测两次）。
   正解：**支撑函数只需要「上边界点」**（固定 x0,x1、x2 取最大，77.6 万点、1 秒）。
3. 🔴 **割的合法性靠构造，不靠运气**：$b=\max_{\text{整数可行点}}w^\top x$ 保证合法；LP 点是否被切是另一个问题。
   断言要**成对写**：`Z_CUT >= Z_BF`（没切掉整数点）与 `Z_CUT < Z_LP`（真的切到了 LP 点）。
4. ⚠️ **`linprog` 的 bounds 里不要混 `None` 与 `float`**：`min(bounds[i][1], v)` 遇 `None` 抛 `TypeError`；统一用 `np.inf`。

## B. 约束 QP：四校巡回排课

### 十问

1. **解决什么问题？** 凸目标 + 线性约束，**约束不改造（不罚函数），只问「每一步怎么走」**。
2. **什么时候用？** 投影做不了的可行集（最短路/匹配/流）、高维单纯形、矩阵范数球。
3. **为什么适合？** FW 每步只要一个 **LMO（线性子问题）**；线性优化在结构上几乎总有专用解法。
4. **数学模型？** $\min_P f(x)=\frac12\sum(x_i-18)^2$，$P=\{x\ge D,\ \sum x\le76,\ x_1+x_4=30\}$。
5. **怎么求解？** FW（$\gamma=2/(k+2)$，LMO 用 linprog）vs PGD（步长 $1/L$，投影用 SLSQP）。
6. **怎么实现？** LMO 必须在 **x 空间**建模（见避坑 1）。
7. **怎么验证？** KKT 复核（$\lambda_S=0,\ \lambda_G=3$）+ 两法同点 + 间隙是上界 + 顶点组合分解。
8. **有什么缺点？** FW 是 $O(1/k)$，精度高时很慢；解贴顶点、可能不唯一。
9. **替代方法？** 近端梯度、增广拉格朗日（Day35）、有效集法、ADMM。
10. **怎么进论文？** 约束表 + 解 + **KKT 乘子翻译成管理语言** + 收敛曲线 + 为什么选这条走法。

### 实跑数字

| | FW | PGD |
|---|---|---|
| 每步 | 一个 **LP** | 一个 **QP**（投影） |
| 到 $f-f^\ast\le10^{-2}$ | 11 步 | 0 步 |
| 到机器精度 | 129 步（间隙 3.6e-14） | 2 步 |
| 解 | $\tfrac13(10,26,20,20)+\tfrac14(10,14,20,20)+\tfrac5{12}(22,14,20,8)$ | 直接 $(15,18,20,15)$ |

最优 $x^\ast=(15,18,20,15)$、$f^\ast=11$；KKT：$\lambda_S=0$（**总课时 76 节没卡住，只用了 68**）、$\lambda_G=3$（公平线才是瓶颈）、
西庄被自家食堂底线顶死在 20。

公平线扫描：$h=30$（镇里口径）$f^\ast=11$；**$h=36$ 最便宜 $f^\ast=2$**；$h=42$ 之后 $f^\ast=19$ 且 $h>42$ **不可行**。

### 三条避坑

1. 🔴 **LMO 在 $z=x-D$ 空间写错**：把「各自底线」合成一个总量上界，可行域被削成小方块，
   FW **收敛得漂亮**（间隙降到 1e-14）却落到 $f=202$（真最优 68）。**只有 `FW == 精确解` 这条断言能抓。**
2. 🔴 **目标写成「越小越好」= 最优解全贴底线**：第一版 $f=\sum x_i^2$，最优就是 $D$，"公平线"永远不咬人 → 零教学点。
3. 🔴 **公平线写成 $x_4-x_1\ge D_4-D_1$** 时下界恰好是 $D$ 向量本身 → 下界与理想冲突，$f^\ast$ 被下界吸走；
   改成 $x_1+x_4=30$ 才有咬合力。
