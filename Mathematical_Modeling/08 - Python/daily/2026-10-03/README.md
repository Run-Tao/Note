# Day35 · 拉格朗日松弛与次梯度法（代码）

> 教案正文见 [[Day35 - 拉格朗日松弛与次梯度法]]（`04 - Optimization/`）。
> 脚本：`lagrangian_relaxation_subgradient.py`；图：`lagrangian_relaxation_subgradient.png`。

## 一句话

Day4 学了整数规划（分支定界），Day26 学了 LP 对偶（影子价格）——
本课把两者接起来：**当 MILP 求解器算不动时，用拉格朗日松弛让大整数规划
"自己裂开成一堆独立小背包"，用次梯度法边解边调乘子，再用贪心修复拿可行解，
下界与可行解一夹逼就得到"离真最优多远"的凭据**。
用「一批订单分给几台产能不同的机器」决策跑通全套。

## 真实决策背景

加工厂接到 **N 个订单**要在 **M 台机器**上生产：

- 订单 $i$ 交给机器 $j$：**成本** $c_{ij}$、**占用产能** $d_{ij}$（不同机器不同）；
- 每台机器产能上限 $Q_j$；每单**必须且只能**分一台机器（不拆单）。

问：**怎么分使总成本最小** = **广义指派问题 GAP**（NP-hard）。
与指派问题（Day22 匈牙利）的关键区别：**$d_{ij}$ 依赖"订单×机器"，产能约束把所有订单耦合在一起**
——不能各自挑最便宜，这正是它难、也正是适合分解的地方。

## 手写实现的算法（`scipy.linprog/milp` 仅作独立对照/裁判）

- `knapsack_01`：标准 **0-1 背包 DP**（带回溯）——这是分解后的**子问题核心**；
- `lagrangian_subproblem`：**松弛"每单恰好一次"约束** → 分解为 **M 个独立 0-1 背包**
  （机器 $j$ 挑"净收益 $u_i-c_{ij}$"最大的订单、不超产能），返回 $L(u)$、松弛解 $x$、次梯度 $g$；
- `subgradient_lr`：**次梯度法** $\max_u L(u)$，两版步长：
  **变体 A** $t_0/\sqrt{k}$（盲跑，无需 UB）+ **变体 B** Polyak $t=\beta(UB-L)/\|g\|^2$（需上界）；
- `make_feasible`：**贪心修复**——把松弛解修成合法分配（超产能改派、漏单补塞），给可行解/上界；
- `lp_relaxation_bound` / `exact_gap`：`scipy.linprog` 求 LP 松弛下界、`scipy.milp` 求真最优，**仅作对照**。

## 实测（`.venv` 真实跑通，M=6、N=22，产能/需求≈1.22）

| 口径 | 成本（元） | 相对真最优 |
|---|---|---|
| **LP 松弛下界**（松整数） | **246.74** | 低 **7.0%**（积分间隙）|
| **拉格朗日下界**（变体 A 盲跑 $t_0/\sqrt{k}$）| **262.82** | 低 **0.98%** |
| **拉格朗日下界**（变体 B Polyak）| 261.98 | 低 1.30% |
| **MILP 真最优**（`scipy.milp`）| **265.43** | — |
| **可行解**（贪心修复上界）| 271.78 | 高 2.39% |

- **LP 松弛解有 8 个"半个订单"的分数分量**——不可执行，故必须整数方法；
- **拉格朗日把 LP 下界从距真最优 18.69 元抬到 2.61 元**（**积分间隙 7.0% → 1.0%**）；
- **真最优被夹逼在 $[262.82,\ 271.78]$ 内**（宽度仅 3.4%）；
- 最优乘子 $u_i^*$ = 每个订单的"**指派影子价**"（贵的/难派的订单更高）。

## 怎么验证（六条硬约束，全部通过 ✓）

1. **LP 松弛 ≤ 真最优**（下界），且**存在积分间隙**（LP 解是分数假解）；
2. **拉格朗日下界 ≤ 真最优**（弱对偶定理）；
3. **拉格朗日对偶间隙 0.98% < 5%**（下界够紧）；
4. **可行上界 ≥ 真最优**，且 **$[$下界,上界$]$ 夹住真最优**；
5. **拉格朗日下界 > LP 松弛下界**（LR 确实更紧）；
6. **背包分解子问题 DP == 暴力枚举**（松弛确实裂成了独立小背包）。

## 缺点与替代方法

- **对偶间隙一般非零**（整性所致），只有子问题具整数多面体性时才紧；
- **次梯度法不保证单调收敛**、步长敏感（$\beta$/$t_0$ 需调）；
- **Polyak 需先有上界**（靠启发式构造可行解）；
- **子问题必须精确解**，否则下界不再是合法下界（危险）；
- **替代**：分支定界（Day4）、割平面、列生成、Benders 分解、商用 MILP（小规模首选）；
- **与 LP 松弛关系**：LR 下界 ≥ LP 松弛下界；LP 本身很紧时，LR 的意义在**分解与规模**。

## 避坑记录（本课实测教训）

1. **松弛对象选错，整门方法就废了**——初版**松弛产能约束**、在子问题里保留"每单恰好一次"，
   结果子问题退化成"每单独立挑一台机器"，$L(u)$ 随 $u$ 增大**单调下降**、
   最优值恒为 0（数学上等价于"松弛了个寂寞"）。
   **正解：松弛"指派/覆盖"约束**，才能让子问题裂成 M 个独立背包——
   **"松弛哪条约束"决定"能不能分解 + 下界紧不紧"，这是拉格朗日松弛的第一决策。**
2. **乘子初始化不能拍 0**——$u=0$ 时背包净收益全为负 → 松弛解 $x=0$，
   若乘子还被非负投影（松弛不等式时）会**永久卡死在 0**、下界恒 0。
   乘子初值应取在**有意义的量级**（本课用平均成本 $\bar c$）。
3. **教学实例要"有积分间隙"才有对比**——初版实例的 LP 松弛恰好整数
   （LP 下界 = 真最优），"LP 松弛 vs 拉格朗日"这个核心教学点直接落空；
   压紧产能（cap_ratio 1.30→1.05）后 LP 间隙升到 **7.0%**、
   拉格朗日补到 **1.0%**，对比才立起来
   （**教学数据要刻意设计以暴露算法行为**，与 Day22/24/25/26/31/33/34 同一教训）。
4. **暴力枚举校验要选对规模**——初版用 N=22 的背包做"DP vs 暴力"断言，
   $2^{22}$ 组合 + 浮点比较导致断言误报；改为**专门的小规模随机背包**（6 件）做交叉验证，
   干净且可靠（**验证断言本身也要"可验证"**）。
