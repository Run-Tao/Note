# Day40 · 最大权匹配（KM 算法）（代码）

> 教案正文见 [[Day40 - 最大权匹配KM算法与人员任务最优配对]]（`04 - Optimization/`）。
> 脚本：`kuhn_munkres_weighted_matching.py`；图：`kuhn_munkres_weighted_matching.png`。

## 一句话

Day22 的匈牙利法解的是「**最多配几对**」（最大**基数**匹配）；一旦给边加上**权重**，
问题就变成「**配得多值钱**」（最大**权**匹配 / 指派问题）。本课全手写 **KM 算法
（Kuhn-Munkres，匈牙利法的加权版）**：把收益表翻译成一组**对偶势** $u_i,v_j$，
在「紧边」构成的相等子图里找增广路，找不到就整体调价（收紧 $\delta$），
匹配一完美即全局最优——用「调价」代替「试错」。

## 真实决策背景

某咨询公司接到 **6 个项目**，要派 **6 名顾问**各自认领 1 个（一人一项、一项一人）。
每个顾问做每个项目的预期创收不同，怎么派总创收最大？

模型（指派问题 / 最大权完美匹配）：

$$
\max\ \sum_{i=1}^{n}\sum_{j=1}^{n} w_{ij}\,x_{ij}
\quad\text{s.t.}\quad
\sum_{j}x_{ij}=1\ \forall i,\quad
\sum_{i}x_{ij}=1\ \forall j,\quad
x_{ij}\in\{0,1\}.
$$

实例：$n=6$，收益矩阵刻意让**全局最高格（顾问3→项目0，87）是个陷阱**——
贪心会先抢它，却锁死两位强顾问，导致总收益大跌。

## 为什么不能贪心、也不能直接套匈牙利

- **贪心**「每次抢当前最大收益」只顾一步，不回头 → 本例比最优**少赚 24.6%**；
- Day22 **匈牙利法**只解等权（每条边权重都是 1）的**基数**匹配，
  「尽量多配」的判据在权重进来后就失效了；
- 权重版的正确工具是 **KM 算法**，它的灵魂是对偶。

## KM 的灵魂：对偶势 + 相等子图

> 引入行势 $u_i$、列势 $v_j$，维持 $u_i+v_j\ge w_{ij}$（**对偶可行**）；
> 取等号的边叫**紧边**。在只由紧边构成的**相等子图**里求完美匹配——
> 一旦求得，由**弱对偶定理**（任何匹配权重 $\le$ 任何对偶可行势之和，取等即最优）
> 立刻知道它就是**全局最优**。找不到完美匹配时，给树上行的势 $+\delta$、
> 树上列的势 $-\delta$（$\delta=\min$ 松弛量），把至少一条松边推成紧边，扩张相等子图。

复杂度 $O(n^3)$，与 Day22 匈牙利同阶，只是多了一层权重与势。

## 关键运行结果（`.venv` 实跑）

```
顾问 6 名 / 项目 6 个

[KM 算法] 最优总收益 = 456.0
    顾问0 → 项目2（79）  顾问1 → 项目3（70）
    顾问2 → 项目0（84）  顾问3 → 项目5（83）
    顾问4 → 项目4（63）  顾问5 → 项目1（77）
[暴力枚举裁判] 最优总收益 = 456.0          # 与 KM 完全一致
[贪心对照]    总收益 = 344.0（比最优少 112，−24.6%）
[随机压力测试] 50/50 张随机图 KM == 暴力真最优
```

**⭐ KM 456.0 == 暴力真最优 456.0；贪心 344.0，少赚 112（−24.6%）。**

## 断言（全部通过）

- KM 总收益 == 暴力枚举（$6!=720$ 种排列）真最优；
- 完美匹配：一人一项、一项一人；
- 对偶可行：$-u_i-v_j \ge -w_{ij}$（在最小化 $-w$ 上的对偶可行）；
- 贪心 ≤ 最优，且贪心也是合法完美匹配；
- 50 张随机图 KM == 暴力真最优，全部一致。

## 避坑记录（本课经验）

1. **最大化 ≠ 直接用最小化版本的公式**：初版把 e-maxx 的最小化 KM 直接套在
   `w` 上（只把 `cur = w-u-v` 当松弛），对「最高收益不在对角侧」的矩阵会**漏最优**
   （500 张随机图只对 437 张）。正解：**在 `-w` 上跑标准最小化 KM**，结果取负。
2. **KM 标准实现要求代价非负**（初始 $u=v=0$ 才可行）——本课收益全为正，取负后满足；
   若收益含负值需先整体平移使最小元 ≥ 0。
3. **无限循环排查靠「加步数上限 + trace」**：初版回溯 `while j0` 链因 `way` 指针
   构成环而空转，定位后用标准 e-maxx 回溯（`p[j0]=p[j1]; j0=j1`）修正。
4. **教学实例要刻意种下「贪心陷阱」**：把全局最高格放在一个会锁死两位强顾问的位置，
   贪心差距拉到 **24.6%**，教学点才立起来
   （与 Day22/24/25/26/35/36/37/38/39 同一教训，第 N 次复现）。
5. **独立裁判必须真独立**：暴力枚举 $n!$ + **50 张随机图压力测试**双保险
   （与 Day21/22/35/38/39 同一做法）。
6. **图输出路径用 `__file__` 锚定**（参照 Day36/37/38/39）。
