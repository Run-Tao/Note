# Day34 · 约束非线性优化：KKT、罚函数法与对数障碍内点法（代码）

> 教案正文见 [[Day34 - 约束非线性优化罚函数与内点法]]（`04 - Optimization/`）。
> 代码：`constrained_nlp_penalty_barrier.py`；图：`constrained_nlp_penalty_barrier.png`。

## 一句话

Day33 讲透了**无约束**非线性优化、Day5 把 `scipy` 求解器当黑箱解 NLP——
本课打开**第二个黑箱**：用同一道「三作物种植面积」决策，手写**罚函数法（外点）**与
**对数障碍内点法**，并用 **KKT 条件 + 影子价格 + 独立求解器 SLSQP** 三重交叉验证，
回答：**约束下最优解长什么样、为什么卡边界、约束值多少钱、机器怎么逼出解**。

## 真实决策背景

农产品贸易商决定三种作物的种植面积 $x=(x_1,x_2,x_3)$（亩），目标是最小化「机会成本」（等价于利润最大）。
利润含**规模效应二次项**（种得越多单位利润递减），约束是**非线性**的：

- 目标：$\min_x\ f(x)=-\sum_i(\text{price}_i x_i-\text{scale}_i x_i^2)$（凸二次）；
- **土地约束**：$\sum_i x_i\le 50$（线性）；
- **用水约束**：$\sum_i w_i x_i^2\le 450$（**非线性**，边际耗水递增——这是"为什么不能用 LP"的建模依据）；
- 面积非负：$x\ge 0$。

参数：price = [120, 95, 140]，scale = [1.1, 1.5, 0.9]，w = [0.35, 0.6, 0.45]。
（数据经**刻意设计**使土地与用水在最优处**同时卡脖子**——否则互补松弛/影子价格两个教学点会落空。）

## 手写实现的算法（`scipy.optimize` 仅作独立对照）

- `f / grad_f / g / grad_g`：目标、约束及**解析梯度/雅可比**（数值梯度自检，偏差 < 1e-6）；
- `_bfgs_inner`：手写 BFGS（同 Day33）——用于**罚函数**子问题的内层求解；
- `penalty_method`：$\min f+\rho\sum\max(0,g)^2$，$\rho$ 倍增 $1\to10^6$；
- `log_barrier_method`：$\min f-t\sum\log(-g)$，$t$ 缩减 $10\to0.01$；
  **手写"可行起点 + 自适应步长梯度下降"**，只接受严格可行且下降的步 → 全程留在域内（内点法核心保证）；
- `sp_minimize(..., method='SLSQP')`：独立求解器，**只用于验证**，不作教学主体。

## 实测（`.venv` 真实跑通）

### 实验1 · 无约束（贪心）解 vs 带约束最优

| 方案 | $x_1$ | $x_2$ | $x_3$ | 目标 $f$ | 约束 |
|---|---|---|---|---|---|
| **无约束（贪心）** | 54.55 | 31.67 | 77.78 | −20267 | **土地超 114、用水超 3915（严重不可行）** |
| **罚函数（外点）** | **17.347** | **5.800** | **26.853** | **−5361.62** | 可行 |
| **对数障碍（内点）** | 17.344 | 5.802 | 26.854 | −5361.60 | 可行（严格内点逼近） |
| SLSQP（独立对照） | 17.347 | 5.800 | 26.853 | −5361.620 | 可行 |

**约束把贪心解狠狠顶回可行域**——无约束最优点严重违反土地/用水，根本不可执行。

### 实验2 · 影子价格（KKT 乘子 + 实测放宽）

罚函数解处 **土地与用水两个约束同时紧**（$g_1=g_2=0$），非负约束全松：

| 约束 | 状态 | KKT 乘子 $\mu$ | 实测：放宽 1 单位目标改善 |
|---|---|---|---|
| 土地 | **紧** | **71.91** | **+68.80** |
| 用水 | **紧** | **0.82** | **+0.81** |
| $x_1,x_2,x_3\ge0$ | 松 | 0 | 0 |

**平稳性残差 $\|\nabla f+\sum\mu_i\nabla g_i\|=$ 9.9e-10**（数值零）✓；
**互补松弛**：紧约束 $\mu>0$、松约束 $\mu=0$ 逐项成立 ✓。
> **要点**：土地最值钱（多 1 亩净赚 68.8），用水也很值钱但稍逊（+0.81）——
> 这就是"**该先松哪个约束**"的排行榜，与 Day26 LP 影子价格同源（非线性推广）。

### 实验3 · 两种外部逼近：从外 vs 从内

**罚函数（外点）**：$\rho$ 小 → 解**违反约束**（max_g=+4.17），$\rho$ 倍增至 $10^6$ → 违反量 **单调降到 3.6e-5**、收敛到最优。
**对数障碍（内点）**：$t$ 从 10 降到 0.01 → 到边界的距离 **从 −0.141 单调收到 −1.4e-4**（始终在域内，max_g<0）。

> **要点**：两法**从外、从内两个方向包抄同一个 KKT 点**——罚函数"先犯规再纠偏"、
> 障碍法"贴着墙根走"；实测二者一致（最大分量差 **2.9e-3**），且都 ≈ SLSQP。

## 怎么验证（四条硬约束，全部通过 ✓）

1. **解析梯度 == 数值梯度**（目标 & 约束雅可比，偏差 < 1e-6）；
2. **KKT 平稳性残差 ≈ 0**（9.9e-10）+ **互补松弛**逐项成立；
3. **两法一致**：罚函数 vs 对数障碍解差 2.9e-3，且都 ≈ SLSQP（差 3.7e-5 / 2.9e-3）；
4. **影子价格可实测**：放宽约束实测改善量 ≈ KKT 乘子。

## 缺点与替代方法

- **罚函数**：$\rho\to\infty$ 引发**病态**（条件数随 $\rho$ 增）；且解只在极限处可行；
- **对数障碍**：要求严格内点（Slater），初始必须可行，边界解只能"逼近"；
- **KKT 仅必要**（非凸下只是驻点）——非凸仍靠多起点（Day33）；
- **SQP / 内点法**是工业默认（`scipy` SLSQP、IPOPT、KNITRO），二阶收敛但要解 QP/线性系统；
- 约束含**整数/组合**时（Day4 ILP）只能分支定界，不能直接套 KKT。

## 避坑记录（本课实测教训）

1. **纯投影梯度当内层求解器会卡在次优解**——初版罚函数/障碍子问题用手写投影梯度 + 固定 lr，
   结果罚函数收敛到只卡土地、用水松的**次优点**（x₂≈12，而真解 x₂≈5.8），
   与 SLSQP 差 27！改为**手写 BFGS**（罚函数）+ **可行起点自适应梯度**（障碍）后，
   两法分别精确到 3.7e-5 / 2.9e-3。**内层子问题的求解器选择决定整门方法成败**。
2. **对数障碍的障碍项在域外无定义（log 负数）**——若内层用"无约束 BFGS"直接冲出去会得 NaN；
   必须用**只接受严格可行步**的线搜索（本课最终做法），否则算法会散架。
3. **教学数据必须让两个约束在最优处同时紧**——初版用水上限给太松（1000），
   最优只卡土地，影子价格/互补松弛两个教学点全部落空；把用水上限压到 450 后两约束同时紧，
   教学点才立起来（**教学数据要刻意设计以暴露算法行为**，与 Day22/24/25/26/31/33 同一教训）。
4. **解析梯度必用数值梯度自检**——优化课最隐蔽的坑是"梯度写错一个符号、求解器照样跑但结果从根上错"。
