# Day 8 — 电商/零售选址：把"客流散点"切成 K 个片区开 K 家店（K-Means 聚类）

> 锚点：[[Learning_Roadmap|Learning Roadmap]] Level 8 · 数据分析与机器学习 / 无监督聚类。
> 前面 Day3–7 都在优化与启发式里打转(把决策"求到最优/很好")。这一课换赛道到**机器学习的第一类——无监督聚类**：没有人给你答案标签，只有一堆"客流点位"，要你自己发现"这里其实有几坨人"。用"300 个潜在客流点在新区散布，到底开几家店、各家开哪、各覆盖哪些点"跑通。开几家不是拍脑袋——用 **肘部法 + 轮廓系数** 告诉你"数据自己说 3 家最合适"。

## 0. 一句话总结

聚类 = **无监督**：输入只有 $n$ 个样本(客流点)的坐标，没有"该属哪簇"的标签，目标是把相似样本自动归成 $k$ 簇。**K-Means** 是其中最经典的迭代算法，交替做两步直到收敛：①分配(每个点归到最近质心) → ②更新(每簇质心取均值)。在散点坐标上它能自然把多中心的客流切成簇，**簇的质心就是"开店位置"**。关键难点是 **$k$ 怎么定**——用肘部法(SSE 曲线拐弯处)+ 轮廓系数(峰值)交叉验证，本数据二者都指向 $k=3$：开 **3 家店**最好，再多就是过度切分。

---

## 一、这个方法解决什么问题？（10问之1）

**决策对象是一堆没有标签的样本，要按"相似度"自动分组**：

- **选址/分区**：几百个潜在客流/收货点散布在城市，开 k 家店/仓库怎么就近各管一片（本课）；
- **客群画像**：用户按消费金额、频次分群，好针对不同群做不同运营；
- **异常检测前置**、**图像压缩**(把像素颜色聚成 k 类)、**降维可视化**的分组底色；
- 地理/营业点/商品 SKU 的"自然有几类"。

典型问法：*"我们收集了新区 300 个潜在客群的坐标(热度+距离)，准备开几家连锁店，每家服务就近的一批人，问：开几家?各开在哪?"* —— 这就是**把连续散点聚类成 k 簇，每簇质心≈店址**。

## 二、什么情况该用它、为什么适合？（10问之2、4）

- **没有标准答案标签**(不知道谁该归哪)——有标签的分类是 **KNN/监督**(本课只说簇)；
- **想先"看数据本来长什么样"**：有几坨、边界在哪、中心在哪，聚类是最自然的探索工具；
- **选址要"就近覆盖"**：K-Means 用欧氏距离就近归簇，质心天然是"到本簇所有点距离平方和最小"的点 → 数学上正对"开在客流重心"；
- 若数据**有椭圆/流形/重叠严重的结构** → K-Means(硬圆形簇)会切错，改 **GMM(高斯混合,软簇)/DBSCAN(任意形状)**；
- 若目标是"预测某个离散标签" → 这时才用**监督分类(KNN)**。

## 三、数学模型是什么？（10问之3）

给 $n$ 个样本 $\{x_1,\dots,x_n\}\subset\mathbb{R}^d$ 与指定簇数 $k$，找**划分 $C_1,\dots,C_k$** 与**质心 $\{\mu_1,\dots,\mu_k\}$** 使"组内平方和 SSE"最小(k-means = 找 k 个质心,每点归最近并最小化总距离²)：

$$
\min_{\{\mu_j\},\{C_j\}}\; \sum_{j=1}^{k}\sum_{x_i\in C_j}\lVert x_i-\mu_j\rVert^2
$$

这是 **NP-hard** 的离散+连续混合问题，但 **K-Means 的交替坐标下降**(Lloyd 算法)能高效找到极好的**局部最优**：

1. **分配步**：每个点归到"距离最近"的质心 → $C_j=\{x_i:\lVert x_i-\mu_j\rVert^2 \text{ 最小}\}$；
2. **更新步**：把质心移到本簇点的均值 → $\mu_j=\frac{1}{|C_j|}\sum_{x_i\in C_j}x_i$；
3. 重复到质心几乎不动(收敛)。

一轮只降 SSE 不升，故必收敛；但**结果依赖初值**，所以工程上**多随机初值跑多次取最好**。

**怎么定 $k$（本课核心算法问题）**：
- **肘部法**：画 SSE vs $k$，在"下降骤缓的拐点"取 $k$——到某点后多加一簇只换来微小改进，不值得；
- **轮廓系数 Silhouette** $s_i=\frac{b_i-a_i}{\max(a_i,b_i)}$($a_i$=到同簇平均距,$b_i$=到最近邻簇平均距)，$s\!\in\![-1,1]$，**越近 1 簇越清晰**；对每个 $k$ 求全体均值，**峰值处是最佳 $k$**。

## 四、如何求解？（10问之5）

手写三步对 sklearn 的 `KMeans` 是**同一套 Lloyd 算法**，可互相印证：

```python
# 手写核心(分配→更新循环)
for _ in range(iters):
    dist = ((X[:,None,:]-C[None,:,:])**2).sum(-1)   # (n,k) 距离矩阵
    lab  = dist.argmin(1)                            # 分配: 归最近质心
    C    = np.array([X[lab==j].mean(0)              # 更新: 簇内均值
                     if (lab==j).any() else C[j] for j in range(k)])
    if np.allclose(C_old, C, atol=1e-8): break       # 收敛即停
```

要诀：**初值不要全随机**(改 **k-means++**：离已选质心越远的点越可能被选中当下一质心，收敛更稳更快)；每轮检查空簇兜底；**多次随机跑取 SSE 最小**。

定 $k$ 用标准库：
```python
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score
lab = KMeans(n_clusters=3, n_init=20, random_state=0).fit_predict(X)
print(silhouette_score(X, lab))
```

## 五、结果与解读（代码实际跑通输出）

300 客流点、3 个人口高斯热区"真身"埋在里面(数据造得就像零售选址背景)：

```
肘部法(SSE 随店数 k):  k=2→49340  k=3→10535  k=4→8850 ...(3 之后降幅骤缓)
轮廓系数:  k=2=0.660  k=3=0.769  k=4=0.620  k=5=0.483 ...(3 是峰值)
[手写 vs sklearn] k=3 指派一致率 = 100.0%, SSE 两边都 = 10535.2
选址决策:  片区A 100 点 →店(20.1,15.6)  片区C 101 点→店(54.7,45.0)  片区B 99 点→店(59.0,17.5)
```

**怎么读(结果解释)：**
1. **"开几家"有据可依**：SSE 拐在 $k=3$、轮廓系数也峰在 $k=3(0.769)$——**两个准则一致说 3 家**，不是拍脑袋。开 2 家(0.660)说明某批离得远的人被硬凑一簇(轮廓掉)、开 4 家(0.620)则把本是一坨的客流硬拆散(过拟合式切分)，都不如 3 清晰；
2. **店开在客流重心**：三个质心 ≈ 三坨客流的中心（坐标上 ≈20/55/59 两列、上下两排），正是"就近覆盖"，每家约服务 100 人、规模均衡；
3. **手写=标准库**：指派 100% 一致、SSE 一样——**手写版本没写错**、可放心用于教学/讲清原理，生产直接用 sklearn(更快更稳)即可；
4. **无监督的价值**：整个流程没给过一个"正确分组"标签，簇与 k 全是从数据自己长出来的——它回答的是"数据说了算"的一类问题。

图：`kmeans_elbow_clusters.png` —— 左图 300 散点按簇着色 + ★黄心标开店点；右图 SSE 肘部曲线(红虚线标 k=3)+ 绿色轮廓系数副轴，一眼看两准则共同指向 3。

## 六、如何验证？（10问之6）

- **与标准库对照**：手写与 sklearn `KMeans` 在同 k 下**指派一致率≥99%、SSE 几乎相等** → 手写实现正确；
- **合法性断言**：恰产生 $k$ 个非空簇、质心形状 $(k,2)$；
- **方法间交叉**：**肘部法与轮廓系数都要指向同一 $k$**（本课都=3），避免单准则误判；
- 可视化自检：散点着色无交错串簇、质心落在各坨中心；
- 稳健性(练习可做)：换不同 `random_state` 与簇数，看肘部与轮廓结论是否稳定。

## 七、缺点与替代？（10问之8、9）

- **假设"簇是凸/圆形/大小相近"**：细长条、嵌套圆、密度不均会被切错 → 换 **DBSCAN(密度,任意形状、自动定簇数)或 GMM(椭圆协方差、软簇)**；
- **对初值敏感 / 可能局部最优**：需 k-means++ + 多次重启取 SSE 最小；
- **$k$ 仍然要你选**：肘部/轮廓给的是"启发式建议"，不是硬定理；数据若本来无簇(均匀散点)，任何 k 都牵强；
- 对**离群点**敏感：单个很远点会"拽"质心 → 先清洗或改中心点聚类 K-medoids；
- 若是有标签分类问题 → 用**KNN(监督)**，那属于下一课。

## 八、怎么写进论文？（10问之10）

- 问题层：无监督、无标签、想按相似度分组(结合选址背景)；
- 方法层：给目标(最小 SSE)+ Lloyd 两步伪代码 + "k-means++ 初始化、多重启";
- **选择 $k$ 的证据**：肘部图 + 轮廓系数表，说明为何取 3；
- 结果层：簇数、各簇规模与质心坐标(即店址)、着色图;
- 可信层：手写与 sklearn 一致率/SSE 对照表，证明实现与结论可靠;
- 讨论层：不同 k、不同 init 的稳定性;与 DBSCAN 比在该图景孰优(能写一句"圆形簇假设成立时 K-Means 合适")。

## 九、可迁移性（练习）

- 换 `DBSCAN(eps, min_samples)` 跑同一数据，比较它"自己要几坨"与 K-Means 的 3 之差；
