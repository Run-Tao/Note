## 十问

**1. 这一课解决什么决策？**
云溪县 2027 年社区养老服务站：3 个站已定，问**责任片怎么划、边界设在哪、哪些片区两站都不认**。
现行划法是「沿江一刀 + 河西再一刀」。

**2. 为什么不能用 KMeans / Ward？**
它们只看直线距离。南坡安置离谁都不近 → KMeans 把它切成**单点片**（8/1/9），
而它在「探视/串门」图上是**孤立点**：离得远 ≠ 走得远，**没有来往 ≠ 有关系**。

**3. 图怎么建？**
18 个片区为节点，**互近邻（mutual kNN，k=5）**连边，边权 $w=1/(1+d)$。全图 34 条边。
互近邻的意义：只有**双方**都认对方是近邻才连，把「单向热脸」的边剪掉。

**4. Ncut 和 Min-Cut 差在哪？**
Ncut 的每一项除以 $\mathrm{vol}(A)$（这片总来往量）。Min-Cut 会为了省一条边把**小池子**割出去（割一条边就省一大块），
Ncut 不允许 —— 小片割一条边比分母都大，代价立刻爆表。

**5. 结果是什么？**
片1 河东（7 片区，5 480 人）/ 片2 河西中段（6，3 970）/ 片3 河西老街（3，2 960）；
北岭、南坡**未入图**，走个案。
跨片 7 条边，全在河西内部；**唯一那条过江桥（铁路南—河东南苑 2.12 km）没被切**。

**6. 和手工划法比？**
同一个 Ncut 目标：手工「两刀切地图」0.8018，谱聚类 **0.7543（−5.9%）**，ARI 0.7592。
差异只在**河西老街怎么分** —— 手工切法把文昌巷（老城中心）划去了「过江带」。
⇒ 报告要写的是「边界从 x=1.4 挪到巷口」，不是「谱聚类更好」。

**7. 稳不稳？**
k=5 时半径 1.8/2.0/不设 → ARI 0.86/0.86/1.00（**半径不是旋钮**）；
k=6/7 → 0.86/0.72（结论范围 **k=5~6**）；
坐标 ±60 m 抖动 100 次 → 中位 1.000、89 次完全一致。

**8. 换图会怎样？**
RBF 全连接（153 条边）→ **ARI 0.55**，断层被填平；单向 kNN（56 条）→ 0.71。
⇒ **谱聚类的结论强度 = 对图的假设的强度**。图错了，谱方法给你一个又快又准的错答案。

**9. 本征间隙能定 k 吗？**
不能。本征值 `0, 0.027, 0.476, 0.613, …`，最大间隙在 2→3（0.449）⇒ 间隙说 k=2；站要 3；孤立点再算两块是 4。
**间隙回答「图里有几块天然断开」，不回答「我要几个站」。**

**10. 能写进论文的一句话？**
「以互近邻图（k=5，34 条边）为输入，归一化割谱聚类给出三片（Ncut 0.754）；
相较现行两刀切法（0.802）改善 5.9%，差异集中于河西老街的归属；
对近邻数 k=5~6 稳健（ARI ≥ 0.86），对**图的定义**不稳健（RBF 全连接下 ARI 0.55），
故『串门为本地行为』这一前提须由入户调查核实；
两个安置点在图中无邻居，不参与聚类，另立个案服务。」

## 避坑（4 条，全部实跑暴露）

1. 🔴 **度 0 孤立点 → `1/√0 = inf` → 特征向量 NaN → k-means 抛 `Input X contains NaN`**。修法：只对非孤立点取子矩阵 + `keep` 掩码。
2. 🔴 **孤立点混进去不报错**：k-means 把它随手丢进某片，片规模从 3 变成 5，**静默污染**。
3. ⚠ **假旋钮**：邻域半径加与不加结论几乎一样（互近邻已剪过一遍了）。不起作用的参数写进敏感性分析就是凑数。
4. 🔴 **假胜利**：第一版手工切法实际切了 3 刀（比 Ncut 多一刀），Ncut 显得赢 23%；改成「两刀」后是 5.9%。
   **给对照方法设不公平的基线，是自己骗自己。**
