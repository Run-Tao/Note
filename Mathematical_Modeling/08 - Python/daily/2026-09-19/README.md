## 决策背景

同一道"**4 座候选城市落户选址**"（与 Day15 同题，便于横向对照），5 个指标：

| 指标 | 方向 | 甲 | 乙 | 丙 | 丁 |
|---|---|---|---|---|---|
| 人才供给 | 效益+ | 8.0 | 6.5 | 7.0 | 7.5 |
| 生活成本 | 成本− | 7.5 | 6.0 | 9.0 | 8.0 |
| 政策补贴 | 效益+ | 6.0 | 8.5 | 7.0 | 7.5 |
| 交通枢纽 | 效益+ | 7.0 | 6.0 | 8.0 | 9.0 |
| 市场潜力 | 效益+ | 9.0 | 6.5 | 7.5 | 7.0 |

## 运行结果（.venv 实测）

- **AHP**：λmax=5.0331、CI=0.0083、**CR=0.0074 < 0.1 通过一致性**；权重 人才 0.3760 > 生活成本 0.2147 = 市场 0.2147 > 政策 0.1209 > 交通 0.0738。
- **熵权**：市场潜力 0.2450 最高（数据区分度最大）、政策补贴 0.1798 最低；与 AHP 明显不同——**"数据里的区分度" ≠ "专家眼里的重要性"**。
- **组合赋权**：线性(α=0.5) 人才 0.2825 / 市场 0.2298 / 成本 0.2060 / 政策 0.1503 / 交通 0.1314；乘法归一更"偏袒"主观权重（人才 0.3523）。
- **VIKOR**：群体效用 S、个体遗憾 R、折中 Q。**v=0.5 时 Q：甲 0.0000 < 丁 0.3337 < 丙 0.7105 < 乙 0.9654**，妥协解 = 城市甲。
- **灰色关联**：甲 0.7217 > 乙 0.5709 > 丁 0.5611 > 丙 0.4414，最推荐城市甲。
- **四法冠军一致 = 城市甲**；第 2–3 名有分歧（TOPSIS：丁>乙>丙；VIKOR：丁>丙>乙；GRA：乙>丁>丙）——这正是三种"口径"的差异所在。
- **敏感性**（权重 ±50% 扰动 2000 次）：夺冠频率 **GRA 96.2% > VIKOR 86.5% > TOPSIS 78.5%**，城市甲在三种方法下均稳居第一。
- 断言全过：权重和为 1、CR<0.1、Z∈[0,1]、Q∈[0,1] 且端点取到 1、关联度∈(0,1]、冠军一致性检查、敏感性计数守恒。

## 三个递进问题（本课主线）

1. **权重到底怎么定？** → 主客观各有权重后，用**线性加权合成**（可调 α，直观可控）或**乘法归一合成**（主客观"共识"才凸显）把两套权重并成一套。
2. **只认"离理想解最近"够吗？** → 不够。TOPSIS 会牺牲"短板极狠"的方案敏感性；**VIKOR 同时最小化群体效用 S 与个体遗憾 R**，再用折中系数 v 决定"重群体效益"还是"重个体公平"。
3. **数据少、信息不完整时排序稳不稳？** → **灰色关联分析(GRA)** 用参考序列 + 灰色关联系数 ρ(分辨系数) 度量"曲线形状相似度"，对样本量小、信息不完全最友好。

## 结论

主客观组合赋权 + 三法交叉验证，给出 **"城市甲"最推荐** 且稳健（GRA 夺冠率 96%）。这也示范了论文里的正确姿势：**别只报一个排名，要报多个方法一致 / 分歧 + 权重敏感性**，才能回答"这个结论凭什么是可靠的"。
