## 十问（按 `README` 的「10 问」组织）

### 1. 这个问题解决什么决策
云溪县农资公司 2027 年春耕「0 号复合肥」县级中心仓：**8 周一个订货季，提前期 1 周，整箱 20 吨**。
库管每周被问两句话：**「现在要不要下单」**、**「一次下多少」**。这两句话看起来是一个问题，
其实是两个 —— 一讲的核心就是把它们拆开。

### 2. 什么情况下该用
需求随机、可以补货（不是一次性备货）、补货要花钱等、卖不掉能存、缺了会赔。
国内赛题里对应：**农资/药品/备件中心仓、应急物资储备、生鲜配送前置仓、卷烟成品库存**。
决定性判据是 `K`（一次补货单的固定成本）**是否显著**：`K ≈ 0` 时问题退化成每周做一次单期报童，本讲也算了一遍。

### 3. 模型是什么
- **单期报童**：$\min_S\ h\,\mathbb E[(S-d)^+] + p\,\mathbb E[(d-S)^+]$，一阶条件 $\Pr(d\le S^*)=\dfrac{p}{p+h}$；
- **周期订货（n 期）**：每 $T$ 周在周初补一次、补到 $S=s+\mu T$，周均成本
  $\dfrac{K}{T}+\text{持有}+\text{缺货}$，对 $(T,s)$ 搜索；等价于 $(s,S)$ 的**固定批量近似**，好处是 $T$ 可直接拿去排单；
- **非平稳**：Wagner-Whitin 前向 DP，$C(j)=\min_{i\le j}\{C(i-1)+K+h\sum_{t=i}^{j}(t-i)d_t\}$，$O(T^2)$；
- 所有成本**单位统一**：$h=2800\times0.20/52=10.7692$ 元/吨·周（年持有率折到周），$p=1800$ 元/吨（不欠单口径）。

### 4. 结果（实跑数字）
| 项 | 数字 |
|---|---|
| 临界分位数 $p/(p+h)$ | **0.9941** |
| 报童 $S^*$（三角分位数 / 数值最优） | **226.9 / 226.8 吨**（双签一致） |
| 安全库存 | **106.9 吨 = 2.18 个 sd** |
| K 从 0 → 30000（30000 倍）时 $s$ | **全部 270** |
| 同区间补货周期 $T$ | **1 周 → 6 周** |
| 三角 vs 正态（同均值同方差）$S^*$ | 226.9 vs 243.2（**+7.2%**） |
| 季节计划（K=4200） | **3 次进货**：第 1 周 180 吨、第 3 周 450 吨、第 6 周 371 吨 |
| 整箱 20 吨 | 20 桶下**反而便宜 155 元/周**（年 8,074 元） |
| 服务水平 | β = 99.665%，α = 100.00% |
| 只抄 $S^*$ 当订货点（不管 K） | 周均贵 **+1,370 元（年 71,238 元）** |

### 5. 核心结论（三句）
1. **K 不在报童公式里** —— 从 0 涨 30,000 倍，$s$ 一个数都没动（270 → 270），动的是 $T$（1 → 6 周）。
   「K 大就该多备安全库存」是错的；K 买的是**更少的单**，不是更大的安全库存。
2. **分布形状决定 $S^*$，而且是有界性决定它** —— 三角(0,240,120) 与同均值同方差的正态，$S^*$ 差 7.2%；
   差别全在右尾：正态把「永远发生不了的需求」也算进 99.41% 分位（243.2 已越过实际上界 240）。
3. **非平稳需求下，「每期都做报童」会毁掉 K 换来的批次经济** —— W-W 给的是 3 次进货，
   第 3 周旺季一开始一次压足 450 吨；而逐周报童是 8 次进货，光 K 就多付 5×4200 = 21,000 元。

### 6. 怎么做（方法链）
报童解析 → 周期仿真（Monte Carlo，20000 条路径 × 150 周期）→ 对 $(T,s)$ 网格搜索 → W-W DP → 整箱取整 → 服务水平复核。
**每一步都有一条独立的复核路径**：解析分位 vs 数值积分最低点、DP 成本 vs 枚举、仿真 vs 解析。

### 7. 怎么读结果
- $s=270$ 而 $S^*=227$：$s$ **比** $S^*$ **还高**，因为一次补货要撑 2 周 —— 「订货点 = 报童量」是把单期结论误用到多期；
- 整箱反而更便宜：向上取整让补货量系统性偏大，等于免费加安全库存，本实例 $p$ 很贵所以正好值钱（换个便宜的 $p$ 结论就翻）；
- β 与 α 差 0.33 个百分点：报告里写「服务水平 99%」必须说清楚是「需求满足率」还是「周期不缺货率」。

### 8. 局限（如实写）
- 周期订货是 $(s,S)$ 的**固定批量近似**，真正的 $(s,S)$ 允许每次补到 $S$、量随库存浮动；
  本讲的「周期订货」口径让 $T$ 成为整周数，便于排单，但代价是 $\le 2\%$ 的最优性损失；
- 三角分布是**假设**，真实化肥需求是右偏的长尾（促销、灾害抢购），$p=1800$ 也是拍的；
- 提前期固定 1 周；提前期本身随机（供应商迟到）时 $s$ 要再加一层 —— 见教案§九；
- **未做**：真正的 $(s,S)$ DP（随机动态规划，需处理二维状态与在途队列，本轮探路时写崩两次，见避坑 1）、多级库存（中心仓 + 乡镇站）、需求相关的补货（同一批农户）。

### 9. 下一步
① 真 $(s,S)$ 随机 DP（状态 = 现货 + 在途队列，值迭代）与本节周期订货对照，量出「固定批量近似」到底贵多少；
② 提前期随机的 $s$ 修正（$s=\mu L+\sigma_{\text{组合}}\Phi^{-1}(\cdot)$，提前期方差进组合方差）；
③ 多级库存的牛鞭效应（中心仓 → 乡镇站），接 Day57 的 DES 框架；
④ $(R,Q)$ 与 $(s,S)$ 在同一批数据上的成本比；
⑤ K 的构成反过来算：把「拼车」省下的 K 折算成补货周期，回答「值不值得为这单化肥等两天」。

## 避坑（本轮实跑暴露）

1. 🔴 **随机多期 DP 的第一版永远最优 = 永远不下单**。因为把「下单成本 $c q$」放进 $V$、未来需求按期望算，
   推迟下单永远更便宜（时间价值 $c$ 被重复计入）。两次重写都掉进这个坑（`_abandoned_v1_order_up_to_level.py` 是第一次）。
   **正确做法**：以「订货量 $\to$ 库存 $\to$ 需求」的现金流出为口径，或直接用「周期订货 + 仿真」绕开，
   不要手写一个没有严格时序的 DP 然后相信它。
2. 🔴 **正态无界 + 大缺货罚 + 提前期 = 病题**。本班早年 Day18 的 (s,S) 在这组参数下会得到「最大订货量 $q^*=0$」：
   因为欠单越滚越多、成本只随「欠的量」涨，$q$ 拉满也堵不住。**这不是代码 bug，是模型病** ——
   换有界分布（三角）后立刻正常。**见到「最优解在边界且反直觉」，先查分布是否有界。**
3. ⚠️ **提前期的实现必须落在「在途队列」上**。第一版把 $q$ 当本周可用（$L=0$），
   于是缺货率虚低、$s$ 虚低；改成 `pipeline` 队列（下周到）后 $s$ 从 210 抬到 270。
4. ⚠️ **「$T$ 随 $\sqrt K$ 增长」是错的** —— 那是 EOQ 的 Q，不是周期订货款式的 T。
   本轮 8 个 K 上 $T$ 是 1,1,1,1,2,3,4,6，单调不减但远低于 $\sqrt K$ 量级（K 涨 7 倍 T 才涨 1.5 倍）。
   图 (c) 的标题已改为「单调不减（不是 √K）」，**不要把 EOQ 的结论硬安到另一种口径上**。
5. ⚠️ **整箱约束别预设「一定是代价」** —— 向上取整等价于加安全库存，$p$ 贵时反而省钱（本讲 −155 元/周）。
6. ⚠️ 三角分布抽样用逆变换 $u\le (c-a)/(b-a)$ 两支，直接 `np.random.triangular` 也行；
   但**成本积分必须用同一个分布的 pdf**，否则解析 $S^*$ 与仿真最优对不上（本轮差 0.1 吨以内才算过）。
7. ⚠️ `np.math` 在 NumPy 2.x 已删除 → 用 `math.erf`；`np.trapezoid` 替代 `np.trapz`（NumPy 2.x 弃用）。
8. ⚠️ 中文图需 `Noto Sans CJK SC`，本机已在 `font_manager` 里，跑通无告警。

## 与 Day18 / Day27 的关系

| | Day27 报童 | Day18 (s,S) MDP | 本讲 |
|---|---|---|---|
| 决策次数 | 1 次 | 每期 | 每 $T$ 周 |
