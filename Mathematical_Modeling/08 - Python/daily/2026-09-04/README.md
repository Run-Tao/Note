# Day 3 — 线性规划（LP）：从"口头决策"到"可求解标准模型"

> 锚点：[[Learning_Roadmap|Learning Roadmap]] Level 6 · 优化模型第一课。
> 之前 Day1/Day2 打通了 NumPy 工具链，今天开始进入**真正的模型方法**——用最快入门的**线性规划(LP)**切入优化题主战。

## 0. 一句话总结

把"在资源约束下怎么安排生产最赚钱"这类问题，翻译成 **目标函数 + 约束条件 + 决策变量** 的标准 LP，再用 `scipy.optimize.linprog` 一行求解并获得**可解释的最优解和影子价**——这就是 90% 优化赛题的骨架。

---

## 一、这个方法解决什么问题？（10问之1）

**资源分配 / 生产计划 / 调度 / 选址 / 物流**等"在有限约束下找最优决策"的问题。
典型问法：*"如何安排 A、B 两种产品的产量，使总利润最大？"*（本文案例即此类）

## 二、什么情况该用它、为什么适合？（10问之2、4）

- **决策变量可连续取值、目标函数与所有约束都是线性** → 用 LP。
- LP 有**成熟高效的求解算法（单纯形 / 内点法-HiGHS）**，大规模也能秒解；
- **可解释性强**：不只给一个数，还给出每项约束的"影子价"（稀缺资源值多少钱），方便做资源决策。
- 若变量要求整数 → 升级为整数规划(ILP)；目标/约束非线性 → 非线性规划(NLP)。本文先打 LP 底子。

## 三、数学模型是什么？（10问之3）

**标准形式**（scipy 接受的形式，统一求最小化）：

$$
\min_x \; c^T x \quad \text{s.t.} \quad
A_{ub}\,x \le b_{ub},\quad A_{eq}\,x = b_{eq},\quad
l \le x \le u
$$

**三要素对照本文案例：**

| 要素 | 定义 | 本例 |
|---|---|---|
| 决策变量 $x$ | 你要决定的数量 | $x_A, x_B$ = A、B 产品产量 |
| 目标函数 | 要最大/最小的量 | $\max\; 30x_A + 40x_B$（利润） |
| 约束条件 | 有限资源/上下限 | 机器1: $2x_A + x_B \le 100$；机器2: $x_A + 3x_B \le 120$；$0\le x_A\le40$，$10\le x_B\le50$ |

> 利润最大化 ⇒ 对 scipy 要 **min(负利润)**：$c=[-30,-40]^T$。

## 四、如何求解？（10问之5）

```python
from scipy.optimize import linprog
import numpy as np
c = np.array([-30., -40.])                 # 求 min(-利润)
A_ub = np.array([[2,1],[1,3],[1,0],[0,1]]) # 约束系数
b_ub = np.array([100.,120.,40.,50.])
bounds = [(0,None),(10,None)]              # A>=0, B>=10
res = linprog(c, A_ub=A_ub, b_ub=b_ub, bounds=bounds, method="highs")
```

## 五、结果与解读（本文代码实际跑通输出）

```
最优解：A = 36.00 件, B = 28.00 件
最大利润 = 2200.00 元
机器1、机器2 工时均拉满(紧约束)
机器1 工时 +1，利润增加 ≈ 10 元（影子价）
```

- **最优解落在两条产能约束的交点**（36,28），说明 A、B 产能基本用尽；
- **影子价 = 10 元/h**：机器1 每多 1 小时，利润多 10 元 → 若加班成本 <10 元/h 就值得买工时。这就是 LP 带给决策的"额外红利"。
- 图 `lp_feasible_region.png` 画出了**可行域多边形**，红点为最优顶点——LP 最优解总在**可行域顶点**上，这是单纯形法遍历顶点的直观依据。

## 六、如何验证？（10问之6）

- 数值自检：代码末尾断言 `A=36, B=28, profit=2200`，跑通即通过；
- 结构自检：最优解代入所有约束都满足且两条产能约束取等（可行性 + 紧约束）；
- 敏感性：把机器1 工时 100→101 重解，偏差即影子价（已在代码中实现）。

## 七、缺点与替代？（10问之8、9）

- 只适合**线性 + 可控约束**；现实常含整数（产量为整数）→ 用**整数规划**（分支定界）；含随机量 → 随机规划/仿真；多目标冲突 → 加权或 Pareto（多目标规划）。
- linprog 适合中小规模；大规模/复杂约束建模可用 PuLP / CVXPY / OR-Tools（本机暂未装，随进度引入）。

## 八、怎么写进论文？（10问之10）

论文里应出现：①**符号表**（变量含义+单位）；②目标函数与约束的**数学公式**；③说明**求解器与算法**（如 HiGHS 内点法）；④**结果表 + 敏感性/影子价分析**说明该方案稳健且有决策价值。切忌只贴一段代码。

## 九、可迁移性（练习）

- 改动需求上/下界或利润系数观察最优解怎么变（灵敏度大方向）；
- 把模型扩成 3 种产品、加一道"机器2 至少用 60h"的等式约束试试 $A_{eq},b_{eq}$ 的用法。
