# Day41 · 中国邮递员问题（代码）

> 教案正文见 [[Day41 - 中国邮递员问题最小权完美匹配与欧拉回路]]（`05 - Algorithms/`）。
> 脚本：`chinese_postman_matching_euler.py`；图：`chinese_postman_matching_euler.png`。
> 运行：`cd /home/ubuntu/Note && ./.venv/bin/python "Mathematical_Modeling/08 - Python/daily/2026-10-10/chinese_postman_matching_euler.py"`

## 一句话

**怎么走一条路，把片区里每条街都扫到、最后回到车场、总里程最短？**
答案是：**把「奇度路口」两两配对（用最短路配对、用 KM 求最小权完美匹配），
再把配对的路径重复走一遍，图就变成欧拉图，一趟走完。** 本课把 Day14（最短路）、
Day22/39/40（匹配）与**欧拉回路**合体，解决经典的**中国邮递员问题（CPP）**。

## 真实决策背景

某社区环卫车要从**车场（顶点 0）**出发，扫过片区里 **15 条街道**至少一次，最后回到车场。
街道有里程（权重），求**总行驶里程最短**的巡游路线。

- **决策变量**：一条闭合巡游 $W$（可重复走边）；
- **目标**：$\min\sum_{e\in W} w_e$；
- **约束**：$W$ 覆盖每条边至少一次、连通、首尾相接。

实例：9 个路口、15 条街、各边权和 = **65**；度数分布 `[3,4,4,3,3,4,3,3,3]`，
**奇度路口 = {0,3,4,6,7,8}（6 个）**，所以图**不是欧拉图**，必须重复走一些边。

## 为什么难、以及怎么破

- 欧拉定理：**连通图存在欧拉回路 ⟺ 每个顶点度数为偶**。奇度路口「进多出少」，一笔画走不通。
- 破法：**把奇度路口两两配对，沿配对的**最短路**重复走**，把奇变偶。于是

$$
\min_{\text{完美匹配 } M}\ \sum_{(i,j)\in M} d(v_i,v_j),\qquad d=\text{全源最短路 (Floyd–Warshall)}.
$$

- 这就是 Day40 的**最小权完美匹配（KM）**能秒解的问题——**CPP = 各边走一遍（base） + 奇度点最小权完美匹配（补奇）**。

## 算法链路（全部手写，未用 networkx）

1. **Floyd–Warshall** 全源最短路（带 `next` 矩阵还原路径）；
2. **KM（最小化版）** 求奇度点最小权完美匹配（选最省的配对）；
3. 把匹配对之间的最短路**加进图**，构成多重图；
4. **Hierholzer** 求欧拉回路 → 还原成一条真实巡游；
5. **`itertools` 暴力枚举全部配对**作独立裁判；
6. **两个对照**：A. 每条街往返两遍（笨办法）；B. 最近邻贪心巡游。

## 实跑结果（`.venv` 实际跑通）

| 项目 | 数值 |
|---|---|
| 各边各走一次 base | **65** |
| 奇度点配对后重复边 | `(0,3)`、`(4,7)`、`(6,8)` |
| 重复里程 | **10**（4+4+2） |
| **最优总里程** | **75** |
| 独立裁判（暴力枚举配对） | **10**（KM == 暴力 ✅） |
| 贪心对照（最近邻巡游） | **82**（比最优多 7，**+9.3%**） |
| 笨办法对照（每条街两遍） | **130**（比最优多 55，**+73.3%**） |
| 欧拉回路 | `[0,3,6,8,1,4,7,8,6,5,7,4,5,2,3,0,2,1,0]`，覆盖全部 15 街且闭合 ✅ |

**断言全过**：KM == 暴力裁判；巡游覆盖所有边且闭合；最优不劣于两个对照；回路段数 ≥ 边数。

## 避坑记录

1. **KM 的「对角线陷阱」**：e-maxx 最小化 KM 要求「任意行配任意列」，
   对角线为 0 时会给出「人人配自己、总代价 0」的**假解**——**必须把对角线抬成大数**禁止自配对（本课第一版即栽在此，KM 报 0 而真值 12）。
2. **KM 总权重「每对只算一次」**：`match` 是双向的，对 `i` 求和会**双倍计数**，须只累加 `i<match[i]`。
3. **Hierholzer 必须作用在「含重复边的多重图」上**：4/6 个奇度点的原图**根本没有欧拉回路**，
   第一版直接对原图求回路 → 既漏边又不闭合。**先补重复边、再求欧拉回路**。
4. **教学实例要让贪心真吃亏**：第一版实例贪心恰等于最优，「贪心会亏」教学点落空；
   重设权重后贪心多走 **9.3%**，教学点才立起来（教学数据要刻意设计以暴露算法行为）。
5. **独立裁判要真独立**：`itertools` 暴力枚举全部配对（6 点 = 15 种）交叉验证 KM。
6. **图路径用 `__file__` 锚定**，任意 cwd 都能正确落图。
