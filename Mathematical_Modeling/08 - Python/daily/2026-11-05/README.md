## 一句话结论

**同是「1 支班组、6 条作业」，只看条数是 34、看价钱是 44（+29%）；4 支班组时精确解 86，
按开始时间贪心 79、按密度贪心 76——而把「本刻已有几条作业」当容量的错解 B 账面 128，看着最赚，
实际峰值并发 10 支班组、超限 2.5 倍：同一条「不重叠」约束，单位写成「条」还是「人」，是两个不同的问题。**

## 十问

1. **谁在决策？** 云溪水库汛前检修项目经理 + 各作业面班组长。
2. **决策是什么？** ① 这 3 天窗口里选哪些作业做完；② 每条作业的开工时刻（决定能与谁并行）；③ 买几支班组。
3. **不做的代价？** 推到汛后只能潜水作业，单价约翻 2.6 倍；`船-闸墙注浆`（1500 元）没做完要等一年。
4. **数据从哪来？** 检修清单 36 条 + 4 支班组编制 + 潮位换算的窗口，全部硬编码在脚本顶部常量 `JOBS`。
5. **量化目标？** 窗口内完成作业的合同价款合计（百元）。
6. **可行域？** 每刻并行作业所需班组数 ≤ K（每条作业要 1~3 支）；同作业面内部顺序由区间不重叠表达。
7. **对照方案？** 最早完工优先（只看条数）/ 加权区间 DP / 按开始贪心 / 按密度贪心 / 错解 B（把"条数"当容量）/ 时间维精确 DP。
8. **敏感什么？** 班组数 K = 1,2,3,4,5,6,8，边际 +17/+25/+15/+19/+14/… 不单调；改 `JOBS` 的止时刻可复现「窗口放宽」。
9. **结论对谁有用？** 项目经理（4 支班组值 86，第 5 支再加 19）、班组长（窗口紧的先上）、财务（别拿单一影子价格外推）。
10. **哪一步最可能错？** 把「条数 ≤ K」当「$\sum r_i x_i \le K$」（容量单位写错）；把"兼容图独立集"直接当成"可并行集"；
    用贪心当最优；用单班组影子价格外推多班组。

## 教案要点（详见教案 §三、§六）

- **条数不是钱**：A 与 B 都是 6 条，但 A 把短而便宜的活儿全捡了（打磨 1.5 h / 600 元、抄表 1 h / 400 元），
  B 用一条 4 h 的护坦清石（900 元）换掉两条小活 → +29%。
- **错解 B 的机理**：约束本意是 $\sum_{i
i t} r_i x_i \le K$（每刻要几支人），错解把它写成"每刻已有几条作业 ≤ K"。
  每条作业要 1~3 支班组 → 账面 128、真实并发 10。**不可行方案的「收益」不能拿来比大小。**
  > [!note] 为什么本讲没有"错解 C：两两相容 ⇒ 可同批"
  > 在这 36 条作业上，4 支班组时**任取两条相容作业都开得起来**，于是"相容图"退化为完全图、
  > 最大权独立集退化为一个点，这条错路在本数据上**根本走不出来**。
  > 原先那个演示函数 `wrong_pairwise_pool_formulation` 会自己算错（它把两条作业的报酬直接相加），
  > 2026-11-06 起改为**不可调用 + 说明**，不再在结果里出现。
- **精确解为什么毫秒级**：任何时刻并行 ≤ K ⇒ 开工时刻必落在「某条作业的开始 / 结束」上，
  状态 = 4 条在进行作业的结束时刻（无序元组），状态峰值只有 34。剪枝 DFS 同题要 46 s——**换状态表示，差 5 个数量级**。

## 避坑（全部实跑暴露）

1. **并行可行性必须用事件扫描**：同一时刻先释放再占用，逐刻累加；不能按「排序后相邻不重叠」判（多班组时作业本来就重叠）。
2. **先写出错解并让它失败**：错解 B（单位写成条数）账面 128、并发 10，可运行、可断言；这条比"纸上举一个例子"扎实。
3. **剪枝 DFS 不算精确**：LP 上界 + DFS 在 36 条上要 46 s，且曾因上界写松而跑不完 → 改用时间维 DP。
4. **时间维 DP 的迁移键写漏**（`k = (t, busy + (e,)*r)` 变成残留变量）会**静默算错**：靠「单班组与加权 DP 对齐（44 vs 34 单调关系）」交叉验证才抓出来。
5. **敏感性不能用贪心代算**：早期用贪心得 7/14 条，边际曲线完全失真；每档都必须精确。
6. **实例必须一开始就有结构冲突**：初版「房间类」权重太低，4 班组最优 = 贪心（都 75），整节课 0 教学点（= Day67 搁置教训）；
   调高 `房-消防整改` 6→9、`房-网络布线` 5→7 后缺口稳定为 7。
7. `json.dump` 遇 `np.int64` 直接 `TypeError` → 统一 `int()` / `bool()`。
8. 中文图零告警（Noto Sans CJK SC）；`__pycache__` 不入库（已在 `.gitignore`）。
9. **滚动窗口不是区间**：本讲把「潮位只涨不落」简化为固定截止时刻；若窗口随决策移动（先抽水后作业），要换成时间索引 MILP。
