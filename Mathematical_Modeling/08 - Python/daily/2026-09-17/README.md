## 场景：新厂选址 + 4 条产线产能分配

决策变量 $x_j \ge L_j$（第 $j$ 条产线投入，亿元），$\sum_j x_j \le B=100$。
两个冲突目标：

| 产线 j | 利润系数 π_j (亿元/亿元) | 排放系数 e_j (万吨/亿元) | 单位碳赚钱效率 π/e |
|---|---|---|---|
| 1 | 2.10 | 1.60 | 1.31 |
| 2 | **3.20（最赚）** | **5.60（最脏）** | 0.57 |
| 3 | 1.40 | 0.90（最干净） | 1.56 |
| 4 | 2.80 | 4.20 | 0.67 |

- 目标一 $f_1$（利润，↑）$= \sum_j \pi_j x_j - F$；
- 目标二 $f_2$（碳排放，↓）$= \sum_j e_j x_j$；
- 政策下界 $L=[12,12,20,12]$（保就业/供应链），地块固定开销 $F$ 见下。

## 三大方法在代码里的实现

1. **加权和法** `weighted_sum_solve(w)`：解 $\max (1-w) f_1 - w f_2$，**手写 LP 顶点解**（把剩余预算全给加权边际收益最高的产线）；
2. **ε-约束法** `eps_constraint_solve(eps)`：解 $\max f_1$ s.t. $f_2 \le \varepsilon$，在候选点集上取最优；
3. **Pareto 工具**：`dominates()` / `fast_nondominated_sort()` / `crowding_distance()` / `hypervolume_2d()`——NSGA-II 的非支配排序与拥挤度、以及 2D 超体积，全部**手写**。

## 实测结果（`.venv` 实际跑通，主案例 乙地 F=9.5）

| 指标 | 结果 |
|---|---|
| 只追利润 | $f_1=256.50$ 亿元，$f_2=401.20$ 万吨 |
| 只追减排 | $f_1=115.70$ 亿元，$f_2=154.80$ 万吨 |
| **冲突代价** | 减排到最干净要牺牲利润 **140.80 亿元**；多赚到顶要多排 **246.40 万吨** |
| Pareto 前沿 | 量化降密后 **160 个非支配解** |
| 加权和法解集 | 扫 101 个权重只得到 **4 个不同点**（"台阶"；永远停在顶点） |
| ε-约束法独有点 | **49 个**（加权和法碰不到的 Pareto 点） |
| 膝盖点 knee | $f_1=115.70$，$f_2=154.80$，$x=[12,12,20,12]$ |
| 2D 超体积 HV | **24799.3**（参考劣点 $(f_1^{\min}-5, f_2^{\max}+5)$） |

断言全过：前沿两两互不支配、单目标极值在前沿上、前沿单调、HV>0。

### 一句话读图

- 左图：**固定开销越低的地块，整条 Pareto 前沿越靠左上**（甲地/丙地优于乙地）；
- 中图：**加权和法只会跳到几个孤点**，ε-约束法把中间前沿补齐（红三角）；
- 右图：**加权和扫权重的"台阶"现象**——权重从 0.25 到 0.5 解完全不动。

## 关键结论（建模一课）

> 单目标优化答案是一个点；**多目标优化答案是一族"不亏的路"**。
> **加权和法最省事，但它有硬伤**：①解永远落在可行域顶点上、对权重不连续；
> ②**非凸前沿段永远取不到**（本文 49 个点即为实证）。
> 真实项目中更稳妥的做法是 **ε-约束法 或 多目标进化算法（NSGA-II）**一次跑出整条前沿，
> 再用**膝盖点**给决策者一个推荐折中解，用**超体积 HV** 量化解集质量。
