# Day24 · 稳定婚配（Stable Marriage）与 Gale-Shapley 延迟接受算法

> 教案正文见 [[Day24 - 稳定婚配Gale-Shapley与延迟接受]]（`05 - Algorithms/`）。
> 代码：`stable_marriage_gale_shapley.py`；图：`stable_marriage_gale_shapley.png`。

## 一句话

**当"最优"没法定义时，退而求"稳定"**——不存在互相更喜欢的"私奔对"。手写 **Gale-Shapley 延迟接受算法**，并穷举全部稳定匹配，实测验证该算法的三大定理：① 必终止且稳定；② 主动方拿最优稳定匹配、被动方拿最差；③ 结构性约束（主动方优势对每个人单调成立）。

## 真实决策背景

4 男 4 女，各持完整偏好排序，求一个**无人想反悔**的配对。与 Day22（指派）对照：指派有明确成本函数、解唯一；本课**无全局目标函数**、解可能多个。

## 关键结果（仓库 `.venv` 实跑）

**男士主动**：M1–W1、M2–W2、M3–W3、M4–W4 → 男士总排名和 **3**、女士 **3**。
**女士主动**：M1–W2、M2–W1、M3–W3、M4–W4 → 男士总排名和 **5**、女士 **0**。

**全部稳定匹配恰好 2 个**（穷举 4! = 24 种筛出）：

| # | 配对 | 男士总排名和 | 女士总排名和 |
|---|---|---|---|
| 1 | M1–W1、M2–W2、M3–W3、M4–W4 | **3**（最优） | 3 |
| 2 | M1–W2、M2–W1、M3–W3、M4–W4 | 5 | **0**（最优） |

- **定理②实测**：男士主动 → 男士拿到全部稳定解中排名和最小的 **3**；女士主动 → 女士拿到最小的 **0**。**"谁主动谁占优"是定理不是巧合。**
- **定理③实测**：每位男士在"男士主动"下的伴侣排名，**永远不差于**"女士主动"下的排名（M1:1≤2、M2:1≤2、M3:1≤1、M4:4≤4）。
- **敏感性**：随机扰动偏好 2000 次，**95.8% 结果与基准不同** → 匹配对偏好高度敏感，交付必须附稳定性证明。

## 代码要点（手写、零专用匹配库）

- `gale_shapley()`：主动方表白、被动方"延迟接受 + 随时可反悔"（踹掉旧对象，回自由队列）。
- `is_stable()`：遍历所有非夫妻对，检查是否构成阻塞对。
- `all_stable_matches()`：穷举 $n!$ 个匹配筛出全部稳定解，作为定理核对基准。
- **断言**：两种主动方向结果均稳定、主动方排名和 = 全体稳定解最小、结构约束逐人成立，全部通过。
