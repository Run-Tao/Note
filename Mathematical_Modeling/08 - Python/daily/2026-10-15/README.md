# Day46 · 时间序列 ARIMA（Box-Jenkins）手写实现（代码）

> 教案正文见 [[Day46 - 时间序列ARIMA与县域景区游客量预测]]（`03 - Mathematical Models/`）。
> 脚本：`arima_timeseries_forecast.py`；图：`arima_timeseries_forecast.png`。
> 运行：`cd /home/ubuntu/Note && ./.venv/bin/python "Mathematical_Modeling/08 - Python/daily/2026-10-15/arima_timeseries_forecast.py"`

## 一句话

**县域景区要预测未来 12 个月游客量来排班/采购**——客流是"**有惯性（自相关）+ 长期回归容量均位**"的平稳序列，
三招土办法（看去年同月 / 取近 12 月均值 / 画直线外推）各差一大截。
**手写 ARIMA（差分 → ACF/PACF → BIC 定阶 → 条件最小二乘估参 → Ljung-Box 检验 → 递推预测）**
在**多原点滚动回测**上平均 MAPE **10.88%**，稳胜三类基线（16.78% / 11.85% / 12.44%），
BIC 自动选出的 **ARIMA(1,0,0)** 恰好就是数据的真模型。

## 真实决策背景

某县「云溪谷」景区要排下一年度运营计划（售票窗口、保洁班次、接驳大巴、旺季临时工），
依据是**未来 12 个月的月度游客量预测**。数据 = 过去 96 个月（8 年）的月度游客量（万人次）。

**为什么难？** 因为三招"看着都对"的直觉会吃亏：

| 土办法 | 直觉 | 为什么会亏 |
|---|---|---|
| 朴素法（看去年同月 / 上个月） | "去年这时候多少，今年差不多" | 只盯少数几期，噪声大 |
| 移动平均（近 12 月均值） | "平均一下更稳" | 把"旺季/淡季""涨/跌"全抹平 |
| 线性趋势外推 | "前几年一直涨，那就画直线" | 景区容量有限，客流**不会无限涨** |

**真相**：客流是**围绕容量均位（≈19 万人次/月）波动、带惯性**的平稳序列——
本月多、下月往往还多（**自相关**），但长期必**回落到均位**（**均值回复**）。
**ARIMA 正好把"惯性（AR）+ 差分（I）+ 误差修正（MA）"三块写进模型。**

## 数据生成（刻意设计）

脚本 `make_series()` 生成 96 个月：

$$y_t = \mu + \phi\,(y_{t-1}-\mu) + \varepsilon_t,\quad \mu=20,\ \phi=0.72,\ \varepsilon\sim N(0,2.4^2)$$

即**一阶自回归（AR(1)）+ 均值回复**。**刻意不含强确定性季节**——因为本讲模型是**非季节性 ARIMA**；
若数据有强季节，纯 ARIMA 会输给"去年同月"，那是 **SARIMA** 的战场（见教案「局限」一节）。

## 代码结构（零专用时序库，不依赖 statsmodels）

| 函数 | 作用 |
|---|---|
| `difference` / `integrate` | 差分与积分（预测时把差分掉的水平还原） |
| `acf` / `pacf` | 自相关 / 偏自相关（PACF 用 Durbin-Levinson 递推） |
| `fit_ar_yw` | **Yule-Walker 方程**估 AR(p)（解 Toeplitz 方程组） |
| `_arma_residuals` / `fit_arma_css` | **条件最小二乘（CSS）**估 ARMA(p,q)：最小化一步预测误差平方和 |
| `fit_arima` | 差分 + ARMA，返回 AIC/BIC |
| `adf_like` / `choose_d` | **手写 ADF 式平稳性检验**，自动定差分阶数 $d$ |
| `auto_arima` | 在 $(p,q)$ 网格上按 **BIC** 自动定阶 |
| `ljung_box` | **Ljung-Box 白噪声检验**（残差诊断） |
| `naive_seasonal` / `moving_average` / `linear_trend` | 三类"土办法"基线对照 |
| `rolling_backtest(_baseline)` | **多原点滚动回测**（诚实的评估裁判） |
| `forecast_arima` | 向前递推预测 + 积分还原 |

## 关键结果（`.venv` 实跑）

```
[数据] 共 96 个月，均值 19.05，范围 [11.12, 26.78]  平稳、均值回复

[平稳性/定阶] ADF 式检验 t=-3.11 -> 平稳；自动选差分阶数 d=0
[ACF/PACF] 原序列 lag1..4  ACF=[0.689 0.389 0.247 0.165]（拖尾）
                          PACF=[0.689 -0.162 0.091 -0.015]（1 阶截尾）→ 初判 AR(1)

[BIC 定阶] 最优 ARIMA(1,0,0)  BIC=154.11   ← 与真值一致（真模型就是 AR(1)）
[残差检验] Ljung-Box Q=17.30, p=0.099  → 残差≈白噪声，模型充分

[多原点滚动回测 · 预测 12 步 · 13 个预测原点] 平均 MAPE：
    ARIMA      平均=10.88%   中位= 9.81%   最差=24.19%
    季节性朴素   平均=16.78%   中位=15.05%   最差=33.65%
    移动平均     平均=11.85%   中位=10.10%   最差=30.91%
    线性趋势     平均=12.44%   中位= 9.49%   最差=30.02%

[未来 12 个月预测（全量重训 ARIMA(1,0,0)）]
    第+1月=21.62 → 逐月回落到第+12月=19.10（万人次），长期收敛到容量均位 19.05
```

**ARIMA 平均 MAPE 10.88% 最低、且最差原点也最稳（24% vs 基线 30%+）。**

**断言全过**：差分阶数为 0/1、ARIMA 滚动回测平均 MAPE 优于三类基线、残差通过 Ljung-Box（p>0.05）、未来预测为正且有限。

## 避坑记录

1. **"切一刀留出集"会被运气骗**——第一版用单次留出（末尾 12 月）对比，线性趋势因恰好切在有斜率的位置而"意外夺冠"，ARIMA 反而落后。改成 **13 个原点的滚动回测取平均**后，ARIMA 才稳定胜出（**评估方法本身要先做对**，否则会得出相反结论）。
2. **教学实例要刻意设计成 ARIMA 的主场**——初版用"强确定性季节"数据时，纯 ARIMA 输给"去年同月"的季节性朴素法（那是 SARIMA 的地盘）；改成**平稳 + 均值回复**结构后，"惯性 + 回复"正是 ARIMA 的强项，教学链才立起来（**教学数据要刻意设计以暴露方法适用边界**，与 Day22–45 同一教训）。
3. **差分序列的均值不要重复加**——预测递推时序列 `dx` 存的是**去均值后**的值，若把"含均值的预测值"又 append 回 `dx`，均值会每步叠加、**预测指数级爆炸**（本课第一版 ARIMA(1,0,0) 第 12 月预测到 62 万人次，明显爆表）。修正：**递推留在零均值空间，只在输出时加回 $\mu$**（与 Day 45 DE 的"基向量必须互异"一样，属于"数值实现细节决定成败"）。
4. **定阶用 BIC 不用 AIC**——AIC 在本例选到 ARIMA(3,0,2) 过拟合（真值是 AR(1)），BIC 惩罚参数更重，选出简朴且正确的 ARIMA(1,0,0)（**"奥卡姆剃刀"在时序定阶里是硬要求**）。
5. **估计前统一去均值**——`fit_arma_css` 先把序列减均值再拟合零均值 ARMA，常数项就是均值本身；否则 AR 的均值项与截距混在一起、预测会漂移。
6. **PACF 用 Durbin-Levinson 递推**而非直接解大方程组——稳定且 $O(\text{nlags}^2)$；ACF 用"除以 N"的有偏估计，与 Box-Jenkins 教材一致。
7. **多起点回测要固定随机种子**——数据生成用 `np.random.default_rng(seed)`，保证"ARIMA 最优"这一结论可复现（与 Day42–45 同做法）。
