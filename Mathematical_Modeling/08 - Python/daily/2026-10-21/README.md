## 场景

云溪县热电厂 40 个运行班的燃煤单耗台账。老链条炉只在中低负荷 30–36 t/h 跑（6 班、抖动大），新循环流化床覆盖 16–60 t/h（30 班、稳定）。3 月 14 日夜班老炉唯一拉到 60 t/h，单耗记 110.8（台账标"化验补录"）。

要回答：老炉要不要提负荷？老炉比新炉费多少煤？那条 60 t/h 的记录算样本还是事故？

## 10 问速答

1. **解决什么问题**：OLS 算出的系数、SE、t 值**能不能直接用于决策/考核**。
2. **什么时候用**：任何"数据表 → 系数 → 下结论"的任务，尤其在系数要写进合同、考核、政策建议时。
3. **为什么需要**：OLS 只保证"给定假设下最优"；假设破了它**照样输出好看的数字**，但含义已经变了。
4. **数学模型**：$y=X\beta+\varepsilon$，$\hat\beta=(X^\top X)^{-1}X^\top y$；诊断量 $h_i$、$t_i^*$、$D_i$、RESET、White、BP。
5. **求解方法**：`np.linalg.inv` + 手写外部学生化残差（逐点删点重估）、三明治协方差、辅助回归算 $nR^2$。
6. **参数从哪来**：全部从数据估；真实曲线 $w=97+0.016(t-40)^2+3\cdot\text{老炉}+1.2\cdot\text{二班}$ 由脚本生成，用于**验证诊断能不能抓到已知的病**。
7. **结果怎么读**：线性模型斜率 −0.022（t=−0.49）→ "提负荷没用"；补 $ton^2$ 后顶点 **38.68 t/h**，30→36 t/h 平均每吨省 **1.35 kg** → 年省标煤约 **38.9 t**。
8. **怎么检验**：RESET / White / BP / 分组 F / 杠杆-残差图 / Cook / QQ + D'Agostino；最后用**零点校准**（1000 组真线性数据）证明虚警率守在 5%。
9. **敏感性**：删掉 0 号 → 斜率 t 从 −0.49 变 **−2.41**（结论翻转）、老炉罚额 +55%；全量 HC1 → 老炉 t 从 3.00 掉到 **1.91（不显著）**。
10. **坑**：原始残差不判异常点；高杠杆≠坏点；Cook>1 不是铁律；删点前必查原始记录；HC1 不治设定误设；补高阶项救不了脏数据。

## 关键实跑数字（`.venv`，`-W all` 零告警）

- OLS：$R^2=0.2257$、$\hat\sigma=3.286$、产量斜率 **−0.022**（p=0.62）、老炉 **+4.414**（t=3.00，p=0.0052）；
- **RESET** $F(2,30)=85.0$，$p=4.4\times10^{-13}$ → 设定误设；
- **White** $LM=33.04$（df=6），$p=1.0\times10^{-5}$；**BP** $LM=12.63$（df=3），$p=5.5\times10^{-3}$；
- **分组 F** $=5.45$，$p=2.4\times10^{-3}$：老炉残差 sd **5.79** vs 新炉 **2.48**（2.3 倍；真实 $\sigma$ 比是 4 倍，被 OLS 双向拉平）；
- **正态** D'Agostino $K^2=9.83$，$p=0.0073$；
- **0 号班**：$h=0.300$（超 $2p/n=0.222$，未过 $3p/n=0.333$）、$t^*=+4.97$、Cook $D=1.52$（次大 0.197，**7.7 倍**）、DFFITS $+3.25$；
- **HC1**：老炉 t 3.00 → **1.91**（不显著）；截距 46.20 → 43.35；
- **删 0 号**：斜率 −0.022 → **−0.087**（t 由 −0.49 变 **−2.41**）、老炉 4.41 → 6.84、$\hat\sigma$ 3.29 → 2.49（−24%）；RESET 仍 $p=5\times10^{-4}$；
- **保留 0 号 + 补 $ton^2$**：$\hat c_2=0.0198$（真值 0.0160，**高估 24%**），$R^2=0.8698$，$\hat\sigma=1.369$（−58%），顶点 **38.68 t/h**（真值 40）；
- **零点校准**（1000 组线性同方差假数据）：RESET 虚警 **4.50%**、White **3.70%**、BP **3.20%**。

## 避坑记录（本讲实跑暴露的）

1. **数据设计来回返工 9 版**，根因是"同时要求五个诊断都报警"太苛刻：早期版本噪声 $\sigma=2.8$ 压过了 U 形幅度，$R^2$ 只有 0.08，"设定误设"看不出来。最后靠**三条可解析的设计原则**定下来：① 曲率 $c_2$ 必须让 U 形幅度明显大于 $\sigma$；② 杠杆靠**设计矩阵的极端组合**（老炉只在中段跑 + 唯一一条 60 t/h）而不是靠 y 造；③ 异方差必须**真实存在于两条产线之间**（σ 比 4）。
2. **Shapiro-Wilk 不要手抄**：手推 Royston 近似式时把 p 值算成 1.0000。正态性检验的近似式**版本差异极大**，改用 `scipy.stats.normaltest`（D'Agostino $K^2$），逻辑一句话讲得清、结果可信。
3. **$h=0.300$ 只过了 $2p/n=0.222$，没过 $3p/n=0.333$**——不要为了"漂亮"去调数据把它顶过 3p/n，"警示区 vs 清理区"的分歧本身就是教学点（**判据之间不总一致，要如实报**）。
4. **断言要留张力**：`assert |c2_hat - c2_true|/c2_true > 0.10` —— 保证"补二次项能拟合但系数被坏点带偏"这件事**真的发生**，否则讲不出"先修数据再改模型"。
5. **`assert 2 <= sd_a/sd_b <= 3.5`**：真实 $\sigma$ 比 4，但 OLS 会把两组残差"双向拉平"成 2.33 —— 断言卡在 (2, 3.5) 才既验证了异方差存在、又验证了"OLS 残差会掩盖真实差距"。
6. **中文字体**用 `font.family="sans-serif"` + `[Noto Sans CJK SC, WenQuanYi…, DejaVu Sans]` 回退链；`axes.unicode_minus=False` 否则负号变方框。
7. **`warnings.filterwarnings("error")`**：让任何 font/glyph 告警直接变成失败，`-W all` 下跑一遍确认 0 条。
8. **图路径用 `__file__` 锚定**（参照 Day36–50）。
