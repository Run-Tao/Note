# Day32 · 主成分分析 PCA 与主成分回归 PCR（代码）

> 教案正文见 [[Day32 - 主成分分析PCA与主成分回归PCR]]（`05 - Algorithms/`）。
> 代码：`pca_principal_component_regression.py`；图：`pca_principal_component_regression.png`。

## 一句话

**指标又多又重叠（多重共线性）时，OLS 系数会剧烈摆动、符号反常**；
本课用 **PCA** 把 8 个强相关指标旋转成少数几个**互不相关的主成分**，
再用主成分做回归（**PCR**）——回答银行风控那句：
"**指标撞车得厉害，怎么压成几维、还不丢预测力？到底哪几个维度在决定风险？**"

## 真实决策背景

一家**农商行**想给小微企业做"**年违约损失金额**"预测，用了 8 个经营/财务指标
（营收、利润率、总资产、经营现金流、员工数、订单量、负债率、成立年限）。
现实里这些指标**高度相关**（大企业各项都大、风险企业各项都差），
OLS 系数不稳定、无法向业务解释。风控真正要的是：
1. 一个**稳定**的违约损失预测（用于计提拨备）；
2. 一句**能讲给人听的话**——到底哪几个维度在决定风险。

数据由 **3 个潜在因子**生成（这正是"业务维度"）：
**F1 企业规模 / F2 盈利能力 / F3 风险敞口**，8 个指标 = 3 因子线性组合 + 小噪声。
真实违约损失只由这 3 个因子决定（真值系数 `[0.20, -0.70, 1.10]`）。

## 模型（本课实现的就是它）

1. **标准化** `Z`（PCA 前必做，否则量纲大的列霸占方差）；
2. 对相关阵做**特征分解**（本课用 SVD，数值更稳）：`Z = U S Vᵀ`，
   主成分得分 `T = Z V`，载荷 = `V` 的列，第 k 个主成分解释方差比 = `s_k² / Σs_j²`；
3. 主成分**两两正交** → 回归时没有共线性；
4. **PCR**：取前 q 个主成分做 OLS，再映射回原变量空间 `β_PCR = V[:,:q] @ β_T`。
   注意 β_PCR **有偏**（丢了 n−q 个方向），但**方差大幅降低**，
   共线强时总误差反而更小——**偏差-方差权衡**。

对标 OLS / Ridge，并做：碎石图 + 载荷解读 + q 扫描 + Bootstrap 系数稳定性。

## 实测（`.venv` 真实跑通，N=600，训练 70% / 测试 30%）

**解释方差**：PC1 54.50% · PC2 23.99% · PC3 19.38% ·（累计 97.86%）…
**共线性诊断**：VIF = 13.5 ~ 24.5（**普遍 > 10，严重共线**）、设计矩阵条件数 12.3。

| 方法 | 训练 RMSE | 测试 RMSE |
|---|---|---|
| OLS（全 8 指标） | 0.529 | 0.563 |
| **PCR（q=3，累计 97.86%）** | 0.533 | **0.553** |
| Ridge（λ≈58.8） | 0.538 | **0.547** |

**PCR 测试误差比 OLS 低 0.010**（在共线数据上降维反而更准）。

**⭐ q 选择**：取累计解释方差 ≥90% → **q=3**——**恰好等于数据里真实的 3 个潜在因子**！
这份数据里 PCA 把业务真实维度"找回来"了。q 扫描最优 q*=4（测试 0.553）。

**⭐ 系数稳定性（Bootstrap 300 次重采样系数标准差）**：

| 指标 | OLS | PCR |
|---|---|---|
| 营收 | 0.111 | **0.011** |
| 总资产 | 0.115 | **0.010** |
| 订单量 | 0.116 | **0.010** |
| （8 指标平均） | ~0.105 | **~0.012** |

**PCR 系数抖动是 OLS 的 1/10 左右**（且所有指标无一例外更稳）
—— 这就是共线性下 PCR 最实在的收益：**预测更稳、结论更可信**。

## 避坑记录

1. **PCA 前必须标准化**。本课在标准化后的数据上做主成分；若直接对原始指标做，
   量纲大的列（如营收 vs 利润率）会霸占第一主成分，结论完全错。
2. **PCR 的系数有偏、不可直接作因果解读**。它擅长"稳定地预测"，
   但丢掉的主成分方向**可能恰恰含真实信号**——本课之所以 q=3 表现好，
   是因为真实信号就在前 3 维；若信号藏在尾部小方差方向，PCR 会翻车（这是它的边界）。
3. **教学数据必须真的共线**。初版噪声太大（VIF 仅 ~3），PCR vs OLS 的差距微乎其微、
   "系数稳定性"教学点落空；把噪声从 0.55 压到 0.18 后 VIF 升到 13~25，
   PCR 的稳定性优势（10 倍）和 q=3=真实因子 两个教学点才立起来。
