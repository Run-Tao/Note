## 十问

### 1. 解决什么决策
云溪县农资公司春耕「0 号复合肥」县级中心仓：一季 8 周，**要交一张 8 周的到货计划**（第一阶段），
需求出现后再卖、缺、存、季末半价处理（第二阶段）。

### 2. 什么情况下用
「现在就得定、未来才揭晓」的排产/备货/采购/容量预留题。判据是**决策不可逆 + 未来不确定 + 事后可补救**。

### 3. 模型
$\min_{a\ge0}\ h\frac{\bar L}{2}\sum a_w+\frac1{|S|}\sum_s[\sum_w(pL_{s,w}+hI_{s,w+1})+(c-r_u)I_{s,9}]$，
库存递推 $I_{w+1}=(I_w+a_w-d_{s,w})^+$。EV = 单场景（均值）；SAA = n 个随机场景；PI = 每周事后最优（下界）。

### 4. 结果
| 项 | 数字 |
|---|---|
| EV 真值 / SAA(n=100) 真值 | 37,410 / 37,299 元/周 |
| **VSS** | **−111 元/周（−0.30%）** |
| **EVPI** | **+32,851 元/周（87.8%）** |
| 场景口径 vs 真值（n=5/20/100/500） | +23.5% / +81.0% / +74.1% / +81.4%（**全正**） |
| LP vs 两段网格 | 64,924 vs 80,102（网格差 23.4%） |
| L=2→4（同一计划） | 36,670 → 38,062（**+3.8%**） |
| L=1→5（重新优化） | 最优总量 **920 → 920 吨** |
| 同量前移（第 1 周 +20%） | 37,410 → **33,990（−9.1%）** |
| p=10800 时 VSS | **−34.7%** |

### 5. 三句核心
1. **VSS 可以是负的**：本实例 p=1800、季末只亏 1400 → 「多备几乎免费」，EV 偏多刚好占到便宜；
2. **EVPI ≫ VSS（87.8% vs 0.3%）**：值钱的是预测，不是求解器；
3. **提前期随机 ≠ 多备**：需求逐周独立时，L 只影响「钱垫多久」，最优总量 920 吨纹丝不动。

### 6. 怎么做
场景树 LP（HiGHS）→ 蒙特卡洛 6 万条路径裁判 → 网格/参数族双签 → 重抽抖动 → p / L / 段数 / 同量前移四路扫描。

### 7. 怎么读
VSS 的**符号**是参数区间的位置（p 涨 6 倍就翻），不是模型性质；EVPI 才回答「要不要投钱做预测」。

### 8. 局限
K 不在主模型里（【七】参数族不可信）；需求无自相关；L 只进在途资金；单级库存；场景 = 峰值×季节（周间完全相关）。

### 9. 下一步
K 进 MILP（一季几趟）、自相关需求×随机 L、CVaR、滚动时域、等量抽样、用 LP 解做局部搜索代替手写参数族。

## 避坑表（本讲返工全部来自复跑既有半成品）

1. 🔴 **两段网格上界 420/480 装不下旺季总量** → 最优永远顶在边界，L 与 K 的扫描全部得出「不影响」的假结论。上界必须 ≥ 最坏需求合计（8×240=1920 的理论量级）。
2. 🔴 **在场景树上优化、在评估分布上计分** = 过线性拟合。原来对 100 个峰值×季节的树寻优却在 6 万条真路径上打分，得 82,950（假数）。改：优化与计分用**同一批路径**。
3. 🔴 **K 被计了两次**：`simulate(k_each=K)` 已按趟计入，又在外面 `+ K*trips/W`。重复计费会让「趟次少」的解被系统性偏爱。
4. 🔴 **`k_seg_plan` 把首批硬编码在第 1 周** → 4 段跑出 33,052 元/周的假最优（计划 `[229,229,...]`，而 L=2 时第 1 周不可能到货）。**最优落在参数族边界 → 先怀疑参数族**。
5. 🔴 **场景树口径偏差被误读成「双向随机」**：实跑四组全正，且不随 n 收敛（取决于该组场景均值 111~125 vs 真 120）→ 改成「报忧」。
6. ⚠️ **`best_saa["plan"]` 是 list**，`.sum()` 直接 AttributeError；统一 `np.sum`。
7. ⚠️ `meta` 里 `runtime_s` 与 `elapsed_s` 重复（脚本重写过、json 字段没清），保留两个是为了兼容旧报告。
8. ⚠️ **断言拿 `round(...,2)` 后的值比全精度** → 阈值放宽到 0.01。
