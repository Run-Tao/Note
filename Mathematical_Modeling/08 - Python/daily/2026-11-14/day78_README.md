## 十问

1. **解决什么问题？** 已解完一个 LP，要判断「几项参数**同时**变化时，最优基、影子价格还成不成立」。
2. **什么时候用？** 报告要给结论的有效范围；多部门同时改预算；判断「要不要重跑模型」。
3. **为什么适合？** 只用一个线性组合 $\sum_j|\Delta b_j|/\Delta b_j^{\max}\le 1$，不用重解，只用手上的灵敏度表。
4. **数学模型？** 基可行当且仅当 $B^{-1}(b+\Delta b)\ge0$；100% 法则是它的**充分条件**（分母取最紧的一行）。
5. **怎么求解？** HiGHS 解主问题；单项幅度单侧扫描到「有效约束集改变」；两两组合沿 45° 二分找拐点；几千组随机扰动做真解对照。
6. **怎么实现？** 有效约束集 = 卡死行号 + 等于 0 的变量号；**别用影子价 > 0 判断**（退化行会漏）。
7. **怎么验证？** 对偶值 vs 有限差分；法则上限 vs 实测拐点；6000 组抽样漏报计数；外推误差 vs 真解。
8. **缺点？** 只覆盖右端项（不管目标系数、技术系数）；只给充分条件；退化多解时「基变」≠「方案变」。
9. **替代？** 参数规划（精确拐点）、鲁棒对等 LP、SAA/蒙特卡洛、逆优化。
10. **怎么进论文？** 影子价 → 单项区间 → 同时变动实测（配法则判据）→ 法则管不到什么 → 「超过多少必须重解、谁接替了瓶颈」。

## 实跑数字

### 基准（万里水、万元）

```
z* = 4544.00
A城：甲库 260 ；B城：乙库 20 + 丙库 180
卡死：甲、乙、丙三库（两条管网都有余量）
影子价：甲 9.000 ｜ 乙 9.400 ｜ 丙 1.800 ｜ A过水 0 ｜ B过水 0
```

🔴 单价最高的丙库（11.2）**影子价格最低（1.8）**——它是两城共用的替代水源，不是「值钱的库」。

### 单个资源可改幅度（基不变）

| 资源 | 基准 | 可降 | 可升 |
|---|---|---|---|
| 甲库可供 | 260 | 99.8% | 15.2% |
| 乙库可供 | 200 | 9.8% | 59.8% |
| 丙库可供 | 180 | 99.7% | 10.8% |
| A 城过水 | 300 | 13.2% | 400%（基准宽松） |
| B 城过水 | 320 | 37.3% | 375%（基准宽松） |

### 两两同时改：法则上限 vs 真实拐点

| 组合 | 方向 | 法则 | 真实 | 倍数 |
|---|---|---|---|---|
| 甲+乙 | 放宽 | 12.1% | 15.4% | 1.27× |
| 甲+乙 | 收紧 | 8.9% | 10.0% | 1.13× |
| 甲+丙 | 放宽 | 6.3% | 11.1% | 1.76× |
| 甲+丙 | 收紧 | 49.9% | 100% | 2.00× |
| 乙+丙 | 放宽 | 9.2% | 60.0% | 6.54× |
| 乙+丙 | 收紧 | 8.9% | 100% | **11.26×** |

### 三库等比放宽

- 法则在 **6.0%** 松口；**真实换基 15.5%**；
- $t\le15.5\%$ 时 $z$ 严格线性（影子价完全可信）；$t>15.5\%$ 后**甲库影子价 9.0 → 0**（A 城管网接替瓶颈）。

### 对照模型（三库三城 + 总调水上限）

```
z* = 2990.00；影子价 甲 0.000 ｜ 乙 0.400 ｜ 丙 1.800 ｜ 总调水上限 9.000
单独 +10 万m3：甲 +0.00 ｜ 乙 +0.40 ｜ 丙 +1.80
```

→ 「扩丙库最划算」是错的：总调水不动，扩任何一座库只是把水在城市之间重新分配。

## 避坑（8 条）

1. 🔴 保底面积写成 $x_i\ge r_i\sum x$ 时 $x=0$ 恒可行 → 全 0 解、影子价全 0，脚本静默出图（Day73 同款）；
2. 🔴 改结构时 `A_ub` 行数与 `b_ub` 长度不同步 → `must be 1-D` / broadcast 错；
3. 🔴 「有效约束」不能用「影子价 > 0」判断（退化行），统一 `b - A x ≤ 1e-7`；
4. 🔴 允许幅度要扫到「约束集变」，不是「$z$ 变」；
5. 🔴 别硬造「法则失效」的例子（本实例 11 倍都不失效）；实例给什么就写什么；
6. 🔴 反例搜索 0 命中也是结论（±35% 内未找到）；
7. 🟡 画图选错资源（甲 vs 乙），拐点后谁在动要先看一眼；
8. 🟡 `np.float64` 进 json 崩（Day66 家族）；中文图用 Noto Sans CJK。
