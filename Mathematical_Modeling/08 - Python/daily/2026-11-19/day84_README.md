## 10 问速览

1. **解决什么**：同时决定「修哪几条（0-1）」与「水怎么流（连续）」，最小化运营 + 造价年化。
2. **何时用**：出现「候选线路 / 新建管道」，且造价是**一次性、与流量无关**的。
3. **为什么适合**：结构一眼对得上业务；本题 $2^4$ 可全枚举当**精确裁判**；有两层下界可打印 gap。
4. **模型**：$\min \sum c_ax_a + \sum \tilde f_k y_k$，s.t. 守恒、$0\le x_a\le u_a$、$x_{a_k}\le u_{a_k}y_k$，$y_k\in\{0,1\}$。
5. **怎么解**：全枚举 / MILP+大M / LP 松弛 / 拉格朗日松弛，四条路互为裁判。
6. **大 M**：本可只取 4.0（最大容量）；实测 4→1e6 答案不变，但**别当规律**（$M$ 进目标时会拖垮界）。
7. **验证**：枚举 vs MILP 双签；两下界都 ≤ 真最优；水源侧「运营 > 0」防漏水；超可加与政策夹逼逐条断言。
8. **缺点**：LP 松弛极弱、取整 = 乱猜；$n$ 大要上列生成；造价 ±20% 足以翻转结论。
9. **替代**：逐条塞（Day83，仅在候选互不干扰时准）、贪心按回收期、次模最大化（**本讲目标不次模**）、Benders。
10. **进论文**：单条表 + 组合表 + 下界表 + 一句「目标不满足次可加，逐条评估系统性低估 41%」。

## 避坑（7 条，全部真踩）

1. 🔴 **零成本水源余水弧让全题变 $z=0$**（水从源头「空运」到镇）→ 必须两条并联弧：取水 2.00 元/m³ / 不取 0 元。
2. 🔴 **造价不能和日省直接相加**（差 4 个数量级）→ 6%、20 年等额年金折成「万元/日」。
3. 🔴 **LP 松弛给出 $-0.0$** → JSON/表格统一 $\pm0$。
4. 🔴 **候选弧下标不能假设紧跟基础弧**（水源弧是最后追加的）→ 按 (u,v) 现查。
5. 🔴 **Benders 割是下界不是上界**：写成 `LinearConstraint(A, -inf, b)` 会永远选 $y=0$、LB 恒 0 且**判定收敛**，
   无报错无警告 —— 靠「上界必须等于枚举最优」的交叉验证才逮住。
6. 🔴 **$y=0$ 处子问题退化**，包络定理斜率不成立（建了反而「更贵」）→ 固定费用上 Benders 不平凡，改用拉格朗日。
7. ⚠️ **贪心本例恰好最优**（可行性结构太简单）→ 如实写，不硬造「贪心崩」的例子；超可加才是贪心的真危险。
