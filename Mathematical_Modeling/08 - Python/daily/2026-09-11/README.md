# Day 11 — 信贷风控(三)：决策树 / 随机森林

配套教案：[[Day11 - 决策树与随机森林信贷规则与集成]]（`05 - Algorithms/`）

## 10 问（精简成文）

1. **解决什么问题**：信贷员要的不是黑箱分数，而是"拒贷的**具体理由**"。Logistic 边界是直线、KNN 给不出规则，决策树能把决策拆成一串可念的 if-else。
2. **问题实质**：把分类做成"贪心的二十问游戏"——每刀让子结点基尼不纯度下降最多。
3. **模型/变量**：自变量 = {收入, 负债率}；因变量 = 好客户(0)/违约(1)；树结构 = 结点(特征, 阈值) + 叶子(违约概率)。
4. **求解方法**：手写 CART——`gini` → `best_split`（遍历特征×阈值）→ 递归建树；超参 max_depth / min_samples_leaf 防过拟合。
5. **为什么不能更深**：不限制深度 → 训练集 100%、测试崩（高方差/过拟合）。本课实测训练测试喇叭口。
6. **随机森林怎么做**：自助采样 + 每次切分只抽部分特征 → 造多样化的树 → 投票平均，摊薄方差。
7. **结果解读**：深度4 树测试 0.7611；特征重要性 负债率 0.675 > 收入 0.325；混淆矩阵显示"拒错好客户 19 vs 漏放坏账 24"的代价权衡。
8. **意外发现**：随机森林（0.733）**跑输**单棵树（0.761）——小数据 + 仅 2 特征时"特征随机"造不出多样性，集成不灵。
9. **检验**：与 sklearn 交叉对照（同量级）；方向断言（高负债→高违约概率）；重要性归一化。
10. **局限与下一步**：单树不稳 → 可上 GBDT/XGBoost、或先做特征工程/PCA；下一步可转集成学习或评价类 AHP/TOPSIS。

## 要点

- 决策树 = 贪心挑最纯一刀，长成**可读规则**、**自动抓交互**、给概率；但**高方差**。
- 随机森林 = 样本自助 + 特征随机 → 投票集成；**数据/特征太少时未必赢单树**。
- 判定线仍是**业务决策**；特征重要性可用于**特征筛选**。
