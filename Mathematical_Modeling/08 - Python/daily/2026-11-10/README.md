## 一句话结论

**值函数 $g(b)$ 是一条分段线性的折线，不是一条直线。** 本例只有三段：预算 < 7.50 万工时时边际 2.80，
7.50~7.81 时只有 0.10，7.81 以后是 0。**把 2027 报表上那个「每万工时 2.80」直接拿去给 2028 做预算，
会高估 28 倍以上**——因为 2028 的瓶颈已经从「钱」换成了「评估师编制与护理员」。

## 十问

1. **解决什么问题？** 右端项（预算）连续变动时，最优值与最优解的**整条路径**，而不是一个点。
2. **什么时候用？** 先定资源总量、再定怎么用的两阶段决策：预算谈判、编制审批、指标分解、产能扩张。
3. **为什么适合？** $b$ 变动只破坏可行性、不破坏检验数（Day58），所以从上一段的基出发就能算出整条路，且**只有有限段**。
4. **数学模型？** $\max c^\top x$ s.t. $Rx\le\hat b$、$\mathbf1^\top x\le b$；每段 $g(b)$ 是 $b$ 的仿射函数，换基即换斜率。
5. **怎么求解？** 粗网格扫描（0→9.5，221 点）→ 斜率变化处二分到 $10^{-6}$ → **双侧实解核对**（解与紧约束真的换了）→ 凹性自检。
6. **怎么实现？** 5 变量 4 约束的小 LP 直接**顶点枚举**（比通用求解器更可信，Day59 的 presolve 假最优教训）；`solve(b, extra=...)` 支持追加一行专项。
7. **怎么验证？** ① 拐点两侧斜率必须真的差；② 每段解代回约束可行、紧约束与斜率解释一致；③ 末段斜率 0 时必须能指出卡的是人；④ 斜率单调不增。
8. **有什么缺点？** 单参数才能画成线；折线是理想化（多一个护理员不是连续量）；只描述同一模型下的变化；台阶层（0.10）对差分步长敏感。
9. **替代方法？** 多场景重解、参数单纯形（跟基走）、ε-约束法（Day17）、拉格朗日对偶（Day35）。
10. **怎么进论文？** 交付「预算—效果曲线 + 每段价格 + 每段瓶颈 + 政策有效区间」，边际与平均必须同时报并标注对应预算。

## 避坑记录（本轮 6 次实例重建，全部实跑暴露）

1. **参数选错，整节课死**：第一版用「床位总数 $S$」做参数，放大后最优恒为「全上内科」，值函数一条直线、零拐点。
2. **基数落在可行域外 ⇒ $g\equiv0$，脚本沉默通过**：第二版护理工时基数 38 让所有顶点不可行，跑出一张漂亮的全 0 图；
   **只写了「段数≥2」的断言抓不住**，补上 `g(0)>0` 才炸出来。→ **断言要卡「数是真的」，不只卡「形状对」**。
3. **假拐点成对出现**：二分窗口重叠会在真实折点附近报出两个间距 0.014 的拐点，出现「段 2 的 $a>b$」。
   修法：收尾后 1e-5 双侧斜率核对（阈值 1e-3）、并做间距去重。
4. **台阶层浅（0.10）定不准**：1e-6 差分与噪声同量级 → 改 1e-5 差分 + 与两侧实解比对。
5. **「不生效」≠「零成本」**：专项要求超过可行上限时返回 `inf`，被 `None` 过滤后表格只剩一行；必须显式标「不可行」。
6. **对照要选在有争议的那一项上**：最初想用「最贵的上门护理」做 0.5 万的对照，它净收益最低、一投就掉 1.125，
   只能说「别投它」，说不出「优先补重度失能划不划算」——换成与老人协会主张一致的居家/日间才有信息。
