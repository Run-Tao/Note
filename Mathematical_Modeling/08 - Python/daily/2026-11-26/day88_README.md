## 十问

**1. 这一课解决什么决策？**
云溪县 16 村「一村一品」底账分几类、320 万扶持资金怎么切块。党组会上业务科说 5 类、领导说 7 类。

**2. 为什么轮廓系数回答不了这个问题？**
轮廓只看平铺的划分，不告诉你「5 → 6 时是谁被拆开了」。层次聚类保留整条合并路径，**k = 选哪一刀不切**。

**3. 切树的判据是什么？**
**jump** = 这一刀高度 ÷ 下一刀高度。本例 k=5 处 **0.53**、k=7 处 **0.33**、k=6 只有 **0.04**。

**4. 紧致度（簇内平均距离）能不能用？**
不能单独用。k=2→8 它从 0.326 单调降到 0.082，**每个 k 都在变好**，永远不会给你一个肘部。

**5. 5 还是 7？**
数据给的是「两个台阶」：k=5（业务上叫大产业区）与 k=7（再按粮/菜拆平原）。
**差在联星、新坝是否单列**，两刀高度只差 **0.0101**，但对应的钱是 20 万/村 → 33~50 万/村。

**6. 三种连接方式一致吗？**
average / complete / ward 在 **k=5 与 k=7 两处 ARI 都是 1.000**，在 k=3/4/6 只有 0.725 / 0.777 / 0.800。
⇒ **台阶上可信，台阶之间是算法的选择。**

**7. 权重会不会改结论？**
k=5 的分组对三个权重口径**完全不敏感（ARI=1.000）**；k=7 下把收入权重提到 3 倍，**新坝**被拆出来（ARI 0.838）。
⇒ Day87 说「三个单例」，本讲说**只有云顶是真的**。

**8. FCM 说了什么？**
云顶在 5 个簇上的隶属度是 **(0.20, 0.19, 0.22, 0.21, 0.18)** —— 近乎均匀，**跟谁都不像**；
桐子 0.348；联星 0.817、新坝 0.835（**不模糊**，粮/菜分账得不到隶属度支持，只能靠政策理由）。

**9. 稳定吗？**
bootstrap 200 次：k=5 **0.919**、k=7 0.829、k=6 0.746。k=5 最稳。

**10. 能写进论文的一句话？**
「层次聚类（average）在 k=5 与 k=7 处各有一刀明显台阶（jump 0.53 / 0.33），中间 k=6 不成立（0.04）；
k=7 与业务规矩分（地形×主产业）ARI=1.000 ⇒ **本模型印证而非发现了人工分类**；
k=5 对三套权重稳健（ARI=1.000），**建议主线报 5 类、粮菜分账作情景分析**；
FCM 显示云顶无归属（隶属度近均匀），宜走个案政策。」
