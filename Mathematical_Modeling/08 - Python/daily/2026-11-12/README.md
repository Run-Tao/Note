## 一句话结论

**20 点这张图上，全枚举 1.1 秒就给出精确最优 146 km（两个独立枚举裁判一致）；局部搜索 1000 次重启也到 146，
SDP 松弛给 149.49（间隙仅 2.4%）。而 GW 的 0.878 是「期望保证」——1000 条轨迹里有 13.8% 低于 0.878，最差一条只有 0.808。**
所以这篇的真正结论不是「哪个算法好」，而是：**每条保证都有它自己的适用范围，报数时必须写清楚。**

## 十问

1. **解决什么问题？** 把一组对象劈成两半，让「被切开的关联」最大（Max-Cut）或最小（Min-Cut）。
2. **什么时候用？** 二分片区、分班/分队、社区发现第一步、Ising 模型、电路分平面；任何「划线」能吃成钱的问题。
3. **为什么适合？** 目标是一个干净的二次型 $\frac14\sum w(1-x_ix_j)$，$x\in\{\pm1\}^n$，NP-hard 但结构透明，适合讲算法与保证。
4. **数学模型？** $\max \sum_{i<j}w_{ij}(1-x_ix_j)/2$ s.t. $x_i\in\{\pm1\}$。
5. **怎么求解？** ① 全枚举（$n\le22$，裁判）；② 1-flip 局部搜索 + 多起点；③ SDP 松弛 + 随机超平面舍入（GW）；④ 舍入后再局部搜索。
6. **怎么实现？** 20 点 45 边、总里长 177 km；SDP 用 Burer–Monteiro（$U=Z/\|Z\|$）+ L-BFGS 多起点（无 MOSEK，**近似求解**，靠自检）。
7. **怎么验证？** ① 两个独立枚举裁判必须一致；② SDP ∈ [OPT, Σw]；③ 所有 1-flip 局部最优满足半划分门槛；④ 同实例多次重启能到最优；⑤ 单次最差必须显著低于最优（否则教学点消失）。
8. **有什么缺点？** 局部搜索只保证 $1/2$；GW 的 0.878 是期望，单次无保证；SDP 需要专业锥规划求解器，本讲近似在 $n\ge50$ 会失效；本讲求不出紧的对偶界。
9. **替代方法？** 模拟退火 / GA（Day6）、禁忌搜索（Day42）、谱方法（快但没保证）、专用 SDP 求解器（MOSEK/SDPT3）。
10. **怎么进论文？** 分区图 + 割值 + 三档方案 + 每条保证的适用范围；报松弛间隙；报最差轨迹；**别把 0.878 写成结果**。

## 八条避坑

1. **SDP 目标里漏掉常数项** → 值低于最优，违反松弛性质。断言 `sdp_val >= OPT` 是唯一能抓住它的东西。
2. **SDP 的量纲系数（0.125 vs 0.25）来回改**，值在 88.5 / 149.49 之间跳。锁死办法：**取一维嵌入 $u_i=x_i e$，SDP 值必须恰好等于割值**。
3. **MILP 线性化写错时求解器不报错**。两种写法都在 $x\equiv1$ 处给出 177（真实割 0）。放弃 MILP，改两个独立枚举。
4. **半划分门槛方向别写反**：局部最优是 $\sum w x_ix_j\le0$（内部 ≤ 总权一半），不是 ≥0。
5. **`res.x` 切片可能读到被改写的缓冲** → 统一 `.copy()`。
6. **Powell 对归一化参数化会破坏可行性** → 只用 L-BFGS（jac 先做数值校验）。
7. **别为了讲理论界硬造最坏例子**：三角簇 / K4 链 / 3-正则图等 6 种构造全部 = 1.000。换维度（随机稀疏图 × 只跑一次）立刻出现 0.787。
8. **JSON 里所有数 `round(float(x), 3)`**（Day66/Day70/Day74 家族）。
