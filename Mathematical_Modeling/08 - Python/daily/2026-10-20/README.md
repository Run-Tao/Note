## 场景

云溪县河段断面只有 9 个季度氨氮数据（2024Q2–2026Q2），要定：现在发不发限排令、发几级、发多久。Ⅲ 类水硬线 2.00 mg/L，内控软线 1.80 mg/L。

## 10 问速答

1. **解决什么问题**：小样本、无机制、无历史同期时的"趋势 + 越线时刻"预警。
2. **什么时候用**：4~10 个等间隔点、近似单调、级比检验通过；样本多到能数 ACF 就改用 ARIMA。
3. **为什么适合**：只估 2 个参数（$a,b$），参数/样本比远低于回归/ARIMA；"半机制"假设（增长率稳定）在单调序列上成立。
4. **数学模型**：灰微分方程 $x^{(0)}_k + a z^{(1)}_k = b$ → 白化方程 $\dot x^{(1)}+a x^{(1)}=b$ → IAGO 还原。
5. **求解方法**：最小二乘 $\hat p=(B^\top B)^{-1}B^\top Y$（`np.linalg.lstsq`）+ 白化解解析式；DGM(1,1) 用 AGO 一阶递推对照。
6. **参数从哪来**：全部从数据估；$a$ = 发展系数（$-7.56\%$/季），$b$ = 灰作用量（0.947）。
7. **结果怎么读**：2026Q3 = **1.553**；软线 1.80 → $k^\*=10.09$（2027Q1），硬线 2.00 → $k^\*=11.24$（2027Q2）。
8. **怎么检验**：级比检验 + 后验差 C/P（全段与剔首点两口径）+ 扩展窗口滚动回测 + 数据扰动。
9. **敏感性**：删末点 / 末点 ±3% → $k^\*$ 漂 0.09~0.30 季；0.5% 噪声 ×300 → $11.25\pm0.06$，P5~P95=[11.14,11.35]。
10. **坑**：AGO 累计值不能直接比阈值；IAGO 首点要回填；先平移再累加；C 好看不代表准；末点敏感必须报区间。

## 关键实跑数字（`.venv`）

- 级比 $\lambda\in[0.8936,0.9062]$ ⊂ 可容区 $(0.8187,1.2214)$ → **通过**；
- $a=-0.07555$、$b=+0.94660$，等价增长率 **7.56%/季**；
- 后验差 **C=0.0190 / P=1.00「好」**（剔首点 C=0.0217 同等级）；拟合 MAPE 0.44%；
- 2026Q3：**GM 1.5532** / DGM 1.5547 / 增长率法 1.5782 / 直线 1.4733 / 最后值 1.4200；
- 滚动一步：**增长率法 0.0061** < DGM 0.0093 < **GM 0.0103** < 直线 0.0514 < 最后值 0.1200 —— **土办法赢了，但 GM 能解析反解越线时刻**；
- 越线：软线 1.80 → $k^\*=10.09$（2027Q1，+6 个月）；硬线 2.00 → $k^\*=11.24$（2027Q2，+10 个月）；
- 扰动：删末点 +0.09 季 / 删两点 +0.15 / 末点 ±3% ∓0.28~0.30 / 噪声 $11.25\pm0.06$；
- 决策：**2027Q2 ± 1 个月越硬线，且不早于 2027Q1** → 「本季发一级限排令、按 2~3 季执行、每季复核，连续两季环比 >9% 则提前一级」。

## 避坑记录

1. **AGO 累计值 ≠ 瞬时值**：第一版拿 $\hat x^{(1)}(k)$ 和 2.00 比，反解出 $k^\*=0.84$（"第一个点就越线"）。改为 **AGO 曲线斜率** $dx^{(1)}/dt$ 后正确。
2. **IAGO 首点不能再用白化解**：第二版令 $\hat x^{(1)}(0)=x^{(1)}(0)$ 后再用白化解算 $\hat x^{(1)}(1)$，首点被压成 $0.66-0.83$ 的负值。正确的是**首点直接回填 $x^{(0)}_1$**。
3. **先平移再 AGO**：直接对大初值累加时 $b$ 被初值主导，拟合出 `[-0.08, 1.03, ...]` 的负浓度（首轮实跑即复现）。
4. **AGO 之差不加平移量**：`x1h[1:] - x1h[:-1]` 得到的是 $y$（已平移）尺度的差，忘了 `+off` 会让整条拟合线掉一个常数。
5. **`-W all` 当失败用**：`warnings.filterwarnings("error")`，字体缺字/除零/溢出任何一条都立刻崩，不靠肉眼查乱码。
6. **中文字体走回退链**：`font.family="sans-serif"` + `["Noto Sans CJK SC","DejaVu Sans"]`。
7. **扰动必须重置平移基准**：噪声加在**原始尺度**上再交给 `gm11`（内部平移），不能在已平移的 $y$ 上加噪声。
8. **后验差 C 要两口径**：首点残差恒 0，9 点序列实际只有 8 个残差参与离散度，必须同时报"剔首点"。
