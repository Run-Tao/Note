# Day 5 — 非线性规划（NLP）：当"风险"进入目标，LP 就罢工了

> 锚点：[[Learning_Roadmap|Learning Roadmap]] Level 6 · 优化模型第三课（数学规划三件套收尾：Day3 LP → Day4 ILP → Day5 NLP）。
> 上一篇 Day4 管住"离散决策"，今天讲**连续变量但仍非线性**的问题：风险本身是权重的二次型，LP 只认直线只会教你把钱**全押回报最高那条**——却对翻船风险视而不见。用"三条产品线怎么分预算"把它跑通。

## 0. 一句话总结

**风险 = 权重协方差二次型 $w^\top\Sigma w$，不可线性相加**，所以必须上 **NLP/QP**。`scipy.optimize.minimize(SLSQP)` 在"预算分光 + 最低回报达标 + 不卖空($w\ge0$)"下最小化总风险，最优是把钱**分到高回报线 + 避险线**，波动从 20% 压到 14.4%、回报还保住 10%——比 LP 式"全押最高回报"更聪明。

---

## 一、解决什么问题？（10问之1）

目标/约束出现**乘、乘方、商、对数、指数**等非线性时：
- 投资组合/资本配置（风险方差二次型）、收益递减/饱和(边际报酬递减)、非线性成本、工程优配。
- 典型问法：*"预算 W 分给三条产品线(各有期望回报 $\mu_i$ 与协方差 $\Sigma$)，怎么分配让总风险最小、同时总回报不低于某值？"*
- 本课用研发/营销的三条产品线资金配置切入。

## 二、何时用、为何适合？（10问之2、4）

- 风险是决策核心 → 方差 $w^\top\Sigma w$ 天然二次 → NLP/QP，LP 表达不了；
- 最优解埋在**多变量曲面内部**而非线性顶点处；
- 是金融资配/供应链/ML(正则化)通用地基；论文写"均值-方差"即刻提档；
- 目标约束全线性 → 回去用 Day3 LP / Day4 ILP（更快更稳）；
- 含整数+非线性 → MINLP 极难，先别碰。

## 三、数学模型？（10问之3）

- 期望回报 $\mu_p=\mu^\top w$（线性）；风险 $\sigma_p^2=w^\top\Sigma w$（**二次型**，含 $w_iw_j\sigma_{ij}$ 交叉项→非线性→风险不可相加）：

$$
\min_w w^\top\Sigma w \quad\text{s.t.}\quad \sum_i w_i=1,\ \ \mu^\top w\ge\bar r,\ \ w_i\ge0
$$

二次目标 $w^\top\Sigma w$ 使它是 **二次规划(QP)**（NLP 里最规矩的一类）。LP 想不通"为何不全押回报最高线"——因为全押时 $\sigma^2$ = 那条线自身方差会爆，二次型曲面把它拉回做分散化。

## 四、如何求解？（10问之5）

平滑有约束选 **SLSQP**（`scipy.optimize.minimize`，逐次二次规划，支持等式+不等式）；纯 QP 也可 `trust-constr` 或专用求解器(OSQP/cvxopt)。标准步骤：写目标 → 列约束(dict) → bounds(不卖空 $0\le w\le1$) → **可行初值(等权 $w_0=(1/3,1/3,1/3)$)** → minimize → 检查 `res.success` 与约束残差。

```python
from scipy.optimize import minimize
risk = lambda w: float(w @ Sigma @ w)          # 二次目标(风险)
cons = [
    {"type": "eq",    "fun": lambda w: np.sum(w) - 1.0},  # 预算分光
    {"type": "ineq",  "fun": lambda w: (mu @ w) - 0.10},  # 回报>=10%
]
res = minimize(risk, np.ones(3)/3, method="SLSQP",
               bounds=[(0, 1)]*3, constraints=cons)       # w>=0 不卖空
```

> 要诀：**初值须可行**，否则 SLSQP 起点就飞走；等权是天然可行起点。

## 五、结果与解读（代码实际跑通输出）

线1 12%/高波动、线2 10%且与线1强相关、线3 6%/低波动低相关(避险)。要求回报≥10% 最小化风险：

```
LP式全押线1:  回报12%, 方差0.0400 (波动≈20.0%)        ← 孤注一掷
NLP 最优:     线1=66.7% 线2=0% 线3=33.3%  回报10%, 方差0.0207 (波动≈14.4%) ✅
解析 GMV(可卖空无约束) w=[-9,10,0] → NLP 是它的 w>=0 现实约束版
纯最小方差(不管回报) w=[0,18.2%,81.8%], 方差≈0.0088
```

**解读三连：**
1. **"全押最高回报"坏决策**：回报 12% 但波动 20%，一次大回撤吞掉多年收益，LP 看不见；
2. **NLP 用 1/3 的钱买"保险"**：线1(高回报)66.7%+线3(避险)33.3%，波动 20%→14.4% 而回报仍 10%；**线2=0**（回报比线1差又高度相关，加它既不增收益也不能分散=浪费预算——遍历协方差后的结论，非凑数）；
3. **收益是风险换来的**：回报从最低风险的(约6%)抬到 10%，方差 0.0088→0.0207——有效前沿上每一格都标着价签。
图：左图单资产点 vs 优化组合★(更少的风险、保住回报=分散化破"高回报低风险不可兼得")；右图一串 target 的 NLP 解描出**有效前沿**(risk-return 权衡曲线)，★正好落在其上。

## 六、如何验证？（10问之6）

- 约束自检：Σw=1、w≥0、$\mu^\top w\ge$ 目标 全过；
- 方法交叉：SLSQP 与 trust-constr 各解一次，权重差<5e-3即一致（防单求解器自欺）；
- 解析对照：无回报约束的最小方差有闭式 $w_{gmv}=\Sigma^{-1}\mathbf{1}/(\mathbf{1}^\top\Sigma^{-1}\mathbf{1})$（可含负权），确认数值解是它的 $\ge0$ 现实约束版——"理论底 + 约束现实"双层核对。

## 七、缺点与替代？（10问之8、9）

- **局部最优**：非凸时 SLSQP 只保局部 → 多初值重跑或换启发式(模拟退火/遗传，后续 Day)；
- 对初值敏感、可能不收敛：须给可行初值并查 success；
- $\Sigma$ 要估且样本少不稳 → Ledoit-Wolf 收缩/因子模型；
- 大规模高维 → 专用 QP/凸求解器(OSQP) 远快于通用 minimize；
- 纯线性 → Day3/4。可加蒙特卡洛撒点 + 帕累托下包络可视化佐证有效前沿。

## 八、怎么写进论文？（10问之10）

符号表($w_i,\mu,\Sigma,\bar r$) → 目标(方差二次型)与约束，明说"风险不可加→二次型→非线性" → 求解器(SLSQP/OSQP)+初值容差 → 结果表(单资产 vs 组合权重与方差, 强调 20%→14.4% 而回报不降) → 敏感性(扫 target 画有效前沿) → 可附解析 GMV 公式作理论锚。

## 九、可迁移性（练习）

- 加第 4 条相关避险线或"单类上限 $w_i\le0.5$"看变化；
- 把协方差对角化(全独立)重算——体会相关=0 时分散化最划算；
- 目标改**最大化夏普比率** $\frac{\mu^\top w-r_f}{\sqrt{w^\top\Sigma w}}$（带分数=非线性）对比最小方差；
- 蒙特卡洛撒 1 万随机 $w$ 画散点+你的有效前沿，看"上包络才是最优边界"。
