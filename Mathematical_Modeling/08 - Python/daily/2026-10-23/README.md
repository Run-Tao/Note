## 场景

味源 / 河湾两家酱菜厂争同一批商超名额，3 个新品方案 × 3 种铺货打法，格子是味源的赢利（万元）：

| 味源 ＼ 河湾 | 低价促销 | 高端陈列 | 餐饮直供 |
| --- | --- | --- | --- |
| 萝卜条 | 62 | 18 | 44 |
| 豆腐乳 | 30 | 70 | 24 |
| 酸菜 | 51 | 36 | 58 |

## 关键实跑数字（`.venv`，`-W all` 0 告警，11 条断言全过）

- 行最小 18 / 24 / 36，列最大 62 / 70 / 58，**鞍点 0 个**；$\max\min=36$、$\min\max=58$，缺口 22 万；
- 味源 LP：$p^*=(0,\ 0.2727,\ 0.7273)$；河湾 LP：$q^*=(0.6182,\ 0.3818,\ 0)$；**$v^*=w^*=45.2727272727$，差 1.4e−14**；
- 味源 LP 三条约束的影子价格 $=(0.6182,0.3818,0)$ **逐位等于** $q^*$ → 对偶命题数值成立；
- 防御：对手只出低价 / 只出高端 → 45.27；只出餐饮 → **48.73**；均匀 → 46.42；
- 变招无利：三个纯方案面对 $q^*$ 期望 $=(45.20,45.27,45.27)$，最大即 $v^*$；
- 冒牌策略（对手最优反应下保底）：均匀 41.33（**−8.7%**）、只出酸菜 36.00（−20.5%）、75% 豆腐乳 30.75（**−32.1%**）、只出萝卜条（含 62 万最高格）18.00（**−60.2%**）；
- 单参数扫描 $p=(x,1-x,0)$：顶点 $x\approx0.64$，最坏 41.33 < 45.27；
- 敏感性（每格 +1 万 → 博弈值增量）：最大 **酸菜×低价促销 0.4416**，次之豆腐乳×低价 0.1965；**餐饮直供整列 = 0**；九格合计 1.1278（**不是 1**，见避坑 3）。

## 避坑

1. **两个 LP 必须独立建模**：共用一份"聪明"的代码会让"对偶关系成立"变成自证。
2. **均衡双向核对方向别写反**：`A @ q`（味源各纯方案面对 $q^*$）取 **max** = $v^*$；`p @ A`（河湾各打法面对 $p^*$）取 **min** = $v^*$。初版对行侧取了 min → `AssertionError`。
3. **不要断言"逐格偏导之和 = 博弈值"**：线性最优值的次梯度在退化点不唯一，实测合计 **1.1278** 而非 1；逐格偏导是单向边际，不是总量分摊。
4. **对偶解符号**：约束写成 $-A^\top p+v\le0$ 时，`ineqlin.marginals` 为负，需取负才是 $q^*$。
5. **仓库外路径不能用 `apply_patch`**（会报 Path escapes sandbox root），用 `edit`/`write` 或脚本改。
6. **教学实例要做四项体检**（已写成断言）：无鞍点、天真策略全严格劣于最优、结构清晰（有整行/整列退出支撑集）、敏感性有 >0.3 的命门格。
7. **图里不用下标字符**：`p₁/x₂` 在 Noto Sans CJK 下 glyph missing，改 `p1/x2`。
