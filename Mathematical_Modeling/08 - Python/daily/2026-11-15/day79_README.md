## 十问

1. **解决什么问题？** LP 解完，要判断「**几个目标系数同时变、方向还不限**」时，原来的基/方案还成不成立。
2. **什么时候用？** 价格/补贴标准还没定、要先交方案；报价谈判可能涨也可能降；论文灵敏度分析要一句扛得住追问的结论。
3. **为什么适合？** 「基不变」在目标系数上是**线性**条件（检验数 $r_j$ 对 $c$ 线性），所以盒子顶点可全枚举（$2^n$ 个）。
4. **数学模型？** $r_j(\delta)=c_j+\delta_j-(c_B+\delta_B)^\top B^{-1}a_j\ge0$；$t^*=\max\{t:\forall|\delta_j|\le t,\ r_j(\delta)\ge0\}$。
5. **怎么求解？** 自写单纯形拿**基元组**；单项区间二分；$t^*$ 用 32 个顶点枚举 + 二分。
6. **怎么实现？** 判据一律 `simplex(c)[2] == BASE`（比较基元组），**不比较目标值**——目标值容差会吞掉换基。
7. **怎么验证？** 影子价 vs 有限差分；越界 1.05 倍必失基；3000 组随机扰动法则漏报计数；400 个随机 LP 看 t* 分布。
8. **缺点？** 只对一个基成立；盒子形状是拍的；目标系数上极保守；不覆盖技术系数 A。
9. **替代？** 参数规划（一条路精确）、多参数规划（精确区域）、鲁棒对等 LP、蒙特卡洛失基概率。
10. **怎么进论文？** 基准+基结构 → 逐项区间 → $t^*$ 写成人的句子 → 报「法则拦下但其实没事」的实测。

## 避坑（6 条）

1. 🔴 **`linprog` 拿不到「基」**：用「卡死行号」当代理在带下限/恒定紧的实例上会把不同基判成同一个，$t^*$ 直接假（本讲返工 3 轮的主因）。必须自己写单纯形、比较基元组。
2. 🔴 **实例退化到 0 教学点**：第一版三约束全松、只有上限紧，$t^*=\infty$。换 4 轮实例（含 3000 次随机搜索）才得到「一条资源紧 + 一个包为零 + 三个包顶格」。
3. 🔴 **`np.array(tuple) * t` 报 `can't multiply sequence`**：顶点枚举一律 `np.array(sg, float)`。
4. ⚠️ **中文引号进 f-string 直接 SyntaxError**（踩两次）：统一用「」。
5. ⚠️ **∞ 的单项上限不能直接进条形图**，会拉爆 y 轴：截断到 3000 并在图例标注。
6. ⚠️ **随机 LP 抽查只抽 3 变量**：$2^n$ 顶点 × 二分 × 400 个 LP，n=10 会慢到不可接受；本讲如实说明未做高维。
