# Day37 · 割平面法（Gomory Cut）（代码）

> 教案正文见 [[Day37 - 割平面法Gomory割与整数规划的削顶点求解]]（`04 - Optimization/`）。
> 脚本：`gomory_cutting_planes.py`；图：`gomory_cutting_planes.png`。

## 一句话

Day4 学了整数规划（**分支定界**：在搜索树上分治剪枝）、Day26 学了 LP 单纯形与对偶，
本课补上整数规划的**另一条精确路径**——**割平面法（Cutting Planes）**：
**不分支、不搜索**，只在同一张 LP 上不断追加**合法割**，
把可行域一点点"削"，直到 LP 最优解自己变成整数。
用「工厂整数排产」决策跑通全套，核心的 **Gomory 分数割直接从最优单纯形表读出**。

## 真实决策背景

一家工厂用有限的**设备工时**和**原料**同时生产两种产品：

- 产品 1：每件用设备 3 工时、耗料 1 单位、赚 **5** 元；
- 产品 2：每件用设备 1 工时、耗料 2 单位、赚 **3** 元；
- 本周可用设备工时 **10**、原料 **8**。

问：**各生产多少件，总利润最大？**（件数必须整数）

$$
\max\; 5x_1+3x_2
\quad\text{s.t.}\quad
3x_1+x_2 \le 10,\quad x_1+2x_2 \le 8,\quad x_1,x_2\in\mathbb{Z}_{\ge0}.
$$

## 为什么需要割平面法

- **LP 松弛**：$x=(2.4,2.8)$、利润 **20.4**——分数解"看着更赚"，但不可执行；
- **整数最优**：$x=(2,3)$、利润 **19**——差 **1.4 元**就是**整数间隙**；
- Day4 的**分支定界**靠"分"（分支出子问题、重解 LP、树上剪枝）；
  割平面法换一条路——**靠"削"**：不分支，只在同一 LP 上加约束。

一条割要同时满足：**合法**（所有整数可行点都满足，否则切掉真最优）+ **有效**（切掉当前 LP 的分数顶点）。

## Gomory 割的来历

取 LP 最优表里**分数取值**的整数基变量所在行：

$$x_B+\sum_j a_{Bj}x_j=b_B,\qquad b_B=\lfloor b_B\rfloor+f_0,\ \ a_{Bj}=\lfloor a_{Bj}\rfloor+f_j.$$

因所有 $x$ 整数，$\sum_j f_j x_j \equiv f_0 \pmod 1$，且左端 $\ge0$，故

$$\sum_j f_j\,x_j \;\ge\; f_0.$$

**这就是 Gomory 分数割**：它对任何整数解都成立（合法），却违反当前分数 LP 顶点（有效）。

## 脚本结构

`gomory_cutting_planes.py`——**主算法零专用求解器全手写**：

- `simplex`：**手写表式单纯形法**（$\max c\cdot x,\ Ax\le b,\ x\ge0$），
  返回最优解 + **最终单纯形表与基变量**；
- `gomory_cut_from_tableau`：从最优表选"分数取值整数基变量"行，构造割 $\sum_j f_j x_j\ge f_0$；
- 割含松弛变量 → 用 $s_k=b_k-A_kx$ 消去，化回"只含原变量"的约束；右端为负则 $\times(-1)$ 翻成 $\le$ 形；
- `cutting_plane_rounds`：主循环；`enumerate_integer_feasible`：**暴力枚举**核验割的合法性；
- `solve_exact_milp`：`scipy.milp` 求整数真最优，**仅作独立裁判**。

## 实测结果（`.venv` 真实跑通）

| 口径 | 目标（利润） | 解 |
|---|---|---|
| LP 松弛 | **20.4000** | $x=(2.4,2.8)$（分数，不可执行） |
| 割平面 第1轮 | 20.0000 | $x=(2.5,2.5)$ |
| 割平面 第2轮 | 19.3333 | $x=(2.6667,2)$ |
| **割平面 第3轮** | **19.0000** | $x=(2,3)$ ✓ 整数 |
| **整数最优**（`scipy.milp`） | **19.0000** | $x=(2,3)$ |

- **仅 3 条割**就把 LP 上界 **20.4 → 19.0**（= 整数最优），LP 解自己变成整数 $(2,3)$；
- 三条割：$2x_1+2x_2\le10$、$3x_1+2x_2\le12$、$4x_1+2x_2\le14$；
- **暴力枚举核验**：15 个整数可行点，**没有任意一个被割切掉**（割只削 LP 顶点）。

## 验证（八条硬约束，全部通过 ✓）

1. LP 松弛 == 20.4 且解为分数；
2. 整数真最优 == 19（`scipy.milp`）；
3. 割平面到达整数最优（== 19）；
4. 割平面解为整数；
5. 割平面解 == `scipy.milp` 最优解 $(2,3)$；
6. **所有割都不切任何整数可行点**（枚举核验）；
7. 至少用到 1 条割；
8. 暴力枚举最优 == `scipy.milp`。

## 避坑记录

1. **教学实例必须"LP 松弛真的小数"**——初版用 `max 3x1+5x2, x1+2x2≤8, 3x1+2x2≤12`，
   结果 **LP 松弛最优恰好是整数 $(2,3)$**（LP=整数=21），"分数解不可执行""割平面"两个教学点**全落空**。
   换成 `max 5x1+3x2, 3x1+x2≤10, x1+2x2≤8` 后 LP=$(2.4,2.8)$ 两坐标皆分数、割平面 3 步收敛，
   教学链才立起来（**教学数据要刻意设计以暴露算法行为**，与 Day22/24/25/26/31/33/34/35/36 同一教训，已第 N 次复现）。
2. **割含松弛变量，必须代入消元才能入库**——单纯形表里的割 $\sum_j f_j x_j\ge f_0$ 是
   在"原变量 + 松弛变量"空间写的；直接用会把割的系数维度与当前约束列表错位（初版报
   `inhomogeneous shape`）。正解：用 $s_k=b_k-A_kx$ 把松弛项**代入消去**，化回只含原变量的约束。
3. **单纯形表要求右端非负**——割化回约束后若右端为负，本课 `simplex`（初始松弛基）会失效；
   须整式 $\times(-1)$ 翻成 $\le$ 标准形（初版正是栽在这里，导致割加了等于没加、LP 恒定 20.4、无限循环）。
4. **核验割合法性的不等式方向别写反**——初版判"违反"写成 `coef@x < rhs-tol`（对 `≤` 约束而言方向错），
   把所有合法割都误报成"切掉了整数点"。正解：`≤` 约束的违反是 `coef@x > rhs+tol`。
5. **输出图路径用 `__file__`**——参照 Day36 的既有缺陷记录，本课图保存到
   `os.path.dirname(os.path.abspath(__file__))`，从任意 cwd 运行都能正确落图。

## 局限 / 关系

- **纯 Gomory 割退化慢、数值不稳**：大规模问题可能要加成千上万条割才收敛——
  这是它提出后一度"叫好不叫座"的原因；
- **现代=分支切割（Branch-and-Cut）**：割**抬升下界** + 分支**保证有限终止**，
  这才是工业 MILP 求解器的真身；
- 与 **Day4 分支定界**（靠"分"）、**Day35 拉格朗日**（对偶侧抬下界）、
  **Day36 列生成**（主原侧加列）并列为整数规划求解的四大手法。
