## 十问

1. **解决什么决策**：云溪县民政局养老站的「夜里探视/送餐**有向**往来」里，责任片怎么划；更要紧的是——**有向往来能不能当无向相似度用**。
2. **为什么不能只用 Day89 的对称 Ncut**：Day89 的互近邻图是「你像我」的对称关系；而夜里送餐、探视、转送是「我去你那儿」，A_ij ≠ A_ji。对称化会**凭空造出**不存在的边（见第 6 问：切坏 6 对）。
3. **模型怎么构造**：17 片区（借 Day89 的地理分区重立表，见避坑 ①），有向往来矩阵 A，造 4 个**行随机**矩阵：P_nwk = D⁻¹A（NWK1）、P_sym = D⁻¹(A+I)（NWK2）、P_dsc = P_sym 行中心化（DSC）、K1-2 = 只用前 12 个「河西中段 + 老街」片区的主块。全部只用**右**特征向量，模降序。
4. **关键判据**：最大模（=1，Perron）；**第 2 大到第 3 大之间的本征间隙**定片数；**模 > 0.5 之外还有没有结构**靠逐向量与对称 Ncut 的 |cos| 检验（亲缘检验）。
5. **结果（全部来自 `_result.json`）**：
   - P_sym 模序列 `1.000 / 0.872 / 0.551 / 0.338 / 0.336 / 0.219 …`，最小模 **4.83e-3 > 0**、无复特征值 ⇒ **不可约非周期，没有「零模个数 = 片数」这张牌**；
   - **本征间隙最大在 2→3（0.872 → 0.551 = 0.321）**，第二大间隙 3→4（0.213）⇒ 数据说 **k=3**，与群体真值 **ARI = 1.000**（东 7 / 河西中段 7 / 河西老街 3）；
   - k=2 时 ARI **0.643**、k=4 时 **0.837** ⇒ k=3 是真优，不是运气；
   - **亲缘检验**：P_sym 的 v0/v1 vs 对称 Ncut = **0.957 / 0.981**，但 **v2 = 0.013** ⇒ P_sym 只有**前两维**来自「无向图双向填充」，第三维是别的东西；
   - **同一数据 NWK1 vs NWK2 的 ARI = 0.645**，λ2 0.872→0.839 ⇒ 不加自环的行归一化（NWK1）把三片切成了两种样子（见第 7 条）；
   - 对称化对照：`平均 (A+Aᵀ)/2` 与 `max(A,Aᵀ)` 都把山上的「河西工业/河西南苑」并进中段，**ARI 0.671（掉 32.9%）**，**切坏 6 对**真往来（北岭—南苑、南坡—南苑、南苑—工业……）；`截断差值` 直接出 6 个孤立点，跑不起来；
   - 主块 K1-2（12 片区）与全图 NWK2 在 12 片区上 **ARI = 1.000**，与 `sklearn.cluster.SpectralClustering(precomputed)` **ARI = 1.000**；
   - 噪声 0.05% / 0.2% / 1% 有向噪声：ARI **0.724 / 0.645 / 0.587**（1% 就很伤）；稀疏到保留 30% 边仍 **ARI 1.000**，保留 15% 直接出 5 个孤立点。
6. **和 Day89 / 基线比**：同一批坐标，Day89 对称 Ncut 分三片；本讲 P_sym 与群体真值 ARI 1.000，而「平均对称化」只有 0.671——**是同一个目标函数（Ncut）在当裁判**，不是各说各话。
7. **稳不稳**：换 k 两种都劣（第 5 问）；加了有向噪声 0.05% 就掉到 0.724 ⇒ **RWSC 对噪声比对称 Ncut 敏感**；稀疏 30% 不动。
8. **换假设**：把「有向」改成「无向」（平均/取大）→ 结论崩；把完整图改成主块 → 不变（ARI 1.000）⇒ **结论的前提是「往来有方向」，不是「有 17 个片区」**。
9. **回答不了什么**：零模个数与「片数」之间的关系（不可约时没有零模）；有向图的**弱连通分量**（要 tarjan，本讲没做）；DSC 的「高有向性」阈值没扫；出片顺序与编号无业务含义。
10. **论文一句话**：*「夜里探视与送餐是有向的。把 A 行归一化后取右特征向量，可以把有向社区划分问题写成 Ncut 的随机矩阵版本；但它与对称 Ncut 的等价性只在前两维成立，把有向数据当无向平均会切出 32.9% 的错误分片。」*

## 语义闸门（入库前逐条打勾）

- [x] **闸门 1 · 统计量对齐**：ARI 全部用 `sklearn.metrics.adjusted_rand_score`；手写 k-means 与 sklearn `SpectralClustering(precomputed)` ARI = 1.000 已打印。
- [x] **闸门 2 · 下标空间**：K1-2 只有 12 行，第一次跑直接撞上 `Found input variables with inconsistent numbers of samples: [17, 12]` ⇒ 改为 `group_true[keep12]`；亲缘检验也把 K1-2 排除（12 维 vs 17 维不可比）。
- [x] **闸门 3 · 无样本筛选**：孤立点清单 `[]` 显式打印；稀疏化到 15% 时 5 个片区成孤立点，记入 `sparse` 而**不静默剔除**。
- [x] **闸门 4 · 判定逻辑自证**：喂了一个**已知非实**的东西 —— P_nwk 的最大虚部 **7.86e-02**，`cluster_from_vectors` 必须抛错（`assert max_imag < 1e-9`），证明「非实特征向量不能直接给 k-means」这道闸门真的会拦。

## 避坑（逐条来自实跑）

1. **数据口径与 Day89 不同，本讲独立建表**：Day89 的 18 片区名（东片 8 + 河西老街 7 + 北岭/南坡 2）按「无向互近邻图」设计，本讲要做**有向往来**，按「谁来送、送给谁」重新立了 17 个片区名与坐标（东 7 / 河西中段 7 / 河西老街 3）。代价是**不能与 Day89 的片号直接比**，只继承它的**建模教训**（孤立点、本征间隙、图假设强度）。
2. `Dm ** -0.5` 在 numpy 里是 **`np.diag(d)` 的逐元素幂**，不是对角矩阵幂 —— 矩阵得一步 `np.diag(d ** -0.5)` 两步再乘；Day89 的写法是散写在 `Dm ** -0.5 @ S …` 里靠 `@` 硬凑，本讲改成显式两次。
3. `np.linalg.eig` 返回的复杂数组即使虚部全是 0，`sklearn` 也会报 `Complex data not supported` ⇒ 必须先 `np.real_if_close` + 显式断言虚部 < 1e-9。
4. **「加不加自环」不是小事**：去掉自环（NWK1 = D⁻¹A）后，只出不进的片区在 Fiedler 向量上被推到极端，三片的 ARI 从 1.000 掉到 **0.724**，并且**分片方式完全不同**（东 7 / 西 9 / 老街成了中段的一部分）。第一维很像（cos 0.9996）不代表整体像（v2 cos 0.052）——**只看第一维的余弦相似度会被骗**。
5. 对称化三种写法（平均 / 取大 / 截断差值）里**第三种会直接造出孤立点**（`河东新村/北岭/南坡/西市场/南苑/工业` 六片），因为它只保留净流向，A 稀疏到有些行全零 —— 前两种才跑得通，**并且都切错 32.9%**。
6. 稀疏化到 15% 时出现 5 个孤立点 —— 与 Day89 同一个病（`1/√0 = inf`），本讲用**闸门 3**把清单打出来，而不是修成 17 个再跑。
7. 生成的 PNG 里不能出现 `⁻¹` 这种上标负号（Noto Sans CJK 缺字形，`-W error` 直接抛错）；写成 `D^-1`。
