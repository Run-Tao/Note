## 一句话结论

**固定站数 $K$ 时贪心四次全部命中最优（(1−1/e) 只是下界，不是损失）；
但把「选几个」换成「花多少钱」以后，贪心在批复的 36 万上只拿到最优的 75.4%** ——
因为它第一步就买了最贵的站（30 万），剩下的钱再也买不起任何站。

## 十问

1. **解决什么问题？** 目标写不成线性、只能写成集合函数 $v(S)$ 时，怎么选一组站/项目/巡检点。
2. **什么时候用？** 价值随集合增长、但每多一个的增量递减（次模）；覆盖、传播、多样性、信息增益都属于这一族。
3. **为什么适合？** 次模性 ⇒ 贪心有常数保证，且与实例规模无关；也让「敏感性分析」有意义（边际递减可预测）。
4. **数学模型？** $\max v(S)$ s.t. $|S|\le K$ 或 $\sum_{i\in S}c_i\le B$；$v(S)=\sum_j w_j(1-\rho^{n_j(S)})$。
5. **怎么求解？** 贪心（增益最大）/ 性价比贪心（增益÷造价）/ 1-swap 局部搜索；裁判 = 全枚举 $2^4$。
6. **怎么实现？** 4 站 8 村，覆盖矩阵由「上游 + 半径 + 提前量门槛」三条物理规则生成，不手写。
7. **怎么验证？** 次模性抽样 2731 对零破坏；贪心 ≥ (1−1/e)×精确；精确值随预算单调；ρ 上升第二站增量必须下降。
8. **有什么缺点？** 保证是最坏情形；预算版无常数比；ρ 是建模假设；1-swap 邻域看不到「同时换两个」的解。
9. **替代方法？** MILP（Day4）、LP 松弛取整（Day60）、拉格朗日（Day35）、更大邻域搜索。
10. **怎么进论文？** 覆盖矩阵 + 覆盖重数 + 价值函数 + 预算曲线 + 贪心实测比值；保证写成**适用范围**。

## 七条避坑

1. **不要为了讲 (1−1/e) 去硬造「贪心差 30%」的例子。** 固定 K 的连续覆盖结构里，贪心就是很强（600 组随机搜索零命中）。硬造 = 伪造。
2. **预算版不是固定 K 的附庸。** 站价一不均，贪心的失效机理就变了（「买最大块」vs「买最划算的组合」），必须单独讲。
3. **写敏感性之前先打印「谁被覆盖了两次」。** 第一版实例没有任何村被两站覆盖，ρ 只是整体等比缩放，第二站增量恒等于第一站 —— 一张漂亮的假图。
4. **别用 `globals()` 改全局参数做扫描。** ρ 扫完忘了复原，K 曲线整段错位；改成 `value(S, rho=None)` 显式传参。
5. **断言别硬编码下标。** `SCAN[2] > SCAN[4]` 换预算表就误报，改成「相邻单调」。
6. **局部搜索 0 次移动不是 bug。** 1-swap 看不到「同时换两个」的解；用局部搜索「验证」贪心是无效的（Day66 同款教训）。
7. **JSON 里所有数都要 `round(float(x), 4)`。** `json.dump` 遇 `np.float64` 会崩（Day66/Day69/Day70 家族）。
