## 一、决策（10 问之一）

云溪县民政局 2027 年社区养老服务站：站数已经由建筑面积和预算**硬性定死 3 个**（东片区、西片区各一个，第三个在老城），
现在要解决的是最容易被糊过去的一步 —— **责任片怎么划**。

划片划错了不会有人立刻发现，但它决定：

1. **哪些老人要走多远**（片边界 = 服务半径）；
2. **两个站之间谁来兜底**（边界上的片区，两个站都说「不归我」）；
3. **边界设在哪儿最省钱**（切断的「串门」越多，家属探视越绕，投诉越多）。

民政局的原始划法是「**两刀切地图**」：沿江分河西/河东，河西再按东西一刀。这一讲要回答的就是：
**这两刀，切对了吗？**

## 二、为什么这一题不能用 KMeans / 层次聚类（10 问之二）

距离类方法只看「直线有多远」。三个片区在几何上给出了三个反例：

| 现象 | 几何怎么说 | 实际情况 |
| --- | --- | --- |
| 铁路南 vs 河东南苑：直线 2.12 km，中间是江 | 「有点远」 | **唯一的过江桥就在这里**，两边天天往来 |
| 河西新村 vs 河东一村：直线 2.34 km | 「更远了」 | 江上没有桥，两家互不串门 |
| 北岭安置 / 南坡安置：离最近片区 3.2 km 以上 | 「最近的邻居」 | **谁也不挨，一年到头不来往** |

任何基于坐标的聚类（KMeans、Ward）都会得出「北岭/南坡属于‘最近的’那片」。
本讲实测：KMeans 直接把这 18 个片区切成 8 / 1 / 9 —— **南坡安置被单独切成了一片**，
因为它离谁都不近，而 KMeans 只想让簇「紧凑」。

> **这一课的第一句话**：老年服务不是按地图分的，是按**来往**分的。
> 把「来往强度」写成图，才是这道题正确的输入。

## 三、方法：把来往写成图，把「切得贵不贵」写成目标函数（10 问之三、四）

### 3.1 建图

18 个片区 = 18 个点。两点之间的边表示「**家属顺路探视 / 老人日常串门**」的强度：

$$
w_{ij} = \frac{1}{1+d_{ij}} \quad\text{仅当}\quad (i\in \mathrm{kNN}(j))\ \wedge\ (j\in \mathrm{kNN}(i))
$$

**互近邻**（mutual kNN）是关键选择：单向 kNN 会让「枢纽点」以自己为中心连出一圈，
互近邻则要求**双方都认对方是最近的那几个邻居**，自然把「一方热、一方冷」的边剪掉。
本讲 k=5。这一图共 **34 条边**，其中河西↔河东**只有 1 条**：`铁路南 — 河东南苑`。

### 3.2 Ncut

$$
\mathrm{Ncut}(A_1,\dots,A_k)=\sum_{c=1}^{k}\frac{\mathrm{cut}(A_c,\bar A_c)}{\mathrm{vol}(A_c)},
\qquad \mathrm{vol}(A)=\sum_{i\in A}d_i
$$

- `cut` 是**被切断的串门强度总和**；
- `vol` 是这片**总来往量**（节点度之和）。
- **分母是 Ncut 的全部内容**：它把「切断量」按每片的来往量归一化，
  这样就不会为了省一条边，把两个小片区（池子小、一条边占比就大）单独割出去 ——
  这正是 Min-Cut 会犯的病，也是 Ncut 论文（Shi & Malik, 2000）要修正的地方。

求解用谱松弛：取 $L_{sym}=I-D^{-1/2}WD^{-1/2}$ 最小的 $k$ 个特征向量，按行归一化后做 k-means
（Ng-Jordan-Weiss 的做法）。本讲另外手写了**幂迭代**求 Fiedler 向量，与 Day63 的谱二分逐点对照。

### 3.3 一个必踩的坑：孤立点

互近邻图把「北岭安置」「南坡安置」摘成了**度 0 的孤立点**。此时：

```python
1.0 / np.sqrt(deg)      # deg = 0 → inf  →  特征向量全 NaN  →  k-means 抛 ValueError
```

代码里第二版修法是**只对非孤立点取子矩阵**（`keep` 掩码），孤立点显式剔除、单独报名单。
这比「把孤立点行置 0、本征值记为 1」更干净：它们本来就**不该参与 Ncut** —— 在图上没有邻居的人，
「属于哪一片」这个问题在图上是无定义的。

## 四、结果（10 问之五~八）

### 4.1 三片（Ncut = 0.7543）

| 片 | 成员 | 老人数 |
| --- | --- | --- |
| 片1 河东 | 河东一村、河东二村、学府路、体育场、政务中心、河东南苑、**东岗安置** | 5 480 |
| 片2 河西中段 | 文昌巷、河西新村、铁路南、石坝口、砖瓦厂、船厂宿舍 | 3 970 |
| 片3 河西老街 | 西门口、老码头、钟楼下 | 2 960 |
| — 未入图 | **北岭安置、南坡安置** | 520 + 470 |

切下去的「桥」共 7 条，全部在河西内部（1.01~1.68 km），**唯一那条过江桥（2.12 km）没有被切**。

### 4.2 和「两刀切地图」比（同一个目标函数当裁判）

| 划法 | Ncut |
| --- | --- |
| 民政局两刀切地图 | 0.8018 |
| 谱聚类 Ncut | **0.7543（−5.9%）** |

两法的 ARI = **0.7592**（重叠数给出的直觉值是 75.9%，见上表对照），差别集中在两处：
① **两刀切把河西老城按 x=1.4 又一刀劈开** —— `西门口 / 老码头 / 钟楼下 / 砖瓦厂 / 船厂宿舍` 被判进同一片，
   但 `文昌巷`（老城中心、1 240 老人）被划去了「过江带」；
② 谱聚类把**东岗安置**留在了河东片，两刀切因为 x≥4.0 的规则也把它留在了河东 —— 这一点两者一致。

> **这是本讲最值钱的一句话**：两条划法只差 5.9%，但差的这一刀正好落在一群老邻居中间。
> 报告里该写的不是「谱聚类更好」，而是「**边界建议从 x=1.4 挪到西门口—文昌巷那条巷子**」。

### 4.3 三个稳健性测试（10 问之七）

| 测试 | 结果 | 怎么读 |
| --- | --- | --- |
| k = 5，半径 1.8 / 2.0 / 不设 | ARI 0.86 / 0.86 / 1.00 | **半径不是旋钮**，只差「铁路南归谁」 |
| k = 6 / 7 | 平均 ARI 0.86 / 0.72 | 结论适用范围 **k=5~6**，写到论文里 |
| 坐标 ±60 m 抖动 ×100 | 中位 1.000，89/100 完全一致 | 边界上的片区会漂，主线稳定 |
| 换 RBF 全连接图 | **ARI 0.55** | 断层被填平，片散了 |
| 换单向 kNN | ARI 0.71 | 「枢纽」把链拉长 |

**RBF 那一行是本讲的灵魂**：坐标一个数都没改，只是把「谁是邻居」从 34 条边改成 153 条全连接，
结论就散了一半。**谱聚类不是「更聪明的聚类」，它是「把你对邻居的定义放大」**。
你对图的定义错了，谱方法会又快又准地给你一个错答案。

### 4.4 本征间隙：它回答的不是你的问题

最小 8 个本征值：`0, 0.027, 0.476, 0.613, 0.727, 0.962, 1.135, 1.164`

最大间隙在 **2→3（0.449）** ⇒ 间隙说 **k=2**。可站有 3 个；把两个孤立点再算两块是 **4**。
用间隙定 k 不是「算法不准」，而是**它回答的问题不同**：它回答「图里有几块天然断开」，不回答「我要几个站」。

> 站数是**业务给定的**，片数是**数据给定的**。混为一谈，就会出现「模型说 2 个站，预算说 3 个站」的尴尬。

## 五、踩坑记录（四条，全部实跑暴露）

1. **孤立点 NaN**：`1/√0 = inf` → 本征向量 NaN → `KMeans` 报 `Input X contains NaN`。
   报错信息里看不出是「数据里有两个没人理的片区」，只会让人以为矩阵坏了。
2. **孤立点静默污染**：第一版不剔除，k-means 把北岭、南坡丢进片 3，片 3 从 3 个片区变成 5 个 —— **没有任何报错**。
3. **假旋钮**：第一版用「邻域半径 CUT=2.2 km」当参数做敏感性，结果加不加半径结论几乎一样 ——
   因为互近邻已经替你把远处的边剪掉了，半径只是在剪第二遍。
   **一个不起作用的参数写进敏感性分析就是凑数**，会让人误以为「做了很多稳健性检验」。
4. **假胜利**：第一版把「手工切法」写成「沿江一刀 + 河东按 x 中位数」，它比 Ncut 贵 23% —— 看起来 Ncut 大胜。
   仔细一看是手工切法被写成了 3 片里的 1 片还要再拆（一共切了 3 刀，而 Ncut 只切 2 刀）。
   改成「两刀切地图」后差距回到 **5.9%**。**给对照方法设不公平的基线，是自己骗自己。**

## 六、给民政局的建议（写法示范）

> **建议：三片按「河东 / 河西中段 / 河西老街」划，边界设在西门口—文昌巷的巷口，不设在 x=1.4。**
>
> - 依据：谱聚类（互近邻图，k=5）Ncut = 0.7543，优于现行两刀切法的 0.8018，改善 5.9%；
>   两法 75.9% 成员一致，**差异只在「过江带」这一刀**。
> - **北岭安置、南坡安置在「探视/串门」图上是孤立点**（与任何片区都没有来往），
>   不能靠聚类判定归属：建议就近挂靠（北岭 → 片3，南坡 → 片2），并单列「每月上门一次」的个案服务量。
> - 过江桥 `铁路南—河东南苑` 没有切断，两片**双站共管**：河东站每周二、河西站每周五驻桥东服务点。
> - 敏感性：k 取 5~6 结论稳定（ARI ≥ 0.86）；若把「来往」定义为全城高斯衰减（RBF），
>   结论不稳（ARI 0.55）⇒ **本结论成立的前提是「串门是本地行为、出了片区就基本不来往」，这一点需要一次入户调查核实。**

## 七、没做的（如实交代）

- **没有做**谱聚类的正规实现对照（`sklearn.cluster.SpectralClustering` 的 `discretize` 选项、`eigsh` 稀疏求解）；
  本讲 N=18，`scipy.linalg.eigh` 就够，规模上去必须换 Lanczos（`scipy.sparse.linalg.eigsh`）。
- **没有扫 k 之外的其他旋钮**：路径/自带权重（如公交班次）没试；Ncut 的 k 与 NMI 交叉验证没做。
- **没有做二部图（老人—片区）的谱聚类**（协同聚类），那是另一种写法，接 Day87 的「分界村」正好用得上。
- **数据是编的**：坐标与老人数量级按县城社区台账习惯设置，结论不可外推到真实县。
