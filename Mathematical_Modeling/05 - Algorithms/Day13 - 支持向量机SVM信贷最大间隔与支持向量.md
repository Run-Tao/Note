# Day 13 — 信贷风控(五)：SVM / 最大间隔——让边界尽量"宽敞"

> 锚点：[[Learning_Roadmap|Learning Roadmap]] Level 8 · 数据分析与机器学习 / 监督分类 · 支持向量机。
> **Day10** 用 Logistic 回归给出"线性打分 + sigmoid → 概率"；今天演它的**硬派兄弟 SVM**：同样一条直线边界，但追求不同——Logistic 追"每个点都别猜太错"（极大似然），SVM 追"把好坏两群推得越开越好"（**最大间隔**）。这带来一个硬核副产品：**边界只由贴着它的少数"支持向量"决定，其余样本删掉都不影响**。

## 0. 一句话总结

**Logistic 关心"每个样本的概率对不对"，SVM 只关心"离边界最近的那些点有没有被分对、且离得够不够远"。** 把这两群往两边推得越开越好，得到的是一条**留有余量**的边界；真正"顶住"边界的只有那几个贴着它的样本——它们叫**支持向量**，其余样本删了对边界毫无影响。数学上，这就是最小化 **合页损失(hinge loss) + L2 正则**：$0.5\lambda\|w\|^2 + \frac1n\sum_i \max(0, 1 - y_i(w^\top x_i+b))$。

## 一、这个方法解决什么问题？（10问之1）

**决策对象：同样"该贷还是该拒"，但样本少、维度高、还怕个别脏点带偏边界的场景。**

Logistic 用所有样本的似然一起决定边界，一个离群的"异常好客户"也会拽动直线；SVM 只看**间隔带内**的样本，$|f(x)|>1$ 的点对权重**零贡献**——外面再远、再多，也不动摇边界。所以 SVM 在**小样本、高维（如文本、基因）**上很吃香，且对个别极端点更稳健。

## 二、问题的实质：把"分类"变成"留最大余量"

- 对**线性可分**数据，能让两类都分对的直线有无穷条。SVM 说：选**离两类都最远**的那条。
- 定义间隔带 $|w^\top x + b| = 1$：想让**最近的点也满足 $y_i(w^\top x_i+b)\ge 1$**，同时**最大化带宽 $2/\|w\|$**，等价于**最小化 $\|w\|^2$**。
- 现实数据不可分 → 加**松弛变量 $\xi_i\ge0$**（软间隔）：允许个别点进入间隔带甚至被错分，但**要罚**。这正好等价于**合页损失**：$y_if(x_i)\ge1$ 罚 0，否则按"差多少"线性罚。

**关键洞察**：合页损失对 $|f|>1$ 的样本梯度为 0——这就是"支持向量决定边界"的数学来源。

## 三、与 Logistic 的完整对照（本课核心）

| | Logistic 回归（Day10） | **SVM（Day13）** |
|---|---|---|
| 目标 | 极大似然/交叉熵（每点都别猜太错） | **最大化间隔**（最近的点也要够远） |
| 输出 | **概率** $\in[0,1]$ | **有符号决策值**（距离），非概率 |
| 受谁影响 | **所有样本**都参与 | **只有支持向量**（带内/错分点） |
| 损失 | 对数损失（处处可导） | **合页损失**（带外梯度为 0） |
| 正则作用 | 防过拟合（C 越小正则越强） | **直接是间隔宽度**（$\lambda$ / C 调松紧） |
| 稳健性 | 对离群点较敏感 | 对**远离边界**的点不敏感 |

一句话：**Logistic 求"最不意外的概率模型"，SVM 求"最大可能的安全走廊"。** 两者都是线性边界，差别在"边界由谁决定、优化什么"。

## 四、结果怎么读（拒绝纸上谈兵）

本课实测（600 客户、切 420 训练 / 180 测试、用训练集统计量标准化防泄漏）：

- **正则扫描（lam 越大=间隔约束越松）**：lam=0.001 时 $\|w\|=1.66$、支持向量 200 个、测试 0.761；lam=0.5 时 $\|w\|=0.68$、支持向量 340 个、**测试 0.778（最优）**；lam=5/20 时 $\|w\|$ 掉到 0.14/0.036、几乎全部样本变成支持向量、测试坍塌到 **0.606**——**正则太强=间隔被压扁=边界退化成"几乎人人算支持向量"，反而欠拟合**。甜点在 lam≈0.5。
- **与 Logistic 对照**：同一份标准化数据，Logistic(C=1e6) 测试 **0.761**、$\|w\|=2.17$；手写 SVM **0.778**、$\|w\|=0.68$。SVM 的 $\|w\|$ 明显更小 = 间隔更宽，且测试略好——印证"留余量"的价值。
- **与 sklearn 交叉对照**：`LinearSVC` 测试 0.761；**手写 $w$ 与 LinearSVC $w$ 余弦相似度 0.9999**（方向几乎完全一致），证明手写 hinge 实现正确（尺度不要求一致，方向才是关键）。
- **混淆矩阵**：好判对(TN)=53、拒错好客户(FP)=18、漏放坏账(FN)=22、坏判对(TP)=87；误拒率 0.254、漏放率 0.202——仍是"两类错误此消彼长"的业务权衡（和 Day9/Day10 一脉相承）。
- **决策值分离**：好客户决策值均值 **−0.471**、坏客户 **+0.491**，正负分开、离 0 越远越有把握——注意 SVM 给的是**"分得多开"而非概率**，做额度排序时可当"安全边际"用。
- **支持向量决定性**：**只用 340 个支持向量重训，方向余弦仍 =1.0000**——把带外的 80 个样本全删掉，边界方向不变，实测坐实"支持向量决定边界"这句话。

## 六、一句话带走

**SVM 把"分类"翻译成"留最大余量"**：最大化好坏两群之间的安全走廊，边界只由贴着它的少数**支持向量**撑起，其余样本删了都不改边界——这既带来对离群点的稳健，也埋下对**尺度**（必须标准化）与**正则强度**（太强会全员变支持向量、太弱会贴数据）的敏感。它是"最大间隔"视角的线性分类器，与 Logistic 的"最大似然"视角构成同一决策的两种哲学。
