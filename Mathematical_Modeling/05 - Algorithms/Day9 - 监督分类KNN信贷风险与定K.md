# Day 9 — 信贷风控：给"新一笔申请"打 风险标签，该贷还是该拒（KNN 近邻分类）

> 锚点：[[Learning_Roadmap|Learning Roadmap]] Level 8 · 数据分析与机器学习 / 监督分类。
> Day8 在一片**没有标签**的客流散点上自动切出 K 簇(无监督聚类)。这一课补上"监督"的另一半：**手里已经有 600 个"好坏已知"的历史客户**，来了一笔**新的贷款申请**，问该贷还是该拒？——**KNN(K-近邻)** 是最直观的答案：在历史库里找到和新申请"最像/最近"的 K 个人，**看他们多数是好是坏，多数派说了算**。与 Day8 一对：聚类是自己发现分组（无标签），KNN 是拿已知标签当样本库做预测（有标签）。

## 0. 一句话总结

KNN 是**惰性/记忆型**的监督分类算法：**不训练**出任何权重或函数，预测时才拿新样本到训练集里算距离，挑出 **K 个最近邻**，按**多数票**给出类别（回归则取均值）——本质就一句"物以类聚、近朱者赤"。两个工程要点决定成败：①特征必须**先标准化**（否则量纲大的特征在欧氏距离里喧宾夺主）；②**K 不能太小也不能太大**——太小被单个噪声点带偏(过拟合)，太大被远处的异类稀释(欠拟合)，本数据在 **K=11** 处测试准确率最高。

## 一、这个方法解决什么问题？（10问之1）

**决策对象：已知一批带标签(答案)的历史样本，要预测"新样本属于哪类"**：

- **信贷风控**：拿历史好坏客户学"什么样的人会违约"，新申请来了判该贷还是该拒（本课）；
- **客户流失预测 / 精准营销**：历史"流失/留存"客户学规则，判断新客户危不危险；
- **医疗初筛**：用历史已确诊样本判新病例所属类别；
- 图像/手写字符识别、垃圾邮件/文本分类等一切"给类别标签"的二/多分类。

典型问法：*"我们手里有 600 个历史客户的月收入、负债率，以及他们最终好不好（违没违约）。现在来了个新客户，只知道他的收入负债率，问：他是'会违约'还是'守约'，该不该批贷款?"* —— 就是**拿最近 K 个"已知结局"的近邻投票**。

## 二、什么情况该用它、为什么适合？（10问之2、4）

- **有标签**的新样本分类问题 → 监督分类；而 Day8 那种**无标签**自动分组 → 聚类(K-Means/DBSCAN)；
- 想要一个**简单、可解释、无训练成本**的基线：KNN **不需要拟合**，预测即查表投票，任何新手能一眼看懂"为什么这么判"(因为它标出了邻居)；
- 决策边界**高度非线性/不规则**时，KNN 用"局部多数"能自动贴合任意形状，比线性模型灵活；
- 若数据量大(几百万行)或维度高 → 每次预测要扫全库距离，慢；改 **KD-Tree/Ball-Tree** 索引或换树/线性模型更好；
- 若想拿到"概率输出"或特征重要性 → 改逻辑回归/决策树/随机森林等**参数化**模型。

## 三、数学模型是什么？（10问之3）

训练集 $\{(x_i,y_i)\}_{i=1}^n$，$x_i\in\mathbb{R}^d$ 为特征、$y_i\in\{0,1\}$(好/坏). 对查询点 $q$，KNN 预测：

1. 算 $q$ 到每个训练样本的距离（默认欧氏）：
   $$
   d(q,x_i)=\sqrt{\sum_{j=1}^{d}(q_j-x_{ij})^2}
   $$
2. 取距离最小的 **K 个**下标 $\mathcal{N}_K(q)=\arg\min_{K}\{d(q,x_i)\}$；
3. **多数票** 给出类别：$\hat y(q)=\arg\max_{c}\sum_{i\in\mathcal{N}_K(q)}\mathbf 1[y_i=c]$.

**关键工程一：为什么要标准化。** 欧氏距离里，量纲大(如月收入≈几十)的特征平方差会**淹没**量纲小(负债率∈[0,1])的特征——不标准化等于"只按收入判"，负债率白做。做法：$z=\frac{x-\mu}{\sigma}$(用**训练集**的均值/标准差，测试集沿用同一 $\mu,\sigma$，避免信息泄漏)。

**关键工程二：K 怎么定（本课核心算法问题）。**
- **K 太小(如 1)**：只信最近一/几个邻居 → 恰好碰到单点噪声/离群就翻车，决策面锯齿状、**过拟合**；
- **K 太大**：把本属于别类的远处样本也拉进来投票 → 决策被稀释、边界过平滑，**欠拟合**；
- 工程实践：**留出验证 / 交叉验证**扫一串 K，取测试(验证)准确率峰值；**K 取奇数**天然避免平票。本数据峰值 **K=11**。

## 四、如何求解？（10问之5）

手写核心三步对 sklearn `KNeighborsClassifier` 是同一算法，可互证：

```python
def knn_predict_batch(train, tlab, Q, k):        # train/tlab 已标准化
    D  = ((train[None,:,:]-Q[:,None,:])**2).sum(-1)  # (m,n) 距离矩阵
    nb = np.argsort(D,1)[:,:k]                       # 每查询点最近 K 邻下标
    votes = tlab[nb]                                 # (m,k)
    return (votes.sum(1) >= (k+1)/2).astype(int)     # 多数票(>半数为坏)
```

对照标准库：

```python
from sklearn.neighbors import KNeighborsClassifier
model = KNeighborsClassifier(n_neighbors=11).fit(Xs_train, y_train)
pred  = model.predict(Xs_test)     # 记得测试也用训练集的 mu/sd 标准化
```

**交叉验证 / 留出评估**（防过拟合的通用套路）：把数据切成"训练 + 留出测试"，**只用训练集 fit**(KNN 无 fit 但标准化参数$\mu,\sigma$只能从训练拿)，测试集模拟"从没见过的新客户"来评估真实泛化。

## 五、结果与解读（代码实际跑通输出）

600 名历史客户(好 300 / 坏 300)，特征=月收入 × 负债率；420 训练 / 180 留出测试，两云刻意部分重叠(现实中好人也偶有违约)：

```
[手写 vs sklearn] k=7 测试准确率两边都=0.894、指派一致率=100.0%(实现正确)
[定K扫描 准确率]  K=1→0.894(偏小过拟合) ... K=9→0.917  K=11→0.928(峰值)  K=15起→0.922走平回落
结论: 峰值 K=11, 测试准确率 0.9278
[K=11 混淆矩阵]          预测好   预测坏
          实际好(0)        90       8
          实际坏(1)         5      77
  误杀好客户(拒错,FP)=8(8.2%) | 漏网坏客户(放贷坏账,FN)=5(6.1%)
[违约倾向] 把 K 邻"坏客户占比"当风险分: 真实违约者平均风险分0.920 vs 真实守约者0.136
```

**怎么读(结果解释)：**
1. **"该贷还是该拒"有据可依**：对每个新申请，看它训练库里最像的 11 个人——若其中过半是"坏"，就判拒(风险高)；KNN 给的不只是标签，K 邻里坏人的比例就是**违约倾向分**(0~1)，可拿去设阈值做差异化(如高分行大力授信、中分行缩额、低分行拒)；
2. **K 的选择**：K=1 太激进(只看最像一人，被噪声带偏)→0.894；升到 K=11 显著到 **0.928**（投票平滑了单点偶然）；再大(K≥15)被远处异类稀释而回落——**不是越大越好，中间才有甜点**；
3. **边界不规则性**：决策图里蓝/红分区并非直线，而是贴数据"你中有我"的局部多数边界——这是 KNN 不需要假设线性可分就能做到的；
4. **误差要分清代价**：假设**拒错一笔(FP)=损失营收**、**放错一笔(FN)=本金坏账**，后者代价通常大得多——所以生产里常调阈值"宁可多拒几个守约的,也别放漏违约的"，而不是纯看准确率(可练习改判定线)。

图：`knn_decision_boundary_k.png` —— 左图蓝(贷)/红(拒)决策边界 + 180 个留出测试点(蓝圈=实为好、红叉=实为坏，看谁被边界判错)；右图测试准确率随 K 曲线，红虚线标峰值 K=11。

## 六、如何验证？（10问之6）

- **与标准库对照**：手写与 sklearn `KNeighborsClassifier` 测试集**指派一致率=100%、准确率逐 K 相等** → 手写实现正确；
- **留出评估**：评估只在**没参与"训练"**(也没泄漏标准化统计量)的 180 人上做，防过拟合自欺；
- **合理性断言**：K 峰值落在中间(约 5–13 而非 1)、准确率 >90%、误判可控；
- **方法间交叉**：可写k折交叉验证重扫一遍 K，峰值是否仍 ~11(把一次性留出的波动抹平)；
- 稳健性：换随机种子重造数据/重切分，看 K 峰值与准确率是否稳定。

## 七、缺点与替代？（10问之8、9）

- **惰性/记忆成本**：预测时要扫全库算距离，样本/维度一大就慢 → 用 KD-Tree/Ball-Tree、或上参数化模型(逻辑回归/随机森林/XGBoost)；
- **维数灾难**：维度很高时"最近邻"不再近(高维里所有距离趋于相等) → 先 PCA 降维或换模型；
- **受量纲/离群影响**：不标准化就失真；离群点会干扰投票 → 先清洗，或加权(越近的邻权重越高)；
- **不输出概率校准**：多数票比例不是严格校准的概率 → 要可靠概率用逻辑回归/概率校准；
- **类别不平衡**：某类样本太多会主导投票 → 用加权投票或过/欠采样。
- 若只要**连续预测**(如"违约损失金额") → 用 **KNN 回归**(K 邻取均值) 或线性回归。

## 八、怎么写进论文？（10问之10）

- 问题层：监督、有标签、新样本分类(结合信贷风控背景:给新申请打风险标签)；
- 方法层：描述"距离→K近邻→多数票"，强调**标准化(用训练集统计量,测试集沿用)**与外层**留出/交叉验证选 K**，避免信息泄漏；
- 模型选择证据：准确率随 K 曲线(表/图)+ 峰值 K 说明为何取中间值；
- 结果层：混淆矩阵 + **FP/FN 的代价解读**(拒错 vs 放账风险) + 违约倾向分分布；
- 可信层：手写与 sklearn 逐 K 对照一致率，证明实现与结论可靠；
- 讨论层：不同 K、不同距离度量(曼哈顿/余弦)、加权投票、与逻辑回归/随机森林在成本-效果上的权衡。

## 九、可迁移性（练习）

- 把判定线从"过半数=坏"调成"邻里有 3 成是坏=拒"，重算 FU/FN，体会**阈值换平衡**；
- 换 **k 折交叉验证**重扫 K，验证 K=11 是否稳定(不依赖单次留出)；
- 用 Day8 的**聚类结果当伪标签**练跑 KNN——体会"聚类(无监督)学出分组 → 拿一部分标注后 KNN 用于预测"的标签稀缺套路；
- 加第三个特征(信用卡张数/负债笔数)重训，看准确率升不升、决策图是否更可分(顺带体会维度)。
