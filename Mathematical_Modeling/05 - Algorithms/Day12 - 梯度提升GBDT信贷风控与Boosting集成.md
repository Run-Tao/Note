# Day 12 — 信贷风控(四)：集成学习的另一半——Boosting / GBDT

> 锚点：[[Learning_Roadmap|Learning Roadmap]] Level 8 · 数据分析与机器学习 / 集成学习。
> **Day11** 用**随机森林**演了 **Bagging**——一堆"彼此独立"的树**并行**生长、投票平均，核心是**降方差**。今天补上集成的**另一半：Boosting**——一堆**很弱**的浅树**串行**接力，每棵新树专攻"前面还没解释掉的错"，核心是**降偏差**。同一个"该贷还是该拒"的决策，两套集成哲学对照。手写 GBDT + 与 sklearn 交叉验证。

## 0. 一句话总结

**Bagging 是"多个人同时答题取平均"，Boosting 是"一个人先答、下一个人专门订正他的错、再下一个人订正前两人的错……"**。GBDT（Gradient Boosting Decision Tree）里，"错"被精确定义成**损失函数的负梯度**；对分类常用的 **LogLoss** 而言，这个负梯度恰好就是**残差 $y-\hat p$**。所以流程极简：**从对数几率初值出发，每轮拿当前预测算残差 → 训练一棵浅回归树去拟合残差 → 乘一个小的学习率后累加进总分 $F$**。弱树一棵棵接力，把偏差一层层削掉，最终 $F$ 经 sigmoid 就是违约概率。

## 一、这个方法解决什么问题？（10问之1）

**决策对象：同样要"能不能贷 + 为什么"，但要求更高的判别精度，且愿意接受一个不那么好念的模型。**

Day11 的随机森林已能集成，但在**小数据 + 特征少**时，它的"随机抽特征"造不出多样性，优势发挥不出来（实测森林 0.733 反被单树 0.761 反超）。Boosting 换一条路：**不靠"树们彼此独立"，而靠"树们彼此纠错"**。每棵树都盯着**前面所有树的总预测还差多少**，专挑软肋打。工业界（信用评分卡升级、点击率预估、风控）最主流的树模型 XGBoost/LightGBM 全是这个思路——**本课先手写最朴素的 GBDT，把"串行纠错"的原理吃透**。

## 二、问题的实质：把"集成"看成"在函数空间里做梯度下降"

这是 Boosting 最美的视角：

- 我们要最小化**损失** $L=\sum_i \ell(y_i, F(x_i))$，其中 $F$ 是**整个模型**（一堆树的加和）。
- 普通梯度下降在**参数空间**走；Boosting 在**函数空间**走：把"每棵树"当成一步**更新方向**。
- 对每个样本求**负梯度** $r_i=-\partial \ell/\partial F(x_i)$，这就是"**当前模型在该样本上错得多厉害、该往哪边修**"。
- 训练一棵树去**拟合这些负梯度** $r_i$（一个回归任务），再把它**乘学习率**加进 $F$——这一步相当于"沿负梯度方向走一小步"。

**关键巧合（分类场景）**：LogLoss 下 $r_i = y_i - \text{sigmoid}(F(x_i))$，就是**残差**。所以工程上直接说"**每棵树拟合前一轮的残差**"。

## 三、与 Bagging（随机森林）的完整对照（本课核心）

| | Bagging / 随机森林（Day11） | **Boosting / GBDT（Day12）** |
|---|---|---|
| 树的生长 | **并行**、彼此独立 | **串行**、后者依赖前者 |
| 每棵树 | 要**深/强**（否则单棵太弱） | 要**浅/弱**（深度 2 的"树桩"，好防止学太快） |
| 制造多样性靠 | 自助采样 + 特征随机 | **每棵树面对不同的残差**（天然的多样性来源） |
| 主要削减 | **方差**（平均掉高方差） | **偏差**（逐步逼近真函数） |
| 过拟合风险 | 树越多越**稳**（不会过拟合） | 树太多**会过拟合**（一直盯残差=背噪声） |
| 关键旋钮 | 树数、树深 | **树数 + 学习率**（此消彼长） |

一句话：**Bagging 靠"独立"平均方差，Boosting 靠"接力"削减偏差**。所以两者连调参直觉都相反——随机森林里树多点没坏处，GBDT 里树点多了要早停。

## 四、结果怎么读（拒绝纸上谈兵）

本课实测（训练 336 / 验证 84 / 测试 180，标准化防泄漏）：

- **主模型**（120 棵树、lr=0.1、深度 2）：训练准确率 **0.8006**、测试 **0.7778**；训练 logloss 0.6741→0.4389，验证 logloss 0.6849→0.4248 仍在下降。**训练测试的差距（0.80 vs 0.78）比 Day11 单棵深树小得多**——Boosting 的"弱树 + 学习率"本身就是强正则。
- **轮数效应**：1 棵树测试仅 0.478（**比随机猜还差**，因为只有 0.1 步长，还没走够）；20 棵跳到 0.778（偏差快速下降）；120 棵仍 0.778 但训练升到 0.801——**这就是 Boosting 的过拟合征兆**：验证曲线见顶就该停。
- **学习率效应**（固定 60 棵）：lr=0.05/0.1 测试 0.778；lr=0.3→0.783；lr=1.0→0.789 但**训练飙到 0.851**。**lr 大=走得急=更快拟合也更快过拟合**；lr 小=稳但需要更多树。工业默认 lr=0.05~0.1 配几百上千棵树。
- **混淆矩阵**：好判对 65、**拒错好客户 29**、**漏放坏账 11**、坏判对 75。注意**漏放坏账降到 11**（Day11 树是 24）——GBDT 对"违约"这类少数但关键的类别判别更狠；**拒错好客户 29** 是代价，仍是业务上要权衡的判定线。
- **概率分离**：真实违约者平均违约概率 **0.715** vs 守约者 **0.352**，可分性好，能当**风险排序分**用。
- **特征重要性**：负债率 **0.728** ≫ 收入 0.272，与 Day11（0.675/0.325）**同向**——**负债率是主导判别变量**，两个独立实现互相印证，可作特征筛选/业务解释依据。
- **交叉对照**：sklearn `GradientBoostingClassifier`（同参）测试准确率 **0.7778**，与手写**完全一致**，证明手写 GBDT 实现方向正确。

## 六、一句话带走

**Boosting = 在函数空间做梯度下降**：每棵浅树专门拟合"前面还没修好的残差（负梯度）"，用小学习率一步步累加，弱树接力把**偏差**削下去。它和 Bagging 恰好互补——**Bagging 并行平均降方差、Boosting 串行接力降偏差**，所以调参直觉相反（森林树多无妨，GBDT 树多要早停）。**学习率 × 树数是一对跷跷板**，小 lr + 多树 + 浅树是工业标配。
