# Day 8 — 零售选址：把"客流散点"切成 K 个片区开 K 家店（K-Means 聚类）

> 锚点：[[Learning_Roadmap|Learning Roadmap]] Level 6(LP→ILP→NLP→GA/SA 优化主线已走完) → 本期切到 **Level 8 ML 主线第一课**：无监督聚类。
> 前面几课都在"求最优/很好的解"；这一课换赛道到**机器学习第一类——无监督**。没人给你"每个客流点该归哪片"的标签，只有一堆坐标散点，要算法自己发现"这里其实有几坨人"。用"新区 300 个客流点，开几家门面、各开哪、各覆盖谁"切入。开几家不拍脑袋——**肘部法 + 轮廓系数**告诉你数据自己说 **3 家**最合适。

## 0. 一句话总结

聚类解决"**没有标签、按相似度自动分组**"：把 $n$ 个客流点坐标归成 $k$ 类，K-Means 交替做**分配(归最近质心)→更新(簇内均值)**直到收敛，**每簇质心≈开店位置**。难点是 **$k$ 怎么定**——肘部法(SSE 曲线拐弯)+ 轮廓系数(峰值)在本数据都指向 $k=3$：**开 3 家店**，再多或少都让"簇→居民"的归属变模糊。

---

## 一、这个方法解决什么问题？（10问之1）

给一堆**无标签**样本 $x_1..x_n$，想知道"自然分成几类 / 每类中心在哪"：

- **选址/分区**：几百个潜在客流点，开 k 家店/仓就近各管一片(本课)；
- **客群分层**：按消费金额+频次把人分成高/中/低价值群，好分别投放；
- **异常检测前置 / 图像压缩(k 种主色) / 特征分箱**。
- 典型问法：*"300 个客流坐标(热度、距地铁)，开几家店?各开在哪?"* —— **连续散点聚类成 k 簇、质心当店址**。

## 二、何时用、为何适合？（10问之2、4）

- **没有正确分组标签** → 无监督;若想"预测某点属于哪类"→ 监督分类(下一课 KNN)；
- 想**先摸清数据的天然结构**(几坨、中心、边界)时,聚类是第一探索工具；
- **"就近覆盖"选址**完美匹配:欧氏距离就近归簇 + 质心是"到本簇所有点平方和最小"→ 数学上正对店址；但只适合**凸/圆/大小近似的簇**,细长/嵌套/密度不均会切错 → 改 DBSCAN/GMM。

## 三、数学模型？（10问之3）

给 $n$ 个样本与 $k$，求划分+质心使"组内平方和 SSE"最小：

$$
\min_{\{\mu_j,C_j\}}\;\sum_{j=1}^{k}\sum_{x_i\in C_j}\lVert x_i-\mu_j\rVert^2
$$

NP-hard；但 **Lloyd 交替**高效给局部最优：①**分配** $x_i\to$ 最近质心；②**更新** $\mu_j=$ 簇均值；重复至不动。每轮 SSE 不升故收敛,但**依赖初值**→ 用 **k-means++ 初始化 + 多初值重启取 SSE 最小**。

**$k$ 怎么定**：
- **肘部法**：SSE 随 $k$ 下降,在一处"从陡转缓"的**拐点**取 $k$——多开一家只换来微小改进；
- **轮廓系数** $s_i=\frac{b_i-a_i}{\max(a_i,b_i)}$($a$=同簇平均距,$b$=最近邻簇平均距)∈[−1,1],全体均值峰在"簇最清晰"的 $k$。

## 四、如何求解？（10问之5）

手写的三步循环与 sklearn `KMeans` 是**同一套算法**,可互证正确：

```python
for _ in range(iters):
    dist = ((X[:,None,:]-C[None,:,:])**2).sum(-1)   # (n,k)
    lab  = dist.argmin(1)                            # 1)分配
    C    = np.array([X[lab==j].mean(0)
                     if (lab==j).any() else C[j] for j in range(k)])  # 2)更新
    if np.allclose(C_old,C,atol=1e-8): break         # 3)收敛
```
要诀：k-means++ 选初值、空簇兜底、多重启取最优。

定 $k$ 用标准库：`KMeans(n_init=20).fit_predict(X)` + `silhouette_score(X, lab)`。

## 五、结果与解读（代码实际跑通输出）

300 客流点，底子里埋了 3 个人口热区：

```
肘部法 SSE: k=2→49340  k=3→10535  k=4→8850 ...(3 后降幅骤缓)
轮廓系数:  k=2=0.660  k=3=0.769  k=4=0.620  k=5=0.483 ...(3 为峰)
手写 vs sklearn: k=3 指派一致率=100.0%, SSE 都=10535.2
选址:  片区A 100点→(20.1,15.6)   片区C 101点→(54.7,45.0)   片区B 99点→(59.0,17.5)
```

**解读：**
1. **两家准则都点头 3 家**：SSE 拐在 3、轮廓峰也在 3(0.769)。开 2 家(0.660)把离得远的一批硬塞进一簇(轮廓掉);开 4 家(0.620)把本是一坨硬拆散(过拟合)——都不如 3 干净；
2. **店开在客流重心**：质量心(约 20/55/59 × 上下两行)≈三坨客流中心,每家服务约 100 人、规模均衡,正是"就近扎营"；
3. **手写=标准库**：100% 一致、SSE 相同——手写没写错,讲原理用它,生产用 sklearn 更稳；
4. **无监督本色**：全程没喂过一个"归属标签",$k$ 与分组全靠数据自己长出来。

图：`kmeans_elbow_clusters.png` —— 左散点三色簇+★开店点;右肘部曲线(红虚线标 k=3)+绿轮廓副轴,一眼看两准则同指 3。

## 六、如何验证？（10问之6）

- 与 sklearn 对照：手写 vs `KMeans` 指派一致率≥99%、SSE 相等 → 正确；
- 合法性：恰 $k$ 非空簇、质心形状 $(k,2)$；
- 方法交叉：肘部与轮廓须指向同一 $k$；
- 稳健性(练习)：换 random_state / 簇数,看结论是否稳定。

## 七、缺点与替代？（10问之8、9）

- 假设簇凸/圆/近等大小 → 细长嵌套改 **DBSCAN(任意形状、自定簇)** 或 **GMM(椭圆软簇)**；
- 对初值敏感/局部最优 → k-means++ + 多重启；
- **$k$ 仍要你选**,启发式非定理;数据本无簇则任何 k 都牵强；
- 对离群点敏感(拽质心) → 清洗或 K-medoids；
- 有标签分类 → 换 KNN 监督(下一课)。

## 八、怎么写进论文？（10问之10）

背景(无标签选址) → 目标(SSE)+Lloyd 伪代码+k-means++ → **k 的证据**(肘部+轮廓表/图,说明为何 3) → 结果(各簇规模、质心即店址、着色图) → 可信(手写 vs sklearn 一致率) → 讨论(随机种子/DBSCAN 对照)。

## 九、可迁移性（练习）

- 同一数据换 DBSCAN,比较它自己给的簇数与 K-Means 的 3；
- 造难簇(两椭圆重叠/一条流形带)重做,看 K-Means 切错、DBSCAN/GMM 更合理；
- 换客群画像维度(消费×频次)聚类,给每簇"高价值/潜力/流失"标签与差异化动作；
- 体会"聚出的分组"与下一课"KNN 用它预测"的递进关系。
