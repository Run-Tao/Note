## 一、这一课解决什么决策

某县「云溪谷」景区要排下一年度的运营计划。门票窗口开几个、保洁排几班、接驳大巴买票还是包车、旺季临时工招多少——**全看"下个月来多少人"**。管委会主任老李要一份**未来 12 个月游客量的预测**，并且要能回答一句关键的话：**"这个预测我能信几分？"**

> **决策问题：已知景区过去 96 个月的月度游客量，如何预测未来 12 个月？预测误差有多大？**

**为什么不能拍脑袋？** 因为老李脑子里有三招"看着都对"的土办法，**每一招都会吃亏**：

1. **"看上个月多少人，下个月就按这个数排"**（**朴素法**）——客流有波动，上个月恰逢节假日高峰，下个月就空养一堆人；
2. **"取最近 12 个月的平均"**（**移动平均**）——把"旺季/淡季""增长/回落"全抹平了，该多备的时候不备；
3. **"前几年一直涨，那就画条直线往上延"**（**线性趋势外推**）——景区接待能力有限，**客流不会无限增长**，直线外推迟早飞天。

> **真相：这个景区的客流是"围绕一个长期容量均位（约 19 万人次/月）上下波动、且带惯性"的平稳序列**——本月多、下月往往还多（**客流惯性**），但长期一定会**回落到均位**（**均值回复**）。三招土办法里：朴素法只看最近一期（噪声大）、移动平均把惯性抹平、直线外推又假设"永涨"。**只有把"惯性 + 均值回复"同时写进模型，才能真正算准**——这正是 **ARIMA** 要干的事。

**那 ARIMA 是什么？** 一句话：**它把"未来的值 = 过去的值的某种加权 + 过去的误差的某种加权"这件事，用一套标准化流程（定阶 → 估计 → 检验）拟合出来，再往前递推。** 这套流程就是 **Box-Jenkins 方法论**。

## 二、ARIMA 是什么：把"时间序列"拆成三块

ARIMA$(p,d,q)$ 由三个字母构成，正好对应"把非平稳序列变成可用自回归描述"的三步：

| 字母 | 含义 | 直觉 |
|---|---|---|
| **AR**（$p$） | 自回归阶数 | **用"过去几期的值"预测本期**——"客流有惯性，上个月多，这个月也多" |
| **I**（$d$） | 差分阶数 | **做几次差分把序列变平稳**——"整体在涨/在跌，先把'涨'这件事减掉，看剩下的波动" |
| **MA**（$q$） | 移动平均阶数 | **用"过去几期的预测误差"修正本期**——"上次估高了，这次往下修一点" |

形式化地，ARIMA$(p,d,q)$ 说：设 $y_t$ 是原序列，先做 $d$ 次差分得 $w_t=\Delta^d y_t$（$w$ 是平稳的），然后

$$w_t = c + \underbrace{\phi_1 w_{t-1}+\cdots+\phi_p w_{t-p}}_{\text{AR：过去的''值''}} + \underbrace{\theta_1 \varepsilon_{t-1}+\cdots+\theta_q \varepsilon_{t-q}}_{\text{MA：过去的''误差''}} + \varepsilon_t$$

### Box-Jenkins 四步套路（本课的主线）

1. **平稳化（定 $d$）**：画图 + 平稳性检验（本课手写 ADF 式检验）。非平稳就差分，直到平稳 → 决定 $d$；
2. **定阶（定 $p,q$）**：看 **ACF（自相关）** 和 **PACF（偏自相关）** 的"拖尾/截尾"形态初判，再用信息准则（**AIC/BIC**）网格搜索自动选 → 决定 $p,q$；
3. **估计参数**：AR 用 **Yule-Walker 方程**（本课手写），ARMA 用**条件最小二乘（CSS）**最小化一步预测误差平方和（本课手写，无 statsmodels 依赖）；
4. **诊断与预测**：残差做 **Ljung-Box 白噪声检验**（残差里没结构了，模型才算"榨干"了信息）→ 往前递推预测 + 给预测区间。

> **和"机器学习预测"的区别**：回归/树模型是"**输入特征 → 输出**"，特征要你自己造；ARIMA 是"**序列自己的历史 → 未来**"，它**把时间结构本身当模型**——这是时间序列这类问题的"专用武器"。

## 三、为什么它适合这个问题（10 问中的核心）

| 十问 | 回答 |
|---|---|
| **解决什么问题？** | 给定一条随时间变化的数值序列，**预测它接下来的取值**，并量化预测不确定区间。 |
| **什么情况用？** | 单变量/少变量、有**明显自相关**（今天与昨天相关）、可按等间隔采样的序列：客流、销量、用电、水位、股价…… |
| **为什么适合本问题？** | 月度游客量有**客流惯性（AR）** 和 **均值回复**，正好是 ARIMA 的模型假设；三招土办法（朴素/移动平均/直线）都不能同时抓住这两点。 |
| **怎么用代码实现？** | 差分 → ACF/PACF → BIC 定阶 → Yule-Walker/CSS 估参 → Ljung-Box 检验 → 递推预测，全程手写约 200 行。 |
| **结果怎么检验？** | **多原点滚动回测**（多个预测原点取平均 MAPE）比"切一刀留出集"稳健得多；再用朴素/移动平均/线性趋势三类基线对照。 |
| **局限？** | 只擅长**线性、自相关**结构；**强确定性季节**必须上 SARIMA（本课未含，见下）；参数与阶数选择有主观成分；对突变（政策/灾害）无预知能力。 |

## 四、跑出来的结果（`.venv` 实跑）

```
[数据] 共 96 个月，均值 19.05（万人次），范围 [11.12, 26.78]  平稳、均值回复

[平稳性/定阶] ADF 式检验 t=-3.11 -> 平稳；自动选差分阶数 d=0
[ACF/PACF] 原序列 lag1..4  ACF=[0.689 0.389 0.247 0.165]（拖尾）
                          PACF=[0.689 -0.162 0.091 -0.015]（1 阶截尾）→ 初判 AR(1)

[BIC 定阶] 最优 ARIMA(1,0,0)  BIC=154.11        ← 与真值一致（真模型就是 AR(1)）
[残差检验] Ljung-Box Q=17.30, p=0.099  → 残差≈白噪声，模型充分

[多原点滚动回测 · 预测 12 步 · 13 个预测原点] 平均 MAPE：
    ARIMA      平均=10.88%   中位= 9.81%   最差=24.19%
    季节性朴素   平均=16.78%   中位=15.05%   最差=33.65%
    移动平均     平均=11.85%   中位=10.10%   最差=30.91%
    线性趋势     平均=12.44%   中位= 9.49%   最差=30.02%

[未来 12 个月预测（全量重训 ARIMA(1,0,0)）]
    第+1月=21.62 → 逐月回落到第+12月=19.10（万人次），长期收敛到容量均位 19.05
```

**怎么读结果？**

- **ARIMA 的滚动回测平均 MAPE = 10.88%，是四种方法里最低的**：比"看去年同月"的季节性朴素（16.78%）低了近 6 个百分点，也稳胜移动平均（11.85%）和线性趋势（12.44%）。**注意看"最差"那一列**——三类基线在最差的预测原点上误差能飙到 30%+，ARIMA 只有 24%，**说明它不只是平均好，而是"不容易翻大车"**。
- **BIC 自动定阶选出的 ARIMA(1,0,0)，恰好就是数据的真模型**（一阶自回归、无需差分、无需移动平均项）——这说明"按流程走"能自动把模型认出来，不需要人会"调参玄学"。
- **残差 Ljung-Box p=0.099 > 0.05**：残差里已经没有可利用的自相关结构了，说明"该榨的信息都榨干了"，模型充分。
- **未来 12 个月预测逐月回归到均位 19 万人次左右**：这正是**均值回复**的体现——它不是"平"，而是"现在是旺季高点 21.6，会慢慢向长期容量线 19 靠拢"。**对老李的意义**：不要按最近一个高点（21.6）去备全年的货，而要按"回落后的常态"排班，**旺季多备、淡季减配，全年稳在一个容量区间**。

> **决策交付物**：一份**未来 12 个月游客量预测 + 95% 预测区间**（排班/采购的依据）+ 一份**"三招土办法会多错多少 %" 的量化证据**（滚动回测表）+ 一个**经 Ljung-Box 检验、可复用的 ARIMA 工具**。

## 五、把 ARIMA 放进"预测方法地图"

| 方法 | 核心思想 | 适用 | 本仓出场 |
|---|---|---|---|
| **朴素法 / 移动平均** | 用最近值/近期均值当预测 | 几乎无规律、快速基线 | 本讲（对照） |
| **线性/多项式趋势外推** | 拟合一条曲线往未来延 | 强确定性趋势、短期 | 本讲（对照） |
| **ARIMA（Box-Jenkins）** | 差分平稳 + 自回归 + 移动平均 | **线性自相关、平稳/可平稳化** | **本讲** |
| SARIMA | ARIMA + 季节性差分 | 强季节（月度/季度） | 待补 |
| 指数平滑 / Holt-Winters | 指数加权 + 趋势/季节分量 | 平滑趋势 + 季节 | 待补 |
| 状态空间 / 卡尔曼滤波 | 隐状态递推 | 含噪、可解释观测方程 | 待补 |

**一句话定位**：**ARIMA 是时间序列预测的"母语级"方法**——它是后面一切（SARIMA、ARIMAX、状态空间）的地基；但它**只管线性自相关**，遇到**强确定性季节（比如"每年 7 月必爆"）**要用 **SARIMA**（季节性差分 + 季节 AR/MA），这是本讲诚实的边界。

## 六、迁移面（还能用在哪）

ARIMA 是"**等间隔采样、自己影响自己**"型序列的通用预测锤子：

- **运营排班 / 库存 / 采购**：景区/餐厅/商超的客流、销量预测（本讲）；
- **公共事业**：日用电量、供水量、某路段车流量预测；
- **金融**：收益率、波动率序列（ARIMA-GARCH 前身）；
- **环境**：气温、PM2.5、水位的短期预测；
- **赛题抓手**：任何给出"**一段时间的历史数据表 + 让预测未来几期**"的题（国赛/美赛/各类预测赛），ARIMA 都是**必须跑一遍的基准模型**——哪怕最后用 LSTM，也得拿 ARIMA 当底线比。

## 七、本讲小结（划重点）

1. **ARIMA 解决"用序列自己的历史预测未来"**——尤其适合有**惯性（自相关）**、可**差分平稳**的等间隔数据。
2. **三个字母就是三步**：AR（用过去的**值**）+ I（**差分**掉趋势）+ MA（用过去的**误差**）；稳稳经过 **差分 → ACF/PACF → 信息准则 → 估计 → 残差检验 → 预测** 这套 Box-Jenkins 流程。
3. **定阶别靠眼睛数**：ACF/PACF 只提供初判，**BIC 网格搜索**能稳健地自动选阶（本课自动选出的 ARIMA(1,0,0) 恰是真模型）。
4. **评估别切一刀**：单次留出集会被"这一次切分"的运气左右，**多原点滚动回测**才是诚实的裁判（本课用它证明 ARIMA 平均最好且最差也最稳）。
5. **检验看残差**：Ljung-Box 白噪声检验通过（p>0.05），才说明模型"榨干了信息"；否则要加阶/换模型。
6. **诚实说局限**：ARIMA 只抓**线性自相关**；**强确定性季节**要上 SARIMA，**突变**（政策、灾害）它无能为力——**交付预测时一定要带预测区间和误差指标，而不是甩一个数字**。
