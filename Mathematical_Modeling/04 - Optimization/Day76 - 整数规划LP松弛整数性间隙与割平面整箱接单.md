## 一、这一课解决什么决策

云溪县「味源」酱菜厂接了 2027 年春季的外协订单。董事会问的问题跟去年一样朴素：

> **这周三道工序，三种酱菜，各做多少箱？**

去年我们的答案是 $(638.55,\ 629.12,\ 141.25)$ 箱 —— 见 Day52。**这个答案在纸上很美，在车间里不存在。**
订单只收整箱：半箱要拆托盘、人工分装、再过一次质检，人工成本比利润还高。

所以真正的决策是：

$$\max\ 170x_1+210x_2+260x_3\quad\text{s.t.}\ Ax\le b,\quad x\in\mathbb{Z}_{\ge0}^3$$

三道工序的工分矩阵 $A$ 与可用工分 $b$ 与 Day52 完全相同（同一家厂、同一周）。

**但这一课要讲的不是「怎么解」，而是「你怎么知道解对了」** —— 因为整数规划是所有优化模型里最容易被「看起来对」的数字骗到的一类：

- LP 松弛给你一个**上界**，它会告诉你「最好也不过如此」；
- 四舍五入给你一个**看起来像答案的东西**，它可能违反约束，而**求解器不会报错**；
- 割平面告诉你「这个上界还能再压多少」，它**不动答案，只动界**。

这三个数一起报，才是一份能进论文的整数规划结果。

## 二、10 问式拆解

1. **解决什么问题？** 决策变量只能取整数（整箱、整辆、整台、整人），却又要最优化一个线性或单个目标。
2. **什么时候用？** 生产批量、排班、选址、下料、装箱、指派 —— 国内建模赛题里一半以上的「优化题」本质都是 ILP。
3. **为什么适合？** 因为真实世界里「半箱」「半个人」「半个值班」不存在；一旦把变量改成整数，可行域就从**多面体**变成**多面体里的一堆孤立点**，问题的性质整个变了。
4. **数学模型？**
   $$\max\ c^\top x\ \text{s.t.}\ Ax\le b,\ x\ge0,\ x\in\mathbb{Z}^n$$
   LP 松弛 = 去掉 $x\in\mathbb{Z}^n$ 的那一个等式。
5. **怎么求解？** 小实例：**切片枚举**（固定前两个变量、第三个取最大），126 万格 → 0.5 s；中等实例：分支定界 / 割平面（求解器里）；教学验证：**邻域全枚举 + 求解器**两路互证。
6. **怎么实现？** 见 §六：向量化枚举、支撑函数割、HiGHS MILP 三方夹逼。
7. **怎么验证？** 五条断言写死在脚本里（见 §四.5）：LP 界 ≥ 整数最优、两路枚举一致、MILP 一致、间隙为正、**加割后的 LP 界不得低于整数最优**（否则割切掉了合法整数点）。
8. **有什么缺点？** 整数规划是 NP-hard；间隙可能极小（本例 0.023%）也可能极大（背包类可达 50%+）；割平面在真实规模上需要**大量**割 + 分支定界配合，本讲只演示一条。
9. **替代方法？** 动态规划（[[Day16 - 动态规划DP设备更新与01背包]]、[[Day56 - 动态规划预算分配与县域村路分档投资]]）、拉格朗日松弛（[[Day35 - 拉格朗日松弛与次梯度法]]）、列生成（[[Day36 - 列生成法与Dantzig-Wolfe分解]]、[[Day65 - 门窗型材下料问题切法与列生成]]）、元启发式（[[Day6 - 启发式元启发式GA与SA求解TSP]]）。
10. **怎么进论文？** 交付**三个数**：LP 上界、整数最优、间隙；再附一张「舍入错在哪儿」的表；最后说清「这个间隙对本厂意味着什么」（本例：63.94 元/周 ≈ 3300 元/年，但排产表上会多出 17 箱酸菜和少 6 箱豆腐乳）。

## 四、实跑结果（`.venv`，`-W error` 零告警，11 条断言全过，2.5 s）

### 4.1 三个数一起报：LP 界 / 整数最优 / 间隙

| 量 | 值 |
|---|---|
| LP 松弛最优 | $(638.5522,\ 629.1246,\ 141.2458)$，$z_{\text{LP}}=277{,}393.94$ |
| **整数最优** | $(640,\ 623,\ 145)$，$z_{\text{IP}}=277{,}330$ |
| **整数性间隙** | **63.94 元/周（0.0231%）** |
| 裁判 A：邻域全枚举（±1 箱） | 277,330（12 个邻域可行点，无一更好） |
| 裁判 B：HiGHS MILP | 277,330，解相同 |

**读数**：间隙只有 0.023%，看起来微不足道。但请注意 —— **这不是「舍入一下就行」**。
最优整数解离 LP 解有 $(+1.45,\ -6.12,\ +3.75)$ 的距离，**三个分量全都不是最近整数**。

### 4.2 🔴 核心一：四舍五入会给出「不可行但更漂亮」的答案

把 LP 解逐项四舍五入 → $x=(639,\ 629,\ 141)$：

- 账面利润 **277,380 元** —— 比真正的整数最优还高 50 元，**漂亮得可疑**；
- 但它**违反灌装工序 0.4 工分**（约束超了）；**一个浮点舍入就能让整张表作废**；
- 而 `linprog` / `milp` **不会报错** —— 它只是把这个数交给你，因为「你给的是 LP 解，我返回的是你带来的东西的舍入」。

> 这条是整数规划排产表最常见的翻车方式，也是本课第一个断言要抓的东西：
> `if feasible: 才允许 z <= z_IP` —— 写这句时，**不可行的解一被看到就会炸**。

### 4.3 核心二：向下取整「一定可行」，但每件产品都白干半箱

$x=(638,\ 629,\ 141)$ → **277,210 元**，比最优少 **120 元/周（0.043%）**。
「砍一刀修」（超限后按单位工分利润最低的产品往下砍）给出的结果**和全取整一模一样（277,210）** ——
因为它连「该怎么修」都没找对：超限的是灌装，而灌装贡献最大的恰恰是该**留**的那个。

| 方案 | $x$ | 可行 | 利润 | 相对最优 |
|---|---|---|---|---|
| **[错]** 四舍五入 | (639, 629, 141) | ❌ 灌装 +0.4 | 277,380（假） | — |
| **[错]** 全向下取整 | (638, 629, 141) | ✔ | 277,210 | 99.957% |
| **[错]** 砍一刀修 | (638, 629, 141) | ✔ | 277,210 | 99.957% |
| **整数最优** | (640, 623, 145) | ✔ | **277,330** | 100% |

**注意差的结构**：最优解是「萝卜 +2、豆腐乳 −6、酸菜 +4」——**它不是任何一个方向上的局部修正**，
所以「从上往下砍」「从下往上补」这类一步修正，注定只能落在 99.957%。

### 4.4 🔴 核心三：割平面不动答案，只动界

我们要一条**在所有整数解上都成立、却把 LP 最优点切掉**的平面。这一条是从数据结构里「看得见」的：

$$\boxed{5x_1+5x_2+5x_3\le 7040}\quad\Longleftrightarrow\quad x_1+x_2+x_3\le 1408$$

**它为什么成立？** 在所有整数可行点里，$\max(x_1+x_2+x_3)=1408$（落在 $(636,631,141)$）。
**它为什么能切到 LP 点？** LP 解 $x_1+x_2+x_3 = 1408.92$，比 1408 多 0.92 箱。

| | LP 值 | 解 |
|---|---|---|
| 原 LP 松弛 | **277,393.94** | (638.55, 629.12, 141.25) |
| **加这条割后的 LP** | **277,331.67** | (640.17, 622.67, 145.17) |
| 整数最优（不动） | 277,330 | (640, 623, 145) |

**间隙从 63.94 元压到 1.67 元 —— 缩小 97.4%，而整数最优一个数字都没变。**

这就是「割平面」的全部意义：它不给你新答案，它告诉你**你离真答案有多近**。
一个能说出「我的答案最多差 1.67 元」的方案，和一个只能说「差不多就这」的方案，在评审会上是两份东西。

> **次要读数**：候选割里 `(k,k,k)·x ≤ 1408k` 对 k=2,3,4,5 全部等价（都给出同一个 LP 界）；
> 而 `(5,4,4)`、`(4,5,5)`、`(4,3,3)` 三条都只是**部分**有效（间隙 27.5 / 43.3 / 39.0），
> 说明割的**强度**差别很大 —— 「加一条割」和「加一条好割」不是一回事。

### 4.5 五条断言（脚本里写死，不成立就崩）

```python
assert Z_LP >= Z_BF - 1e-6          # LP 松弛必须不差于整数最优
assert abs(Z_LOCAL - Z_BF) < 1e-6   # ±1 邻域全枚举不能找到更好的整数解
assert abs(Z_BF - Z_MILP) < 1e-6    # HiGHS 与切片枚举必须一致
assert GAP > 1e-6                   # 必须有正间隙（否则教学点消失）
assert Z_CUT >= Z_BF - 1e-6         # 加割后的 LP 界不得低于整数最优 ← 抓「割切掉了整数点」
assert Z_CUT <  Z_LP - 1e-9         # 加割后界必须严格下降 ← 抓「割根本没起作用」
```

**最后两条是一对**：只写第一条，割写错（把整数点也切了）会被抓住；
只写第二条，割没起作用（切掉的是空气）也会被抓住。**一对互相咬住的断言，比一条「看起来很强」的断言可靠得多。**

### 4.6 敏感性：产能放大 10%，间隙跟着涨

| ρ（工分上限比例） | LP 上界 | 整数最优 | 间隙（元） |
|---|---|---|---|
| 0.90 | 249,654.55 | 249,580 | 74.55 |
| 0.95 | 263,524.24 | 263,450 | 74.24 |
| **1.00** | **277,393.94** | **277,330** | **63.94** |
| 1.05 | 291,263.64 | 291,190 | 73.64 |
| 1.10 | 305,133.33 | 305,070 | 63.33 |

**读数**：间隙不是常数（63~75 元之间抖）。这一点在论文里很值钱：
**「我的间隙只有 0.02%」这句话，只在 ρ=1 的那一个点上成立**，产能一动它就会变 ——
报间隙必须报**区间**，不是单点。

## 五、这一课最容易写进论文的三句错话

1. ❌「LP 松弛解四舍五入后即为最优整数解」 → 本例四舍五入**不可行**，且账面还更高，**双重错误**。
2. ❌「整数规划与线性规划的差距可以忽略」 → 本例 0.023% 确实小，但**决策变量全变了**（$x$ 三项全动），
   对车间来说这是三张不同的领料单；「差距小」说的是**钱**，不是**方案**。
3. ❌「用割平面把间隙压到 0」 → 本例一条割把间隙压到 1.67 元，但 $\text{gap}=0$ 需要**证明** LP 极点已是整数；
   一条割只能**缩小**界，不能宣告最优。

## 六、Python 实现的关键点（本课踩坑最多的地方）

1. **切片枚举要向量化**：126 万次 Python 双层循环 = 34 s；`np.meshgrid` + 一次求 `min` = **0.5 s**。
   建模课里凡是要枚举 10^6 量级，先问「能不能一次算完」。
2. **支撑函数只要「上边界点」**：对 $w\ge0$，$\max w^\top x$ 一定在「固定 $x_1,x_2$、$x_3$ 取最大」的边界点上取到 ——
   77.6 万个点、1 秒扫完，**不需要**生成 1.1e9 个全整数点。
3. **割的合法性要由数据保证**：$b=\max_{\text{整数可行点}} w^\top x$ 是「by construction 合法」；
   而 $x_{\text{LP}}$ 是否越过它，是能不能切到的问题 —— **两件事分开写，别混。**
4. **断言成对写**：`Z_CUT >= Z_BF` 与 `Z_CUT < Z_LP` 互咬（见 §四.5）。
5. **中文图**注册 Noto Sans CJK SC；**不要用 `x₁ / x₂` 这类下标字符**（CJK 字体不含 U+2081–2089，`-W error` 下会报 Glyph missing）。
