## 一、这一课解决什么决策

Day4 用**分支定界**解决了整数规划：如果 LP 松弛解出 $x_1=2.4$ 这种小数，就分两支
（$x_1\le 2$ 与 $x_1\ge 3$），在搜索树上左右搜、把没希望的枝剪掉。

但分支定界有个"笨"的地方：**它靠"试"——分出一大堆子问题，一个个重解 LP**。
于是自然要问：

> **能不能不分支、不搜索，就在同一张 LP 上不断"追加一条约束"，让 LP 的最优解自己变成整数？**

这就是**割平面法（Cutting Planes）**，1958 年由 **Ralph Gomory** 提出，
它和分支定界并列为整数规划的两大精确算法基石（工业求解器里两者是**配合使用**的）。
本课回答决策者/建模者最关心的五个递进问题：

> "**LP 松弛解为什么'看着最优、实则不能用'？**"
> "**能不能不加分支，只加约束就把解逼成整数？**"
> "**那条神秘的割（cut）到底从哪来？凭什么它是对的？**"
> "**为什么割'切掉了 LP 顶点、却切不掉任何一个整数点'？**"
> "**割平面能单独把整数最优切出来吗？为什么工业界还要结合分支定界？**"

**决策背景（本课的真实问题）**：一家工厂用有限的**设备工时**和**原料**同时生产两种产品：

- 产品 1：每件用设备 3 工时、耗料 1 单位、赚 **5** 元；
- 产品 2：每件用设备 1 工时、耗料 2 单位、赚 **3** 元；
- 本周可用设备工时 **10**、原料 **8**。

问：**两种产品各生产多少件，总利润最大？**（件数必须整数，不能卖 2.4 件。）

写成整数线性规划：

$$
\max\; 5x_1 + 3x_2
\quad\text{s.t.}\quad
\begin{cases}
3x_1 + x_2 \le 10 & \text{(设备工时)}\\
x_1 + 2x_2 \le 8 & \text{(原料)}\\
x_1, x_2 \ge 0,\ \text{整数}
\end{cases}
$$

## 二、为什么 LP 不够、为什么要新算法（选型）

先把整数约束**放开**，解 LP 松弛：

- **LP 松弛最优**：$x=(2.4,\ 2.8)$，利润 **20.4** —— 现实里"生产 2.4 件、卖 2.8 件"**不可执行**；
- **整数最优**：$x=(2,\ 3)$，利润 **19** —— 真正能落地的方案。

两者差 **1.4 元**，这叫**整数间隙（integrality gap）**：正是"不可分割"造成的损失。
**关键认知**：整数最优解 $(2,3)$ **根本不在** LP 最优顶点 $(2.4,2.8)$ 附近——
你把 LP 解"四舍五入"成 $(2,3)$ 这次碰巧对了，但更多时候会**直接不可行**（Day4 演示过）。

那么怎么找整数最优？

| 方法 | 思路 | 特点 |
|---|---|---|
| **分支定界**（Day4） | 分数变量分两支，在搜索树上剪枝 | 通用、稳，但要重解很多子 LP |
| **割平面法**（本课） | **不分支**，在同一 LP 上不断加"合法割"，把可行域削向整数点 | 每轮回"解一次 LP"就抬升下界，天然和其他方法组合 |

一句话：**分支定界靠"分而治之"，割平面靠"精雕细琢"**。二者合体就是工业求解器里的
**分支切割（Branch-and-Cut）**——现代 MILP 求解器（Gurobi / CPLEX / HiGHS）的主力。

## 三、模型与算法是什么（割从哪来）

### 3.1 先看清："割"要满足哪两条

一条割就是**一条新的线性不等式** $a\cdot x \le b$（或 $\ge$），加进 LP 约束里。它必须同时满足：

1. **合法性（valid）**：**所有整数可行点都满足它**——否则会把真最优解切掉，答案就错了；
2. **有效性（cutting）**：它**切掉当前 LP 的分数最优顶点**——否则加了也没用。

> **这正是割平面法的灵魂**：割"切掉 LP 的分数解、却碰不到任何整数点"。
> 于是每加一条割，LP 可行域里"整数点的集合"一点没变，但 **LP 上界被压低了**，
> 逼着 LP 最优解往整数点方向挪。

### 3.2 Gomory 割：从 LP 最优单纯形表里"读"出来

Gomory 的天才之处：**那条割不用猜，直接从 LP 最优单纯形表里读**。

设最后解得 LP 最优，看**取分数值**的那个基变量 $x_B$（比如 $x_1$）所在的行：

$$
x_B + \sum_{j} a_{Bj}\, x_j = b_B,
\qquad b_B \text{ 是分数，例如 } 2.4.
$$

把阈值和系数都拆成"整数部分 + 小数部分"（$0\le f<1$）：

$$
b_B = \lfloor b_B\rfloor + f_0,\qquad a_{Bj} = \lfloor a_{Bj}\rfloor + f_j.
$$

代入并移项：

$$
x_B + \sum_j \lfloor a_{Bj}\rfloor x_j - \lfloor b_B\rfloor
= f_0 - \sum_j f_j\, x_j.
$$

**左边一定是整数**（所有 $x$ 是整数），所以**右边也必须是整数**。
而右边 = $f_0 - \sum_j f_j x_j$，且因 $0\le f_j<1$、$x_j\ge0$，可得 $\sum_j f_j x_j \ge 0$，于是右边 $\le f_0 < 1$。
一个 $\le f_0<1$ 的整数只能是 $\le 0$。所以：

$$
\boxed{\;f_0 - \sum_j f_j\, x_j \le 0
\quad\Longleftrightarrow\quad
\sum_j f_j\, x_j \;\ge\; f_0\;}
$$

**这就是 Gomory 分数割**：$\sum_j f_j x_j \ge f_0$。

- 它对**任何整数解**都成立（推导只用了"整数"这一条）→ **合法**；
- 但当前 LP 最优解里那条行取的正是 $x_B=b_B$ 使该行等式成立，代入得 $\sum_j f_j x_j = f_0 - (x_B - \lfloor b_B\rfloor)$……
  而当前分数顶点会**违反**这条割 → **有效**（切掉它）。

> **一句话**：Gomory 割 = **"把最优表里那个'小数'提出来，逼它必须被整数性'填平'"**。
> 这就是"为什么割切不掉整数点"的证明——**它本来就是从'变量必须是整数'推出来的**。

### 3.3 主算法（割平面法一轮做什么）

```
重复：
    1. 解当前 LP → 得最优解 x* 与目标
    2. 若 x* 已经是整数：停，就是整数最优
    3. 否则：在最优先单纯形表里找"取值分数的整数变量"所在的行
    4. 从该行读出 Gomory 割 Σ f_j x_j >= f_0，把它加入 LP 约束
    5. 回到第 1 步
```

**每加一条割，LP 目标就"更差一点"（上界下降），而整数可行点一个没丢**——
上界不断向整数最优逼近，直到 LP 最优解自己落在整数点上。

## 四、如何用 Python 实现

脚本：`08 - Python/daily/2026-10-05/gomory_cutting_planes.py`。**主算法全手写、零专用求解器**：
`scipy.milp`（求真最优）**仅作独立裁判**。

- `simplex(c, A, b)`：**手写表式单纯形法**（解 $\max c\cdot x,\ Ax\le b,\ x\ge0$），
  返回最优解、目标、以及**最终单纯形表 + 基变量**（读割的原料）；
- `gomory_cut_from_tableau(...)`：从最优表找"取值分数的整数基变量"行，
  按 $f_j$、$f_0$ 构造割 $\sum_j f_j x_j \ge f_0$；
- 割里含松弛变量，需**代入 $s_k=b_k-A_k x$ 消去**，化回"只含原变量"的约束再入库；
  若右端为负，整式 $\times(-1)$ 翻成 $A x\le b$ 标准形（保证初始基可行）；
- `cutting_plane_rounds(...)`：主循环；`enumerate_integer_feasible(...)`：
  小规模**暴力枚举**整数点，给"割是否合法"当裁判；`solve_exact_milp(...)`：`scipy.milp` 对照。

## 五、实测结果（`.venv` 真实跑通，$\max 5x_1+3x_2$，$3x_1+x_2\le10$，$x_1+2x_2\le8$）

```
[LP 松弛] 最优=20.4000  x=[2.4 2.8]  -> 分数产量不可执行 (最大分数程度=0.4000)
[整数真最优] 19.0000  x=[2. 3.]  (scipy.milp 对照)

[割平面法 迭代]
  第 0轮: LP最优=20.400000  x=[2.4 2.8]    最大分数程度=0.4000  累计割数=0
        + Gomory割: (2.0)x1 + (2.0)x2 <= 10.0000   (来自取分数的基变量 x1)
  第 1轮: LP最优=20.000000  x=[2.5 2.5]    最大分数程度=0.5000  累计割数=1
        + Gomory割: (3.0)x1 + (2.0)x2 <= 12.0000
  第 2轮: LP最优=19.333333  x=[2.6667 2.] 最大分数程度=0.3333  累计割数=2
        + Gomory割: (4.0)x1 + (2.0)x2 <= 14.0000
  第 3轮: LP最优=19.000000  x=[2. 3.]      最大分数程度=0.0000  累计割数=3
```

| 口径 | 目标（利润） | 说明 |
|---|---|---|
| LP 松弛 | **20.4000** | $x=(2.4,2.8)$，分数、不可执行 |
| 割平面 第1/2/3轮 | 20.0 → 19.333 → **19.0** | 每加一条割抬升下界 |
| **整数最优** | **19.0** | $x=(2,3)$，与 `scipy.milp` 一致 |

- **只用 3 条割**，就把 LP 上界从 **20.4 削到 19.0 = 整数最优**，LP 最优解自己变成了整数 $(2,3)$；
- 三条割分别是 $2x_1+2x_2\le10$、$3x_1+2x_2\le12$、$4x_1+2x_2\le14$——
  它们**都从"取分数的基变量 $x_1$ 所在行"读出来**，形式简单、系数全是整数；
- **割的合法性经暴力枚举核验**：15 个整数可行点，**没有任何一个被割切掉**——
  割"只切 LP 顶点、不碰整数点"在本例完全成立。

## 六、如何验证（八条硬约束，全部通过 ✓）

1. **LP 松弛 == 20.4 且解为分数**——问题确实需要整数处理；
2. **整数真最优 == 19**（`scipy.milp` 对照）；
3. **割平面到达整数最优**（目标 == 19，与 milp 一致）；
4. **割平面解是整数**（最大分数程度 < 1e-6）；
5. **割平面解 == `scipy.milp` 最优解**（$(2,3)$ 逐位一致）；
6. **所有割都不切任何整数可行点**（暴力枚举核验合法性）；
7. **至少用到了 1 条割**（确实是靠割而不是靠原始 LP）；
8. **暴力枚举最优 == `scipy.milp`**（枚举实现正确）。

**结论**：**割平面把 LP 上界 20.4 一路削到整数最优 19.0（间隙归零）**——
不分支、不搜索，只在同一张 LP 上追加 3 条约束，就把解逼成了整数。

## 七、有什么缺点 / 替代方法

- **只靠 Gomory 分数割会"退化慢"**：现实大规模问题里，纯割平面法可能**加成千上万条割、
  收敛极慢**（数值误差累积、"尾巴"拖得长）——这是它 1958 年提出却一度"叫好不叫座"的原因；
- **数值不稳**：割的系数可能越来越"脏"（大数字、小数字混杂），浮点误差让 LP 解失真；
- **需要单纯形表**：割从"最优基"读出，得有表式实现（本课手写正是为讲清这一点）；
- **现代做法 = 分支切割（Branch-and-Cut）**：**分支定界 + 割平面**配合——
  用割**快速抬升下界**、用分支**保证有限终止**，这才是工业求解器的真身；
- **替代 / 相关方法**：分支定界（Day4）、**分支切割（本课的工业形态）**、
  分支定价（Day36 列生成 + 分支，Day36 已提及）、**Gomory 混合整数割（本课的推广）**、
  覆盖割 / 流覆盖割等专用割、商用 MILP 求解器。

## 八、怎么选（决策表）

| 情形 | 首选 |
|---|---|
| 小规模整数规划、想快速看整数最优 | 直接 MILP 求解器（HiGHS / `scipy.milp`） |
| 想理解"整数最优怎么被逼出来" | **割平面法**（本课）+ 分支定界（Day4） |
| LP 松弛间隙大、想收紧下界 | 加割（本课）/ 拉格朗日（Day35）/ 列生成（Day36） |

| 真实工程求解 | **分支切割**（割 + 分支，商用求解器） |

## 九、怎么写进数学建模论文

- **问题重述**：把"排产"翻译成"整数决策变量 + 线性约束 + 线性目标"，点明**"件数必须整数"**；
- **假设**：两类资源固定可得、单位消耗与利润固定、产量非负整数、允许资源未用尽（松弛变量）；
- **符号**：$x_1,x_2$ 产量、$c$ 单位利润、$A$ 消耗矩阵、$b$ 资源上限；
- **模型**：给出 ILP，**并强调"为什么不能直接用 LP 解"**（分数解不可执行、整数间隙）；
- **算法**：写清"解 LP → 从最优表读 Gomory 割 → 加割 → 再解"主循环，
  并用**几何图**画出割如何削掉 LP 顶点、**收敛图**展示上界被逼向整数最优；
- **结果**：报最终整数方案 $(2,3)$、利润 19，并给出 **LP 上界 → 整数最优的收敛过程**；
- **检验**：用**暴力枚举**核验"割不切整数点"、用求解器对照整数最优；对利润系数做敏感性；
- **诚实交代局限**：纯割平面法退化慢、数值不稳，工业界用分支切割。
