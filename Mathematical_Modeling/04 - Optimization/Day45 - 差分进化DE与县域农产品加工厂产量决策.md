## 一、这一课解决什么决策

一家县域农产品加工厂，用**同一条产线**生产 3 种产品：果干（$x_1$）、果汁（$x_2$）、冻干蔬菜（$x_3$），单位都是吨/周。厂长老王要定**每周各产品各做多少**，让**周利润最大**。

> **决策问题：三条产品线各排多少产量，在三重约束下利润最高？**
> $$\max_{x_1,x_2,x_3}\ \Big[\underbrace{\textstyle\sum_i p_i x_i}_{\text{销售收入}}+\underbrace{A\textstyle\sum_i \sin(\omega_i x_i)}_{\text{价格批次波动}}-\underbrace{\textstyle\sum_i \tfrac{c_i x_i^2}{1+a_i x_i}}_{\text{边际成本先降后升}}+\underbrace{\gamma\sqrt{x_1 x_2}}_{\text{果渣共用的协同收益}}\Big]$$
> 约束：$x_1+x_2+x_3\le 110$（产线工时）、$0.5x_1+1.5x_2+0.2x_3\le 95$（冷藏库）、$0.8x_1+0.4x_2+1.2x_3\le 78$（排放）、$0\le x_i\le U_i$。

**为什么不能拍脑袋？** 因为**目标函数不是那个乖巧的倒扣碗**：

- **边际成本先降后升**（规模经济）：每多产一吨，成本先降（摊薄固定成本）、后升（设备超负荷），所以每种产品单独看，利润对产量是**一条先升后降的曲线**——这已经够麻烦了；
- **价格有"批次波动"**：县域小厂议价能力弱，收购价/售价随季节和批次起伏，用正弦项 $\sin(\omega_i x_i)$ 刻画。**这一项是"魔鬼"**——它把原本平缓的利润面**揉出大量局部峰谷**。本实例里，梯度法能爬到的**局部最优多达 23 个**；
- **三产品竞用同一资源**：产能、冷藏、排放三个约束把它们绑在一起，一个多产另一个就得少产。

> **结局：真正的全局最优（周利润 4166.6 千元）藏在一个"从零产量出发的梯度法根本走不到"的角落里。** 我们用传统的梯度法（SLSQP）从"零产量"起步，它一头扎进一个**局部最优**、只赚 **3897.1 千元**——**比最优少赚 6.91%**，而老王**根本看不出来自己亏了**（那个解完全合规、看着也很"均衡漂亮"）。

**那怎么办？** 请出今天的主角——**差分进化（Differential Evolution, DE, Storn & Price 1997）**。

## 二、DE 是什么：一群"解"，用"彼此之差"当步长

先记住一句话：**梯度法靠"问目标函数往哪下坡"走路；DE 靠"看同伴之间差多远"走路**。

DE 维护一个**种群**（比如 60 个候选产量方案），每一代做三件事——**变异 → 交叉 → 选择**：

### ① 变异（mutation）：$v = x_{r_1} + F\cdot(x_{r_2} - x_{r_3})$

这是 DE 的灵魂。随机挑**三个不同的同伴** $r_1,r_2,r_3$，用**后两个之差** $(x_{r_2}-x_{r_3})$ 当作扰动量，加到第一个身上。

- 差向量 $x_{r_2}-x_{r_3}$ 是"**当前种群自己在探索空间中天然形成的步长**"：种群初期散布得开、差向量大、步子大（探索）；后期大家挤在一起、差向量小、步子自动收窄（开发）。**这是 DE 最漂亮的地方——步长不用人工设定，种群自己会调节。**
- $F\in[0,2]$ 是**差分权重**，缩放这个自适应步长（本课 $F=0.6$）。

> 和 PSO（Day44）对比：PSO 的步长是"朝 pbest/gbest 冲"，方向由**记忆**决定；GA（Day6）的扰动是**固定分布**的随机突变；**只有 DE 的步长取自"种群内两个体之差"**——种群越多样、步子越大。

### ② 交叉（crossover）：把试验个体拼出来

把变异个体 $v$ 和原个体 $x_i$ 按维"抽签拼接"，得到试验个体 $u$：每一位以概率 $CR$ 取 $v$、否则取 $x_i$（**并强制至少继承一维**，防止退化）。$CR$ 是**交叉概率**（本课 $CR=0.9$，鼓励多继承变异信息）。

### ③ 选择（selection）：贪心，不优就丢弃

算 $u$ 与 $x_i$ 的适应度，**谁好留谁**（一对一贪婪竞争）。这一步保证**种群最优值单调不劣**——DE 绝不会"退步"。

### 约束怎么办？——惩罚法

上面的 $x_1+x_2+x_3\le110$ 等约束，最省事的处理是**惩罚法**：把"违反量"乘以一个大惩罚系数（本课 1000），加到"最小化目标"上：

$$\text{fitness}(x) = -\text{profit}(x) + 1000 \times \big[\text{总违反量}\big]$$

于是**任何违约的解都会被重罚**，DE 自然优先收敛到可行域内。（更精细的做法是罚函数/内点法 Day34，但 DE 配惩罚已足够。）

## 三、为什么它适合这个问题（10 问中的核心）

| 十问 | 回答 |
|---|---|
| **解决什么问题？** | 目标函数复杂、**求不了导或导数不可靠**、**多峰**、可能**带约束**的连续优化。 |
| **什么情况用？** | 目标非凸多峰、可行域非凸、解析梯度拿不到、或"能算值但算子难写"。 |
| **为什么适合本问题？** | 利润面 23 个局部最优，梯度法从零起步卡低 6.91%；DE **不需要梯度**、**自适应步长**、**天然并行**。 |
| **怎么用代码实现？** | 变异 + 交叉 + 贪心选择，三件套约 30 行；配惩罚法处理约束。 |
| **结果怎么检验？** | 多起点 SLSQP（×200）+ 密集网格暴力 双裁判交叉；DE 解必须**显式可行**；20 次运行看鲁棒性。 |
| **局限？** | **无最优保证**（元启发式通病）；高维/高精度时收敛慢；惩罚系数要调；参数 $F,CR,NP$ 影响结果。 |

## 四、跑出来的结果（`.venv` 实跑）

```
[DE 差分进化] 种群 60 × 800 代，F=0.6, CR=0.9, 惩罚=1000
  DE 最优产量 x = [78.9061, 26.7153, 3.4908]      ← 果干 78.9 吨、果汁 26.7 吨、冻干蔬菜 3.5 吨
  DE 最优利润 = 4166.6077 千元   可行 = True

[对照① SLSQP 从零产量起步] 利润 = 3897.1324  x = [29.87, 38.35, 32.30]  ← ⭐ 卡在"均衡"的局部最优
[对照② SLSQP 从 40%上限起步] 利润 = 4027.3853  x = [28.43, 49.11, 29.67]
[裁判① 多起点 SLSQP×200] 利润 = 4166.6077  x = [78.91, 26.72, 3.49]  发现局部最优 23 个
[裁判② 网格暴力 70³]     利润 = 4157.9598  x = [78.84, 26.09, 3.62]  （网格受分辨率限制，是下界）

[鲁棒性] DE 独立运行 20 次（不同种子）：最好=最差=均值=4166.6077，自身浮动 0.000%
```

**怎么读结果？**

- **DE 比"零产量起步的梯度法"多赚 6.91%**（4166.61 vs 3897.13）——这就是"局部最优陷阱"的真实代价。注意 SLSQP 那个解 **$x=[29.9,38.3,32.3]$ 看起来非常"均衡、合理"**，正是这种"看着对"的解最容易骗过决策者。
- **DE 找到的最优，和"200 次随机起点的 SLSQP"完全一致**（4166.6077）——两条完全不同的技术路线互证，可信度大增。顺带数出：这个地形确实有 **23 个局部最优**。
- **网格暴力（343000 点）给了 4157.96 的下界**——比 DE 低 0.21%，符合预期（网格是离散采样，永远够不到精确峰值），进一步佐证 DE 的解是靠得住的。
- **20 次独立运行全部落在同一点（零浮动）**——本实例下 DE 非常稳定。但**要诚实**：这是"这个实例很友好"，**不是"DE 保证最优"**（换成更崎岖的问题就会浮动，见 Day43/44）。

> **决策交付物**：不是"一行最优产量"那么简单，而是——一份**最优排产方案**（果干 78.9 / 果汁 26.7 / 冻干蔬菜 3.5 吨/周）+ 一份**"天真梯度法会让你少赚 6.91% 的量化证据"** + 一套**经双裁判核验、可复用的 DE 工具**。

## 五、把 DE 放进"元启发式地图"

到这里，本仓库的**元启发式家族**已经相当完整，DE 补上了"**进化算法里连续优化那半边**"：

| 范式 | 代表 | 机制核心 | 出场 |

| 记忆式局部搜索 | 禁忌搜索 | 禁忌表 + 特赦 | [[Day42 - 禁忌搜索与单机总加权延误排产|Day42]] |
| 群体智能（离散） | 蚁群 ACO | 信息素正反馈 | [[Day43 - 蚁群算法ACO求解TSP最短环游|Day43]] |
| 群体智能（连续） | 粒子群 PSO | pbest/gbest 双力牵引 | [[Day44 - 粒子群优化PSO与县域冷链中转站选址|Day44]] |
| **进化算法（连续）** | **差分进化 DE** | **种群内"个体之差"当自适应步长** | **本讲 Day45** |

**一句话区分 GA 与 DE**：GA 的突变是"**从固定分布里抽一个随机量**"，DE 的突变是"**从种群自己当前的分布里借一段差**"——后者**自带尺度自适应**，这正是 DE 在连续优化上往往比 GA 更省心的原因。

## 六、迁移面（还能用在哪）

DE 是"**连续 + 多峰 + 可算值 + 难求导**"型问题的通用锤子，几乎在所有学科里都有落地：

- **工程参数标定**：把仿真模型调参到和实测吻合（拟合目标不可导）；
- **神经网络超参 / 权重训练**（小网络、低维时 DE 很能打）；
- **化工 / 能源 / 电力经济调度**：非线性成本 + 多重运行约束；
- **投资组合 / 定价决策**：非凸收益 + 风险约束（接 [[Day5 - 非线性规划NLP_均值方差投资组合|Day5]]、[[Day29 - CVaR风险厌恶两阶段随机规划|Day29]]）；
- **赛题抓手**：任何"**目标函数写得出、但梯度求不动、又有多个约束**"的国赛/美赛题，DE 都是保底的求解引擎。

## 七、本讲小结（划重点）

1. **DE 解决"能算值、难求导、多峰、带约束"的连续优化**——尤其适合写不出解析梯度、又怕梯度法卡局部最优的场合。
2. **它的超能力在"变异"**：$v = x_{r_1} + F(x_{r_2}-x_{r_3})$ 用**种群内个体之差**当步长，**步长自适应**——种群散时步子大（探索）、种群聚时步子小（开发）。
3. **三件套**：变异（生新解）→ 交叉（拼新解）→ 贪心选择（留好解）；约束用**惩罚法**加进适应度。
4. **不保证最优**：它是"用可控随机性换可接受计算时间"的启发式（元启发式通病）；交付时**必须显式报可行性 + 跑鲁棒性 + 上独立裁判**。
5. **本课实例的教训**：从零起步的梯度法会掉进一个"**看着最均衡、其实少赚 6.91%**"的局部最优——**这种"看起来对"的解，正是决策最容易踩的坑，也是 DE 这类全局搜索的价值所在。**
