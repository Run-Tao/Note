# Day 5 — 非线性规划（NLP）：当"风险"进入目标，LP 就罢工了

> 锚点：[[Learning_Roadmap|Learning Roadmap]] Level 6 · 优化模型。
> 上一篇(Day4)用整数变量管住了"不可分割的决策"；今天往上再走一步，讲数学规划三件套的收尾：**非线性规划（NLP）**。它是 Day3 的 LP 和 Day4 的 ILP 都"够不着"的那类问题——**当最优解不在"直线/顶点"上，而是躲在一条弯曲的曲面上**。用一个真实到骨子里的例子切入：**钱就这么多，怎么分给三条产品线才既赚得够、又不至于翻船**。

## 0. 一句话总结

LP 只认"回报相加"，于是它教你把**所有钱压到回报最高那条线**——却对"风险(波动)"视而不见，全押一次就能让你某年腰斩。**风险本质上是权重的二次项**（方差 $w^\top\Sigma w$），这迫使你放弃线性目标、走进**非线性规划 NLP**。`scipy.optimize.minimize(SLSQP)` 在"预算分光 $+$ 最低回报达标 $+$ 不卖空"下最小化总风险，给出的最优是**把钱分到"高回报线 + 避险线"，而不是孤注一掷**——波动从 20% 压到 14.4%，回报还保住了 10%。

---

## 一、这个方法解决什么问题？（10问之1）

当你的**目标函数或约束里有乘、乘方、商、对数、指数**这些"非线性"，LP/ILP 全都没辙。典型场景：

- **投资组合 / 资本配置**：收益可加，但**风险(方差)是二次项**——加权时"波动不是相加而是带交叉项"，全押反而放大风险；
- **收益递减 / 饱和**：产量或投入带来**边际报酬递减**（对数、$-\alpha x^2$ 类），目标不再是一条直线；
- **非线性成本 / 非线性约束**：运费随距离直线但…仓储费随规模平方涨；`x·y` 这类交叉项在选址/排产里到处都是；
- **工程最优化**：梁的截面、弹道、化合物配比，几乎全是非线性。

典型问法：*"预算这么多，三条产品线各有期望回报与两两协方差，怎么分配让总风险最小、同时保证总回报不低于某个数？"*（本文案例）

## 二、什么情况该用它、为什么适合？（10问之2、4）

- **风险是决策的核心**时：风险=权重协方差 $w^\top \Sigma w$ 天然二次 → 必须用 NLP/QP，LP 压根表达不了；
- **最优解在多变量曲面内部**而非线性边界顶点时；
- NLP / QP 在金融资产配置、供应链、推荐、机器学习(正则化/损失)里是**通用地基**，竞赛论文里写"均值-方差优化"即刻提升档次；
- 若**目标和约束全是线性的** → 用前面的 LP/ILP（更快更稳，别硬上 NLP）；
- 若**有离散整数变量 + 非线性** → MINLP（极难，先别碰）。

## 三、数学模型是什么？（10问之3）

设 $w_i$ = 投给产品线 $i$ 的资金比例（$i=1,2,3$），决策向量 $w=(w_1,w_2,w_3)$：

- 组合期望回报：$\mu_p = \mu^\top w$（$\mu$ 是各线期望回报列向量，**线性**）；
- 组合风险(方差)：$\sigma_p^2 = w^\top \Sigma\, w$（$\Sigma$ 是协方差矩阵，**二次型**——这就是非线性的来源，含交叉项 $w_iw_j\sigma_{ij}$，风险不可相加）。

$$
\min_{w}\; w^\top \Sigma\, w
\quad\text{s.t.}\quad
\begin{cases}
\sum_i w_i = 1 &\text{(预算全部分光，归一化)}\\
\mu^\top w \ge \bar r &\text{(期望回报不低于目标值)}\\
w_i \ge 0 &\text{(不卖空)}
\end{cases}
$$

目标 $w^\top\Sigma w$ 是 $w$ 的**二次函数**，故叫 **二次规划(QP)**，是 NLP 里最规矩、最好解的一类。LP 会问"凭什么不把 1 全给回报最高的那条"——因为那样 $\sigma_p^2$ 会爆炸（$=$那条线自己的方差），NLP 用曲面把它拉回来做**分散化**。

## 四、如何求解？（10问之5）

- **约束多、目标平滑**时首选 **SLSQP**（`scipy.optimize.minimize`，可带等式+不等式约束，逐次二次规划）；
- 纯 QP 也可用 `trust-constr`（信赖域）或专用 QP 求解器(`cvxopt`/`quadprog`/`OSQP`)；
- **标准步骤**：写目标函数 → 列约束(dict) → 给 bounds(不卖空 $0\le w\le1$) → 给一个可行初值(等权 $w_0=(1/3,1/3,1/3)$) → minimize → 检查 `res.success` 与约束是否满足。

> 求解要诀：**初值要可行**（满足约束），否则 SLSQP 容易在起点就飞掉；本课用"等权"作天然可行起点。

## 五、结果与解读（本文代码实际跑通输出）

三条产品线：线1 期望 12%/高波动、线2 10%/与线1强相关、线3 6%/低波动低相关(避险)。预算归一为 1，要求总回报 ≥10%，最小化风险：

```
[LP式·只求收益·极端] 全押线1:  回报=12%,  方差=0.0400 (波动≈20.0%)
[NLP 最优 target=10%]
  权重: 线1=66.7%  线2=0.0%  线3=33.3%   (和=100%)
  实际回报=10%,  方差=0.0207 (波动≈14.4%)   ← 波动从20%压到14.4%
[解析核对] 全局最小方差(理论,可卖空) w=[-9,10,0] —— 现实要 w>=0, NLP 是它的约束版本
[最小方差约束版(不管回报)] w=[0,18.2%,81.8%], 方差≈0.0088 << 0.0207
```

**怎么读这三行（结果interpretation）：**
1. **"全押最高回报"是坏的决策**：回报确实到 12%，但波动 20%——一次大回撤可能吞掉两三年收益，LP 完全没看见这条；
2. **NLP 帮你"用1/3的钱买保险"**：最优是 线1(高回报)66.7% + 线3(避险)33.3%，波动骤降到 14.4%、回报仍 10%；**线2 是 0**——它比对极高回报线1"又差又像"(回报低且高度相关)，加它既不提回报也不能分散，纯属浪费预算（这正是遍历协方差结构后的结论，不是凑出来的）；
3. **风险的代价要认清**：想要回报从"纯最低风险的 6%"抬到 10%，就必须让方差从 0.0088 升到 0.0207——**收益是用风险换来的**，有效前沿上每一格都标着这个价签。

画图里：左图把**三个单点资产**和 **NLP 最优组合★** 放在"波动-回报"平面，一眼看到★往左上(更右上)走——更少风险更高回报的不可能三角被分散化破了一角；右图用一串不同 target 的 NLP 解描出**有效前沿**(risk-return 权衡的边界曲线)，本课最优解正好落在它上面。

## 六、如何验证？（10问之6）

- **约束自检**：断言权重之和 $=1$、每个 $\ge0$、$\mu^\top w\ge$ 目标——全部通过；
- **方法交叉**：同一 QP 用 SLSQP 与 trust-constr 两种算法各解一次，权重差 < 5e-3 即一致，防"某个求解器自己骗你"；
- **解析对照**：对"无回报要求的最小方差"给出解析解 $w_{gmv}=\Sigma^{-1}\mathbf{1}/(\mathbf{1}^\top\Sigma^{-1}\mathbf{1})$（可含负权重），确认数值解是它的 $\ge0$ 现实约束版——用"理论底 + 约束现实"双层核对。

## 七、缺点与替代？（10问之8、9）

- **NLP 可能陷局部最优**：非凸目标时 SLSQP 只保证局部 → 多初值重跑或换**全局/启发式**(模拟退火、遗传，后续 Day 讲)；
- **对初值敏感**、可能不收敛：要先给可行初值、检查 success；
- **协方差 $\Sigma$ 本身要估**：样本少时估值不稳 → 用 Ledoit-Wolf 收缩/因子模型；
- 目标若带绝对值/sparse → 转成**锥规划/线性目标**再解更好；大规模高维 → 专用 QP/凸求解器(OSQP)比通用 minimize 快得多；
- 纯线性 → LP/ILP（Day3/4）。可选展示类替代：把所有可行 $w$ 蒙特卡洛撒点画散点云 + 帕累托下包络，直观验证有效前沿。

## 八、怎么写进论文？（10问之10）

论文需出现：①**符号表**（$w_i,\mu,\Sigma,\bar r$）；②**目标(方差二次型)与约束公式**，明说"风险不可加、二次型导致非线性"；③求解器(SLSQP/OSQP)与初值/容差设置；④**结果表**：单资产 vs 组合权重与 $\sigma_p^2$，强调"分散化把波动 20%→14.4% 而回报不低于 10%"；⑤**敏感性**：扫描 target 画有效前沿，说明回报-风险权衡；⑥可加解析 GMV 公式作理论锚。

## 九、可迁移性（练习）

- 加"第 4 条正相关避险线"或"每类投入有上限 $w_i\le0.5$"，看权重与前沿怎么变；
- 把协方差对角化(全独立)重算——体会"相关性=0 时分散化最划算"；
- 目标改成"最大化夏普比率 $\frac{\mu^\top w - r_f}{\sqrt{w^\top\Sigma w}}$"(有分数=非线性)，重解看和最小方差差别多大；
- 用蒙特卡洛撒 1 万个随机 $w$ 画散点 + 你算出的有效前沿，可视化"为什么那根上包络是最优边界"。
