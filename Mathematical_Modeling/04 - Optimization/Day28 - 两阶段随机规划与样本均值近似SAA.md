## 一、这一课解决什么决策

报童模型（Day27）回答"**今天备多少货**"，但它只有**一个决策、一个时点**。
真实扩张/投资问题几乎都是**两拍**的：

1. **第一拍（现在，需求未知）**：建多大产能？投多少设备？签多少长期合同？
   —— 这些决策**一旦拍板就改不了**（here-and-now，本周决策）。
2. **第二拍（将来，需求揭晓后）**：多出来的需求怎么调？不够的货从哪补救？
   —— 这是**事后补救**（recourse），随每个需求场景不同而不同。

> 关键点：第一阶段的目标**不是**最大化某个场景下的收益，而是
> $$\min_{x}\ \ c^\top x \;+\; \mathbb{E}_{\omega}\big[\,Q(x,\omega)\,\big]$$
> 其中 $Q(x,\omega)$ 是"投了 $x$、看到需求 $\omega$ 后第二阶段的**最优补救成本**"。
> **决策 $x$ 与随机量 $\omega$ 谁先谁后，是两阶段模型的灵魂。**

## 二、10 问式拆解

**Q1 真实问题是什么？** 一家区域乳企在 3 个城市扩张，要先决定各城建多大**日产能**
（建完不改），等各城需求揭晓后，再决定**跨城调货**把货配到位。产能规划 vs 需求波动。

**Q2 决策变量是什么？**
- 第一阶段（现在）：$y_i$ = 城市 $i$ 建的日产能（万瓶/天）；
- 第二阶段（需求 $\omega$ 揭晓后）：$t_{ij}(\omega)$ = 从城 $j$ 调往城 $i$ 的量、
  $u_i(\omega)$ = 城 $i$ 的缺货（应急外购）量。

**Q3 目标函数是什么？**
$$\min_{y}\ \underbrace{\sum_i c_i^{\text{cap}}\,y_i}_{\text{建产能成本(现在)}}
\;+\;\mathbb{E}_{\omega}\Big[\underbrace{\sum_{i\ne j} s_{ij}\,t_{ij}(\omega)
+ p_{\text{em}}\sum_i u_i(\omega)}_{\text{第二阶段调货/应急成本(将来)}}\Big]$$

**Q4 约束是什么？**
- 供货满足（每城、每场景 $\omega$）：本地产能 $y_i$ + 从别处调入 − 外调 + 应急 $\ge$ 需求 $d_i(\omega)$；
- 产能、调货、应急量均 $\ge 0$。

**Q5 数据从哪来？** 需求分布 $d_i\sim N(\mu_i,\sigma_i^2)$（μ=30/20/25，σ=9/6/7.5，变异系数约 0.30）；
建产能成本 100/120/95 元/万瓶；跨城调货成本 = 城间距 × 单位运费（A–B 40、A–C 60、B–C 35）；
极端缺货只能当天紧急外购，单价 600 元/万瓶。

**Q6 怎么求解？** **样本均值近似（SAA, Sample Average Approximation）**：
用 $N$ 个随机场景 $\{\omega^1,\dots,\omega^N\}$ 把期望换成样本平均——
$$\hat d_i(\omega)=\mu_i\!\cdot\!1,\quad
\min_y\ c^\top y+\tfrac1N\sum_{s=1}^N Q(y,\omega^s)$$
因为第二阶段本身就是 **LP**，整个两阶段问题可以**合并成一个大的确定性等价 LP**
（变量 = $y$ + 每个场景的调货/缺货量），这叫**场景展开（scenario expansion）**，
是 SAA 最稳妥的实现方式（不需要写切平面/次梯度）。

**Q7 结果是什么？**（仓库 `.venv` 实跑，200 训练 / 2000 样本外场景）

| 方法 | 第一阶段产能 y | 样本外平均总成本（元/天） |
|---|---|---|
| 两阶段随机规划 SAA | [37.2, 14.8, 34.5]，总 86.5 | **9,877.96** |
| 确定性等价 DET（按需求均值） | [30, 20, 25]，总 75.0 | 11,128.06 |

**SAA 比 DET 多建 +11.47 万瓶/天的缓冲，但样本外成本反而更低。**

**Q8 结果怎么解读？** 这是本课最反直觉、也最值钱的一点：
**"按需求均值规划"看似最省建造费，实则最贵**——
因为需求一波动就要大规模跨城调货、甚至应急外购，补救成本远超多建的那点产能。
随机规划**主动多建缓冲**，是用"确定的小成本"对冲"将来可能的大代价"。

**Q9 比"按均值规划"到底值多少？——VSS**
- **确定性等价（DET）**：把所有随机量换成期望值后当确定问题解，得 $y^{\text{DET}}$；
- **VSS（Value of the Stochastic Solution）** = 用 DET 解经营的真实期望成本 − 用 SAA 解经营的真实期望成本：
  $$\text{VSS} = 11{,}128.06 - 9{,}877.96 = \mathbf{1{,}250.10}\ \text{元/天}\ (\text{占 DET 的 } 11.23\%)$$
  **这就是"承认随机性比假装世界确定、每天多赚的钱"。**

**Q10 信息能值多少？——EVPI**
- **完美信息（wait-and-see, WS）**：每个场景都提前知道需求再定产能，成本 7,801.61 元/天；
- **EVPI（Expected Value of Perfect Information）** = SAA 成本 − WS 成本
  $= 9{,}877.96 - 7{,}801.61 = \mathbf{2{,}076.35}$ 元/天。
  这是**"能把需求预测到 100% 准"的上限价值**——超过这个数去买预测服务就不划算。

## 三、敏感性：两个必须回答的追问

**① 场景数 N 够不够？** 20→800 时样本外成本在 9,862–9,934 间小幅波动，
**N ≥ 100 即趋于稳定**。SAA 的标准做法是"大 N 求解 + 独立样本外评估"，
必要时用**多样本重解**给出解的置信区间。

**② 需求波动变大，要不要多建？** σ ×0.5→×2.0 时**总产能 82.1→99.7 单调上升**：
**波动越大、越要多建缓冲**；且缓冲**优先堆在"建产能更便宜"的城市**
（城市C 95 元、城市A 100 元），而不是硬按需求比例摊——这是随机规划结合成本结构给出的
**投资优先级**，与 Day26 影子价格"先买谁"的思想一脉相承。

## 四、这一课的"增量"在哪

| 维度 | Day27 报童 | Day28 两阶段随机规划 |
|---|---|---|
| 决策时点 | 单周期、一次性 | **两拍**：现在定 + 将来补救 |
| 决策形式 | 一个数 $Q^*$ | **一套决策**：$y$（现在）+ 每个场景的补救 $t(\omega)$ |
| 求解 | 解析分位数 | **场景展开 → 一个大的 LP** |
| 核心概念 | 临界分位点 $C_u/(C_u+C_o)$ | **VSS / EVPI / 样本外评估** |
| 交付物 | 建议订货量 + 服务水平 | 投资方案 + 缓冲 + 信息价值 |

## 五、建模避坑（本课三次踩坑实录）

1. **产能必须同时约束"本地消纳 + 外调"**：初版只写了"外调量 ≤ 产能"，
   结果模型发现"**不建产能也能到处调货**"，最优解退化成 $y=0$ 的假解。
   必须写成**供货满足**约束，产能才有稀缺价值。
2. **缺货罚不能用 $10^6$**：大罚金会让 31/2000 个尾部场景把平均成本从 9.9k 直接打到 77k，
   使"样本外成本"完全被极端场景主导。改用真实量级的应急外购价（600 元/万瓶）后，
   指标才反映常规经营水平——**惩罚系数是模型，不是大数游戏**。
3. **SAA 的固有代价是尾部风险**：训练集最大需求小于测试集时，SAA 可能少建、
   在极端场景付应急价。这正指向下一步——**CVaR / 分布鲁棒优化**。
