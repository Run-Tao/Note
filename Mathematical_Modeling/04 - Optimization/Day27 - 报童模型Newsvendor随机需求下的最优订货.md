# Day27 · 报童模型（Newsvendor）：随机需求下的单周期最优订货

> 锚点：接 [[Day26 - 线性规划对偶理论影子价格与敏感性分析]]（`04 - Optimization/`）——Day26 的 LP 假设"需求/资源已知"，影子价格回答"资源值多少钱"；今天把**需求变成随机变量**，回答决策者最常问的那句："**明天到底该备多少货？**"
> 代码：`08 - Python/daily/2026-09-25/newsvendor_stochastic.py`；图：`newsvendor_stochastic.png`。
> 与 [[Day18 - 随机动态优化排队论MMc与MDP值迭代]] 互为姊妹：Day18 是**多周期序贯**决策（策略表），今天是**单周期一次性**决策（一个数）——随机优化的两个最小样板。

## 1. 这个方法解决什么问题？

"每天清晨决定烤多少只可颂"这类**一次性、需求随机、卖不完会亏、不够卖也亏**的决策：

- 报纸零售：每天订多少份，卖不完只能退（残值）；
- 生鲜/鲜花/时装：**易腐、单季、过期即贬值**的商品备多少货；
- 机票超售、会议室预留、双十一备货、器官/血库配额……
 
它们的共同结构是：**需求 $D$ 是随机的，订货量 $Q$ 必须在看到需求之前定死**，定多了砸手里、定少了错过利润。这就是报童问题（Newsvendor Problem），**库存管理与随机优化的第一课**。

## 2. 什么情况下应该使用？

- 决策是**单周期**的（订一次货、卖一次），不是反复补货——多周期/可补货请转 [[Day18 - 随机动态优化排队论MMc与MDP值迭代]] 的 (s,S) 策略；
- 需求 **随机不可控**，但你能估出分布（均值 + 波动，甚至历史直方图）；
- 商品有**过剩成本 $C_o$**（卖不掉要亏）和**缺货成本 $C_u$**（没得卖少赚），两者不对称。

## 3. 为什么适合这个问题？

因为它把"备多少货"这个靠经验拍脑袋的事，**变成了一个只依赖两个成本数字的分位数问题**：

$$
P(D \le Q^*) = \frac{C_u}{C_u + C_o}
$$

**关键洞察：最优订货量根本不需要预测需求的具体值，只需要知道"缺货与过剩谁更贵"**，以及需求分布的 $\frac{C_u}{C_u+C_o}$ 分位点。这就是它比"预测需求均值然后照订"高明的地方——**均值是错的答案**（本例订均值每天少赚 24.6 元）。

## 4. 数学模型是什么？

**真实决策背景**：一家社区面包店每天清晨要决定烤多少只"当日限定可颂"。

| 参数 | 符号 | 取值 |
|---|---|---|
| 售价 | $p$ | 8.0 元/只 |
| 成本 | $c$ | 3.0 元/只 |
| 隔夜清仓残值 | $s$ | 1.5 元/只 |
| 缺货成本 | $C_u = p - c$ | 5.0 元/只 |
| 过剩成本 | $C_o = c - s$ | 1.5 元/只 |
| 当日需求 | $D \sim N(\mu, \sigma^2)$ | $\mu=200,\ \sigma=40$ |

**模型（单周期期望利润最大化）**：

$$
\max_{Q \ge 0} \; \mathbb{E}[\Pi(Q, D)] = \mathbb{E}\big[\, p\min(Q,D) + s\,(Q-D)^+ - cQ \,\big]
$$

其中 $(Q-D)^+ = \max(Q-D, 0)$ 是过剩量、$\min(Q,D)$ 是实际销量。

**临界分位点定理**：最优解满足

$$
F(Q^*) = \frac{C_u}{C_u + C_o} = \frac{p-c}{p-s}, \qquad
Q^* = \mu + \sigma\, z_{\frac{C_u}{C_u+C_o}}
$$

本题：$\dfrac{5}{5+1.5} = 0.7692$，$z=0.7363$，$\Rightarrow Q^* = 229.45$ 只。

**边际视角（为什么是它）**：多烤第 $Q$ 只，
- 以 $P(D \ge Q)$ 被正常卖出 → 多赚 $C_u$；
- 以 $P(D < Q)$ 沦为过剩 → 倒亏 $C_o$。

令期望边际收益为零：$C_u\,P(D\ge Q^*) = C_o\,P(D<Q^*)$，即得 $P(D<Q^*) = \frac{C_u}{C_u+C_o}$。

## 5. 如何求解？

四种**互相独立**的方法，一一对上给出同一个 $Q^*$：

1. **解析公式**：$Q^* = \mu + \sigma z_{C_u/(C_u+C_o)}$（正态需求）；
2. **网格穷举**：对 $Q$ 网格算样本期望利润，取最大值点；
3. **边际分析**：二分求解 $P(D<Q) = C_u/(C_u+C_o)$ 的临界点；
4. **蒙特卡洛仿真**：按 $Q^*$ 真"经营" 30 万天，看平均利润是否收敛到解析期望值。

## 6. 如何用 Python 实现？

见 `newsvendor_stochastic.py`（**手写、零专用库存库**）：

- `analytical_optimal()`：正态解析解 + 闭式期望利润（用标准正态**损失函数** $L(z)=\phi(z)-z(1-\Phi(z))$）；
- `grid_search()`：$Q \in [100, 320]$ 步长 0.5，40 万需求样本估期望利润；
- `marginal_analysis()`：200 次二分找边际收益零点；
- `simulate_policy(q, n_days)`：30 万天蒙特卡洛，返回平均利润/波动/缺货率；
- `sensitivity_to_forecast_error()` / `sensitivity_to_sigma()`：**参数估偏但没发现**的真实利润损失。

## 7. 如何验证？（仓库 `.venv` 实跑结果）

四种方法结果（实跑）：

| 方法 | $Q^*$ | 期望利润 |
|---|---|---|
| 解析解 | **229.45** | 920.90 |
| 网格穷举 | **229.50** | 920.50 |
| 边际分析 | **229.45** | — |
| 蒙特卡洛（30 万天） | 按 229.45 经营 | **920.93** |

- **四法一致到小数点后一位**，断言全过（解析≈穷举、边际=解析、仿真≈解析）；
- **服务水平** $P(D \le Q^*) = 0.7692$ 与临界分位点**逐位相等**（名字由来）；
- **朴素对照**：只按均值 $Q=\mu=200$ 订 → 平均利润 **896.35**，每天**少赚 24.58 元（2.74%）**，缺货率从 77% 降到 50%；
- **敏感性 A**（均值估偏）：低估 20 只亏 11.0 元/天、高估 20 只亏 8.6 元/天——**低估需求比高估更贵**（缺货成本 $C_u > C_o$ 的必然结果）；
- **敏感性 B**（波动估偏）：$\sigma$ 从 40 估成 20/80，利润损失 5.8/17.4 元/天——**把需求想得太平稳，会订得太少而付代价**。

## 8. 有什么缺点？

- **假设需求分布已知**：真实业务里 $\mu,\sigma$ 都得估，估偏有代价（本课已量化）；
- **单周期**：只订一次；现实里常年经营、可反复补货 → 需要 (s,S)/MDP（Day18）；
- **成本线性、无容量约束**：若添加"冷藏柜最多 250 只"等约束，变成带约束报童，需数值优化；
- **风险中性**：只最大化期望利润，不控制"偶尔巨亏"的风险（可加 CVaR）。

## 9. 有什么替代方法？

- **多周期可补货**：$(s,S)$ 策略 / [[Day18 - 随机动态优化排队论MMc与MDP值迭代]]；
- **分布未知**：只需知道均值和方差时用 **Scarf 界/分布鲁棒优化**；有历史样本时用**样本均值近似（SAA）**；
- **带风险厌恶**：CVaR 报童、均值-方差报童；
- **多商品联合订货**：多变量报童 → 需要 copula 刻画需求相关性。

## 10. 如何写进数学建模论文？

- 竞赛题出现"**备货/预订/超售/配额/单季商品**"且**需求随机、卖不掉有残值**，报童就是首选模型；
- 论文必须交代三件事：① 需求分布怎么来的（拟合/假设 + 依据）；② $C_u, C_o$ 怎么估（这是模型里最容易被评委追问的数字）；③ **敏感性**（参数估偏的代价，本课敏感性 A/B 即模板）；
- 结论写法要落到决策语言："**建议每天烤 229 只，对应 77% 的不缺货概率；因缺货比滞销更贵，宁可多备**"——而不是只丢一个数。

## 一句话总结

**报童模型问的不是"需求会是多少"，而是"缺货和滞销哪个更肉疼"**——最优订货量是需求分布的一个**分位数**（$\frac{C_u}{C_u+C_o}$），缺货越贵就订得越多；预测需求均值然后照订，是最常见也最贵的错误。
