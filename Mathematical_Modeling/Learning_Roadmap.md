# 数学建模学习路线（Level 0 – Level 12）

> 路线按"数学建模能力"递进，而不是按大学数学课程排列。
> 每一级都是上一级的依赖，最终目标是独立完成一套数学建模竞赛题。

## 路线总览

| Level | 主题 | 前置知识 | 一句话目标 |
| --- | --- | --- | --- |
| 0 | 数学建模思维 | 高中数学 + 基础编程 | 建立"现实问题 → 模型"的思维方式 |
| 1 | 问题分析与数学表达 | Level 0 | 把文字题翻译成数学语言 |
| 2 | 数据分析与可视化 | Level 1 + Python 基础 | 从数据中找规律，驱动建模 |
| 3 | 经典数学模型 | Level 1–2 + 微积分基础 | 掌握方程类机理建模 |
| 4 | 统计与预测模型 | Level 2–3 + 概率统计 | 用数据预测并评估误差 |
| 5 | 评价与决策模型 | Level 2 + 线性代数 | 把"哪个更好"变成可计算的评价 |
| 6 | 优化模型 | Level 2 + 微积分、线代 | 在约束下找最优决策 |
| 7 | 图论、网络与动态模型 | Level 3、6 | 处理关系、流动与演化 |
| 8 | 数值计算与算法 | Level 3 + 线性代数 | 让模型算得出、算得稳 |
| 9 | 机器学习模型 | Level 2、4 + 概率统计、线代 | 用数据驱动解决机理不明的问题 |
| 10 | 模型检验与模型改进 | Level 3–9（至少两个方向） | 让模型可信、可辩护 |
| 11 | 历年真题训练 | Level 0–10 | 把能力整合到真实赛题 |
| 12 | 比赛实战与论文写作 | Level 11 | 比赛当天直接执行的工作流 |

## 使用说明

- 按顺序学习；每一级的"达标标准"通过后再进入下一级；
- 每级同时配套 Python 练习，代码服务于建模，不做普通编程教程；
- 疑问记入 `Questions/`，练习与错误记入 `Exercises/`，综合项目记入 `Projects/`。

## Level 0：数学建模思维

> 详细笔记：[[Level 0 - Modeling Thinking|Level 0 - Modeling Thinking]]

**学习目标**

- 建立"现实问题 → 模型"的思维框架；
- 理解建模是"理解现实 + 数学表达 + 求解验证"的循环，不是套公式；
- 熟悉完整建模流程，能复述每个环节的职责与"为什么需要"。

**核心知识**

- 数学建模的定义，及它与**数学解题**、**算法**的区别（模型定"算什么"，算法定"怎么算"）；
- 完整建模主线：**问题重述 → 问题拆解 → 合理假设 → 变量与参数 → 目标与约束 → 模型建立 → 求解 → 结果分析 → 模型检验 → 敏感性分析 → 模型改进 → 模型评价 → 论文**；
- 基本概念辨析：建模对象 / 变量（能决定）/ 参数（已知输入）/ 目标 / 约束 / 假设；
- 模型分类总览：描述、预测、评价、优化；
- 问题导向思维：先问"要回答什么问题"，再选工具。

**前置知识**

- 高中数学 + 基础编程入门（可并行补齐）。

**常见问题类型**

- 任何赛题的第一步：读题、理解背景、建立整体流程意识。

**需要掌握的模型 / 方法**

- 建模流程图、问题重述模板、变量识别初体验（本阶段不要求具体模型）。

**Python 工具**

- 环境搭建：Anaconda / Jupyter Notebook。

**建模竞赛中的典型用途**

- 赛前思维热身；明确"模型是手段，不是目的"。

**推荐学习资料**

- 姜启源《数学模型》第 1 章；
- 数学建模入门公开课；
- 浏览近年赛题（只读题，不做）；
- 1–2 篇获奖论文的"问题分析 / 模型假设"章节。

**练习方式**

- 用 1–2 道简单赛题，只做"问题重述 + 拆解 + 假设"，不求解。

**达标标准**

- 能**独立**画出"现实问题 → 论文"完整流程图并说明各环节作用；
- 任给一个场景，能判断它是"描述 / 预测 / 评价 / 优化"中的哪类，并指出其变量、参数、目标、约束；
- 拿一道陌生赛题，独立写出 1 页"问题重述 + 拆解 + 假设清单"（不求解），且能解释每条假设为何而设；
- 换一个全新现实问题，能套用同一条主线独立写出其建模框架。
（细则见笔记末尾"达标标准"一节。）

## Level 1：问题分析与数学表达

**学习目标**

- 把文字题转化为数学语言；
- 形成规范的问题重述、拆解、假设与符号体系。

**核心知识**

- 问题重述、问题拆解（问题树）、变量 / 参数识别、目标与约束识别；
- 符号表与量纲分析入门。

**前置知识**

- Level 0。

**常见问题类型**

- 所有赛题的读题与选题阶段。

**需要掌握的模型 / 方法**

- 拆解树、假设清单、符号表、量纲分析。

**Python 工具**

- 可选：用 Pandas 读数据做初步观察。

**建模竞赛中的典型用途**

- 比赛最初 1–2 小时的读题与定题。

**推荐学习资料**

- 《数学建模方法与分析》（Meerschaert）前两章；
- 优秀论文的"问题分析"部分。

**练习方式**

- 找 3 道往年题，各写一页"问题重述 + 拆解 + 假设 + 符号表"。

**达标标准**

- 面对陌生赛题，1 小时内给出结构化的问题拆解与假设清单。

## Level 2：数据分析与可视化

**学习目标**

- 从数据中找规律，让数据驱动建模；
- 完成"读数据 → 清洗 → 探索 → 可视化 → 结论"闭环。

**核心知识**

- 描述性统计、相关性分析、分布与异常值、缺失值处理；
- 可视化：散点、直方图、箱线图、热力图。

**前置知识**

- Level 1 + Python 基础（Pandas / Matplotlib）。

**常见问题类型**

- 数据类赛题（大数据、图像、表格数据）。

**需要掌握的模型 / 方法**

- 描述统计、相关性分析、聚类（KMeans）、PCA 降维。

**Python 工具**

- NumPy、Pandas、Matplotlib、Seaborn、scikit-learn。

**建模竞赛中的典型用途**

- 数据预处理与特征探索；数据质量决定模型路线。

**推荐学习资料**

- 《Python for Data Analysis》（McKinney）；
- StatQuest 数据统计系列。

**练习方式**

- 用一份真实数据集完成完整 EDA 报告（含图表与结论）。

**达标标准**

- 能独立完成数据探索到可视化结论的完整闭环。

## Level 3：经典数学模型

**学习目标**

- 掌握机理明确问题的建模：用方程描述过程；
- 会数值求解并解释结果。

**核心知识**

- 初等模型（比例、代数）、微分方程模型（人口、传染病、物理过程）、差分方程；
- 稳态分析、量纲分析。

**前置知识**

- Level 1–2 + 高等数学基础。

**常见问题类型**

- 机理明确的问题（物理 / 生物 / 工程过程）。

**需要掌握的模型 / 方法**

- Malthus / Logistic 模型、SI / SIR 入门、差分方程、稳态分析。

**Python 工具**

- SciPy（`solve_ivp` / `odeint`）、Matplotlib 画相图。

**建模竞赛中的典型用途**

- 机理建模题与趋势预测类题。

**推荐学习资料**

- 姜启源《数学模型》经典章节；
- 3Blue1Brown 微分方程可视化。

**练习方式**

- 复现 Logistic 人口模型，并做参数敏感性分析。

**达标标准**

- 能对一个明确机理问题建立方程模型并数值求解。

## Level 4：统计与预测模型

**学习目标**

- 用数据做预测，并给出误差与可信度；
- 能根据数据特征选择合适的预测模型。

**核心知识**

- 回归（线性 / 非线性）、时间序列、灰色预测、拟合与插值；
- 假设检验、置信区间、误差指标（RMSE / MAE）。

**前置知识**

- Level 2–3 + 概率统计基础。

**常见问题类型**

- 预测类赛题（销量、流量、产量、需求）。

**需要掌握的模型 / 方法**

- 线性 / 多项式回归、指数平滑、ARIMA、灰色 GM(1,1)、Logistic 回归、样条插值。

**Python 工具**

- scikit-learn、statsmodels、SciPy。

**建模竞赛中的典型用途**

- 预测题的主战模型。

**推荐学习资料**

- 《统计学习导论》(ISLR)；
- 往年预测题优秀论文。

**练习方式**

- 两个数据集分别做回归与时间序列预测，比较误差指标。

**达标标准**

- 能根据数据特征选择预测模型，并给出误差分析。

## Level 5：评价与决策模型

**学习目标**

- 把"哪个更好"变成可计算的评价体系；
- 理解权重来源并做稳健性讨论。

**核心知识**

- 指标标准化、权重确定方法、综合评价、决策矩阵。

**前置知识**

- Level 2 + 线性代数基础。

**常见问题类型**

- 评价类赛题（方案选优、城市 / 系统评价、绩效评估）。

**需要掌握的模型 / 方法**

- AHP、TOPSIS、熵权法、PCA 综合评价、灰色关联分析、模糊综合评价。

**Python 工具**

- NumPy / Pandas 自实现；scikit-learn 的 PCA。

**建模竞赛中的典型用途**

- 评价题主战模型；多方案比较。

**推荐学习资料**

- 司守奎《数学建模算法与应用》评价章节；
- 往年评价题优秀论文。

**练习方式**

- 同一评价问题用 AHP / TOPSIS / 熵权法各做一遍，对比结论差异。

**达标标准**

- 能解释权重来源，能做一致性检验与稳健性讨论。

## Level 6：优化模型

**学习目标**

- 把实际决策问题写成标准优化模型；
- 正确调用求解器并解读结果。

**核心知识**

- 决策变量、目标函数、约束条件；
- 线性 / 整数 / 非线性 / 多目标 / 动态规划。

**前置知识**

- Level 2 + 线性代数、微积分基础。

**常见问题类型**

- 资源分配、调度、选址、物流、生产计划。

**需要掌握的模型 / 方法**

- LP / ILP / NLP 建模、单纯形思想、分支定界、动态规划、多目标（加权 / 帕累托）。

**Python 工具**

- SciPy `optimize`、PuLP / OR-Tools、CVXPY（逐步引入）。

**建模竞赛中的典型用途**

- 优化题主战；很多题包含优化子问题。

**推荐学习资料**

- 司守奎优化章节；
- 《运筹学》入门教材；
- CVXPY / PuLP 官方文档。

**练习方式**

- 完整建模一道往年优化题并用求解器求解，做敏感性分析。

**达标标准**

- 能把决策问题写成标准优化模型并正确求解。

## Level 7：图论、网络与动态模型

**学习目标**

- 处理"关系、流动、随机演化"类问题；
- 能识别问题类型并选择对应工具。

**核心知识**

- 图的表示、最短路径、最小生成树、网络流；
- 排队论、马尔可夫链、蒙特卡洛模拟。

**前置知识**

- Level 3、6（机理建模 + 优化思想）。

**常见问题类型**

- 路径规划、物流网络、排队系统、随机过程类题。

**需要掌握的模型 / 方法**

- Dijkstra / Floyd、Kruskal / Prim、最大流、M/M/1 排队、Markov 链、Monte Carlo。

**Python 工具**

- NetworkX、NumPy（随机模拟）。

**建模竞赛中的典型用途**

- 网络 / 交通 / 排队 / 随机类赛题。

**推荐学习资料**

- NetworkX 官方文档；
- 司守奎图论与随机模拟章节。

**练习方式**

- 用 NetworkX 实现最短路径与网络流小案例；写一个蒙特卡洛模拟。

**达标标准**

- 能识别"关系 / 流动 / 随机"问题并选择对应工具。

## Level 8：数值计算与算法

**学习目标**

- 让模型"算得出、算得稳"；
- 具备数值稳定性与复杂度意识。

**核心知识**

- 线性方程组求解、特征值、插值与拟合、数值积分 / 微分、迭代收敛性。

**前置知识**

- Level 3 + 线性代数。

**常见问题类型**

- 大规模计算、病态问题、对效率有要求的题。

**需要掌握的模型 / 方法**

- 高斯消元 / LU、牛顿法、最小二乘、向量化与复杂度估计。

**Python 工具**

- NumPy、SciPy（`linalg` / `optimize`）。

**建模竞赛中的典型用途**

- 保证求解效率与精度；避免数值陷阱。

**推荐学习资料**

- 《数值分析》入门教材；
- SciPy 官方教程。

**练习方式**

- 复现数值实验（如迭代法收敛性），画误差曲线。

**达标标准**

- 能诊断并处理常见数值问题（不收敛、病态、溢出）。

## Level 9：机器学习模型

**学习目标**

- 用数据驱动方法解决机理不明的复杂问题；
- 会做模型对比与超参数选择。

**核心知识**

- 监督 / 无监督、特征工程、交叉验证、过拟合与泛化。

**前置知识**

- Level 2、4 + 线性代数、概率统计。

**常见问题类型**

- 大数据预测、分类识别、聚类、图像 / 文本初探。

**需要掌握的模型 / 方法**

- 线性 / 逻辑回归、决策树 / 随机森林、SVM、KNN、KMeans、PCA、简单神经网络。

**Python 工具**

- scikit-learn、Pandas；深度学习按需引入（PyTorch 入门）。

**建模竞赛中的典型用途**

- 数据量大且机理不明时的预测与分类。

**推荐学习资料**

- ISLR；
- scikit-learn 官方示例；
- 吴恩达机器学习课程（选看）。

**练习方式**

- 完整跑一个"特征工程 → 交叉验证 → 模型比较"的分类 + 回归 pipeline。

**达标标准**

- 能解释为什么选某个模型，并给出对比证据。

## Level 10：模型检验与模型改进

**学习目标**

- 让模型可信、可辩护；
- 任何模型都能给出检验证据与局限说明。

**核心知识**

- 误差分析、假设检验、敏感性分析、稳健性分析、极端情况、对比实验。

**前置知识**

- Level 3–9（至少掌握两个模型方向）。

**常见问题类型**

- 论文评审最看重的部分之一；几乎所有赛题都需要。

**需要掌握的模型 / 方法**

- 残差分析、参数扰动、边界测试、多模型对比、蒙特卡洛稳健性检验。

**Python 工具**

- NumPy 参数扫描、Matplotlib 敏感性图。

**建模竞赛中的典型用途**

- 论文的"模型检验 / 敏感性分析 / 优缺点"章节。

**推荐学习资料**

- 优秀论文的检验部分；
- 统计推断基础。

**练习方式**

- 对自己做过的两个模型做完整的敏感性 + 稳健性检验。

**达标标准**

- 任何模型都能给出检验证据与局限说明。

## Level 11：历年真题训练

**学习目标**

- 把全部能力整合到真实赛题；
- 形成个人"模型工具箱"与论文 / 代码模板。

**核心知识**

- 完整流程演练、时间分配、选题判断、方案比较。

**前置知识**

- Level 0–10。

**常见问题类型**

- 历届国赛 / 美赛 / 校赛真题。

**需要掌握的模型 / 方法**

- 综合运用；形成个人模板（论文、代码、图表）。

**Python 工具**

- 综合运用，积累个人工具函数库。

**建模竞赛中的典型用途**

- 赛前 4–6 周冲刺。

**推荐学习资料**

- 近 5 年真题与优秀论文；
- 竞赛官方网站。

**练习方式**

- 每周 1 套真题，72 小时完整演练（可用周末模拟）。

**达标标准**

- 能独立完成一套真题并写出完整论文。

## Level 12：比赛实战与论文写作

**学习目标**

- 比赛当天直接执行既定工作流；
- 输出符合官方规范、可复现的完整论文。

**核心知识**

- 读题选题、三人分工、时间管理、建模 / 编程 / 论文流程、最终检查清单、常见错误。

**前置知识**

- Level 11（至少一次完整演练）。

**常见问题类型**

- 实战中的一切问题。

**需要掌握的模型 / 方法**

- 个人工作流（读题 → 建模 → 求解 → 论文 → 检查）；
- 论文模板与图表规范（以当年官方规范为准）。

**Python 工具**

- 稳定可复现的代码库 + Git 版本管理。

**建模竞赛中的典型用途**

- 国赛 / 美赛等正式比赛。

**推荐学习资料**

- 竞赛官方规则与格式文档（以当年为准）；
- 获奖队伍经验分享。

**练习方式**

- 赛前检查清单演练与模拟赛。

**达标标准**

- 完成至少一次正式 / 模拟比赛，产出可提交成果。

## 模型知识体系（按问题类型，随学习逐步补充）
