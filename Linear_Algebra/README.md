# 线性代数知识库

> 面向人工智能 / 计算机方向本科生的个人线性代数学习知识库。
>
> 目标不是应付考试，而是理解线性代数背后的数学思想，并把它真正用到机器学习、深度学习、计算机视觉与语音处理中。

## 这个知识库要解决什么问题

很多同学学线性代数只是为了考试：会算行列式、会求特征值，却说不清"为什么学"，也看不到它和 AI 的关系。

这个知识库坚持三个原则：

1. **不只应付考试** —— 每个概念都要理解它背后的几何直觉与数学思想；
2. **建立知识体系** —— 从数学基础一步步通向 AI 应用，形成可复用的知识网络；
3. **学以致用** —— 每学一个概念，都要能说出它在 AI 的哪个环节出现、为什么有效。

## 各目录用途

| 目录 | 用途 |
| --- | --- |
| Inbox/ | 原始笔记：随手记的碎片化想法，每天一个 YYYY-MM-DD.md，无格式要求，永不删除；Agent 提取内容整理后，整个文件移入 Inbox/Processed/ 归档 |
| Notes/ | 按 Level 和主题记录笔记，一主题一文件，用自己的话重写定义与直觉；未解决疑问用 `> [!question]` 标记 |
| Exercises/ | 概念题、计算题、Python/NumPy 验证题，并记录错题 |
| AI_Applications/ | 把抽象概念映射到具体 AI 场景（ML、DL、CV、语音），例如"SVD 用在哪里" |
| Resources/ | 汇总课程、书籍、视频、博客，标注难度与推荐理由；可下载文档存于 Downloads/ |
| Projects/ | 数学概念 → Python 实验 → 可视化 / 实际应用 → 项目记录 |
| Glossary.md | 术语表单文件：重要数学术语中英文对照，并链接相关笔记 |

## 使用建议

0. **维护知识库时默认遵守 [config.md](config.md)**：新建任何笔记、练习或应用笔记前，先读一遍规范；
1. 先打开总览页 [[Linear Algebra MOC]] 或 [Learning_Roadmap.md](Learning_Roadmap.md)，确定自己当前所处的 Level；
2. 学完一个主题后按循环走一遍：**写笔记 → 做练习 → 找 AI 应用案例 → 解决遗留疑问**；
3. 每周回顾一次笔记中的未解决问题和错题，把"没懂"变成"懂"；
4. 每次学习结束时在个人层学习日志（[[Learning Log/README|00 - Personal/Learning Log]]）记录当次进度与遗留问题。

## 学习路线概览

| Level | 主题 | 一句话目标 |
| --- | --- | --- |
| Level 0 | 数学基础 | 学会数学语言，建立微积分与梯度的直觉 |
| Level 1 | 向量与矩阵 | 建立"数据即向量、变换即矩阵"的直觉 |
| Level 2 | 线性方程组 | 理解消元、秩与解的结构 |
| Level 3 | 向量空间 | 从具体计算走向抽象空间与线性变换 |
| Level 4 | 正交与投影 | 理解投影即"最优近似" |
| Level 5 | 特征值与特征向量 | 掌握分解矩阵的几何钥匙 |
| Level 6 | 矩阵分解 | 掌握 LU / QR / SVD 及其数值意义 |
| Level 7 | 机器学习中的线性代数 | 把线代概念对应到经典 ML 模型 |
| Level 8 | 深度学习中的线性代数 | 理解神经网络与 Transformer 背后的线代结构 |

详细的学习目标、核心概念与推荐资料见 [Learning_Roadmap.md](Learning_Roadmap.md)。
