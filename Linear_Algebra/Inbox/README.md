# Inbox 原始笔记

> 工作流：学习 → Inbox → Agent 整理 → 正式知识库（见根目录 [[Knowledge_Workflow]]）。

## 用法

- **这里只放原始笔记**：学习时随手记的碎片化想法，允许不完整、有错误、有猜测；
- **文件命名**：每天一个文件 `YYYY-MM-DD.md`（如 `2026-08-18.md`），当天所有想法都记入其中，不按主题分文件；不改动内容格式；
- **无格式要求**：怎么记都可以，一个想法一条也行；结构化是 Agent 整理的职责；
- **永不删除**：整理后 Agent 从文件中提取内容归入正式笔记，再把整个文件移入 `Processed/` 归档；
- 整理流程：Agent 读取本目录 → 查重 → 验证 → 归类入 `Notes/` → 未解决入 `Questions/` → 更新 MOC。

## 内容类型标记（整理进正式笔记时）

- `> [!note] 我的原始理解（未验证）` — 原始想法，待验证
- `> [!question] 未解决：...` — 链接到 Questions/
- `> [!info] Agent 补充：` — Agent 查资料补充并注明来源
- 已验证内容直接入正式笔记，标注来源与日期
