# 线性代数学习路线（Level 0 – Level 8）

> 面向人工智能 / 计算机方向本科生：从零基础出发，一路通向机器学习与深度学习中的应用。
>
> 原则：**概念优先于计算，理解优先于背诵，应用优先于考试。**

## 路线总览

| Level | 主题 | 前置知识 | 一句话目标 |
| --- | --- | --- | --- |
| Level 0 | 数学基础 | 高中数学 | 学会数学语言与微积分直觉 |
| Level 1 | 向量与矩阵 | Level 0 | 数据即向量、变换即矩阵 |
| Level 2 | 线性方程组 | Level 1 | 用秩理解解的结构 |
| Level 3 | 向量空间 | Level 1–2 | 从计算走向抽象空间 |
| Level 4 | 正交与投影 | Level 1、3 | 投影即最优近似 |
| Level 5 | 特征值与特征向量 | Level 3–4 | 找到"不变的方向" |
| Level 6 | 矩阵分解 | Level 2–5 | 拆开矩阵看本质，SVD 为王 |
| Level 7 | 机器学习中的线性代数 | Level 1–6 + 概率统计基础 | 线代概念对应到 ML 模型 |
| Level 8 | 深度学习中的线性代数 | Level 1–7 + 微积分 | 理解神经网络与 Transformer 的结构 |

## 使用说明

- 按 Level 顺序学习；基础扎实可跳过 Level 0，但建议至少浏览一遍；
- 每个 Level 的完成标准：能用一两句话讲清核心概念，完成配套练习，并在 AI 应用栏中找到至少一个真实例子；
- 学完一个 Level 后更新文末的进度表，并同步在 Notes / Exercises 中留下记录；遗留疑问用 `> [!question]` 标记。

## Level 0：数学基础

**学习目标**

- 熟练读懂教材中的数学符号、定义、定理，不再"怕公式"；
- 掌握集合、函数、复数的基本语言；
- 建立导数、梯度、链式法则的几何直觉（为梯度下降打底）；
- 了解基本证明方法，能判断一个论证是否成立。

**核心概念**

- 集合与运算、映射（函数）；
- 复数与复平面；
- 极限、导数、梯度、链式法则（直觉层面即可）；
- 充分/必要条件、归纳法、反证法。

**前置知识**

- 高中数学已扎实（函数、三角、解析几何），无需复习；本 Level 定位为**快速过渡到大学数学语言**，可跳过，建议仅浏览一遍。

**AI 应用**

- 损失函数与梯度下降：所有神经网络训练的数学基础；
- 复数与 FFT：语音、音频、信号处理的底层工具；
- 数学符号能力：读懂论文公式与源码注释的前提。

**推荐资料**

- 3Blue1Brown《微积分的本质》系列（几何直觉优先）；
- 同济《高等数学》相关章节（作参考书，不做题海战术）；
- Khan Academy（快速复习高中数学与微积分）；
- 《线性代数应该这样学》（Axler）前言与附录符号表。

## Level 1：向量与矩阵

**学习目标**

- 建立"数据即向量、变换即矩阵"的核心直觉；
- 熟练向量与矩阵运算，能解释点积、范数的几何意义；
- 理解矩阵乘法既是"变换的复合"，也是"批量计算"。

**核心概念**

- 向量、线性组合、点积（内积）、范数；
- 矩阵、矩阵乘法、转置、迹、单位阵、逆矩阵（先有直觉，后学计算）；
- 张量的直观理解：向量 → 矩阵 → 三维数组的推广。

**前置知识**

- Level 0。

**AI 应用**

- 一条样本 = 一个特征向量；一批样本 = 一个数据矩阵；
- 图像 = 像素矩阵 / 张量（计算机视觉的起点）；
- 词嵌入（word embedding）：把词映射为向量，用点积衡量相似度（NLP / 检索）；
- 神经网络前向传播 = 一连串矩阵乘法。

**推荐资料**

- 3Blue1Brown《线性代数的本质》第 1–5 集（必看）；
- Gilbert Strang《Introduction to Linear Algebra》第 1 章；
- MIT 18.06（Strang 课程视频，B 站 / OCW 均可）。

## Level 2：线性方程组

**学习目标**

- 掌握高斯消元与行阶梯形，理解秩如何决定解的结构；
- 能判断方程组是唯一解、无穷解还是无解，并说出原因；
- 理解欠定（样本少）与超定（方程多）系统在真实问题中的意义。

**核心概念**

- 高斯消元、行阶梯形、自由变量；
- 矩阵的秩、增广矩阵；
- 齐次 / 非齐次方程组，解空间的几何（点、线、面、超平面）；
- 可逆性与"解存在且唯一"的判定。

**前置知识**

- Level 1。

**AI 应用**

- 线性回归的正规方程（最小二乘问题）；
- 特征多、样本少时的欠定问题 → 正则化的动机；
- 超定系统无精确解 → 求最佳近似解（伪逆的思想雏形）。

**推荐资料**

- Strang《Introduction to Linear Algebra》第 2 章；
- MIT 18.06 对应章节；
- Lay《线性代数及其应用》第 1 章；
- 3Blue1Brown《线性代数的本质》第 6–7 集（用空间变换看方程组）。

## Level 3：向量空间

**学习目标**

- 从"具体计算"上升到"抽象空间"，理解基、维数、线性变换；
- 掌握核（零空间）与像（列空间）的含义与关系（秩-零化度定理）；
- 理解行列式的几何意义：体积的缩放因子。

**核心概念**

- 向量空间、子空间、生成集、线性无关；
- 基与维数、坐标表示；
- 线性变换、核、像、秩-零化度定理；
- 行列式及其几何意义。

**前置知识**

- Level 1–2。

**AI 应用**

- 特征空间 / 嵌入空间：高维向量空间中的点就是数据的"表示"；
- 神经网络隐藏层 = 线性变换 + 非线性激活；
- 降维的思想基础：在高维数据中寻找低维子空间；
- "维度灾难"的直觉来源。

**推荐资料**

- 3Blue1Brown《线性代数的本质》第 8–13 集；
- Strang 第 3 章（向量空间）与第 5 章（行列式）；
- Axler《线性代数应该这样学》（概念更抽象，适合后期精读）。

## Level 4：正交与投影

**学习目标**

- 理解内积空间的几何：长度、角度、正交；
- 掌握投影与最小二乘的联系，能解释"最佳拟合"为什么是投影；
- 会用 Gram-Schmidt 理解正交化的思想（为 QR 分解铺垫）。

**核心概念**

- 内积空间、正交、正交补；
- 投影、最小二乘、正规方程；
- Gram-Schmidt 正交化、QR 分解的雏形；
- 正交矩阵（旋转与反射）。

**前置知识**

- Level 1、Level 3。

**AI 应用**

- 线性 / 多项式回归 = 最小二乘问题；
- PCA 找"信息最多的方向"，依赖正交性与投影；
- 注意力机制中 Q/K 的内积：相似度即投影的直觉；
- 深度网络中的正交初始化、正交正则化。

**推荐资料**

- Strang 第 4 章；
- MIT 18.06 第 14–17 讲；
- StatQuest 的最小二乘与 PCA 视频（应用直觉）。

## Level 5：特征值与特征向量

**学习目标**

- 理解"特征向量方向不变、只被缩放"的几何直觉；
- 掌握特征值计算与矩阵对角化，理解对称矩阵的特殊性；
- 建立"特征分解 = 拆解矩阵作用"的思想。

**核心概念**

- 特征值、特征向量、特征多项式；
- 相似矩阵、对角化；
- 对称矩阵与谱定理（正交对角化）；
- 正定 / 半正定矩阵（与能量、凸性、稳定性相关）。

**前置知识**

- Level 3–4（含行列式）。

**AI 应用**

- PCA = 协方差矩阵的特征分解；
- 谱聚类、PageRank；
- 高斯模型中的协方差矩阵与数据分布；
- RNN 等动力系统的稳定性分析；对抗扰动的几何理解。

**推荐资料**

- 3Blue1Brown《特征向量与特征值》视频；
- Strang 第 5–6 章；
- MIT 18.06 第 21–27 讲。

## Level 6：矩阵分解

**学习目标**

- 掌握 LU、QR、SVD 三类核心分解及其用途；
- 理解奇异值与"秩 = 信息量"的关系；
- 建立数值稳定性意识（条件数），知道"算得出来"不等于"算得稳"。

**核心概念**

- LU 分解（高效解方程组）、QR 分解（正交化 / 最小二乘）；
- SVD：奇异值分解、奇异值、低秩近似；
- 伪逆、条件数与数值稳定性；
- 谱范数与矩阵范数（为 Level 8 的稳定性分析铺路）。

**前置知识**

- Level 2–5。

**AI 应用**

- SVD：PCA 的稳定实现、图像压缩、去噪；
- 推荐系统协同过滤（隐语义模型）；
- 低秩近似：LoRA 等参数高效微调、模型压缩；
- 矩阵补全：缺失数据恢复（推荐、传感器、医学影像）。

**推荐资料**

- 3Blue1Brown《奇异值分解（SVD）》视频；
- Strang 第 6–7 章；
- Stanford CS229 讲义（SVD 与 PCA 部分）；
- 《统计学习导论》(ISLR) 的降维章节。

## Level 7：机器学习中的线性代数

**学习目标**

- 能把每个线代概念对应到具体 ML 模型与训练流程；
- 理解数据矩阵、损失函数、正则化的几何意义；
- 能读懂经典 ML 模型（回归、SVM、PCA）的核心推导。

**核心概念**

- 设计矩阵（数据矩阵）、特征缩放与标准化；
- 最小二乘与岭回归（Ridge），正则化的几何理解；
- 梯度下降中的矩阵运算（批量计算与计算图）；
- 核方法的高维映射直觉：升维以线性化；
- 高斯分布与协方差（线代与概率的衔接点）。

**前置知识**

- Level 1–6 + 概率统计基础。

**AI 应用**

- 线性 / 逻辑回归、Softmax 分类；
- PCA 降维、线性判别分析（LDA）；
- SVM：对偶问题与核技巧；
- K-means 聚类：质心与距离度量；
- 特征工程与向量化计算。

**推荐资料**

- Stanford CS229 讲义与课程视频；
- 《统计学习导论》(ISLR)；
- 周志华《机器学习》（西瓜书）相关章节；
- 《深度学习》（花书）第 2 章与线性模型部分。

## Level 8：深度学习中的线性代数

**学习目标**

- 理解神经网络前向 / 反向传播中的线代结构；
- 掌握张量运算、批量矩阵乘法、雅可比矩阵与梯度传播；
- 理解注意力机制、卷积、嵌入背后的线代本质。

**核心概念**

- 张量与广播运算、批量矩阵乘法；
- 雅可比矩阵与链式法则（反向传播）；
- 权重矩阵的谱性质（谱范数、稳定训练）；
- 注意力机制中的 Q / K / V 投影（内积与缩放）；
- 卷积的矩阵形式（Toeplitz 矩阵视角）、位置编码。

**前置知识**

- Level 1–7 + 微积分（链式法则）。

**AI 应用**

- Transformer 注意力机制（NLP / CV 的核心）；
- CNN 特征图与感受野；
- 词嵌入与向量数据库检索（RAG）；
- LoRA 低秩微调、模型压缩与量化；
- 生成模型（扩散、VAE）中的线性变换与协方差理解。

**推荐资料**

- 《深度学习》（花书）第 2 章（必读）；
- Karpathy 的 micrograd / 从零实现神经网络系列；
- 3Blue1Brown《神经网络》系列（直觉）；
- 经典论文："Attention Is All You Need" 的矩阵部分、LoRA 论文。
