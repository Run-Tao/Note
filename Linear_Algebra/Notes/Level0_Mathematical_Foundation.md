# Level 0 数学基础准备

> 本章节面向即将进入信息类专业（计算机 / 人工智能方向）的学生。
> 目标不是复习高中数学，而是完成**从高中数学到大学数学的思维过渡**。
> 核心思想：**数学是研究结构和关系的语言，而不是公式计算。**

## 学习目标

完成本 Level 后，你应该能够：

- 理解"数学是一种语言"：变量、常量、参数、未知量各有角色，符号服务于结构；
- 掌握集合思想：为什么现代数学从集合开始，以及集合如何对应数据集、样本空间、特征空间；
- 掌握映射思想：函数为什么是映射，定义域、陪域、值域的区别；
- 掌握函数思想：函数既是规则也是变换，理解多元函数与复合函数；
- 建立空间与维度直觉：从一维到高维，明白计算机科学为什么需要高维空间；
- 理解数学证明思维：命题、定理、引理、直接证明、反证法，及其与算法正确性和模型分析的关系；
- 能把以上六个思想与后续的向量、矩阵、线性空间、机器学习、深度学习建立连接。

**学习策略**：遇到每个新概念，先问三个问题——"它描述了什么结构或关系？""数学家为什么要发明它？""它在计算机 / AI 里对应什么？"本笔记就是按这个顺序写的。

## 1. 数学语言

### 引入背景：为什么需要数学语言

日常语言是模糊的："很多""大约""变大了"在不同语境含义不同。数学要处理的是**精确、可验证、可推理**的陈述，因此需要自己的语言。

数学语言有三个特点：

1. **精确**：每个符号的含义唯一确定；
2. **结构化**：符号按规则组合，表达"对象之间的关系"；
3. **可复用**：同一套语言可以描述物理、几何、计算机、AI 中的不同对象。

这和编程是同一个道理：人类语言适合交流，但程序必须用精确的语言（变量、类型、函数）表达，否则无法运行。

### 变量、常量、参数、未知量

**引入背景**：表达"一个数"时，我们常常不知道它是多少，或它随条件变化，于是需要符号来占位。但占位符有多种用途，于是产生了四个不同的角色。

| 概念           | 数学中的角色                     | 直观理解               | 计算机 / AI 中的对应            |
| ------------ | -------------------------- | ------------------ | ------------------------ |
| 变量 variable  | 可以取不同值的量，用于描述关系或变化         | "容器"，随时可以装不同的数     | 程序中的可变变量；模型输入 $x$、中间特征   |
| 常量 constant  | 取值固定不变的量                   | 永远不会变的数            | `const`、固定配置；训练好后被固定住的权重 |
| 参数 parameter | 同一问题中被视为固定的、可调节的量；换一个层面又可变 | "旋钮"：调它不改变结构，只改变行为 | 函数形参；模型权重、学习率等超参数        |
| 未知量 unknown  | 方程中待求解的量                   | "待破案的数"，求解后才知道     | 求解器要找的解；回归中要求解的最优系数      |

**直观理解**：把函数 $y = kx + b$ 当作"关系"看时，$x$ 是输入变量，$y$ 是输出变量，$k$、$b$ 是参数；但当我们研究"怎样的 $k,b$ 最合适"时，$k,b$ 又变成了未知量。**同一个符号的角色由问题框架决定，不是符号本身的属性。**

**AI 联系**：深度学习训练中，模型权重在学习阶段是"变量"（不断更新），推理阶段是"常量"（固定不变），而输入永远是变量。理解这种"角色切换"，是理解训练（fit）与推理（inference）区别的第一步。语音识别中，一段音频的特征向量是变量，模型参数是常量。

**常见误区**：

- 误区：参数和变量是两类本质上不同的东西。→ 正确：它们是"看待方式"不同，同一个量可以既是参数又是变量。
- 误区：未知量就是变量。→ 正确：未知量出现在"求解"语境（$2x+1=5$ 求 $x$），变量出现在"描述关系"语境。
- 误区：数学符号越多越严谨。→ 正确：符号要少而准，服务于结构。

### 常见数学符号

符号是数学语言的"单词"。第一阶段只需认识常用的：

| 符号                                     | 含义              | 会在哪里再次出现  |
| -------------------------------------- | --------------- | --------- |
| $\in$                                  | 属于（元素与集合的关系）    | 集合、特征空间   |
| $\subseteq$                            | 子集              | 集合、子空间    |
| $\cup,\ \cap,\ \setminus$              | 并、交、差（集合运算）     | 数据集划分     |
| $\forall$                              | 任意（对所有……成立）     | 定义、定理     |
| $\exists$                              | 存在（有一个……）       | 解的存在性     |
| $\Rightarrow$                          | 蕴含（如果……则……）     | 证明、逻辑     |
| $\Leftrightarrow$                      | 等价（当且仅当）        | 定理        |
| $\mathbb{R},\ \mathbb{Z},\ \mathbb{N}$ | 实数集、整数集、自然数集    | 空间与维度     |
| $\sum,\ \prod$                         | 求和、连乘           | 损失函数、矩阵运算 |
| $\rightarrow$                          | 映射方向            | 映射、函数     |
| $\lvert x \rvert$                      | 绝对值；以后推广为长度（范数） | 向量长度      |

**使用原则**：不要背符号表，而是每遇到一个符号就问"它表达的是什么关系"。符号只是语言的单词，**句子（结构关系）才是思想**。

## 2. 集合

### 引入背景：为什么现代数学从集合开始

集合论创始人康托的思想：任何数学对象都可以看作"某个整体中的一员"。一旦有了集合，数学就能建立在一条最基本的关系上——**"属于"关系**（$a \in A$）。

几乎所有数学概念都能用集合定义：

- 函数 = 输入集合与输出集合之间的一种对应；
- 空间 = 满足某些规则的点的集合；
- 概率 = 定义在样本空间（一个集合）上的度量。

所以集合是"结构语言"的第一个词：**先有"把对象装进整体"的能力，才能谈对象之间的关系。**

### 数学定义

- **集合**（set）：由确定的对象组成的整体。集合中的对象称为**元素**（element），记 $a \in A$（$a$ 属于 $A$）或 $a \notin A$。
- **子集**（subset）：若 $A$ 的每个元素都属于 $B$，则称 $A$ 是 $B$ 的子集，记 $A \subseteq B$。若 $A \subseteq B$ 且 $A \ne B$，称 $A$ 是 $B$ 的真子集。
- **集合运算**：
  - 并集 $A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$；
  - 交集 $A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$；
  - 差集 $A \setminus B = \{x \mid x \in A \text{ 且 } x \notin B\}$；
  - 笛卡尔积 $A \times B = \{(a,b) \mid a \in A,\ b \in B\}$（所有有序对的集合）。
- 常用记号：空集 $\varnothing$（不含任何元素的集合）。

集合的三个基本性质：**无序、不重复、元素确定**。这与列表 / 数组（有序、可重复）不同。

### 直观理解

- 班级 = 学生集合；偶数集合；坐标平面 = 所有点 $(x,y)$ 的集合，即 $\mathbb{R} \times \mathbb{R}$；
- 计算机：一个数据类型（如 `int`）就是所有该类型值的集合；数据库查询结果是一个集合；
- 笛卡尔积的直觉：一副扑克牌 = 花色集合 × 点数集合（$4 \times 13$ 种组合）。

### AI 联系

- **数据集**：训练集、验证集、测试集都是样本的集合，且要求互不重叠——用集合语言说：两两交集为空，并集是全部数据；
- **样本空间**：所有可能样本组成的集合（如所有 $28\times28$ 图片的集合）；
- **特征空间**：所有可能特征向量组成的集合。Level 1 之后你会知道，它就是实数向量集合 $\mathbb{R}^n$；
- **标签集**：所有可能类别的集合（分类问题中模型输出属于标签集）；
- **聚类**：把样本集合划分成若干"簇"（子集），是集合划分思想。

### 常见误区

- 误区：集合里的元素只能是数。→ 正确：元素可以是任何对象，甚至是集合本身。
- 误区：$\in$ 和 $\subseteq$ 是一回事。→ 正确：$a \in A$ 是"元素属于集合"；$A \subseteq B$ 是"集合包含于集合"。$1 \in \{1,2\}$ 成立，但 $1 \subseteq \{1,2\}$ 不成立。
- 误区：集合和列表没区别。→ 正确：集合无序、不重复；列表有序、可重复，两者用途不同。
- 误区：集合运算太抽象，AI 用不上。→ 正确：数据集划分、类别判定、去重都是集合思想。

## 3. 映射

### 引入背景：为什么函数本质是映射

"函数"在高中常被理解为"一个公式"。但公式只是描述方式之一——很多对应关系（查表、算法、神经网络的权重）根本没有简洁的公式。数学家需要一种更本质的定义：**函数 = 两个集合之间的一种对应关系**，这个关系就是**映射**。

"映射"比"函数"更朴素也更一般：它不关心你"怎么算"，只关心"谁对应谁"。这正好对应机器学习里的核心观点：模型就是**从输入空间到输出空间的映射**——我们不一定知道它的"公式"，我们学习的就是这个对应本身。

### 数学定义

- **映射**（mapping / function）：从集合 $A$ 到集合 $B$ 的映射 $f$ 记作 $f: A \to B$，它给 $A$ 中**每一个元素** $a$ 恰好指定 $B$ 中**唯一一个**元素 $f(a)$。
- **定义域**（domain）$A$：输入允许来自的集合；
- **陪域**（codomain）$B$：声明输出所在的集合；
- **值域**（range / image）$f(A) = \{f(a) : a \in A\}$：实际到达的输出集合。

关键关系：**值域 ⊆ 陪域**，两者不一定相等。

三个重要性质（为后面理解"可逆性"与"信息保持"铺垫）：

- **单射**（injective）：不同的输入给出不同的输出（$a_1 \ne a_2 \Rightarrow f(a_1) \ne f(a_2)$）；
- **满射**（surjective）：值域 = 陪域（声明中的每个输出都被"够到"）；
- **双射**（bijective）：既单又满，即一一对应，此时可以定义逆映射。

### 直观理解

- 自动售货机：按钮（输入）→ 商品（输出）。每个按钮必须且只能对应一种商品；但不同按钮可以对应同一种商品（允许，非单射）；
- 身份证号 → 人：合法映射（每人一个号码）；"姓名 → 人"不一定合法（重名时一个输入对应多个输出）；
- Python 函数：`def f(x): return x**2`。定义域 = 可接受的输入，陪域 = 声明的返回类型，值域 = 实际返回值集合。

### AI 联系

- **机器学习模型 = 映射**：分类器（图像 → 类别）、回归模型（特征 → 数值）、语音识别（音频 → 文本）；
- **监督学习**：训练就是在给定输入集合与标签集合之间学习一个好的映射；
- **神经网络输入输出**：网络本身就是一个由参数决定的映射，输入输出都是高维空间中的点；
- **信息保持**：若网络层是"单射"，信息不丢失；生成模型常希望从低维噪声映射回高维数据（满射 / 双射直觉）。

### 常见误区

- 误区：陪域 = 值域。→ 正确：$f: \mathbb{R} \to \mathbb{R},\ f(x)=x^2$ 的陪域是 $\mathbb{R}$，值域是 $[0, +\infty)$。
- 误区：函数的输入可以对应多个输出。→ 正确：映射要求每个输入恰好一个输出（"良定义"）。
- 误区：没有公式就不是函数。→ 正确：分段函数、查找表、算法、模型权重定义的对应都是函数。
- 误区：一个输入只能对应一个输出，就意味着一个输出也只能对应一个输入。→ 正确：后者是单射条件，普通函数不要求。

## 4. 函数

### 引入背景：函数的两副面孔

函数是映射的具体化。但"函数思想"比映射多一层：我们不仅关心"谁对应谁"，还关心**整个输入空间如何被"搬动"**。

$f(x) = y$ 有两层含义：

1. **计算关系**：给定 $x$，按规则算出 $y$；
2. **变换（transform）**：把输入空间中的每一个点送到输出空间中的另一个点——整个空间被"变形"。

第二层含义极其重要：线性代数的核心对象（矩阵、线性变换）就是把"变换"作为研究对象。**学习线性代数，本质上是学习一类特殊的变换。**

### 函数作为规则

- **数学定义**：函数 $f: A \to B$ 是满足"每个输入恰好一个输出"的对应规则。
- **直观理解**：菜谱（输入食材 → 输出菜肴）；温度换算（℃ → ℉）。
- **AI 联系**：损失函数 $\mathcal{L}$ 是一个规则：给定预测与真实值，输出一个误差数；训练就是在规则下找让误差最小的参数。
- **常见误区**：认为规则必须是一条公式。$\text{ReLU}(x) = \max(0, x)$ 是分段规则，但完全合法，而且是深度学习中最常用的函数之一。

### 函数作为变换

- **数学定义**：把函数看作从输入空间到输出空间的整体作用：$f$ 同时移动定义域里的所有点。
- **直观理解**：地图投影（球面 → 平面）；哈哈镜（图像变形）；拉伸、旋转一张照片（每个点被移动到新位置）。
- **AI 联系**：激活函数就是对特征空间的"变形"——ReLU 把负数全部压到 0，改变整个空间的结构；隐藏层的作用就是不断对输入空间做变换，直到数据"变得可分"。
- **常见误区**：以为变换必须画得出来。高维空间的变换靠代数描述与直觉类比，不靠肉眼画面。

### 多元函数

- **数学定义**：$f(x_1, x_2, \dots, x_n)$：输入是 $n$ 个数的组合（即 $n$ 维空间中的一个点），输出一个数或一组数。
- **直观理解**：BMI = 体重 ÷ 身高² 是两个输入的函数；房间温度是位置 $(x,y,z)$ 和时间 $t$ 的多元函数。
- **AI 联系**：
  - 一条样本有多个特征，模型天然是多元函数；
  - 损失函数是参数的多元函数 $\mathcal{L}(w_1, \dots, w_n)$，"训练"就是求它的最小值——为后面理解梯度下降埋下伏笔；
  - 图像分类：$f(\text{像素数组}) = \text{类别}$，输入是成千上万个数字。
- **常见误区**：以为多元函数是"多个函数"。→ 正确：它仍然是一个函数，只是输入是"多个数组成的一个整体"（未来叫向量）。

### 复合函数

- **数学定义**：$f: A \to B$，$g: B \to C$，复合 $g \circ f: A \to C$ 定义为 $(g \circ f)(x) = g(f(x))$。**先执行 $f$，再执行 $g$。**
- **直观理解**：流水线——每个工位是一道工序，整条流水线是工序的复合；俄罗斯套娃——外层函数套着内层函数。
- **AI 联系**：神经网络就是复合函数的典型：$f(x) = g_L( \dots g_2(g_1(x)) \dots )$，每一层是"线性变换 + 激活函数"。反向传播算法的本质，就是用链式法则沿着这条复合链从后往前分配误差。
- **常见误区**：
  - 读法错误：$g \circ f$ 是先 $f$ 后 $g$，不是先 $g$ 后 $f$；
  - 以为复合必须写出显式公式：神经网络就是这样"算不出显式公式"的复合函数。

## 5. 空间与维度

### 引入背景：为什么计算机科学需要高维空间

计算机处理的数据是一条条的"记录"，每条记录由若干属性（数字）组成：年龄、身高、体重、成绩、像素值……**把每个属性当作一个坐标轴，一条记录就是一个点**，所有点构成一个空间。

- 属性个数 = 维度 = 坐标轴个数；
- 一条数据 = 空间中的一个点；
- 数据集 = 空间中的一群点。

于是许多 AI 问题被翻译成空间语言：分类 = 在空间中画边界把不同类的点分开；聚类 = 找出离得近的点群；回归 = 拟合穿过这些点的"形状"。**这就是计算机科学需要高维空间的原因：数据天然是"多维的点"。**

### 一维、二维、三维

- **一维空间** $\mathbb{R}$：一条实数轴，每个点是一个数。如时间、温度、单特征数据；
- **二维空间** $\mathbb{R}^2$：平面，每个点是一对坐标 $(x,y)$。如地图、成绩散点图、图像中的一个像素位置；
- **三维空间** $\mathbb{R}^3$：立体空间 $(x,y,z)$。如物体的位置、RGB 颜色（红绿蓝三通道就是一个三维向量）；
- **高维空间** $\mathbb{R}^n$：$n$ 个坐标 $(x_1, x_2, \dots, x_n)$。画不出来，但代数规则与低维完全一致。

**关键升级**：空间不只是"点的集合"，还带有**结构**——点之间可以测量距离、可以比较方向、可以定义运算。什么样的结构？这是 Level 3"向量空间"要严格回答的问题。本 Level 只需要建立直觉：**空间 = 点的集合 + 结构**。

### 直观理解

- 二维平面上的距离用勾股定理：$\sqrt{(\Delta x)^2 + (\Delta y)^2}$；推广到 $n$ 维，就是对每个坐标差的平方求和再开方——这个"距离"未来会叫**范数**；
- 一张 $28\times28$ 灰度图：$28 \times 28 = 784$ 个数字，就是 784 维空间中的一个点；一张 $32\times32$ 彩色图是 $32 \times 32 \times 3 = 3072$ 维的点；
- "词嵌入"：把单词映射成几百维的向量，语义相近的词在空间中距离近——**距离 = 语义相似度**。

### AI 联系

- **图片像素向量**：图像分类 = 在高维空间中把"猫图片的点"和"狗图片的点"分开（计算机视觉）；
- **embedding**：词、商品、用户都被表示为高维点，检索与推荐 = 在空间中找近邻（NLP / 推荐系统）；
- **神经网络隐藏层**：把原始输入映射到新的高维表示空间，希望在新空间中数据"更好分"；
- **语音处理**：一帧语音常表示成几十维的特征向量（如 MFCC），语音识别 = 在特征空间中做分类 / 序列决策；
- **高维的麻烦（预告）**：维度越高，空间中点越"稀疏"、距离越不可靠——这被称为**维度灾难**，也是需要降维（如 PCA）的原因。线性代数正是处理这一切的工具。

### 常见误区

- 误区：高维空间是物理上真实存在的地方。→ 正确：它是数学模型，只是把"一组数字"想象成"一个点"。
- 误区：必须能"画出来"才叫理解。→ 正确：高维直觉 = 几何想象 + 代数严格化，两者配合。
- 误区：维度 = 数据条数。→ 正确：维度是一条数据有几个属性（坐标轴数）；数据条数是"有多少个点"。
- 误区：高维空间中距离总是可靠的。→ 正确：高维中距离趋于均匀、区分度下降（维度灾难，后面会学应对方法）。

## 6. 数学证明思想

### 引入背景：为什么大学数学强调证明

高中阶段的数学，重点是"记住结论并会用"。到了大学，问题变成：**结论为什么为真？在什么条件下为真？有没有反例？**

原因有三：

1. **可靠性**：数学结论要求"所有情况下都成立"，而例子永远只能说明"有些情况成立"。证明是唯一能给出全称保证的方法；
2. **结构性**：证明把结论挂在已有的定义和定理上，形成一条无漏洞的推理链——这与程序模块依赖、类型系统是同一精神；
3. **工程价值**：算法为什么正确、模型为什么收敛、为什么有泛化能力——这些问题的答案本质上都是"证明"。

### 命题、定理、引理

- **命题**（proposition）：可以判定真假的陈述。如"两个偶数的和是偶数"；
- **定理**（theorem）：被严格证明的重要命题。定理 = 重要的真命题；
- **引理**（lemma）：为证明某个定理而准备的中间结论，相当于工程中的"辅助函数"；
- **推论**（corollary）：由定理直接推出的结论。

**直观理解**：引理是"工具零件"，定理是"成品"，推论是"顺手拿到的副产品"。写程序时，辅助函数（引理）服务于主功能（定理）。

**AI 联系**：机器学习中的很多结论是定理（如"凸损失函数的局部最优即全局最优"）；分析模型行为（收敛性、误差界）用的就是命题-证明结构。

### 直接证明

- **数学定义**：从已知条件和定义出发，按逻辑规则一步步推出结论。
- **示例**：证明"两个偶数的和是偶数"。设两偶数为 $2a$、$2b$（$a,b$ 为整数），则它们的和为 $2(a+b)$，是 2 的倍数，故为偶数。
- **AI 联系**：证明算法正确性的"循环不变量"方法，本质上是在每一步都维持一个命题为真，结构和直接证明一致。
- **常见误区**：把"举个例子"当证明。例子只能展示"成立"，不能排除反例；只有推理链能保证"总是成立"。

### 反证法

- **数学定义**：要证明命题 $P$，先假设 $P$ 不成立，从这个假设推出矛盾，于是 $P$ 必然成立。
- **示例（经典）**：证明 $\sqrt{2}$ 不是有理数。假设 $\sqrt{2} = p/q$（$p,q$ 互素），平方得 $p^2 = 2q^2$，说明 $p$ 是偶数，设 $p=2k$，代入得 $q^2 = 2k^2$，说明 $q$ 也是偶数，与"$p,q$ 互素"矛盾。故假设错误，$\sqrt{2}$ 是无理数。
- **AI 联系**：反证法特别适合证明"不存在"类结论（如"不存在这样的学习率使所有情况都收敛"），它与测试中"假设成立 → 发现矛盾 → 推翻假设"的思路一致。
- **常见误区**：反证法不是"举反例"。反例直接否定一个命题；反证法是假设命题为假再推出矛盾。

### 逻辑的陷阱：逆命题与逆否命题

对"若 $P$ 则 $Q$"：

- **逆否命题**"若非 $Q$ 则非 $P$"与原命题**逻辑等价**（证明中常互相转化）；
- **逆命题**"若 $Q$ 则 $P$"与原命题**不一定等价**。

例子："若是猫则吃鱼"为真；"若吃鱼则是猫"显然不成立。

**常见误区**：把命题的逆命题当成原命题使用。这在读论文、审查模型假设时是高频错误。

### 证明与算法、模型的关系

- **算法正确性**：排序算法为什么对所有输入都正确？需要证明（如归纳法 / 循环不变量）。测试只能证明"存在 bug"，不能证明"没有 bug"；
- **模型分析**：损失函数为什么容易优化（凸性）？梯度下降为什么能收敛？模型为什么有泛化能力？——都是证明性结论；
- **学习策略**：看不懂证明时，先接受结论、看懂"结构"（前提 → 关键步骤 → 结论），再回头补细节。证明是给"信心"用的，不是给"考试焦虑"用的。

## 7. 与线性代数的连接

本节六个思想不是孤立的，它们是线性代数的"前传"：

| 本 Level 的思想         | 在线性代数中的对应                       | 在 AI 中的对应            |     |
| ------------------- | ------------------------------- | -------------------- | --- |
| 数学语言（变量 / 参数 / 未知量） | 矩阵方程中的符号各司其职（$A$、$x$、$b$ 的角色不同） | 模型输入、权重、待求的解         |     |
| 集合                  | 线性空间 = 满足特定运算规则的集合；子集 → 子空间     | 特征空间、数据集             |     |
| 映射                  | 线性变换 = 保持加法和数乘的映射               | 分类器、神经网络的一层          |     |
| 函数                  | "矩阵作用于向量"正是函数变换视角的推广            | 前向传播、激活函数、损失函数       |     |
| 空间与维度               | $\mathbb{R}^n$ 向量空间、高维空间中的几何    | 像素向量、embedding、隐藏层表示 |     |
| 证明                  | 线性代数中的定理（如解的结构、特征值的性质）          | 算法正确性、模型收敛性分析        |     |

一句话总结连接：**线性代数研究的是"空间之间的变换"——集合给出空间的原料，映射给出变换的概念，函数给出变换的视角，维度给出空间的尺度，证明保证结论可靠。** 你即将在 Level 1 学到的向量与矩阵，就是把"点"和"变换"用最精确的语言表达出来。

## 总结

回到核心思想：**数学是研究结构和关系的语言，而不是公式计算。**

- **数学语言**：符号是为结构服务的，变量 / 参数 / 未知量的区别是"角色"而非"本质"；
- **集合**：现代数学的起点，因为"属于关系"是最基本的结构；
- **映射**：函数更本质的定义——输入输出之间的对应，不管有没有公式；
- **函数**：既是规则又是变换，复合函数对应流水线，也对应神经网络；
- **空间与维度**：数据 = 高维空间中的点，AI 的很多问题 = 空间中的几何问题；
- **证明**：保证"总是成立"的唯一方式，也是算法与模型分析的底层逻辑。

**给自己的检验**：不看笔记，用一句话解释六个概念中的任意一个，并说出它在 AI 里的一个对应物。如果说不出来，说明还没真正理解。
