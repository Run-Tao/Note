# 2026 诺贝尔生理学或医学奖 —— 光遗传学（Optogenetics）

> **获奖者**：Karl Deisseroth（美国，1971–，HHMI / 斯坦福大学）、Peter Hegemann（德国，1954–，柏林洪堡大学）、Georg Nagel（德国，1953–，维尔茨堡大学）
> **获奖理由**：**光门控离子通道（light-gated ion channels）与光遗传学（optogenetics）的发现**
> **公布**：2026-10-05，卡罗琳医学院；奖金 1200 万瑞典克朗，三人均分
> **来源**：诺奖官网公报 + [新华社报道](https://www.news.cn/20261005/ced9aad673384e19be735e533d14029b/c.html)

## 1. 一句话理解

**把一段藻类的"光敏开关"基因装进神经细胞，就能用一束蓝光精确开关指定的神经元**——神经科学由此从"旁听大脑电信号"变成"遥控大脑活动"。

## 2. 科学内容（三层）

### 2.1 发现：通道视紫红质（channelrhodopsin）

- Hegemann 与 Nagel 在**单细胞藻类**中发现该蛋白：位于细胞膜上，**吸收蓝光**后构象改变，**离子通道像门一样打开**，带电离子进入细胞并产生电信号；
- 关键第二步：把它**异源表达**到其他细胞后，这些细胞同样"对光产生反应"——证明它是一个**可移植的光控元件**，而不只是藻类的私有机制。

### 2.2 应用：光遗传学（Deisseroth）

- 将编码通道视紫红质的基因导入**大鼠神经细胞**，蓝光照射即触发神经信号（**2005 年**发表）；
- 两年后（2007）实现**活体小鼠大脑**中用光控制神经细胞活动；
- 由此可研究活体大脑中神经细胞如何影响**记忆、感觉、行为**，并揭示与神经 / 精神疾病相关的**神经回路**。

### 2.3 临床与科学意义

- 已尝试帮助**视网膜疾病**患者恢复部分视觉功能；
- 用于研究**抑郁症、阿尔茨海默病、疼痛**背后的神经机制；
- 与神经记录手段（电生理 / 钙成像）结合，形成对神经活动的"**读—写**"能力。

## 3. 与我的方向（自动化 / 信息类）的连接

> 这是本条目对我最有价值的部分：**光遗传学本质上是一个控制工程问题**。

| 控制论概念 | 光遗传学中的对应 |
| --- | --- |
| 被控对象 | 神经元 / 神经回路（非线性、高维、部分可观测） |
| 执行器 actuator | 光刺激——通道视紫红质就是"光 → 离子流"的驱动器 |
| 传感器 | 电生理记录 / 钙成像 / 电压指示蛋白 |
| **闭环控制** | **闭环光遗传学**：实时读取神经活动 → 反馈调节光刺激 |
| 系统辨识 | 用"光刺激—响应"数据拟合神经元动力学模型 |
| 模型 | 膜电位动力学（Hodgkin–Huxley 类方程）、发放率模型 |

- **数学工具**：微分方程（膜电位）、状态空间模型、反馈与稳定性 → 后续在[[Automation_Plan|自动化主线]]的"信号与系统 / 自动控制原理"中正式学到；
- **数据与机器学习**：神经活动是高维时间序列 → [[Mathematical Modeling MOC|数学建模]]、[[Linear Algebra MOC|线性代数]] 的降维与特征值方法（参见 [[Day32 - 主成分分析PCA与主成分回归PCR|PCA 教案]]）。

## 4. 学习路径（建议顺序）

1. **背景层**（生物学）：细胞膜与离子通道、静息电位 / 动作电位——先搞清"离子进出为什么等于电信号"；
2. **分子层**：视紫红质 → 通道视紫红质（光异构化 → 通道开放），读官方 *popular information*；
3. **方法层**：基因递送（病毒载体 / 转基因）→ 光纤植入 → 光刺激参数（波长、强度、频率）→ 读出手段；
4. **工程层**（我的重点）：闭环光遗传学的控制结构、延迟与带宽限制、状态估计；
5. **文献层**：读官方 *advanced information*（科学背景），再挑 1–2 篇原始论文（Nagel 2003 / Boyden 2005 等）。
