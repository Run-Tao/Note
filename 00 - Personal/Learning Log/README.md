# Learning Log 学习日志

> 让知识库"持续运转"的机制：**按时间记录**，而不是按主题堆笔记。
> 每周一篇、月尾复盘；暑假、学期中、假期都适用。

## 规则

1. **每周一篇**：文件名 `YYYY-Www.md`（如 `2026-W34.md`），按下方模板写；
2. **只写真实状态**：写"真正懂了什么 / 卡住什么"，不写"看了什么课"的流水账；
3. **链接闭环**：卡住的问题 → [[Linear_Algebra/Questions/README|Questions]]；完成的项目 → 对应 Projects/；对照 [[Summer_Plan|当前计划]] 的达标判断自检；
4. **月尾复盘**：当月最后一篇末尾加"本月复盘"（3 条收获 + 3 个问题 + 下月 1 个重点）；
5. **学期切换**：开学后记录课程衔接（如 数学分析 ← 计算层；C++ ← 预备支线），并新增学期计划。

## 模板

```markdown
# 2026-Wxx 周记（M月D日 – M月D日）

## 学了什么
- （内容 + 链接到相关笔记）

## 真正懂了什么
- （能不看笔记讲出来的才算）

## 卡住的地方
- （问题 → 是否已记入 Questions）

## 下一步
- （下周 1–2 件事，具体到可执行）
```
