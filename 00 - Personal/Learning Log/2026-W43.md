## 真正懂了什么

- **间断点的判别不是"看有没有定义"，而是"看左右极限"**：左右极限都存在且相等 → 可去（补定义即可连续）；都存在但不等 → 跳跃；一侧为 $\infty$ → 无穷；都不存在 → 振荡。第一类 / 第二类的分界就是"左右极限是否都存在"。
- **"函数有定义"和"极限存在"是两件事**：$f(x_0)$ 是否定义、取值多少都不影响 $\lim_{x\to x_0}f(x)$ —— 这一点想通了，可去间断点就只是"补一个定义"的机械操作。
- **等价无穷小只在乘除因子里替换**：加减式必须先合并 / 有理化 / Taylor 到第一个非零阶（`7.tex` 5(7) 的错误就出在这里）。
- **极限定义证明的形式在轮换**：$\varepsilon$-$\delta$ / $\varepsilon$-$X$ / 无穷大 $M$-型三种都要会写，不能只练顺手的那一种。（2026-11-02 补充：17 套卷逐题核对下来，分布是 **8 : 6 : 3**，几乎均匀轮换，所以按 3 : 2 : 1 分配练习量即可。）
- **放缩方向是这类题的真正失分点**（2026-11-02）：求下界时**分母要给上界、分子要给下界**；方向一反，结论里的 $\delta$ 就偏大。2015-16 与 2024-25 两份官方答案正是栽在这里（我已复核出反例并给出订正版）。
- **"$\lim f=\infty$" 与 "$|f|\to\infty$" 不是一回事**：前者要求左右同号趋正，后者的左右可以分别趋向 $\pm\infty$。真题按后者出，答题也要按后者写。
