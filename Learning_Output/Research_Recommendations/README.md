# Research Recommendations — 学习资料推荐

## 用途

根据实际学习内容，搜索并推荐：
- 教程
- 论文
- 开源项目
- 官方文档

## 原则

- **不泛泛推荐**，每一条必须说明"为什么推荐"（对应缺口 / 当前进度 / 依赖关系）
- 可下载文档 → 存到对应库 `Resources/Downloads/` 并在索引登记；仅在线资源才留链接
- 不编造资料：链接 / 来源需真实可查

## 命名

`YYYY-MM-DD_主题.md`（如 `2026-08-23_python-numpy.md`）

## 格式

```markdown
# 资料推荐：主题

## 推荐清单
| 资料 | 类型 | 为什么推荐 | 链接/路径 |
|------|------|-----------|-----------|
| ...  | 教程 | 对应某缺口 | ... |
```
