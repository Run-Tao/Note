## 二、新增学习内容

### ✅ 主体一：Day49「微分方程建模 — SEAR 谣言恐慌与县域应急撤离」（`b62d3bc`，11:11）

**这是全库最有分量的一讲**。此前 44 讲覆盖了「从数据找规律」（ARIMA/ML）、「从约束找方案」（规划/启发式）、「从多指标找排序」（评价），唯独缺 **「从机制推演化」**——这正是国赛 A 题（人口、传染病、传热、振动、交通流）的看家范式。

**选题与场景**：云溪县化工厂爆燃，一条"有毒气体扩散"的群聊消息在 12 小时传遍半个县城。应急办 48h 内决定：**要不要广播、什么时候、投多强**。**关键设计**：这个决策**没有历史同期数据可学** → ARIMA/ML 全部失效 → 只能从机制写方程。**这个"用场景反证方法必要性"的选题手法，比前几讲"先有方法再找场景"高一个档次。**

**模型**：SEAR 四仓室（S 未听说 / E 听说未信 / A 恐慌散布 / R 理性等待），$\dot A=\gamma E-(\omega+g)A$。相比 SIR 多一层 $E$（潜伏延迟）——而这一层恰恰是决策"针对谁"的关键。

**本期独立复验（`.venv`，`-W all` 零告警，实跑 ~16s，退出码 0，断言全过）**：

| 检验项 | 结果 |
| --- | --- |
| 无干预峰值 | **89,338 人（29.8%）@ 第 10.3 天**，第 13.6 天跌回一半，$R_0=\beta/(\omega+\gamma)=1.29>1$ |
| 峰值条件自洽 | $\gamma E=44,749.1$ vs $(\omega+g)A=44,669.2$，**相对差 0.18%**；数值 $dA/dt=+80.1$/天（≈0）✅ |
| 持续广播 | 峰值 **10,585（3.5%）**，降幅 **88.2%** |
| 分批投放（40% 警力公平对比） | 峰值 **52,110（17.4%）** vs 持续低强度 **41,660（13.9%）** → **分批更差 25%** |
| 决策曲线 | **$g\ge0.80$/天** 才能把峰值压到 5% |
| 参数反演 | $\hat\beta=2.15$（真值 2.20）、$\hat\gamma=1.26$（真值 1.20），拟合相对误差 **3.9%** |
| 可辨识性 | β 偏离 ±10% → 残差升到 **1.9~2.2 倍**（β 被数据锁住）；但 γ 随 β 漂移（−15% 时 γ→1.90）→ 教案明写"γ 需额外数据才能单独定死" ✅ |
| 敏感性 | β±25% → 峰值 **23.2%~34.3%**，资源需多备 **48%** |

**教学点质量：本讲是近 20 讲里"被数据证伪"风险最低的一讲。** 核心结论——**「库存型系统里，脉冲式干预通常不如持续基线干预」**，直接**推翻了常识直觉**（"分批投放节省注意力"），而且用 40% 警力公平对比堵住了"总量更多所以更好"的漏洞。这与 Day47（IG 相对 NEH **零增益**，教学点没被数据支撑）形成鲜明对照 → **上一期点名的"教学实例必须设计成能暴露方法差异"这条教训，本讲第一次做到了。**

**本讲的"诚实度"也是标杆级**：独立报出"总剂量核对 10.6 vs 10.8（差 2%）"、明写"分批未优于持续 → 诚实记录"，并为"恐慌超过 5% 的人口小时数"单列一表（无干预 246.2h / 持续 0.0h / 分批 180.0h）。**这种"主动交代对自己不利的数字"是学术级习惯，值得固化为教案模板。**
