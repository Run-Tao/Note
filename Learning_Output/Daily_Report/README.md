# Daily Report — 每日学习报告

## 用途

每天读取最近 24 小时的仓库变化，分析：

1. 新增学习内容
2. 新想法
3. 未完成任务
4. 潜在问题

## 命名

`YYYY-MM-DD.md`（如 `2026-08-23.md`）

**同日多份报告**：若同一天因窗口不同产生第二份报告，用后缀区分，不覆盖前一份：

- `YYYY-MM-DD.md` —— 主报告（23:00 窗口）
- `YYYY-MM-DD_Evening.md` —— 晚间追加版（23:00 至 23:55 窗口）

已知实例：[[2026-11-09]] + [[2026-11-09_Evening]]（主报告在 23:00 判定「全日零 commit」，49 分钟后 `166524c` Day72 落地，结论被推翻）。

> [!warning] 读报告先看窗口
> 本目录的报告窗口并非统一为「自然日」。标题/正文首段的「数据窗口」才是基准。
> 下一期做「对比昨日」时，以**当天最后一份**报告为基准。
> 已知待修：cron 23:00 早于仓库主要活跃时段（23:00–24:00），已记入 `2026-11-09_Evening.md` P23。
