## 二、新增学习内容：Day72 双层规划（今天唯一真正的新知识）

### 2.1 内容本身

`Mathematical_Modeling/04 - Optimization/Day72 - 双层规划上层批额度下层重新选片水源地保护与林场采伐.md`

- **模型族**：Stackelberg 主从 / bilevel programming。教案自称「全库零命中的一族」——我核了前接链接（Day60 集合覆盖、Day69 分层覆盖、Day71 极小极大后悔、Day64 VCG、Day27 报童），**确实都是单决策者**，这一讲的增量是真的。
- **场景**：云溪县 10 个林班、3 个取水口（城关→石桥→云岭）。上层批采伐面积额度，下层林场据此重新选整块林班。
- **核心教学点**（我认为这是今天最值钱的一段）：**双层 ≠ 加权多目标**。写成 $w_1F+w_2f$ 就退化成单层，下层不会在你改额度后换方案，整个结论塌掉。
- **算法**：下层 $2^{10}=1024$ 全枚举（不做 LP），上层扫 25 857 组额度，**实测 1.92 s**。
- **主结论**：响应函数是**台阶**不是曲线 —— λ 从 0.70→0.85 额度涨 21%、利润只涨 7 万；0.95→1.00 额度涨 5%、利润跳 230 万。→「多批 20 公顷值多少钱」这类题**没有边际答案**，敏感性要扫「哪块林班的整块面积」，不能扫额度。
- **配套**：`08 - Python/daily/2026-11-09/`（脚本 + PNG + result.json + README 十问）、`Resources/Downloads/Bard-Bilevel-Optimization-Foundations-and-Recent-Advances-2023.pdf`（2.0 MB）、MOC / 模型备赛图谱 / `Teaching_Plan.md` / `pending.yaml` 联动更新。

## 三、新发现的问题

### 3.1 🔴 新发现 P21：Day72 教案 §3.4 的传递系数表是**手写数，不是脚本输出**

教案 214 行里，**第 170 行**那张表写的是：

| $\tau_{tr}$ | 主案额度下的利润 | 不限额度的最优 |
|---|---|---|
| 0.2 | 1 133.6 | 1 396.4 |
| 0.4 | 1 133.6 | 1 396.4 |
| 0.6 | 1 133.6 | 1 281.2 |
| **0.8（主案）** | **1 133.6** | **1 133.6** |
| 1.0 | **997.4** | **1 107.6** |

而 `day72_result.json` 的 `传递敏感性` 是：

| $\tau_{tr}$ | 主案额度下的利润 | 不限额度的最优 |
|---|---|---|
| 0.2 | 1 133.6 | **1 510.8** |
| 0.4 | 1 133.6 | **1 395.6** |
| 0.6 | 1 133.6 | 1 281.2 |
| 0.8 | 1 133.6 | 1 133.6 |
| 1.0 | **967.2** | **967.2** |

**五格里有四格不一致。** 我用脚本实测输出确认 JSON 才对：

```
tr=0.2  主案额度下   1134  无约束   1511
tr=0.4  主案额度下   1134  无约束   1396
tr=0.6  主案额度下   1134  无约束   1281
tr=0.8  主案额度下   1134  无约束   1134
tr=1.0  主案额度下    967  无约束    967
```

**这不是四舍五入误差，是两个定性结论都翻车了：**

1. 教案说「$\tau_{tr}=1.0$ 时**不限额度的最优反而涨到 1107.6**」——**涨这个动作不存在**。真实情况是两边都塌到 967.2，**完全相等**。教案那句话（「说明这时该换工具了」）是建立在一个假现象上的。
2. 教案说 $\tau_{tr}=0.2$ 时不限额最优 1 396.4 —— 真实是 **1 510.8**（= 无约束全砍，即传递系数小到红线根本不咬人，这个解释反而更漂亮也更正确）。

**处方：** §3.4 的表格与两段解释文字，**必须用 `day72_result.json` 的 `传递敏感性` 重写**，并把「$\tau_{tr}=1.0$ 两边相等」这个真事实改写成教学点（→「当传递系数大到主案额度自己不可行时，批额度这个工具彻底失效，上限挡不住任何东西」）。**这是第 4 次出现同一类错：成文数字与机器产出脱钩。** 11-07 是复核脚本共享前提，11-08 是相关矩阵当协方差，今天早上是 returncode 当结论，今晚是手抄表格。**库规第一条（早版 §5.2 已经写了）应该立刻生效。**
