## 二、Day63 讲了什么（先肯定）

### 2.1 选题：全库真空的「图聚类」一族，且与已有讲次边界清晰

`MCL` / `Markov clustering` / `谱聚类` / `Fiedler` 全库零命中属实（我 grep 过）。Day8 是 K-Means（点、欧氏）、Day32 是 PCA（谱方法但不是图）、Day59/60/61 是网络上的**优化**（不聚类）。这条增量是真的，而且**提出了本库迄今最干净的一句方法论**：

> **聚类不是把点分组，是把边分组。**

这句话比 Day61 的「车数不是货÷容量」更本质——它是**建模层面**的陈述，不是**算法层面**的。

## 五、潜在问题

### 🔴 P1｜MCL「在 t=0.20 给 4 团、t=0.27 给 6 团」——那 4 个和 6 个团**全是单点**

教案 §3.2 与 README 的表格是这样的：

| 在哪个图上跑 | MCL 团数 |
| --- | --- |
| 原始图 | 1 |
| t=0.10 | 1 |
| t=0.20 | **4** |
| t=0.25 | **4** |
| t=0.27（骨架） | **6** |

并在 §3.2 与图②标题写下：「**MCL 只有落对断面才跟上**」。**但 `day63_result.json` 里的 `sizes` 是 `[1,1,1,1]` 和 `[1,1,1,1,1,1]`**——我复跑确认，这几个断面上的「团」**每一个都只有一个点**。

这意味着真实情况是：

1. **MCL 在这张图上从头到尾没有产出过任何一个「多点多团」的解**（要么 1 团=全图，要么全单点）；
2. 4 团 / 6 团之所以出现，不是「MCL 找到了结构」，而是**膨胀把每个点的自环锁死**——`clusters` 里返回的是 `[[0],[3],[6],[7]]` 这种，本质是「图被蒸成孤立点」，与「1 团」是**同一个失败模式的两端**（过度膨胀 vs 过度扩散）；
3. 于是图②里那条 `MCL 团数` 曲线（1→1→4→4→6）**视觉上像在追踪断面曲线，实际上只是「单点计数」**——它跟骨架的 3 块没有任何关系，却和 `t` 同步上升，读者会误以为是「MCL 在跟着结构走」。

**为什么必须改**：这一讲的核心教学点是「**不要拿一个聚类算法的输出直接当『几段』**」。P1 恰好是这句话的**实例**，但教案把它讲成了「MCL 落对断面才跟上」，**等于在为 MCL 辩护**，方向反了。真实结论应该是：

> **MCL 在本题的整个参数区间里都没给出有意义的划分**：稠密图上它给「1 团」（过度扩散），稀疏图上它给「全是单点」（过度膨胀），**中间没有一个可用的区间**。这不是参数没调好，是**权重构造（几乎全连接的相似度核）让 MCL 的前提不成立**——MCL 要的是「团」，而这张图上根本没有团。**这才是应该先做 k-NN 稀疏化的原因。**

**处方（三处，10 分钟）**：
1. 表格加一列 `sizes`：`4 团 [1,1,1,1]`、`6 团 [1,1,1,1,1,1]`——**让读者一眼看到它们不是团**；
2. 图②的 MCL 曲线改成**「最大团的大小」**（原始 1、t=0.20 起全是 1），或者干脆换成 `有效团数`（size≥2 的团数，全断面都是 0）——**曲线会立刻变成一条平线，教学效果反而强 10 倍**；
3. 断言改一条：现在只有 `MCL_ON_RAW["k"] != K_BASE`，太弱；建议
   ```python
   assert all(max(s["sizes"]) <= 1 for s in MCL_ROWS), \
       "MCL 在任何断面上都不应产出多点团——否则「过度膨胀」的教学点不成立"
   ```
   —— 这条断言**正好能抓到今天这个「看着像成功其实是失败」的读数**。

> 顺带：§3.2 末尾「正确用法是先构造稀疏图（k-NN 或阈值骨架），再跑 MCL。**本讲做到了第一步，把第二步留作练习**」这句话，在「阈值骨架」这个选项上其实**已经试过了并失败了**（t=0.27 给 6 个单点）。建议改成「**阈值骨架不行（数据在下面），必须换 k-NN**」，否则下一位读者会以为跟着做第一步就能得到 3 团。

### 🟡 P3｜脚本内注释与代码不符：「每段≥3 点」 vs `len(a) < 2`

图③标题写的是「（9 点、**每段≥3 点**）」，但生成该图的枚举用的是 `if len(a) < 2 or len(b) < 2: continue`，**即每段≥2 点**（1.2981 那组解是 7+2，两块里有一块只有 2 个点，正好卡在边界上）。图表标题与代码差一档，**答案值本身没错**（≥2 的正确结果就是 1.2981），只是标注错。
