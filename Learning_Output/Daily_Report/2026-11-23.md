## 二、本日主体：Day86 从「跑不动」到「跑得通」

### 2.1 这一讲要讲什么（选题是对的）

Day85 把提前期钉死 1 周、需求逐周独立同分布；Day86 放开两件事：**提前期随机**（L∈{2,3,4}，均值 2.9 周）+ **一季 8 周的两阶段决策**（第 1 阶段：订货计划不随需求实现；第 2 阶段：需求实现后卖多少、缺多少）。要量的量也是标准的：**VSS**（场景树比按均值算好多少）、**EVPI**（知道未来值多少）、**场景树确定性等价 vs 仿真真值**。

选题逻辑站得住：它正好踩在 Day85 §八.1 自己写的「真 (s,S) 随机 DP 没做成 / 提前期固定没建模」两个洞上。

### 2.2 但它进窗口时是**不可运行**的

我按仓库惯例用 `.venv` 直接跑，第 6 行就崩了：

```
AssertionError: The problem is infeasible. (HiGHS Status 8: model_status is Infeasible)
```

逐步剥出来，**同一个函数里有三处独立的符号错误**，互相掩盖：

| # | 位置 | 错法 | 症状 |
|---|---|---|---|
| 1 | 库存结转行 `(E2)` | 写成 `−I_w −A_w +U_w +I_{w+1} = 0`，A、U 全反号 | 等价于「到货越多库存越少」，LP 恒不可行 |
| 2 | 需求平衡行 `(E1)` | 右侧钉死 `= d`、漏掉缺货项 `L` | 变成「不允许缺货」；n=5 侥幸可行，**n≥20 必崩**——所以「跑通了」是假象，只是小场景没踩到 |
| 3 | 我在修 1、2 时引入的 | 把 `L` 塞进 `(E1)` 左侧当松弛量 | LP 立刻选「不订货、全缺货」最优，账面 0 成本 |
| 4 | 目标函数 | 混用「现金口径」（`−c·U`）与「成本口径」（`p/(p+h)`） | 账面 −6.3 万/周、SAA 偏差 −245% |

**为什么这三条对日报重要**：Day85 的踩坑记录里，第 ① 条正是「手写随机 DP 的最优解恒为『永远不下单』」。**隔了一讲，同一个病以另一种形状回来了**——不是随机 DP，是场景树 LP；不是时序写错，是行列符号写反。这不是偶然失手，是**这类模型当前缺少一道「物理自检」闸门**。

### 2.3 顺带查出一个真·业务错误

`sample_demand()` 的实现是「先抽旺季峰值 ∈[0,240]，再乘季节因子」，于是**旺季周需求上限变成 240×1.25 = 300 吨**——直接越过题目自己写死的「全县耕地硬上限 240 吨」。

这正是 Day85 §五.3 在教案里点名的错：「**需求用正态但存在物理上限，分位数会落在界外**」。**教案批评的东西，下一讲的代码里原样犯了。** 改成「按周均值 μ×季节因子采样、再整体 clip 到 [0,240]」后，旺季周需求被正确压回上限。

### 2.4 修完之后的数字（`.venv` 实跑 29.7 s，`-W error` 零告警，断言全过）

| 口径 | 计划（吨/周，8 周） | 场景树口径（元/周） | 仿真真值（元/周） |
|---|---|---|---|
| **EV**（按均值算一个计划） | 90 / 90 / 150×4 / 110.4×2 | 1,953 | **37,410** |
| **SAA n=5** | 71.5 / 71.5 / 119×4 / 88×2 | 69,678 | 56,409 |
| **SAA n=20** | 83×2 / 139×2 / 142×2 / 104×2 | 74,109 | 40,954 |
| **SAA n=100** | 93×2 / 155×2 / 155×2 / 114×2 | 64,924 | **37,299** ← 最好 |
| **SAA n=500** | 99×2 / 166×2 / 168×2 / 124×2 | 73,725 | 40,651 |
| **PI**（事后全知） | 每周各自最优 | — | **4,559** |

- **EVPI = EV − PI = +32,851 元/周（占 EV 的 87.8%）**：知道未来值这么多。
- **VSS = SAA − EV = −111 元/周（−0.30%）**：**几乎为零，且符号为负**。
- ⚠️ **场景树偏差 +23.5% ~ +81.4%（全部为正）**——**与脚本原设计的预期方向相反**（原 print 写的是「确定性等价会报喜、偏低」，实测是**报忧、偏高**）。机理讲得通：场景树里的 `A` 是**非预见性**的第 1 阶段决策，但每个场景在解 LP 时都「知道」自己的需求已经实现，于是场景树把「一份计划对多场景的错配成本」低估了；仿真才会诚实地让你为错配付钱。**所以这一讲真正的教学点应该改成：「场景树不算未来成本，仿真才算。」**
- **LP vs 两段网格双签**：LP 64,924 vs 网格 82,349（**+26.8%**），LP 计划在 8 周上各不相同（93/93/155/155/155/155/114/114），网格只能表达「首批 + 补批」两段——**「不是求解器说了算」这条成立，但方向是网格吃亏，不是 LP 占便宜**。
- **提前期 L 从 2 → 4 周**：最优订货总量 **800 → 800 吨（+0.0%）**。**「提前期翻倍 ⇒ 库存翻倍」是错的**——这条结论保住了，且是本期最干净的一条。
- **计划抖动**：同一 n=100 重抽 8 次，各周到货量区间宽度最大 **23.9 吨**（旺季 4 周最宽）→ **这种计划还不能直接交给司机**。
- **固定费 K 扫描**：K=0/4200/8400/16800 → 周均 46,080 / 48,180 / 50,280 / 54,480，**最优结构始终是「440 + 480 吨 / 2 趟」不动**。
