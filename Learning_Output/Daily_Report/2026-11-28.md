## 三、昨天 §四 那条语义闸门：今天在真实代码里抓到了它的第 3 个案例

昨天把「**任何在循环里丢弃样本的 `continue`，必须打印丢弃率**」从建议升级为「已验证反模式」，理由是它有 2 个案例（Day87 按结果筛样本 / Day88 bootstrap 按身份去重）。

今天的 `healthcheck.py` 给了**第 3 个案例，而且是同一句话的另一面**：

```python
if skeleton:
    info.append(f"{base}/{sub.name} 骨架待补全（跳过证据检查）")
    continue                    # ← 跳过了一整个检查维度，却记 info
```

- **它丢了什么**：4 个 experiment 的证据完整性检查（result/report/review/env 四件套）；
- **丢了之后有痕迹吗**：有，但在 `info` 里 —— 而 `warnings` 只进 `warns` 列表 ⇒ **`status` 永远是 healthy**；
- **后果**：`health` 连续 **N 期**报「healthy、9 runs 全 verified」，而实际上 4 个 run **一个证据都没查过**。

⇒ 闸门 3 的措辞今天应当再改一次：**「跳过」也是丢弃**。任何 `continue` / `skip` / `pass` 分支，
只要它绕过一项检查或一个样本，**都必须在最终判定里留下可见痕迹（warning 而不只是 info）**。
这条已写进 `_TEMPLATE_README.md` 闸门 3 与 4（后者负责「判定逻辑自证」）。

## 四、G-004 实验：一次「把事故造出来」的实验（本期真正的产出）

`weekly-2026-W48-g-004` 是 11-23 自动生成的骨架，11-25 才登记进 `gaps.yaml`（孤儿条目），**今天补全并跑到 verified**。

### 4.1 设计

构造一个**必然退化**的 0-1 背包：6 个项目，(P0,P1)/(P2,P3)/(P4,P5) 三对**同重同价**，容量 30 = 每对取一个的重量和，恰好卡在「每对只能取一个」的边界上。

### 4.2 结果（全部来自 `result.json`）

| 量 | 值 |
|---|---|
| 最优值 | **39** |
| 同价最优解个数 | **4**（mask 7 / 11 / 19 / 35，两两 Hamming 距离 2） |
| 可行解总数 | 36（全空间 64） |
| **单解基准判分放行数** | **1 / 4 ⇒ 漏放率 75%** |
| **集合比对（参照=完整族）** | **4 / 4** |
| **集合比对（参照=只给一个解）** | **1 / 4** ← **与单解基准完全相同** |
| 容差 1e-9 / 1e-6 / 1e-3 | 族大小**恒为 4**（结论不靠 eps） |
| 辅助指标 `weighted_sum` 在族内 | 10.0 → 9.0 → 8.5 → **8.2**（极差 **1.8**）= 平局被 tie-break 伪装成差异 |
| 反例 1：容量 30→37 | 族 4 → **5** |
| 反例 2：破坏全部配对 | 族 → **1** |

### 4.3 这条结论为什么重要

B1 那次误判（S1+S3 与 S1+S2 同价 15682.20 被判成「错」）一直被当作「评审脚本的 bug」。
今天这个实验说明：**它不是个别 bug，而是「单解基准」这个口径的必然结果** —— 只要题有多解，就有 75% 量级的误判率，
而且**换个名字叫「集合比对」也救不了，除非参照集本身是完整族**。

⇒ 这是本库第一次把一条 gap 从「知道有风险」推到「量化了风险」。**它是一个可以写进评审规则的一句话**，不是又一讲教案。

### 4.4 附带修掉的基础设施

| 缺陷 | 影响 | 修法 |
|---|---|---|
| `result_fingerprint` 对整型 key 调 `.lower()` 崩溃 | 含 `mask`/年份等整型键的结果**存不了指纹**（G-004 第一次跑直接 `AttributeError`） | `str(k).lower()` |
| 指纹**无法从落盘 json 反算** | 不能用「反算指纹」证明结果未被手改 | **不修**（做不到），在复核器 R10 里改成「验证这条边界」，如实记录工具能力 |

### 4.5 三条自我踩坑（保留证据，都要进闸门）

1. 🔴 **「破坏配对」只改了一对** → 另外两对仍在撑族，断言 A6 当场 FAIL（n_opt 仍 4）。⇒ **破坏一个退化来源 ≠ 破坏退化。**
2. 🔴 复核器第一版断言「族大小 = 2^对数 = 8」，实测 **4** —— 假说被证伪：对称性只给上界，**容量几何决定真实大小**。
3. ⚠ 复核器 R10（指纹反算）第一版红叉，一度被我当成「result.json 被手改」—— 实际是**工具能力边界**，不是数据问题。**红叉有两种，别默认是数据坏了。**
